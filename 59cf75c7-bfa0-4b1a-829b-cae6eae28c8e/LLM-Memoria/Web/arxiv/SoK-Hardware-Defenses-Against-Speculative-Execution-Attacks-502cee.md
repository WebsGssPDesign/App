# SoK: Hardware Defenses Against Speculative Execution Attacks

## Resumen
Este artículo sistematiza las defensas de hardware contra ataques de ejecución especulativa, identificando seis pasos críticos que permiten estas vulnerabilidades. Se proponen estrategias defensivas diseñadas para bloquear cada paso individualmente y se analizan 20 soluciones existentes junto con sus características para reducir el sobrecarga de rendimiento. El estudio evalúa el alcance de estas defensas y los compromisos entre seguridad y eficiencia en arquitecturas modernas.

## Datos clave
- Seis pasos críticos de ataque: acceso a datos secretos, ejecución no autorizada y filtración mediante canales ocultos.
- 20 defensas de hardware propuestas que preservan la compatibilidad del software.
- Estrategias defensivas que previenen el éxito del ataque al interrumpir sus etapas esenciales.
- Análisis de sobrecarga de rendimiento (performance overhead) y compensaciones seguridad-rendimiento.
