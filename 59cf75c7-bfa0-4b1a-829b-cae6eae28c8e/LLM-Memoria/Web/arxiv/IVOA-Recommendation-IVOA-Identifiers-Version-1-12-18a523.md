# IVOA Recommendation: IVOA Identifiers Version 1.12

## Resumen
Este documento define la versión 1.12 de los identificadores IVOA, estableciendo un estándar para nombres únicos globales de recursos. Describe la sintaxis y el método de creación de estos identificadores, los cuales pueden representarse en dos formatos equivalentes: una forma etiquetada con XML y una forma compatible con URI. El diseño busca fomentar la unicidad global natural mientras maximiza la libertad de los proveedores de recursos para controlar su contenido.

## Datos clave
- **Versión**: 1.12
- **Componentes**: Dos partes separables (XML-tagged form, URI-compliant form)
- **Funcionalidad**: Permite recuperar descripciones únicas de recursos desde un registro IVOA compatible
- **Objetivo**: Maximizar la unicidad global y la libertad del proveedor para definir el contenido
