# Pattern Avoidance for Fibonacci Sequences using $k$-Regular Words

## Resumen
Este artículo demuestra que las recurrencias de Fibonacci k-arias ($a_k$ y $b_k$) cuentan el número de palabras k-regulares sobre un alfabeto de tamaño n que evitan conjuntos específicos de patrones. El trabajo complementa resultados previos sobre permutaciones restringidas de Stirling y extiende la conexión clásica entre estas secuencias y los números de Fibonacci a contextos más generales para $k \geq 1$.

## Datos clave
- Recurrencias: $a_k(n) = a_k(n-1) + k \cdot a_k(n-2)$ y $b_k(n) = k \cdot b_k(n-1) + b_k(n-2)$.
- Patrones evitados para $a_k$: $\{121, 123, 132, 213\}$.
- Patrones evitados para $b_k$ ($k \geq 2$): $\{122, 213\}$.
- Casos especiales: Fibonacci cuando $k=1$, Jacobsthal cuando $k=2$.
- Conjetura: El número de palabras evitando ciertos patrones vinculares es igual a $a_1(n)^2$.
