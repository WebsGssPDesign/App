# Traffic-Aware Configuration of OPC UA PubSub in Industrial Automation Networks

## Resumen
La falta de directrices claras para asignar tipos de tráfico industrial a configuraciones OPC UA PubSub provoca errores que degradan el rendimiento de la red y comprometen los requisitos en tiempo real. Este artículo propone un conjunto de guías basadas en especificaciones temporales y de calidad de servicio para mapear correctamente estos flujos de datos. La evaluación mediante un caso de uso industrial confirma que una configuración consciente del tráfico es esencial para garantizar la interoperabilidad y el rendimiento predecible en los sistemas de Industria 4.0.

## Datos clave
- **Problema identificado**: Mapeo incorrecto de tipos de tráfico a configuraciones PubSub.
- **Consecuencias**: Degradación del rendimiento de red y violación de requisitos de tiempo real.
- **Solución propuesta**: Guías para asignar configuraciones según especificaciones de temporización y QoS (calidad de servicio).
- **Objetivo**: Asegurar comunicación predecible y soporte a tiempos reales en redes industriales.
- **Validación**: Demostrado mediante un caso de uso industrial que analiza el impacto de la configuración errónea en latencia y ancho de banda.
