# Digital Infrastructure in Astrophysics

## Resumen
La astronomía depende críticamente de una infraestructura digital basada en software de código abierto (FOSS), que abarca desde scripts individuales hasta pipelines complejos para telescopios. Sin embargo, existe un desafío financiero significativo: obtener fondos para el mantenimiento y la actualización continua de estas herramientas es mucho más difícil que conseguir financiación para desarrollar nuevas infraestructuras prometedoras científicamente.

## Datos clave
- Infraestructura digital abierta (FOSS)
- Software escrito por pocos desarrolladores
- Mantenimiento comparado con desarrollo nuevo
- Dificultad para asegurar financiamiento de sostenibilidad
- Analogía con infraestructura física (carreteras y puentes)
