# Verification Protocols with Sub-Linear Communication for Polynomial Matrix Operations

## Resumen
El artículo propone nuevos protocolos interactivos para verificar operaciones de matrices sobre el anillo de polinomios univariados $F[x]$. Estos sistemas optimizan el coste comunicativo, reduciendo los datos transmitidos por debajo del tamaño del resultado verificado mediante aleatoriedad y rondas constantes.

## Datos clave
- **Objetivo**: Verificar computaciones en matrices sobre $F[x]$ (anillo de polinomios).
- **Limitación**: Los protocolos estándar para campos no son suficientes debido a las propiedades específicas de los dominios ideales principales.
- **Características**: Protocolos interactivos, aleatorizados y con un número constante de rondas.
- **Ventaja principal**: Comunicación sub-lineal respecto al tamaño del resultado verificado.
- **Herramientas**: Reducciones a protocolos existentes de álgebra lineal y una nueva prueba para verificar si un vector pertenece al espacio fila de una matriz en $F[x]$.
