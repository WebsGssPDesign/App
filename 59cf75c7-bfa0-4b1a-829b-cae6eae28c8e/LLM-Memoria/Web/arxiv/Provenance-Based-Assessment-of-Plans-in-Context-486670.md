# Provenance-Based Assessment of Plans in Context

## Resumen
Este artículo propone un enfoque basado en procedencia para explicar planes automatizados, integrando información de fuentes diversas y agentes variables dentro del proceso de planificación. La metodología extiende el planificador SHOP3 HTN para generar datos de dependencia, transformándolos en representación PROV-O para evaluar dinámicamente la confianza, riesgos y sensibilidad de los planes mediante algoritmos de propagación gráfica.

## Datos clave
- Extensión del planificador **SHOP3 HTN** para generar información de dependencia.
- Transformación a formato estándar **PROV-O**.
- Uso de algoritmos inspirados en **TMS** (Truth Maintenance Systems) y propagación gráfica.
- Métricas evaluadas: pertinencia, sensibilidad, riesgo, soporte asuncional, diversidad y confianza relativa.
