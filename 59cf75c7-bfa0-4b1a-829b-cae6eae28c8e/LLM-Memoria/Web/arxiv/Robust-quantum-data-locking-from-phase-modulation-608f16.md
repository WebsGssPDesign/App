# Robust quantum data locking from phase modulation

## Resumen
Este artículo presenta esquemas de bloqueo cuántico de datos robustos que mitigan la vulnerabilidad ante fugas de información en claves o mensajes. Se demuestra que aumentar proporcionalmente la longitud de la clave compartida permite mantener una seguridad constante incluso si se filtra una fracción de los datos, facilitando la implementación experimental mediante modulación de fase y códigos aleatorios.

## Datos clave
- Fenómeno: Bloqueo cuántico de datos (permite cifrar mensajes arbitrariamente largos con claves cortas).
- Vulnerabilidad original: La fuga de pocos bits de la clave o el mensaje puede comprometer desproporcionadamente la información.
- Solución propuesta: Aumentar la longitud de la clave compartida en proporción a la fugada para mantener seguridad constante.
- Método simplificado: La modulación de fase es suficiente para generar esquemas de bloqueo fuertes, facilitando realizaciones ópticas.
- Aplicación adicional: Uso de palabras de código aleatorias para descubrir códigos útiles en canales cuánticos ruidosos.
