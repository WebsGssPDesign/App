# ProIO: An Event-Based I/O Stream Format for Protobuf Messages

## Resumen
ProIO es un nuevo formato de datos orientado a eventos que utiliza Protocol Buffers para lograr flexibilidad y neutralidad lingüística en el intercambio de mensajes. El documento describe el concepto, sus implementaciones de software y evalúa su rendimiento frente al estándar ROOT I/O en conjuntos de datos de física de altas energías. Se analiza la relación entre el tamaño en disco y el rendimiento de entrada/salida mediante diferentes combinaciones de compresión y codificación.

## Datos clave
- Formato: ProIO (basado en Protocol Buffers).
- Dominio de aplicación: Registro de eventos Monte-Carlo para física de altas energías.
- Comparativa principal: Rendimiento frente a ROOT I/O.
- Técnicas evaluadas: Compresión genérica y codificación de enteros de longitud variable.
