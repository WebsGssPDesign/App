# Interoperability From OpenTelemetry to Kieker: Demonstrated as Export from the Astronomy Shop

## Resumen
Este trabajo describe un método para transformar datos de trazabilidad del estándar OpenTelemetry en el framework Kieker. El objetivo es ampliar las capacidades de análisis de Kieker al incluir lenguajes como C# y JavaScript, que actualmente no soporta nativamente. Se valida el enfoque mediante la visualización de datos de una aplicación demostrativa llamada Astronomy Shop.

## Datos clave
- **Frameworks involucrados**: OpenTelemetry (fuente) y Kieker (destino).
- **Lenguajes extendidos**: C# y JavaScript.
- **Capacidad resultante**: Creación de árboles de llamadas a partir de instrumentaciones OpenTelemetry.
- **Caso de uso**: Aplicación demostrativa "Astronomy Shop".
