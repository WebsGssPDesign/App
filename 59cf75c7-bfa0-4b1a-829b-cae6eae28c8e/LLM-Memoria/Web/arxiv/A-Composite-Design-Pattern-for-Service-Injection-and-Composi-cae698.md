# A Composite Design Pattern for Service Injection and Composition of Web Services for Peer-To-Peer Computing with Service Oriented Architecture

## Resumen
Este artículo propone un Patrón de Diseño de Inyección y Composición de Servicios para redes P2P no estructuradas, basado en arquitecturas orientadas a servicios (SOA). La solución integra patrones Aspect-Oriented, Strategy, Worker Object y Check-List para crear sistemas autoadaptativos que gestionan fallos sin intervención humana.

## Datos clave
- **Patrones combinados**: Aspect-oriented, Strategy, Worker Object, Check-List.
- **Mecanismo de fallo**: Reconfiguración dinámica mediante módulos de código Aspectual (Aspectual Feature Module) inyectados en memoria si el servicio no está disponible.
- **Tecnología**: Implementación en Java utilizando Web Services y SOA.
- **Objetivo principal**: Composición automática de servicios complejos para cumplir solicitudes del cliente sin interrupción del administrador.
