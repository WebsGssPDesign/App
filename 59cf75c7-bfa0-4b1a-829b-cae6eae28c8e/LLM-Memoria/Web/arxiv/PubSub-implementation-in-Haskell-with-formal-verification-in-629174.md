# PubSub implementation in Haskell with formal verification in Coq

## Resumen
Este documento presenta una implementación del patrón de mensajería PubSub en Haskell para entornos de Software como Servicio en la nube, complementada con una verificación formal de su corrección utilizando el lenguaje Coq. El objetivo es demostrar cómo combinar un lenguaje funcional genérico con un sistema de tipos más estricto para garantizar la validez del software.

## Datos clave
- **PubSub**: Patrón de mensajería basado en la nube utilizado para notificaciones en sistemas complejos, permitiendo enviar mensajes a una o múltiples unidades sin instalación local.
- **Haskell**: Lenguaje de programación funcional genérico con tipos, fundamentado en el cálculo lambda y conocido por sus características avanzadas.
- **Coq**: Lenguaje basado en una versión estricta del cálculo lambda con un sistema de tipos superior al de Haskell, diseñado principalmente para la demostración de teoremas y verificación de corrección de software.
