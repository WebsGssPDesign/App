# Lindstrom theorems for fragments of first-order logic

## Resumen
Este artículo establece teoremas de Lindström para varios fragmentos de la lógica de primer orden, abordando un desafío técnico donde las técnicas tradicionales de codificación suelen requerir el poder expresivo completo de dicha lógica. Los autores proponen dos métodos de demostración: una modificación del prueba original y el uso de conceptos modales como bisimulación y desenrollado en árbol.

## Datos clave
- Fragmentos analizados: fragmentos de k variables (k>2), álgebra de relaciones de Tarski, lógica modal graduada y fragmento guardado binario.
- Técnicas de prueba: modificación del teorema original de Lindström y conceptos modales (bisimulación, desenrollado en árbol, profundidad finita).
- Resultado adicional: implicación de teoremas de preservación semántica para estos lenguajes.
