# High-Level ETL for Semantic Data Warehouses -- Full Version

## Resumen
El artículo propone un enfoque de integración por capas y constructos ETL de alto nivel basados en RDF para Data Warehouses semánticos, superando las limitaciones de las herramientas tradicionales que ignoran aspectos semánticos. Mediante la automatización del flujo de datos a través de metadatos a nivel de esquema, se reduce drásticamente la carga manual de mapeo para los desarrolladores. Un prototipo llamado SETLCONSTRUCT demuestra mejoras significativas en productividad y tiempo de desarrollo al integrar datasets complejos como los de negocios daneses y subsidios europeos.

## Datos clave
- **SETLCONSTRUCT**: Prototipo que automatiza flujos ETL creando metadatos a nivel de esquema, eliminando el mapeo manual operativo.
- **SETLAUTO**: Extensión de SETLCONSTRUCT que reduce un 25% adicional los Conceptos Utilizados (NOUC).
- **Eficiencia**: Reducción del 92% en Número de Caracteres Tipados (NOTC) respecto al marco anterior SETLPROG.
- **Tiempo de desarrollo**: Aproximadamente la mitad del tiempo requerido por SETLPROG, reduciéndose un 27% más con SETLAUTO.
- **Escalabilidad**: El sistema mantiene un rendimiento similar al de las herramientas programables tradicionales.
