# Explainable Machine Learning for Public Policy: Use Cases, Gaps, and Research Directions

## Resumen
El artículo critica la falta de enfoque en necesidades reales dentro del aprendizaje automático explicable (XAI), señalando que muchas metodologías se evalúan en tareas simplificadas sin considerar usuarios finales o casos de uso específicos. Se propone un marco para alinear el desarrollo de XAI con los problemas concretos de políticas públicas, como salud y justicia penal, definiendo claramente a los usuarios y objetivos de cada explicación. El trabajo identifica brechas actuales entre la teoría existente y las aplicaciones prácticas, sugiriendo nuevas direcciones de investigación para lograr un impacto social real.

## Datos clave
- Dominios críticos: salud, sistema de justicia penal, educación, empleo.
- Problema principal: Evaluaciones basadas en conjuntos de datos simplificados o usuarios proxy (AMT) que no reflejan la complejidad del mundo real.
- Contribución metodológica: Un enfoque para identificar casos de uso y desarrollar métodos dirigidos a ellos.
- Objetivo final: Desarrollar métodos de XAI que generen impacto práctico en la sociedad mediante políticas públicas.
