# Compound Schema Registry

## Resumen
El documento propone un Sistema de Registro de Esquemas Compuesto que utiliza modelos de lenguaje grandes (LLMs) para facilitar la evolución semántica de esquemas en flujos de datos en tiempo real. Este enfoque aborda las limitaciones de los registros actuales frente a alteraciones sintácticas complejas, como el renombrado de campos o cambios de tipo, mediante un sistema de IA que interpreta el significado de estas modificaciones sin interrumpir los servicios.

## Datos clave
- **GSE**: Generalized Schema Evolution (Evolución Generalizada de Esquemas).
- **LLMs**: Large Language Models (Modelos de Lenguaje Grandes) para interpretar semántica.
- **STL**: Schema Transformation Language (Lenguaje de Transformación de Esquemas), una representación intermedia para generar mapeos.
- **Problema resuelto**: Manejo automático de alteraciones sintácticas complejas que antes requerían intervención manual y causaban interrupciones.
