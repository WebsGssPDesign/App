# Patterns of Multi-Container Composition for Service Orchestration with Docker Compose

## Resumen
El artículo identifica y nombra patrones de composición de contenedores multi-servicio recurrentes en proyectos exitosos que utilizan Docker Compose. A través del análisis cualitativo y cuantitativo de configuraciones reales, se ofrece una guía práctica para diseñar orquestaciones de servicios similares a los patrones de diseño tradicionales de software.

## Datos clave
- Análisis de un conjunto de datos curado de proyectos exitosos que emplean Docker Compose.
- Identificación de patrones repetitivos en la composición de múltiples contenedores de servicio.
- Propósito: proporcionar ejemplos prácticos para la creación de nuevas orquestaciones de servicios.
- Avance en la investigación empírica de ingeniería de software sobre el uso de Docker Compose.
