# Analyzing and Mitigating (with LLMs) the Security Misconfigurations of Helm Charts from Artifact Hub

## Resumen
Este estudio evalúa la seguridad de los diagramas Helm en Artifact Hub comparando herramientas existentes con el uso de modelos de lenguaje grandes (LLMs) para mitigar configuraciones inseguras. La investigación propone una pipeline que detecta errores, sugiere correcciones mediante LLMs y verifica si estas soluciones cumplen las políticas de seguridad originales.

## Datos clave
- **Helm**: Gestor de paquetes para Kubernetes (K8s).
- **Artifact Hub**: Repositorio centralizado analizado en el estudio.
- **Herramientas de análisis**: Checkov y KICS, utilizadas para detectar configuraciones erróneas.
- **Metodología**: Pipeline automatizado seguido de análisis manual para evaluar falsos positivos.
- **Objetivo principal**: Medir la eficacia de los LLMs en la refactorización segura de diagramas Helm.
