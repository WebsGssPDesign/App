# Ordinal Pooling

## Resumen
El artículo presenta el "Ordinal Pooling", una técnica novedosa para redes neuronales convolucionales que reordena los elementos de una región de agrupación y asigna pesos basados en su posición secuencial. A diferencia del average-pooling o max-pooling tradicionales, este método aprende automáticamente un comportamiento híbrido mediante entrenamiento con gradientes, lo que mejora la precisión y acelera el proceso de aprendizaje.

## Datos clave
- **Ordinal Pooling**: Nueva estrategia de agrupación que reordena activaciones y aplica pesos según su orden secuencial.
- **Mezcla híbrida**: Aprende comportamientos intermedios entre average-pooling (suma promedio) y max-pooling (máximo valor).
- **Diferenciabilidad**: Los pesos se ajustan mediante entrenamiento estándar con gradientes.
- **Beneficios principales**: Mayor precisión, velocidad de entrenamiento mejorada y eliminación de la necesidad de elegir manualmente tipos de pooling o funciones de activación.
- **Aplicación ideal**: Arquitecturas ligeras, cuantizadas y aplicaciones embebidas.
