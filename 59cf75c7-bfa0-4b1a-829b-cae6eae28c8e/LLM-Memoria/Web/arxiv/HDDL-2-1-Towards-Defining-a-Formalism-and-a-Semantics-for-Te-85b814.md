# HDDL 2.1: Towards Defining a Formalism and a Semantics for Temporal HTN Planning

## Resumen
El documento propone la extensión de HDDL para crear una versión 2.1 capaz de manejar restricciones numéricas y temporales, superando las limitaciones de la versión anterior frente a aplicaciones del mundo real como la robótica e industria. Esta iniciativa busca definir un formalismo y semántica que permitan modelar problemas de planificación jerárquica (HTN) con ejecución coordinada y concurrente de acciones. El trabajo sirve como base para futuras discusiones sobre la sintaxis necesaria en esta evolución del lenguaje.

## Datos clave
- HDDL: Extensión jerárquica de PDDL para planificación.
- HTN: Formalismo de Red de Tareas Jerárquicas.
- Limitación actual: HDDL no soporta restricciones numéricas ni temporales (presente en PDDL 2.1).
- Objetivo: Integrar expresiones temporales y numéricas para resolver problemas complejos del mundo real.
