# Modified Levenberg-Marquardt Algorithm For Tensor CP Decomposition in Image Compression

## Resumen
Este estudio propone una versión modificada del algoritmo de Levenberg-Marquardt diseñada específicamente para la descomposición tensorial CP (Canonical Polyadic) aplicada a la compresión y reconstrucción de imágenes. El método formula el problema de descomposición como un problema de mínimos cuadrados no lineales, demostrando ser más eficiente en términos computacionales que las técnicas tradicionales al probarse sobre conjuntos de datos aleatorios e imágenes RGB.

## Datos clave
- Algoritmo: Levenberg-Marquardt modificado para descomposición tensorial CP.
- Aplicación principal: Compresión y reconstrucción de imágenes.
- Enfoque matemático: Formulación como problema de mínimos cuadrados no lineales.
- Resultados: Menor carga computacional comparado con el método tradicional LM.
- Datos de prueba: Tensores generados aleatoriamente e imágenes RGB.
