# Design of Robust and Efficient Edge Server Placement and Server Scheduling Policies: Extended Version

## Resumen
El artículo propone nuevas políticas para la ubicación y programación de servidores en redes 5G que gestionan eficazmente la incertidumbre de la carga de trabajo mediante un nuevo métrico llamado "factor de agrupación de recursos". Estas estrategias demuestran una mayor robustez frente a picos inesperados de demanda y reducen significativamente los costos operativos para los proveedores de servicios.

## Datos clave
- **Factor de agrupación de recursos**: Nuevo indicador diseñado para manejar ráfagas imprevistas de carga.
- **Reducción del 25%**: El algoritmo de ubicación requiere un 25% menos de servidores en comparación con el estado del arte para mantener una tasa de rechazo de carga cercana a cero.
- **Ahorro energético del 13%**: La política de programación disminuye el consumo de energía sin afectar notablemente la calidad del servicio.
- **Validación**: Los resultados se verificaron utilizando tanto trazas reales como sintéticas.
