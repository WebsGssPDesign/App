# Comparison between illumination model and hydrodynamic simulation for a Direct Drive laser irradiated target

## Resumen
El estudio compara un modelo de iluminación con simulaciones hidrodinómicas para analizar la no uniformidad en una esfera iradiada por láser mediante la técnica de Direct Drive Polar. Se determinó que el modelo de iluminación reproduce fielmente el comportamiento principal observado en los datos hidrodinámicos, ofreciendo valores compatibles para los parámetros óptimos del sistema.

## Datos clave
- Configuración: Esfera esférica iradiada por haces a 49° y 131° respecto al eje polar.
- Perfiles de intensidad: Super-gaussian circulares y elípticos.
- Método de optimización: Técnica Direct Drive Polar (desplazamiento paramétrico).
- Simulación hidrodinámica: Esfera plástica con pulsos de potencia planos temporales constantes.
- Medición: Seguimiento del frente de la onda de choque entrante para evaluar la evolución temporal de las no uniformidades.
- Conclusión: El modelo de iluminación es una herramienta válida y eficiente para predecir el comportamiento hidrodinámico en este contexto.
