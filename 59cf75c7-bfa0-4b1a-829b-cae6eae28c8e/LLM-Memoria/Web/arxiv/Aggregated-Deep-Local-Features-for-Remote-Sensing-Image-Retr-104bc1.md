# Aggregated Deep Local Features for Remote Sensing Image Retrieval

## Resumen
Este artículo propone un pipeline para la recuperación de imágenes de teledetección que combina características convolucionales locales atentas con el método VLAD para generar descripciones globales. Los experimentos demuestran que este enfoque supera a otros sistemas incluso sin entrenamiento previo y alcanza resultados de estado del arte tras ajustes finos. Además, se presenta un método de expansión de consultas que mejora el rendimiento aproximadamente un 3% utilizando solo las tres imágenes recuperadas inicialmente.

## Datos clave
- **VLAD (Vector of Locally Aggregated Descriptors)**: Método para agregar características locales en una descripción global.
- **Mecanismos de atención**: Se estudian tanto la atención multiplicativa como la aditiva para extraer características locales.
- **Expansión de consultas sin entrenamiento**: Técnica que mejora el sistema un 3% usando solo las tres imágenes top recuperadas.
- **Reducción de dimensionalidad**: Genera descripciones compactas y acelera los tiempos de recuperación hasta en un 50%.
