# Human in the Loop: Interactive Passive Automata Learning via Evidence-Driven State-Merging Algorithms

## Resumen
El artículo presenta una versión interactiva del algoritmo de fusión de estados impulsada por evidencia (EDSM) para aprender autómatas finitos. Esta aproximación permite recuperar modelos generadores de datos incluso cuando las fuentes son ruidosas o incompletas, aprovechando la experiencia humana que suele ser subconsciente. La interacción directa facilita el uso efectivo de este conocimiento experto en los parámetros del sistema.

## Datos clave
- Algoritmo: Evidencia-driven State-Merging (EDSM).
- Objetivo: Reverse engineering del modelo generador de datos frente a fuentes imperfectas.
- Mecánica: Integración de la experiencia humana subconsciente mediante interacción directa con el algoritmo.
- Aplicación: Aprendizaje de variantes de autómatas finitos.
