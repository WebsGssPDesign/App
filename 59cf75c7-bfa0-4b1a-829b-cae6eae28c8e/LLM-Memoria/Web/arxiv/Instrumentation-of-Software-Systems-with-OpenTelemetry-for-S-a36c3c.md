# Instrumentation of Software Systems with OpenTelemetry for Software Visualization

## Resumen
El documento presenta experiencias sobre cómo utilizar OpenTelemetry para instrumentar automáticamente sistemas de software con el fin de facilitar su visualización y comprensión. Se exploran métodos que incluyen el uso directo de los SDKs de OpenTelemetry y la aplicación de agentes específicos como inspectIT Ocelot tanto en aplicaciones como en pruebas unitarias. Los datos recolectados se exportan a una herramienta de trazabilidad en tiempo real llamada ExplorViz para generar visualizaciones útiles.

## Datos clave
- **Herramienta estándar**: OpenTelemetry (para recopilación de datos de monitoreo).
- **Métodos de instrumentación**: SDKs automáticos y agente inspectIT Ocelot.
- **Alcance del agente**: Instrumentación a nivel de aplicación y pruebas unitarias.
- **Visualizador**: ExplorViz (herramienta para trazas en vivo).
