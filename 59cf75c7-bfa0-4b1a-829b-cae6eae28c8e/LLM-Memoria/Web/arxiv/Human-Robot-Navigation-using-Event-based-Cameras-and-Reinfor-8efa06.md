# Human-Robot Navigation using Event-based Cameras and Reinforcement Learning

## Resumen
Este trabajo presenta un controlador de navegación robótica que fusiona cámaras de eventos con aprendizaje por refuerzo para lograr una interacción humana en tiempo real. A diferencia de los sistemas basados en imágenes tradicionales, este enfoque aprovecha la naturaleza asíncrona de las cámaras de eventos para procesar información visual sin latencia ni desenfoque por movimiento. El sistema utiliza un modelo de gradiente de política determinista profundo y una fase inicial de aprendizaje por imitación, logrando resultados prometedores en entornos simulados como el seguimiento de peatones y la evasión de obstáculos.

## Datos clave
- **Tecnología**: Cámaras de eventos (event-based cameras) + sensores de rango.
- **Algoritmo**: Deep Deterministic Policy Gradient (DDPG).
- **Fase inicial**: Aprendizaje por imitación para mejorar la eficiencia de muestras.
- **Ventajas**: Procesamiento asíncrono, flexibilidad temporal, sin latencia ni desenfoque.
- **Aplicaciones demostradas**: Navegación robusta, seguimiento de peatones, evasión de obstáculos.
