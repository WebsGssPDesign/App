# JaCoText: A Pretrained Model for Java Code-Text Generation

## Resumen
El artículo presenta JaCoText, un modelo basado en Transformers diseñado para generar código Java a partir de instrucciones en lenguaje natural. Este enfoque combina las ventajas de los modelos de generación de lenguaje y de código mediante una estrategia de preentrenamiento híbrida que incluye inicialización potente, entrenamiento adicional con datos específicos de Java y experimentación con longitudes escalables.

## Datos clave
- Modelo: JaCoText (basado en Transformers).
- Función principal: Generar código fuente Java desde texto natural.
- Estrategias implementadas: Inicialización con modelos preentrenados potentes, preentrenamiento adicional en dataset de Java y ajuste fino escalando longitudes de entrada/salida.
- Dataset de evaluación: CONCODE.
- Resultado: Logra nuevos resultados state-of-the-art (estado del arte).
