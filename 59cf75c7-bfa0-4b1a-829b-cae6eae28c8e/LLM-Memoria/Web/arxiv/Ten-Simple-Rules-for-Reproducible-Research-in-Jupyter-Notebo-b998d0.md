# Ten Simple Rules for Reproducible Research in Jupyter Notebooks

## Resumen
La reproductibilidad es fundamental en la metodología científica para permitir que otros investigadores construyan sobre hallazgos previos y extiendan pipelines computacionales. Este documento presenta un conjunto de reglas diseñadas específicamente para guiar a los científicos al utilizar sistemas de cuadernos computacionales, como Jupyter Notebooks. Estas herramientas combinan flujos de trabajo detallados con texto narrativo y visualización de resultados, facilitando análisis transparentes, colaborativos y reutilizables cuando se integran con repositorios de software y licencias abiertas.

## Datos clave
- **Objetivo**: Guiar a biólogos y científicos en la configuración y documentación de análisis reproducible.
- **Herramienta principal**: Jupyter Notebooks (cuadernos computacionales).
- **Ventajas de los cuadernos**: Combinan narración, visualización y flujos de trabajo técnicos en un solo lugar.
- **Requisitos adicionales**: Uso de repositorios de software y licencias de código abierto para maximizar la reutilización.
