# NimbusGuard: A Novel Framework for Proactive Kubernetes Autoscaling Using Deep Q-Networks

## Resumen
NimbusGuard es un sistema de escalado automático para Kubernetes que utiliza aprendizaje por refuerzo profundo y modelos LSTM para predecir la demanda de recursos, superando a los métodos reactivos tradicionales. Al anticipar las necesidades del trabajo antes de que ocurran, el marco logra una mayor eficiencia en costos y rendimiento. Las evaluaciones comparativas demuestran su superioridad frente al Horizontal Pod Autoscaler nativo y KEDA.

## Datos clave
- **Framework:** NimbusGuard (sistema abierto basado en Kubernetes).
- **Tecnología central:** Agente de aprendizaje por refuerzo profundo (Deep Q-Networks).
- **Componente predictivo:** Modelo de Memoria a Largo Plazo (LSTM) para predecir patrones de carga.
- **Enfoque:** Escalado proactivo frente al escalado reactivo tradicional.
- **Herramientas comparativas:** Horizontal Pod Autoscaler (HPA) y KEDA.
