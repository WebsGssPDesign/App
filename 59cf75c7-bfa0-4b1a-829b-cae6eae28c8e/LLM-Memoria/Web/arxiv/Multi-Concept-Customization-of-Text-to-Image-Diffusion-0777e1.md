# Multi-Concept Customization of Text-to-Image Diffusion

## Resumen
El artículo presenta Custom Diffusion, un método eficiente para personalizar modelos de generación de imágenes con texto mediante el ajuste rápido de pocos parámetros. Esta técnica permite aprender nuevos conceptos a partir de pocas muestras y combinar múltiples conceptos personalizados en una sola configuración sin perder rendimiento ni eficiencia computacional.

## Datos clave
- **Método**: Custom Diffusion (ajuste eficiente del mecanismo de condicionamiento).
- **Tiempo de entrenamiento**: Aproximadamente 6 minutos para aprender un concepto nuevo.
- **Capacidad**: Generación variada de múltiples conceptos nuevos y composición con conceptos existentes en entornos novedosos.
- **Optimización**: Uso de optimización restringida por forma cerrada para combinar modelos finamente ajustados.
- **Ventaja**: Superioridad o paridad con líneas base concurrentes, manteniendo baja demanda de memoria y cómputo.
