# Structure induction by lossless graph compression

## Resumen
Este trabajo presenta el algoritmo Graphitour, diseñado para automatizar la inducción de estructuras en grandes conjuntos de datos relacionales representados como grafos. La técnica extiende enfoques de inferencia gramatical a grafos mediante compresión sin pérdida y se ilustra con un caso de estructura anidada en moléculas de ADN.

## Datos clave
- Algoritmo: Graphitour para inducción de estructuras por compresión gráfica.
- Aplicación principal: Descubrimiento automático de patrones en datos relacionales (ej. redes genómicas).
- Base teórica: Relación entre la compresión de grafos y el problema de emparejamiento máximo cardinal (no bipartito).
- Tipos de entrada aceptados: Grafos dirigidos, nodos etiquetados y arcos etiquetados.
- Uso resultante: Representación y clasificación de grafos.
