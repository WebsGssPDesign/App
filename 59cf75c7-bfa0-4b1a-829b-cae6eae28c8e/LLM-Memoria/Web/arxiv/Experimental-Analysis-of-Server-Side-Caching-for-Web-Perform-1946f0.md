# Experimental Analysis of Server-Side Caching for Web Performance

## Resumen
Este estudio experimental evalúa el impacto del almacenamiento en memoria (in-memory caching) con tiempo de vida fijo en aplicaciones web a pequeña escala, comparándolo con configuraciones sin caché. Los resultados demuestran una reducción significativa en los tiempos de respuesta para las solicitudes almacenadas, validando la eficacia de técnicas de caché simples.

## Datos clave
- **Configuraciones analizadas**: Aplicación web sin caché vs. aplicación con caché in-memory y TTL fijo.
- **Herramientas**: Marco ligero de servidor web; medición mediante múltiples peticiones HTTP bajo condiciones ambientales idénticas.
- **Resultado principal**: Reducción significativa del tiempo de respuesta en solicitudes servidas desde la caché.
- **Aplicabilidad**: Ideal para entornos educativos y aplicaciones pequeñas donde se prioriza la simplicidad y la reproducibilidad.
