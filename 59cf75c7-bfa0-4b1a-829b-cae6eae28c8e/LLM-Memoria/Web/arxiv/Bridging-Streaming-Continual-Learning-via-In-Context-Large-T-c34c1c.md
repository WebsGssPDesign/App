# Bridging Streaming Continual Learning via In-Context Large Tabular Models

## Resumen
El artículo propone utilizar modelos tabulares grandes con aprendizaje en contexto (LTMs) como puente natural para el Aprendizaje Continuo de Streaming (SCL). Esta aproximación combina la retención a largo plazo del CL con la adaptación rápida al SL mediante la creación de resúmenes compactos, o "sketches", de los flujos de datos. La estrategia central se basa en dos principios: coincidencia de distribución para equilibrar plasticidad y estabilidad, y compresión de distribución para controlar el tamaño de memoria.

## Datos clave
- **LTMs**: Modelos tabulares grandes que permiten aprendizaje en contexto sin olvidar conocimiento previo.
- **SCL**: Aprendizaje Continuo de Streaming; fusiona retención (CL) y adaptación rápida (SL).
- **Sketches**: Resúmenes compactos generados en tiempo real para consumir flujos de datos ilimitados.
- **Principios clave**: Coincidencia de distribución (balance plasticidad/estabilidad) y compresión de distribución (control memoria vía diversificación y recuperación).
- **Estrategia implícita**: Divide-to-conquer para gestionar la tensión entre aprender nuevo contenido y recordar información pasada.
