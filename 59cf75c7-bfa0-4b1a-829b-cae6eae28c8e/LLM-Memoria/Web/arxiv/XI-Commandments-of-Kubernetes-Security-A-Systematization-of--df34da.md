# XI Commandments of Kubernetes Security: A Systematization of Knowledge Related to Kubernetes Security Practices

## Resumen
Este artículo sistematiza el conocimiento sobre prácticas de seguridad en Kubernetes analizando 104 fuentes para mitigar vulnerabilidades en despliegues. El objetivo es proporcionar una guía práctica a los profesionales mediante la identificación de once mandamientos clave que cubren acceso, actualizaciones y políticas de red. A pesar de los beneficios operativos de la plataforma, su uso requiere medidas específicas para prevenir incidentes de seguridad como el ocurrido en Tesla.

## Datos clave
- 104 artefactos analizados cualitativamente
- Implementación de control de acceso basado en roles (RBAC) con principio de menor privilegio
- Aplicación de parches de seguridad y mantenimiento de versiones actualizadas
- Definición de políticas específicas para pods y redes
