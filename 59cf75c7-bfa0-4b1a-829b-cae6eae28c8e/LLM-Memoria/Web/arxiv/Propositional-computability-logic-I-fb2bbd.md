# Propositional computability logic I

## Resumen
Este artículo presenta una demostración de consistencia y completitud para un fragmento básico de la lógica de computabilidad, entendida como una teoría formal de la computabilidad donde los problemas se modelan como juegos entre una máquina y el entorno. El trabajo define operadores lógicos específicos y atómica como predicados elementales dentro de este marco lógico.

## Datos clave
- **Teoría**: Lógica de computabilidad (formal theory of computability).
- **Modelo de problema**: Juegos interactivos jugados por una máquina contra el entorno.
- **Computabilidad**: Existencia de una máquina que siempre gana el juego.
- **Validación**: Una fórmula es válida si representa un esquema de problemas "siempre computables".
- **Fragmento estudiado**: Incluye operadores para operaciones en paralelo y elecciones (choice).
- **Átomos**: Representan predicados elementales estándar.
- **Recursos adicionales**: Se recomienda el artículo fundacional "Introduction to computability logic" (Annals of Pure and Applied Logic 123, 2003) para entender la filosofía subyacente.
