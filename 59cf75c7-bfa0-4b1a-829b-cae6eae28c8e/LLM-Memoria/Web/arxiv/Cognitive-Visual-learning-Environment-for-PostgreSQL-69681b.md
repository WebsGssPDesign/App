# Cognitive Visual-learning Environment for PostgreSQL

## Resumen
Este proyecto aborda la complejidad y falta de accesibilidad que presenta PostgreSQL para usuarios novatos mediante el desarrollo de un entorno visual de aprendizaje cognitivo. La solución propuesta combina un editor visual con componentes arrastrables junto a un editor textual, diseñado tanto como herramienta de generación de consultas como plataforma educativa interactiva.

## Datos clave
- **Problema detectado**: Complejidad del entorno textual persistente y dificultad para comprender relaciones entre tablas y flujos de consultas.
- **Solución técnica**: Entorno visual e interactivo que integra componentes arrastrables (drag-and-drop) y un editor de texto tradicional.
- **Objetivo dual**: Facilitar la generación de consultas SQL y servir como herramienta pedagógica para aprender estándares de bases de datos.
- **Enfoque metodológico**: Análisis de características dominantes de PostgreSQL y restricciones de la comunidad de usuarios antes del desarrollo del sistema.
