# An Event Preserving Velocity Invariant Representation for Event Cameras

## Resumen
Las cámaras de eventos enfrentan desafíos algorítmicos debido a su circuitería asíncrona, que puede causar observaciones perdidas o desenfoque según la velocidad del movimiento. Se propone SCARF (Set of Centre Active Receptive Fields), una representación en tiempo real que mantiene los eventos crudos y es invariante a la velocidad para manejar escenas estáticas y objetos móviles de forma consistente.

## Datos clave
- **Problema:** Las representaciones tradicionales descartan información temporal al convertir eventos en imágenes, perdiendo datos bajo movimiento lento o rápido.
- **Solución:** SCARF (Set of Centre Active Receptive Fields).
- **Ventajas:** Preserva eventos crudos, maneja movimiento rápido y escenas estáticas simultáneamente, y ofrece estado del arte en eficiencia computacional y calidad de representación.
