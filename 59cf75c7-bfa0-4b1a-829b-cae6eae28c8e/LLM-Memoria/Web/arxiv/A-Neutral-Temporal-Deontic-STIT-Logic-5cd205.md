# A Neutral Temporal Deontic STIT Logic

## Resumen
Este trabajo presenta la lógica de STIT temporal y déontica TDS, diseñada para responder una solicitud prolongada sobre la integración temporal en estas lógicas. A diferencia de enfoques anteriores basados en el utilitarismo, TDS es neutral al demostrar su solidez y completitud respecto a marcos relacionales que no emplean funciones utilitarias. Además, se explica cómo transformar estos marcos neutrales en versiones temporales utilitarias sin perder validez y se discuten problemas específicos de las funciones binarias de utilidad.

## Datos clave
- Lógica TDS: lógica multiagente basada en STIT.
- Neutralidad: no requiere comprometerse con teorías utilitarias para ser válida.
- Transformación: marcos neutrales pueden convertirse en marcos temporales utilitarios preservando la validez.
- Problema identificado: dificultades al usar funciones binarias de utilidad en contextos temporales.
