# Dynamic cache reconfiguration based techniques for improving cache energy efficiency

## Resumen
El aumento en la energía de fuga en las memorias caché de último nivel (LLC) requiere nuevas estrategias más allá de los métodos convencionales. Este estudio propone técnicas controladas por software y asistidas por hardware que utilizan la reconfiguración dinámica de la caché para optimizar el consumo energético sin comprometer significativamente el rendimiento. Los autores validan su enfoque mediante simulaciones aceleradas y comparativas, demostrando una mayor eficiencia energética frente a las soluciones actuales en diversos sistemas informáticos.

## Datos clave
- **Problema**: La energía de fuga (leakage energy) se ha convertido en una fuente principal de disipación en las LLCs debido al avance de la tecnología CMOS.
- **Solución propuesta**: Técnicas de reconfiguración dinámica de caché controladas por software y asistidas por hardware.
- **Objetivo**: Configurar la caché para máxima eficiencia energética manteniendo el rendimiento dentro de límites aceptables.
- **Enfoque**: Sistema completo (system-wide) para evitar que la reconfiguración aumente el consumo de otros componentes del procesador.
- **Aplicaciones**: Procesadores embebidos, de escritorio y servidores; sistemas en tiempo real y con QoS.
- **Herramientas desarrolladas**: Componentes de microarquitectura de bajo sobrecarga para perfiles de configuración y un enfoque de muestreo temporal para acelerar simuladores arquitectónicos completos.
