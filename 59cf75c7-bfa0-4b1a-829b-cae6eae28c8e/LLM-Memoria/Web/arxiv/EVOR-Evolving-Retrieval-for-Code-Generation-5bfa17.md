# EVOR: Evolving Retrieval for Code Generation

## Resumen
El artículo presenta EVOR, un nuevo pipeline para la generación de código que mejora los sistemas tradicionales al evolucionar simultáneamente las consultas y utilizar bases de conocimiento diversas en lugar de estáticas. Los resultados experimentales demuestran que este enfoque logra una precisión de ejecución entre dos y cuatro veces superior a métodos existentes como Reflexion o DocPrompting.

## Datos clave
- **Pipeline EVOR**: Utiliza la evolución síncrona de consultas y bases de conocimiento diversas para superar las limitaciones de los repositorios estáticos.
- **EVOR-BENCH**: Conjunto de datos nuevo compilado con cuatro datasets asociados a bibliotecas frecuentemente actualizadas y lenguajes de programación de cola larga (long-tail).
- **Comparativa**: Supera significativamente a métodos como Reflexion y DocPrompting en tareas que requieren conocimiento externo.
- **Disponibilidad**: El modelo, el código fuente y los datos están disponibles públicamente.
