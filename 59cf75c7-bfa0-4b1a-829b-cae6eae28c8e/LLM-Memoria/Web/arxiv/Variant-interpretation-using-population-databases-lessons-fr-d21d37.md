# Variant interpretation using population databases: lessons from gnomAD

## Resumen
Las bases de datos poblacionales son herramientas esenciales para distinguir variantes patógenas del ruido genético benigno y descubrir nuevas relaciones entre genes y enfermedades. El artículo presenta una guía sobre el uso del Genome Aggregation Database (gnomAD), la colección pública más grande de variaciones genéticas armonizadas, mediante su navegador en línea. Se destacan características clave como la frecuencia alélica, niveles de expresión por base, puntuaciones de restricción y co-ocurrencia de variantes para interpretar candidatos en enfermedades raras.

## Datos clave
- **Herramienta principal**: Genome Aggregation Database (gnomAD).
- **Acceso**: Navegador en línea (https://gnomad.broadinstitute.org/).
- **Características analizadas**: Frecuencia alélica, niveles de expresión por base, puntuaciones de restricción y co-ocurrencia de variantes.
- **Aplicación**: Interpretación de variantes candidatas y genes novedosos en enfermedades raras.
