# Edge-Path Bundling: A Less Ambiguous Edge Bundling Approach

## Resumen
El texto presenta una nueva técnica llamada "Edge-Path Bundling" diseñada para agrupar aristas en visualizaciones de redes y reducir el desorden visual. A diferencia de los métodos anteriores que generan ambigüedades, esta técnica minimiza las conexiones falsas al agrupar cada arista a lo largo de un camino más corto ponderado. El enfoque permite ajustar el nivel de agrupamiento mediante distancias euclidianas o métricas combinadas y facilita la emergencia natural de diagramas dirigidos.

## Datos clave
- **Problema resuelto**: Las técnicas existentes crean "confluent drawings" con ambigüedades que no existen en los datos originales.
- **Mecanismo**: Agrupa aristas siguiendo un camino más corto ponderado para limitar la desviación de una línea recta.
- **Parámetros ajustables**: Distancias más cortas, distancias euclidianas y combinaciones de ambas.
- **Beneficio adicional**: Permite que el agrupamiento de aristas dirigidas surja naturalmente del modelo.
- **Entrada requerida**: Un diseño (layout) preexistente.
