# OpenAPI Specification

## Resumen
La Especificación OpenAPI (OAS), anteriormente conocida como Swagger, es un lenguaje estándar para definir interfaces de servicios web de manera legible por máquinas. Este formato permite generar automáticamente documentación, pruebas y código de cliente, facilitando el desarrollo basado en contratos antes de escribir la lógica del negocio.

## Datos clave
- **Origen**: Desarrollado inicialmente por Tony Tam en 2010; renombrado a OAS en enero de 2016 bajo la iniciativa OpenAPI de la Linux Foundation.
- **Versiones principales**: 3.0 (julio 2017), 3.1 (febrero 2021) y 3.2 (septiembre 2025). La versión 3.1 alineó vocabularios de JSON Schema, mientras que la 3.2 añadió etiquetas estructuradas y soporte para flujos de dispositivos OAuth2.
- **Integraciones**: RAML y API Blueprint han adoptado el formato OAS tras unirse a la iniciativa.
- **Práctica clave**: "Contract-first development" (desarrollo basado en contrato), que permite probar servidores simulados antes de implementar la lógica completa.
- **Características**: Agnóstico al lenguaje, declarativo y capaz de describir métodos HTTP arbitrarios y tipos de medios de streaming.
