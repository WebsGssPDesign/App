# React Router

## Resumen
React Router es un framework web full-stack de código abierto diseñado para aplicaciones con React y Vue.js. Originalmente un proyecto separado, Remix v2 se fusionó en la versión 7 como "Framework Mode", aunque Remix v3 (anunciado en 2025) volvió a diferenciarse al no depender de React. La evolución continúa hasta el lanzamiento de React Router v8 en junio de 2026.

## Datos clave
- **Fusión y división**: Remix v2 se integró en React Router v7; Remix v3 reintroduce la separación con un modelo de componentes propio.
- **Independencia**: El equipo, adquirido por Shopify en 2022, mantiene el desarrollo como open-source e independiente.
- **Versión clave**: React Router v8 fue lanzado en junio de 2026.
- **Propósito**: Crear aplicaciones full-stack sin depender de librerías externas (específicamente Remix v3).
