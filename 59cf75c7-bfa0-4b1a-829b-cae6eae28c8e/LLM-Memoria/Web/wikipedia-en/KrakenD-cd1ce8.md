# KrakenD

## Resumen
KrakenD es una pasarela de API de código abierto escrita en Go, diseñada para gestionar tráfico, enrutar y agregar solicitudes en arquitecturas de microservicios. Su configuración flexible permite la transformación de datos sin modificar los servicios backend, operando tanto en entornos cloud como locales. En 2021, el proyecto se trasladó a la Linux Foundation bajo el nombre Lura Project.

## Datos clave
- **Lenguaje:** Go (estático y stateless).
- **Funciones principales:** Routing, agregación, transformación de API y gestión de tráfico.
- **Protocolos soportados:** HTTP, gRPC, WebSocket, RabbitMQ, Kafka, SOAP.
- **Autenticación:** OAuth2, OpenID Connect, JWT, claves de API.
- **Configuración:** JSON, YAML o TOML (aplicaciones dinámicas).
- **Despliegue:** Docker, Kubernetes, entornos mixtos.
- **Ediciones:** Community (open source) y Enterprise (comercial).
- **Adoptantes:** IBM, National Geographic, Oracle, US Navy.
