# Web framework

## Resumen
Un framework web es un software diseñado para facilitar el desarrollo de aplicaciones web automatizando tareas comunes como la gestión de bases de datos y sesiones. La mayoría se basa en el patrón MVC para separar lógica de negocio e interfaz, aunque existen arquitecturas push y pull distintas. Estos herramientas pueden ser de propósito general o específicas, funcionando tanto del lado del servidor como del cliente.

## Datos clave
- **Definición**: Software que automatiza tareas comunes (bases de datos, plantillas, sesiones) para construir aplicaciones web dinámicas o estáticas.
- **Historia**: Surgió con CGI en 1993; evolucionó hacia entornos integrados (PHP, ColdFusion) y luego "full stack" frameworks.
- **Arquitectura MVC**: Separa Modelo (datos), Vista (interfaz) y Controlador (reglas de negocio); permite modularidad y reutilización de código.
- **Tipos de flujo**: Arquitectura *push* (acción basada) vs. arquitectura *pull* (componente basada).
- **Organización en tres capas**: Cliente, Aplicación (lógica) y Base de Datos (RDBMS).
- **Frameworks del lado del cliente**: Backbone.js, AngularJS, React, Vue.js, Svelte (usados en Single-page applications).
- **Limitaciones HTTP**: El protocolo es sin estado; los frameworks gestionan esto mediante actualizaciones completas o parciales de página.
