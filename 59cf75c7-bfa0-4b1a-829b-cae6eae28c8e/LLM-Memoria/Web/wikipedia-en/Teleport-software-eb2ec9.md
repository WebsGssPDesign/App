# Teleport (software)

## Resumen
Teleport es una herramienta de código abierto que centraliza la gestión de identidades y el control de acceso a infraestructuras como servidores, bases de datos y clústeres Kubernetes. Elimina la necesidad de VPNs al ofrecer un único gateway seguro para protocolos SSH, HTTPS y RDP mediante autenticación basada en certificados.

## Datos clave
- **Componentes principales**: `tsh` (cliente de línea de comandos) y `teleport` (demonio del servidor).
- **Modos de operación**: Node (acceso directo), Proxy (proxy consciente de identidad) y Auth Server (autoridad certificadora).
- **Funciones destacadas**: Grabación de sesiones con eBPF, acceso Just-in-Time (JIT) con certificados efímeros y autenticación sin contraseña.
- **Integraciones recientes**: Soporte para servidores MCP y generación automática de resúmenes de sesiones (v18.2).
- **Licencia**: Cambió de Apache 2.0 a AGPLv3 en diciembre de 2023.
