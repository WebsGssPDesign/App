# Git

## Resumen
Git es un sistema de control de versiones distribuido creado originalmente por Linus Torvalds para el desarrollo del kernel de Linux. Se distingue por mantener una copia completa local del repositorio con su historial, priorizando la velocidad y la integridad de los datos frente a sistemas cliente-servidor tradicionales.

## Datos clave
- **Origen:** Desarrollado en abril de 2005 tras la revocación de la licencia gratuita de BitKeeper.
- **Objetivo de rendimiento:** Aplicar parches en menos de tres segundos (logró 6.7 parches por segundo al inicio).
- **Filosofía de diseño:** Soporte para flujos no lineales, ramas ligeras y desarrollo distribuido donde cada usuario tiene una copia completa del historial.
- **Adopción:** Es el sistema más usado hoy en día (casi 95% de los desarrolladores lo usan como principal).
- **Plataformas populares:** GitHub, GitLab, Bitbucket y SourceForge ofrecen servicios para repositorios Git.
- **Protocolos compatibles:** HTTPS, HTTP, FTP, SSH y protocolo nativo de Git.
