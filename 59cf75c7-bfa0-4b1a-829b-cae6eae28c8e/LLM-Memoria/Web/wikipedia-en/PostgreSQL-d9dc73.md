# PostgreSQL

## Resumen
PostgreSQL es un sistema de gestión de bases de datos relacionales gratuito y de código abierto que destaca por su cumplimiento con SQL y sus propiedades ACID. Evoluciona desde el proyecto POSTGRES de la Universidad de California, Berkeley, integrando soporte completo para SQL en 1996 bajo el nombre actual. Su desarrollo es impulsado globalmente por una comunidad abierta que complementa el motor central con herramientas de interfaz y características especializadas.

## Datos clave
- **Propiedades ACID**: Atomicidad, consistencia, aislamiento y durabilidad en las transacciones.
- **Historial**: Derivado del proyecto POSTGRES (1982) y Postgres95; renombrado en 1996.
- **Versión reciente**: PostgreSQL 18 lanzó un subsistema de E/S asíncrono con hasta un 3x de mejora en lecturas.
- **Control de concurrencia**: Utiliza MVCC (Multiversion Concurrency Control) para crear "instantáneas" del base de datos por transacción.
- **Ecosistema**: Incluye contribuciones de terceros para interfaces gráficas, equilibrio de carga y soporte geoespacial.
- **Licencia**: Software libre bajo la PostgreSQL License (MIT).
