# Country code top-level domain

## Resumen
Un dominio de nivel superior en código de país (ccTLD) es una extensión de internet de dos letras asignada a un país o territorio, basada generalmente en los códigos ISO 3166-1. Aunque la delegación técnica recae en IANA, las políticas de registro y gestión son determinadas por las autoridades locales de cada nación. En 2022, se registraron aproximadamente 153 millones de dominios bajo estos ccTLDs, los cuales representan cerca del 40% de toda la industria de nombres de dominio.

## Datos clave
- **Origen:** Las aplicaciones comenzaron en 1985 con .il, .uk y .us.
- **Regulación:** La creación sigue el RFC 1591 y códigos ISO 3166-1 alpha-2; las políticas específicas dependen de cada país.
- **Estadísticas (2022):** ~153 millones de dominios registrados en ccTLDs.
- **Top dominios:** .cn, .tk, .de, .uk, .nl y .ru tienen el mayor volumen de registros.
- **Casos especiales:** El código 'gb' para Reino Unido fue reemplazado por 'uk'; 'eh' (Sáhara Occidental) nunca se asignó; 'su' es obsoleto pero sigue aceptando registros.
