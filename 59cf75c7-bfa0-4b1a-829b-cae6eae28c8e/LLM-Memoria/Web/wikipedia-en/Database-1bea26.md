# Database

## Resumen
Un sistema de bases de datos integra datos organizados, un gestor (DBMS) y aplicaciones para capturar y analizar información. Su evolución histórica abarca desde modelos navegativos hasta los dominantes sistemas relacionales basados en SQL, seguidos por el auge de las soluciones NoSQL no relacionales.

## Datos clave
- **Definición**: Conjunto organizado de datos gestionado por un DBMS (Software de Gestión de Bases de Datos).
- **Modelos principales**: Relacional (filas y columnas), NoSQL (no relacional) y NewSQL (relacional con rendimiento alto).
- **Historia**: Propuesta del modelo relacional en 1970 por Edgar F. Codd; dominio total a partir de los años 90.
- **Funciones DBMS**: Entrada, almacenamiento, recuperación, administración de usuarios, seguridad y control de concurrencia.
- **Almacenamiento**: Archivos locales para bases pequeñas; clusters o nube para grandes volúmenes.
- **Lenguajes**: SQL es el estándar dominante para modelos relacionales.
