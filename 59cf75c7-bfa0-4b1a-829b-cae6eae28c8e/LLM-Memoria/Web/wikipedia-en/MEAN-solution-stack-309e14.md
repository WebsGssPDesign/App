# MEAN (solution stack)

## Resumen
El stack MEAN es una solución de desarrollo web basada en JavaScript que integra MongoDB, Express.js, AngularJS (o alternativas como React/Vue) y Node.js. Su principal ventaja es permitir escribir tanto el lado del servidor como el cliente únicamente con JavaScript, facilitando la integración entre componentes. Aunque a menudo se compara con otras pila como LAMP, MEAN opera a un nivel más alto, enfocándose en aplicaciones web dinámicas sin incluir una capa de sistema operativo.

## Datos clave
- **Componentes**: MongoDB (base de datos NoSQL con BSON), Express.js (marco modular para Node.js), AngularJS/Angular/React/Vue (frontend), Node.js (runtime).
- **Características**: Uso único de JavaScript, soporte para JSON-like documents, capacidad de renderizado en servidor.
- **Variantes**: MERN (reemplaza Angular con React) y MEVN (usa Vue.js).
- **Origen**: El acrónimo fue acuñado por Valeri Karpov en 2013.
- **Infraestructura**: Express puede actuar como servidor web, pero suele combinarse con proxies inversos como NGINX o Apache.
