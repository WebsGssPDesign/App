# TPT (software)

## Resumen
TPT es una metodología sistemática para la prueba automatizada de sistemas embebidos y ciber-físicos que interactúan con el entorno real. A diferencia de las pruebas funcionales tradicionales basadas en guiones, TPT utiliza un enfoque basado en modelos gráficos mediante autómatas híbridos para verificar el comportamiento continuo y temporal del software.

## Datos clave
- **Enfoque**: Pruebas basadas en modelos (model-based testing) vs. scripts tradicionales.
- **Modelado gráfico**: Uso de autómatas finitos y partición temporal para representar fases lógicas de la prueba.
- **Técnicas principales**: Listas de pasos de prueba, definiciones directas de señales (fuerza de tiempo o código C), funciones cliente/servidor.
- **Generación automática**: Creación de casos desde clases de equivalencia, análisis estático de modelos Simulink y transformación de grabaciones de usuarios.
- **Ventaja clave**: Separa similitudes y diferencias entre casos para evitar redundancias y mantener la claridad en sistemas complejos.
