# React (software)

## Resumen
React es una biblioteca de código abierto mantenida por Meta para construir interfaces de usuario basadas en componentes, siendo una de las tecnologías web más utilizadas según encuestas recientes. Su enfoque declarativo y el uso del Virtual DOM permiten optimizar el rendimiento actualizando solo los elementos modificados en lugar de toda la página.

## Datos clave
- **Paradigma**: Declarativo (los desarrolladores diseñan vistas para cada estado).
- **Componentes**: Entidades modulares reutilizables que se renderizan mediante props y state.
- **Hooks**: Funciones introducidas en v16.8 para acceder al estado sin clases; reglas principales son llamarlas solo a nivel superior y dentro de funciones React (ej: `useState`, `useEffect`).
- **Server Components (RSC)**: Componentes que ejecutan lógica exclusivamente en el servidor, asincrónicos pero sin acceso a hooks ni necesidad de hidratación.
- **Virtual DOM**: Estructura en memoria que compara cambios y actualiza eficientemente el DOM real mediante "reconciliación".
- **Routing**: No incluido nativamente; requiere librerías externas como React Router.
