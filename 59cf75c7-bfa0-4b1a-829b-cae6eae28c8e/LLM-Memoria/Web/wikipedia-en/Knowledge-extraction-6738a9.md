# Knowledge extraction

## Resumen
La extracción de conocimiento es el proceso de generar datos legibles por máquinas e interpretables desde fuentes estructuradas y no estructuradas. A diferencia de la extracción de información tradicional, este método busca ir más allá del simple formato estructurado para facilitar la inferencia lógica, reutilizando ontologías existentes o generando nuevas esquemas basados en los datos fuente.

## Datos clave
- **Definición**: Creación de conocimiento desde bases de datos relacionales y fuentes no estructuradas (texto, imágenes).
- **Objetivo**: Formato máquina-interpretable que permita realizar inferencias lógicas.
- **Herramientas mencionadas**: DBpedia Spotlight, Triplify, D2R Server, Virtuoso RDF Views.
- **Proceso de conversión RDB a RDF**: Mapeo 1:1 donde cada fila se convierte en una entidad y columnas en predicados, o mapeos complejos para ontologías.
- **Conceptos técnicos**: Entity linking (enlace de entidades), resolución de identidad, aprendizaje de ontologías, vocabularios formales (FOAF, YAGO).
