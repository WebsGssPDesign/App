# Helm (package manager)

## Resumen
Helm es un gestor de paquetes para Kubernetes que utiliza "charts" basadas en YAML y plantillas Go para generar manifiestos dinámicamente. A lo largo de su historia, evolucionó desde Helm Classic hacia versiones que eliminaron componentes intermedios como Tiller para comunicarse directamente con el API server de Kubernetes.

## Datos clave
- **Formato de paquete**: Charts (YAML).
- **Mecanismo de generación**: Plantillas Go template syntax.
- **Evolución importante**: Helm 3.0.0 eliminó a Tiller; Helm 4.0.0 lanzado en noviembre de 2025.
- **Reemplazo de servicio**: Helm Hub retirado por Artifact Hub (CNCF).
- **Mmadurez CNCF**: Incubating (junio 2018) -> Graduated (mayo 2020).
