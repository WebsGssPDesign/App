# JSX (programming)

## Resumen
JSX es una extensión de sintaxis similar al XML para JavaScript, diseñada inicialmente por Facebook para React y posteriormente adoptada por otros frameworks. Funciona como azúcar sintáctico que debe ser transpilado a llamadas de funciones de JavaScript estándar antes de ejecutarse en los navegadores o servidores.

## Datos clave
- **Transpilación**: Requiere herramientas como Babel para convertir el código JSX a JavaScript legible por máquinas.
- **Extensión TypeScript**: Se utiliza `.tsx` cuando se combina con TypeScript.
- **Conversión de atributos**: React convierte nombres de atributos HTML (con guiones) a camelCase (ej: `data-*` permanece, pero otros cambian).
- **Expresiones JS**: Solo las expresiones (no sentencias) pueden usarse dentro de JSX mediante llaves `{}`.
- **Elementos anidados**: Múltiples elementos deben envolverse en un contenedor único (`<div>`, `<Fragment>` o `<>`).
