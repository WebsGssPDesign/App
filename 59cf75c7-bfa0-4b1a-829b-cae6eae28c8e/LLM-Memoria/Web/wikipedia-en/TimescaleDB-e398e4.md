# TimescaleDB

## Resumen
TimescaleDB es una base de datos de series temporales de código abierto desarrollada por Timescale Inc., que extiende las capacidades de PostgreSQL para manejar datos orientados al tiempo con alto rendimiento. Utiliza hipertablas y particionamiento basado en tiempo para optimizar la ejecución de consultas, superando a soluciones como InfluxDB en ciertos escenarios. El software se distribuye bajo licencia Apache 2.0, mientras que funciones adicionales están disponibles bajo un acuerdo comunitario específico.

## Datos clave
- **Licencia:** Apache 2.0 (código abierto) y Timescale License Agreement (edición comunitaria).
- **Tecnología base:** PostgreSQL extendido con soporte para SQL estándar.
- **Mecanismo de rendimiento:** Hipertablas (hypertables) y particionamiento basado en tiempo.
- **Fundadores:** Ajay Kulkarni (CEO) y Michael J. Freedman (CTO).
- **Caso de uso principal:** Cargas de trabajo del Internet de las Cosas (IoT).
