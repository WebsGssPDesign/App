# Outline of databases

## Resumen
Este texto ofrece una guía temática sobre las bases de datos, definiéndolas como colecciones organizadas de datos digitales que modelan aspectos de la realidad para soportar procesos específicos. Explica las diferencias entre información, datos y datos informáticos, además de clasificar diversas tipologías según su arquitectura, propósito o estructura de almacenamiento.

## Datos clave
- **Definiciones**: Información (secuencia de símbolos), Datos (valores de variables), Datos informáticos (información para computadoras).
- **Tipos por arquitectura**: Centralizada vs. Distribuida, Relacional, Document-oriented, Gráfica (nodos y aristas), Espacial, Temporal, Series temporales.
- **Tipos por función**: Base de datos bibliográfica, de gestión de configuración, de diseño asistido (EDA), endgame tablebase (ajedrez), Food composition database.
- **Características técnicas**: Bases orientadas a eventos (Active), probabilísticas, en tiempo real y móviles.
