# Open Service Mesh

## Resumen
Open Service Mesh (OSM) fue una implementación de código abierto y gratuita desarrollada por Microsoft para gestionar entornos dinámicos de microservicios en Kubernetes. Basado en el lenguaje Go y la proxy Envoy, el proyecto servía como referencia para la especificación SMI antes de ser archivado en mayo de 2023 tras donarse a la CNCF.

## Datos clave

- **Base tecnológica**: Proxy Envoy
