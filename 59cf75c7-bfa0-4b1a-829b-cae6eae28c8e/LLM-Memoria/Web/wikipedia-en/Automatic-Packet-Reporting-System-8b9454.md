# Automatic Packet Reporting System

## Resumen
El Sistema de Reporte Automático de Paquetes (APRS) es un protocolo de comunicación digital en tiempo real basado en radioafilia que transmite datos como coordenadas GPS, telemetría meteorológica y mensajes. Funciona mediante una red de repetidores locales e internet para crear mapas compartidos con información de estaciones y objetos en movimiento.

## Datos clave
- **Origen**: Desarrollado por Bob Bruninga (WB4APR) desde 1982; el nombre proviene de su indicativo.
- **Protocolo**: Usa tramas AX.25 sin conexión ni confirmación, operando en modo difusión unidireccional.
- **Repetidores (Digipeaters)**: Retransmiten paquetes usando tecnología "store and forward" para extender el alcance hasta cientos de kilómetros.
- **Internet (APRS-IS)**: Las puertas de enlace (IGates) ingieren datos al sistema global para acceso universal.
- **Tipos de datos**: Posiciones, objetos estáticos/móviles, mensajes, consultas y reportes meteorológicos.
