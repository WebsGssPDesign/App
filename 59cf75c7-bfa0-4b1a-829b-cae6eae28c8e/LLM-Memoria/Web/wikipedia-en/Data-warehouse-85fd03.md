# Data warehouse

## Resumen
Un almacén de datos (DW) es un repositorio central que integra información histórica y actual desde diversas fuentes operativas para facilitar el análisis empresarial y la inteligencia de negocios. A diferencia de las bases de datos transaccionales optimizadas para operaciones rápidas, los DWs priorizan la consulta analítica mediante esquemas multidimensionales como los de estrellas. Los datos suelen procesarse mediante flujos ETL o ELT antes de almacenarse para garantizar su calidad y utilidad en reportes complejos.

## Datos clave
- **Conceptos**: Almacén de datos (DW), Inteligencia de negocios, OLAP (Procesamiento Analítico Online), OLTP (Procesamiento Transaccional Online).
- **Diferencias clave**: Los sistemas OLTP usan esquemas normalizados para integridad y velocidad en transacciones; los DWs/OLAP usan modelos desnormalizados para agregaciones y análisis históricos.
- **Tipos de repositorios**: Data mart (enfocado a un área específica), Data lake (almacena datos crudos estructurados, semi-estructurados y no estructurados).
- **Procesos**: ETL (Extraer, Transformar, Cargar) y ELT; Limpieza de datos.
- **Operaciones OLAP**: Roll-up (consolidación), Drill-down (profundización), Slicing & dicing (corte y dados).
