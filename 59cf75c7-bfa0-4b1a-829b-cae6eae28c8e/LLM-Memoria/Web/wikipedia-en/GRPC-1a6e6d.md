# GRPC

## Resumen
gRPC es un marco de trabajo de alto rendimiento para llamadas remotas (RPC) desarrollado inicialmente por Google y ahora disponible como software de código abierto. Utiliza HTTP/2 para el transporte, Protocol Buffers para la serialización e incluye características avanzadas como streaming bidireccional y control de flujo. Su arquitectura permite conectar servicios en entornos de microservicios o dispositivos móviles con servidores backend.

## Datos clave
- **Protocolo base:** HTTP/2.
- **Lenguaje de descripción de interfaz (IDL):** Protocol Buffers.
- **Seguridad:** Soporte para TLS y autenticación basada en tokens.
- **Limitaciones:** No puede ejecutarse directamente en navegadores debido al uso de *trailers* de HTTP, requiriendo un proxy.
- **Adopción:** Usado por grandes empresas como Uber, Netflix, Amazon, Spotify y Dropbox.
- **Herramientas de prueba:** Postman, Insomnia, Step CI.
