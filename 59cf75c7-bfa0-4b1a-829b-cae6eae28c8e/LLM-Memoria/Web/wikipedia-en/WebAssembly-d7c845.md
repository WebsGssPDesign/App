# WebAssembly

## Resumen
WebAssembly es un estándar abierto de código binario portátil diseñado para ejecutar aplicaciones de alto rendimiento en navegadores web y entornos no web, actuando como una interfaz entre programas y su entorno anfitrión. Aunque nació con el objetivo de facilitar la ejecución de lenguajes de bajo nivel como C y C++, hoy soporta más de 40 lenguajes de programación distintos mediante diversas herramientas de compilación.

## Datos clave
- **Historial**: Anunciado en 2015, MVP finalizado en marzo de 2017, recomendación W3C el 5 de diciembre de 2019 y premio ACM SIGPLAN en 2021.
- **Especificaciones**: Versión 2.0 (2024) añade tipos v128 y manejo múltiple de valores; versión 3.0 (septiembre 2025) introduce gestión de memoria con recolección de basura (GC), espacios de direcciones múltiples y manejo de excepciones.
- **Adopción**: Soportado por el 99% de navegadores web desde marzo de 2024; implementaciones fuera del navegador incluyen Wasmtime, Wasmer y WebAssembly Micro Runtime.
- **Compilación**: Se usa compilación anticipada (AOT) o en tiempo real (JIT). Herramientas destacadas: Emscripten (C/C++), Clang v8+, rustc para Rust y Pyodide para Python.
