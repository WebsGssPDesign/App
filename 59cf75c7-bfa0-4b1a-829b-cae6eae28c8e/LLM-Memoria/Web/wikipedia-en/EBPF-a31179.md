# EBPF

## Resumen
eBPF es una tecnología que permite ejecutar programas de manera segura y eficiente dentro del contexto privilegiado del kernel del sistema operativo sin modificar su código fuente ni cargar módulos. Utiliza un verificador interno para analizar estáticamente el bytecode y rechazar cualquier programa que pueda causar inestabilidad, ejecutando lo válido mediante interpretación o compilación JIT.

## Datos clave
- **Seguridad**: Verificación estática que rechaza bucles infinitos o accesos inseguros a punteros.
- **Ejecución**: Modelo orientado a eventos con ejecución hasta el final (run-to-completion).
- **Componentes**: Máquinas virtuales, mapas de datos (hash maps, arrays), llamadas en cola (tail calls) y compilación JIT.
- **Ventajas**: Evita tiempos de inactividad al permitir actualizar lógica dinámicamente; reduce el tamaño del código generado mediante funciones encapsuladas.
- **Casos de uso**: Redes (XDP), trazado, seguridad y análisis de rendimiento en Linux y otras plataformas.
