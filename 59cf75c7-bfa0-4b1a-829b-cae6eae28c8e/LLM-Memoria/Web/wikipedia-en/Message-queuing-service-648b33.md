# Message queuing service

## Resumen
Un servicio de cola de mensajes es un middleware orientado a mensajes desplegado en la nube bajo el modelo de software como servicio (SaaS). Su objetivo principal es eliminar los costos operativos y complejidades de mantener infraestructuras de mensajería internas, facilitando la integración entre organizaciones mediante patrones punto a punto o publicación/suscripción.

## Datos clave
- **Patrones de intercambio**: Punto a punto y publicación/suscripción.
- **Protocolos de acceso**: Java Message Service (JMS), AMQP, APIs REST y servicios web.
- **Beneficios principales**: Reducción de costos, mejora del rendimiento, fiabilidad y escalabilidad ilimitada mediante recursos cloud.
- **Ventajas operativas**: Elimina la necesidad de provisionar capacidad extra para picos de demanda y reduce el tiempo inactivo por falta de recursos.
- **Proveedores destacados**: Apache Kafka, IBM MQ, Microsoft Azure Service Bus, Oracle Messaging Cloud Service, Amazon Simple Queue Service (SQS), IronMQ, StormMQ y AnypointMQ.
- **Ejemplos de uso**: Transmisión de eventos médicos en tiempo real, procesamiento de datos de telemetría vehicular, gestión de colas en centros de llamadas y sistemas de trading de seguridad.
