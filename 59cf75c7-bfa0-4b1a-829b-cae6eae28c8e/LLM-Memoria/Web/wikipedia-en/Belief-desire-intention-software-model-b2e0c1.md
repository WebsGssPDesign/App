# Belief–desire–intention software model

## Resumen
El modelo de software Belief–Desire–Intention (BDI) es un marco para programar agentes inteligentes que separa la selección de planes de su ejecución. Inspirado en la teoría de razonamiento práctico, utiliza conceptos mentales como creencias, deseos e intenciones para gestionar la deliberación y la acción. Aunque permite definir agentes racionales lógicamente, no garantiza automáticamente todas las características de los agentes inteligentes, como la privacidad o la comunicación.

## Datos clave
- **Creencias (Beliefs):** Estado informativo del agente sobre el mundo; pueden ser falsas o cambiar.
- **Deseos (Desires):** Objetivos o situaciones que el agente quisiera lograr.
- **Intenciones:** Deseos a los que el agente se ha comprometido y está ejecutando un plan.
- **Planes:** Secuencias de acciones para cumplir intenciones; pueden ser jerárquicos.
- **Eventos:** Desencadenantes externos o internos que actualizan creencias o activan planes.
- **Extensión BOID:** Versión del modelo que incluye obligaciones, normas y compromisos sociales.
- **Lógica formal:** BDICTL (lógica modal temporal) y LORA (para sistemas multi-agente).
- **Aplicación propuesta:** Diseño de vehículos autónomos basados en valores humanos.
