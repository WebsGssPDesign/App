# Docker (software)

## Resumen
Docker es un conjunto de productos que utiliza virtualización a nivel del sistema operativo para entregar software en contenedores ligeros y portables. Su motor central automatiza el despliegue de aplicaciones, permitiendo que funcionen consistentemente en diversos entornos como Linux, Windows o macOS. El proyecto, iniciado originalmente por Solomon Hykes en 2013, ha evolucionado hacia estándares abiertos y ahora incluye planes de pago para empresas tras eliminar la versión gratuita de escritorio.

## Datos clave
- **Conceptos**: Contenedores (paquetes con software, librerías y configuraciones), Docker Engine (núcleo que gestiona los contenedores), Moby (proyecto de investigación abierto).
- **Tecnología**: Usa recursos del kernel Linux (cgroups, namespaces) para aislamiento; en macOS usa una máquina virtual Linux.
- **Cambios recientes**: En 2025 se endureció la seguridad de redes por defecto y se cambió el ritmo de lanzamientos a cada dos semanas. En noviembre 2025, `containerd` reemplazó al almacén de imágenes nativo.
- **Adopción**: Integrado en Windows Server (2014), Windows 10 (2016) y WSL2; usado por grandes empresas como Microsoft, Google e IBM.
