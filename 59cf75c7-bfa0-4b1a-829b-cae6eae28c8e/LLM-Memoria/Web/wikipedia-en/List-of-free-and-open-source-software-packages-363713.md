# List of free and open-source software packages

## Resumen
Este documento enumera un amplio catálogo de software libre y de código abierto (FOSS), abarcando desde modelos de lenguaje grandes y agentes de inteligencia artificial hasta herramientas especializadas en robótica, diseño asistido por computadora y tecnologías de accesibilidad. Aunque existen diferencias filosóficas entre los movimientos de software libre y de código abierto, la lista destaca paquetes que cumplen con ambas definiciones o son bases para productos comerciales.

## Datos clave
- **Inteligencia Artificial:** Auto-GPT, LangChain, DeepSeek Coder, OpenHands y modelos como GPT-OSS, Llama (implícito en contextos generales), Mistral y Qwen.
- **Robótica y Vehículos Autónomos:** ArduPilot, ROS (Robot Operating System), Webots, PX4 autopilot y TurtleBot.
- **Diseño (CAD/EDA):** Blender, FreeCAD, KiCad, OpenSCAD y Fritzing para diseño electrónico y mecánico.
- **Accesibilidad:** NVDA (lector de pantalla para Windows), Orca (para Linux) y ESpeak (síntesis de voz).
- **Visión por Computadora:** OpenCV y Point Cloud Library.
