# Infrastructure as code

## Resumen
Infrastructure as Code (IaC) es un enfoque que gestiona y aprovisiona recursos de centros de datos mediante archivos definibles por máquinas en lugar de configuraciones manuales. Este método permite tratar la infraestructura como software, almacenando sus configuraciones en sistemas de control de versiones para reducir errores humanos y mejorar la consistencia. Se basa en dos enfoques principales: declarativo (define el estado deseado) e imperativo (describe los pasos específicos).

## Datos clave
- **Enfoques**: Declarativo (qué se quiere lograr) vs. Imperativo (cómo hacerlo paso a paso).
- **Métodos de aplicación**: Push (el sistema envía instrucciones al servidor) y Pull (el servidor busca sus propias instrucciones).
- **Herramientas mencionadas**: CFEngine, Puppet, Chef, Microsoft PowerShell DSC, AWS CloudFormation, StackStorm.
- **Beneficios principales**: Reducción de costos, mayor velocidad de ejecución y disminución del riesgo asociado a errores manuales.
- **Relación con DevOps**: Facilita la colaboración entre desarrolladores y operaciones al integrar la configuración en el ciclo de desarrollo.
