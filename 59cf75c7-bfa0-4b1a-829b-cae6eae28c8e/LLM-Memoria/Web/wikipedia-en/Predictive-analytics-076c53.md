# Predictive analytics

## Resumen
El análisis predictivo utiliza técnicas estadísticas y de aprendizaje automático para analizar datos históricos y actuales con el fin de anticipar eventos futuros o desconocidos. Desde 2022, el campo ha evolucionado hacia la "Predictive GenAI", integrando modelos generativos que no solo pronostican resultados sino que también crean intervenciones automatizadas como correos personalizados.

## Datos clave
- **Tecnologías base:** Minería de datos, modelado predictivo y aprendizaje automático (IA).
- **Evolución reciente (2023+):** Fusión con IA generativa para crear contenido e intervenciones automáticas tras el pronóstico.
- **Infraestructura moderna:** Migración a arquitecturas nativas en la nube, Data Lakehouses (Databricks, Snowflake) y bases de datos vectoriales para datos no estructurados.
- **Accesibilidad:** Uso de NLP para consultas naturales sin necesidad de SQL o Python.
- **Técnicas específicas:** Modelos ARIMA y suavizado exponencial para series temporales que predicen valores futuros basándose en patrones históricos.
