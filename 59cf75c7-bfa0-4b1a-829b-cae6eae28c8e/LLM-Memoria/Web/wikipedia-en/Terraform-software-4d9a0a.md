# Terraform (software)

## Resumen
Terraform es una herramienta de HashiCorp para la infraestructura como código que permite definir recursos mediante configuraciones declarativas en HCL o JSON. Utiliza proveedores específicos para gestionar servicios en múltiples nubes públicas y privadas, automatizando acciones CRUD para alcanzar el estado deseado. A partir de 2023, su licencia cambió a BUSL, lo que motivó la creación del fork OpenTofu bajo una licencia de código abierto.

## Datos clave
- **Licencia histórica:** MPL v2.0 (comunidad).
- **Licencia actual (desde agosto 2023):** Business Source License (BUSL), restringiendo el uso comercial competitivo por parte de la edición comunitaria.
- **Respuesta a la licencia:** Creación del fork OpenTofu (antes OpenTF) bajo MPL y patrocinado por The Linux Foundation.
- **Lenguajes de configuración:** HashiCorp Configuration Language (HCL), JSON.
- **Funcionamiento:** Declarativo (define el estado final) vs imperativo; usa módulos para reutilización.
- **Ejemplos de proveedores:** AWS, Azure, Google Cloud, IBM Cloud, DigitalOcean, VMware vSphere.
