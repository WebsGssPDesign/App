# MySQL

## Resumen
MySQL es un sistema de gestión de bases de datos relacionales gratuito y de código abierto que utiliza el lenguaje SQL para organizar, modificar y extraer datos en tablas. Aunque fue creado por MySQL AB, su propiedad cambió tras ser adquirida primero por Sun Microsystems y luego por Oracle Corporation en 2010, lo que llevó a la creación del proyecto MariaDB como una bifurcación.

## Datos clave
- **Licencia**: GNU General Public License (GPL v2) o licencias propietarias.
- **Lenguajes de programación**: Escrito principalmente en C y C++.
- **Plataformas soportadas**: Linux, macOS, Windows, entre muchas otras (AIX, BSD, Solaris).
- **Stack LAMP**: Componente clave junto con Linux, Apache y PHP/Perl/Python.
- **Usos destacados**: WordPress, Drupal, Facebook, Twitter, YouTube.
- **Motor de almacenamiento por defecto (v5.5+)**: InnoDB (soporta transacciones e integridad referencial).
- **Historial**: Primera versión lanzada el 23 de mayo de 1995; Oracle adquirió Sun en enero de 2010.
