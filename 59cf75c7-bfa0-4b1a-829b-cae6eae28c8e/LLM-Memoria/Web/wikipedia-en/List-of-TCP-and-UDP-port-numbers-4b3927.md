# List of TCP and UDP port numbers

## Resumen
Este documento detalla la clasificación oficial de los números de puerto TCP y UDP gestionada por la IANA, distinguiendo entre rangos para servicios del sistema, aplicaciones registradas y uso privado temporal. Aunque existen asignaciones no oficiales, esta lista se centra en los protocolos con mayor adopción práctica.

## Datos clave
- **Puertos conocidos (Well-known):** Rango 0 a 1023; requieren privilegios de superusuario en sistemas Unix-like.
- **Puertos registrados:** Rango 1024 a 49151; asignados por la IANA sin necesidad de privilegios especiales.
- **Puertos dinámicos/privados (Ephemeral):** Rango 49152 a 65535 (aprox. 16,384 puertos); usados para servicios temporales o personalizados.
- **Autoridad:** La IANA mantiene las asignaciones oficiales, aunque el uso real incluye muchas desviaciones no oficiales.
