# OpenShift

## Resumen
OpenShift es una familia de productos de software de contenerización desarrollada por Red Hat, cuya plataforma insignia combina Kubernetes con Linux para ofrecer servicios en la nube híbrida. Aunque su origen data de 2010, la versión 3 adoptó Docker y Kubernetes, mientras que la versión 4 eliminó la dependencia de Docker utilizando CRI-O y Podman. La arquitectura extiende las capacidades estándar de Kubernetes con recursos nativos como ImageStreams y DeploymentConfigs para gestionar el ciclo de vida de las aplicaciones.

## Datos clave
- **Tecnologías:** Kubernetes (orquestación), CRI-O (runtime), Podman, Buildah, Docker (v3).
- **Productos principales:** OpenShift Container Platform (on-premise), OKD (comunidad/upstream), Red Hat OpenShift Online (SaaS), OpenShift Dedicated y ARO (Azure).
- **Recursos únicos:** ImageStreams, Templates, DeploymentConfig, Routes.
- **Herramientas integradas:** Registro de imágenes integrado, OperatorHub, Prometheus, Fluentd, Loki, Istio (Service Mesh).
- **CLI:** `oc` (superset de `kubectl`), comandos como `new-app`, `start-build`.
