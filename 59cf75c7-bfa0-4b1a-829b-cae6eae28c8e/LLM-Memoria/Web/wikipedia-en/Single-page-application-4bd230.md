# Single-page application

## Resumen
Una aplicación de una sola página (SPA) es un sitio web que actualiza dinámicamente el contenido sin recargar la página completa, ofreciendo una experiencia similar a las aplicaciones nativas. A diferencia del método tradicional, estas aplicaciones cargan recursos iniciales y modifican el DOM en respuesta a las acciones del usuario mediante JavaScript.

## Datos clave
- **Mecanismo:** No hay recarga de página; se usa un único carga inicial o carga dinámica de recursos.
- **Frameworks populares:** Angular (v2+), Ember.js, React, Vue.js, Svelte, Meteor.js, Knockout.js, ExtJS.
- **Patrones arquitectónicos:** MVC (Modelo-Vista-Controlador) y MVVM (Modelo-Vista-ViewModel).
- **Características técnicas:** Unión de datos bidireccional, compilación en el navegador, manejo de estado del cliente y generación de vistas sin interacción con el servidor para nuevas páginas.
