# Webpack

## Resumen
Webpack es un herramienta de código abierto que agrupa módulos JavaScript y genera activos estáticos para aplicaciones web. Permite transformar recursos front-end como HTML, CSS e imágenes mediante loaders y funciona desde la línea de comandos o con archivos de configuración personalizados. Incluye un servidor de desarrollo integrado que facilita la carga caliente (HMR) sin recargar la página.

## Datos clave
- **Función principal**: Bundler para JavaScript y activos front-end.
- **Requisito**: Node.js es obligatorio para su uso.
- **Configuración**: Archivo `webpack.config.js` define reglas y plugins.
- **Code splitting**: Uso de `import()` (recomendado) o la sintaxis legacy `require.ensure`.
- **Webpack Dev Server**: Sirve archivos vía HTTP y permite Hot Module Replacement (HMR).
