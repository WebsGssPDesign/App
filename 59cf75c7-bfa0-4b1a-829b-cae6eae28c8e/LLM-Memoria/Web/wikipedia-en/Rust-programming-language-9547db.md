# Rust (programming language)

## Resumen
Rust es un lenguaje de programación generalista diseñado para priorizar el rendimiento, la seguridad de memoria y la concurrencia sin depender de recolectores de basura tradicionales. Desarrollado inicialmente por Graydon Hoare en 2006 con patrocinio posterior de Mozilla, este lenguaje utiliza un sistema único de "comprobador de préstamos" (borrow checker) para evitar errores de tiempo de ejecución a nivel de compilación. Tras una evolución significativa entre sus versiones inestables y la liberación estable 1.0 en mayo de 2015, Rust ha sido adoptado por grandes empresas como Meta y Amazon para proyectos críticos de software del sistema y servicios web.

## Datos clave
- **Conceptos principales**: Seguridad de memoria, concurrencia, tipos algebraicos de datos, inmutabilidad, comprobador de préstamos (borrow checker).
- **Personas clave**: Graydon Hoare (creador), Brendan Eich (Mozilla).
- **Milestones históricos**: Inicio del proyecto en 2006; lanzamiento público Rust 0.1 en enero de 2012; primera versión estable Rust 1.0 el 15 de mayo de 2015.
- **Herramientas y ecosistema**: Cargo (gestor de paquetes), Crates.io (repositorio de librerías), LLVM (compilador subyacente), Servo (motor web en Rust).
- **Cifras relevantes**: Más de 1.400 contribuidores al compilador tras un año de la versión 1.0; más de 5.000 librerías de terceros publicadas en Crates.io para ese momento.
