# Jenkins (software)

## Resumen
Jenkins es un servidor de automatización de código abierto diseñado para facilitar la integración y entrega continuas en el desarrollo de software, ejecutándose en contenedores servlet o como aplicación web independiente. Originado bajo el nombre Hudson tras una disputa con Oracle, actualmente cuenta con miles de repositorios públicos y forma parte de la Continuous Delivery Foundation. La plataforma se extiende mediante plugins que soportan diversos lenguajes, sistemas de control de versiones y herramientas de prueba.

## Datos clave
- **Origen:** Renombrado de "Hudson" a "Jenkins" en 2011 tras conflictos con Oracle; Hudson fue obsoleto desde febrero de 2017.
- **Ejecución:** Funciona en Apache Tomcat o Eclipse Jetty (por defecto).
- **Integración:** Soporta Git, Subversion, Mercurial y otros; ejecuta Maven, Ant, sbt y scripts.
- **Pipeline Plugin:** Versión 2 (abril 2016) lo habilitó por defecto usando Apache Groovy.
- **Plugins clave:** Mailer (notificaciones), SSH agents, Javadoc, Credenciales.
- **Fundación:** Se unió a la Continuous Delivery Foundation en marzo de 2019 y obtuvo estatus graduado en agosto de 2020.
