# Service discovery

## Resumen
El descubrimiento de servicios es el proceso automático para detectar dispositivos y servicios dentro de una red informática, con el objetivo de reducir la configuración manual por parte de los usuarios o administradores. Este mecanismo permite que agentes de software utilicen mutuamente sus servicios mediante un lenguaje común sin intervención continua del usuario.

## Datos clave
- **Definición**: Proceso automático de detección de dispositivos y servicios en una red.
- **Objetivo principal**: Minimizar el esfuerzo de configuración manual.
- **Protocolos destacados**: Bonjour (AirPrint), DNS-SD, DHCP, LLDP, SSDP (UPnP), SLP, WS-Discovery, WPAD.
- **Aplicaciones**: Redes móviles ad hoc, Kubernetes, servicios web, impresión Apple AirPrint y descubrimiento de vecinos en redes locales.
