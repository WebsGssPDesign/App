# Next.js

## Resumen
Next.js es un framework de desarrollo web full-stack y de código abierto creado por Vercel que extiende las capacidades de React permitiendo renderizado en el servidor y estático. Diseñado para solucionar problemas de rendimiento, SEO y seguridad del lado del cliente, ha sido adoptado por grandes empresas como Netflix y Spotify. A lo largo de su evolución, la versión 15 introdujo Turbopack basado en Rust y soporte para React 19, mientras que la versión 16 añadió una API de adaptadores de compilación.

## Datos clave
- **Propietario/Mantenedor:** Vercel (autor original: Guillermo Rauch).
- **Requisitos:** Node.js e inicialización vía npm.
- **Características principales:** Renderizado en el servidor (SSR), renderizado estático, App Router, React Server Components y Middleware.
- **Herramientas de compilación:** SWC (transpilador) y Turbopack (reemplazo de Webpack).
- **Versión actual destacada:** Next.js 16 con Build Adapters API para integración flexible con proveedores de hosting.
- **Usuarios notables:** Walmart, Apple, Nike, Uber, Spotify.
