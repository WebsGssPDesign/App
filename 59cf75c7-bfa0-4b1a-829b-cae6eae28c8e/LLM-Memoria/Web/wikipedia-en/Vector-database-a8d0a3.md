# Vector database

## Resumen
Una base de datos vectorial almacena y recupera representaciones matemáticas (embedding) de datos en un espacio multidimensional para permitir búsquedas semánticas aproximadas, superando las limitaciones de coincidencia exacta de los sistemas tradicionales. Estas herramientas son fundamentales en aplicaciones como la búsqueda multimodal, motores de recomendación y el método RAG para mejorar respuestas de modelos de lenguaje grandes.

## Datos clave
- **Conceptos**: Embeddings (representaciones vectoriales), espacio de alta dimensión, búsqueda aproximada del vecino más cercano (ANN).
- **Técnicas**: HNSW (Hierarchical Navigable Small World), Hashing sensible a la localidad (LSH), cuantización de producto.
- **Aplicación RAG**: Se utiliza para recuperar documentos relevantes basados en el embedding de una consulta y añadirlos al contexto del modelo antes de generar una respuesta.
- **Tipos de datos vectorizables**: Texto, imágenes, audio y otros formatos complejos.
