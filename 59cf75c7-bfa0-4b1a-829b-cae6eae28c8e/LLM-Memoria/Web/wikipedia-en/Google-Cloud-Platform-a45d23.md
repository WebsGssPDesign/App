# Google Cloud Platform

## Resumen
Google Cloud es una suite de servicios de computación en la nube que ofrece infraestructura, plataformas y entornos sin servidor, ejecutándose sobre la misma infraestructura interna utilizada por productos como Google Search. Ofrece más de 100 productos organizados en categorías clave como cómputo, almacenamiento, redes, análisis de datos e inteligencia artificial. Desde abril de 2008 con App Engine, la plataforma ha expandido sus servicios para incluir bases de datos gestionadas, herramientas de big data y APIs de aprendizaje automático.

## Datos clave
- **Servicios principales**: App Engine (PaaS), Compute Engine (IaaS), Google Kubernetes Engine (GKE).
- **Almacenamiento y BD**: Cloud Storage (object storage), Cloud SQL (MySQL/PostgreSQL/SQL Server), Bigtable, Spanner.
- **Big Data**: BigQuery (data warehouse), Dataproc (Hadoop/Spark), Looker Studio.
- **Cloud AI**: AutoML, TPU, Dialogflow Enterprise, APIs de visión y traducción.
- **Redes**: VPC, Cloud Armor (firewall), Cloud CDN, Cloud Load Balancing.
- **Gestión**: Operations suite, Cloud Console, Cloud Shell.
- **Requisito de registro**: Tarjeta de crédito o datos bancarios.
