# LAMP (software bundle)

## Resumen
LAMP es una de las pilas de software más comunes para aplicaciones web, compuesta por cuatro bloques de construcción de código abierto: Linux como sistema operativo, Apache como servidor web, MySQL o MariaDB como base de datos y PHP, Perl o Python como lenguaje de programación. Este modelo permite montar configuraciones completas mediante repositorios de distribución de Linux y ha evolucionado para incluir alternativas modernas en cada componente.

## Datos clave
- **Componentes originales**: Linux (sistema operativo), Apache (servidor web), MySQL/MariaDB (base de datos relacional), Perl/PHP/Python (lenguaje).
- **Distribución dominante**: Debian y Ubuntu comparten el 58,5% del mercado de servidores web.
- **Alternativas a MySQL**: PostgreSQL (relacional ACID) y MongoDB (NoSQL con documentos BSON).
- **Disponibilidad alta**: Se logra mediante balanceadores de carga (ej. LVS) y replicación maestro-esclavo en bases de datos.
- **Historia**: El acrónimo fue acuñado por Michael Kunze en 1998 para demostrar una alternativa a paquetes comerciales costosos.
