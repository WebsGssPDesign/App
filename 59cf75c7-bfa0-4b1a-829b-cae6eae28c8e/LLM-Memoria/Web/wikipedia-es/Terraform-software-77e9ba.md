# Terraform (software)

## Resumen
Terraform es una herramienta de infraestructura como código desarrollada por HashiCorp que permite definir y desplegar recursos en múltiples proveedores de nube mediante lenguajes HCL o JSON. El software sufrió un cambio significativo de licencia en agosto de 2023, pasando de ser de código abierto bajo MPL a una licencia comercial no abierta, lo que provocó la creación de una versión alternativa llamada OpenTofu por parte de la comunidad.

## Datos clave
- **Desarrollador:** HashiCorp.
- **Lenguajes de configuración:** HashiCorp Configuration Language (HCL) y JSON.
- **Proveedores compatibles:** AWS, Google Cloud Platform, Microsoft Azure, IBM Cloud, OpenStack, VMware vSphere, entre otros.
- **Repositorio oficial:** Terraform Module Registry (lanzado en 2017).
- **Cambio de licencia (10 ago. 2023):** De Mozilla Public License 2.0 a Business Source License 1.1 (código disponible, no abierto).
- **Fork comunitario:** OpenTofu (anunciado el 25 ago. 2023), basado en la versión v1.5.5 bajo MPL y alojado por la Linux Foundation tras la falta de respuesta de HashiCorp.
