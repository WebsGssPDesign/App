# Base de datos de vectores

## Resumen
Una base de datos de vectores almacena listas numéricas que representan características de datos complejos, como texto o imágenes, en espacios multidimensionales. Estas herramientas utilizan algoritmos de búsqueda aproximada del vecino más próximo (ANN) para identificar rápidamente elementos semánticamente similares a una consulta específica. Son fundamentales para aplicaciones modernas como motores de recomendación y la recuperación aumentada generativa (RAG).

## Datos clave
- **Vectores**: Listas de números de longitud fija que representan datos en un espacio de dimensiones altas (cientos a decenas de miles).
- **Embeddings**: Vectores de características calculados mediante aprendizaje automático para representar documentos o palabras.
- **Recuperación Aumentada Generativa (RAG)**: Método que usa bases vectoriales para recuperar documentos relevantes y mejorar las respuestas de modelos de lenguaje grandes (LLM).
- **Algoritmos ANN**: Técnicas como HNSW, Locality-sensitive Hashing (LSH), Product Quantization (PQ) e Índice invertido.
- **Aplicaciones**: Búsqueda multimodal, sistemas de recomendación y análisis semántico.
