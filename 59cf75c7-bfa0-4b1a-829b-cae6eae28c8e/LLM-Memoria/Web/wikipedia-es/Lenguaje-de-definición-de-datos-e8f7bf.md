# Lenguaje de definición de datos

## Resumen
El texto explica cómo SQL actúa como un lenguaje de definición de datos (DDL) dentro de los sistemas relacionales, aunque mezcla acciones imperativas con consultas. Detalla las sentencias principales para crear, eliminar y modificar objetos como tablas, índices y procedimientos almacenados.

## Datos clave
- **CREATE**: Crea nuevos objetos (tablas, índices, usuarios); en algunos RDBMS es reversible dentro de una transacción.
- **DROP**: Elimina objetos completos (tablas, vistas) borrando datos e índices asociados; requiere eliminar referencias explícitamente.
- **ALTER TABLE**: Modifica tablas existentes agregando (`ADD`) o eliminando (`DROP COLUMN`) columnas.
- **Comandos adicionales**: `GRANT` y `REVOKE` gestionan permisos de usuarios o roles.
