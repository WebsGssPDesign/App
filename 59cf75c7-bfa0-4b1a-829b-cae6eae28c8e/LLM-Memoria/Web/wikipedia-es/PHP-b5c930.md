# PHP

## Resumen
PHP es un lenguaje de scripting interpretado del lado del servidor, creado en 1994 por Rasmus Lerdorf y ahora mantenido por The PHP Group. Aunque originalmente significaba "Personal Home Page", su significado actual es el inicialismo recursivo Hypertext Preprocessor. Es ampliamente utilizado para desarrollar aplicaciones web dinámicas y está integrado con diversos sistemas operativos y bases de datos.

## Datos clave
- **Estadísticas**: Instalado en más de 20 millones de sitios web, un millón de servidores y presente en el >75% de los sitios que usan programación del lado del servidor.
- **Evolución**: Evolucionó sin especificación formal hasta 2014; ahora cuenta con una especificación oficial.
- **Versatilidad**: Funciona como módulo (Apache), daemon o CGI, y tiene interfaz de línea de comandos (PHP-CLI).
- **Bases de datos**: Compatible con MySQL, PostgreSQL, Oracle, MongoDB, SQLite, entre otros.
- **Ecosistema**: Base de WordPress, Drupal, Joomla; Wikipedia está desarrollada en PHP.
- **Alternativas**: Competencia directa para ASP.NET, JSP/Java y Node.js.
