# Windows NT

## Resumen
Windows NT es una familia de sistemas operativos de Microsoft, lanzada originalmente en 1993 como "Nueva Tecnología", diseñada para ser estable y compatible con redes UNIX. A diferencia de sus predecesores híbridos de 16/32 bits, NT fue la primera versión puramente de 32 bits con arquitectura múltiple y un núcleo modular que separa el modo usuario del modo núcleo. Con el tiempo, la línea evolucionó para abarcar tanto el mercado empresarial como el de consumidores, fusionándose finalmente en sistemas modernos como Windows XP y posteriores.

## Datos clave
- **Lanzamiento inicial**: Julio de 1993 (Windows NT 3.1).
- **Arquitectura**: Primera versión puramente de 32 bits; núcleo híbrido/monolítico estructurado como micronúcleo.
- **Compatibilidad**: Soporta múltiples arquitecturas (IA-32, x64, ARM, PowerPC, Itanium, DEC Alpha).
- **Características principales**: Windows API, Active Directory, NTFS, BitLocker, Hyper-V y Hardware Abstraction Layer (HAL).
- **Ediciones originales**: Workstation y Server (con versiones Advanced Server y Terminal Server en NT 4.0/2000).
- **Historia clave**: Desarrollo conjunto con OS/2 cancelado; fusión de proyectos Neptune y Odyssey en Windows XP (codenombre Whistler) en 2001.
