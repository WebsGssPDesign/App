# Metadatos

## Resumen
Los metadatos son datos estructurados que describen otras informaciones para facilitar su localización, identificación y gestión. Su uso es fundamental en campos como la informática, las bibliotecas y la biología, actuando como índices semánticos entre usuarios y sistemas.

## Datos clave
- Definición: «Datos sobre datos» o información no relevante para el usuario final pero crucial para los sistemas.
- Clasificación principal: Descriptivos (búsqueda), Administrativos (técnicos, de preservación PREMIS, de derechos) y Estructurales (relaciones internas).
- Aplicaciones: Refinamiento de búsquedas en buscadores, puente semántico para la web e IA, compresión de datos eficiente y adaptación de interfaces (ej. lectura táctil).
- Concepto avanzado: Existencia de «metadatos sobre metadatos» para rastrear el origen de información fusionada.
