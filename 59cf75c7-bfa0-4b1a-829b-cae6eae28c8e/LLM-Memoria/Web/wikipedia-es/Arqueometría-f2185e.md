# Arqueometría

## Resumen
La arqueometría es una disciplina científica que aplica métodos físicos y químicos para estudiar vestigios arqueológicos, con el fin de datarlos, caracterizar materiales y determinar su origen. Esta práctica ha evolucionado desde análisis básicos del siglo XVIII hasta técnicas avanzadas como la espectrometría de masas y la teledetección espacial.

## Datos clave
- **Definición**: "La medida de lo antiguo" (del griego *archaios* y *metron*).
- **Objetivos**: Datación, caracterización de materiales, determinación de propiedades físico-químicas y origen geográfico.
- **Técnicas de datación absoluta**: Radiocarbono (C14) para materia orgánica hasta 50.000 años; Dendrocronología para madera con precisión anual; Termoluminiscencia para cerámicas y sedimentos calentados.
- **Herramientas analíticas modernas**: Espectroscopía infrarroja (FTIR), difracción de rayos X (DRX) y microscopía electrónica (SEM-EDS).
- **Enfoque actual**: Interdisciplinar, cuantitativo, uso de modelos estadísticos, quimiometría y métodos no destructivos portátiles como pXRF.
- **Subdisciplinas**: Arqueomagnetismo, Trazalogía, Petrografía, Palinología, Metalografía.
