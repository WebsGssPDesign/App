# Check MK

## Resumen
Checkmk es un software de monitoreo de infraestructuras TI desarrollado en Python y C++ que evolucionó desde una extensión de Nagios para convertirse en un sistema autónomo con su propio núcleo de alto rendimiento. Ofrece tres ediciones, siendo la Raw Edition gratuita bajo GPL y las Enterprise/Managed Services comerciales, cubriendo servidores, nube, contenedores y sensores. Su fortaleza radica en la automatización del descubrimiento de hosts y servicios, así como en un consumo reducido de recursos CPU gracias a su microcore.

## Datos clave
- **Lenguajes:** Python y C++.
- **Ediciones:** Raw Edition (GPLv2), Enterprise Edition (CEE) y Managed Services (CME).
- **Monitoreo:** Basado en estado, métricas (series temporales/HTML5/Grafana) y registros/eventos.
- **Complementos:** Más de 1700 bajo licencia GPLv2; compatibles con Nagios.
- **Automatización:** Descubrimiento automático de hosts/servicios, configuración dinámica para Kubernetes/AWS/Azure, actualizaciones de agentes (solo CEE).
- **Rendimiento:** Microcore en C++ consume menos CPU que Nagios y almacena datos no persistentes en RAM.
- **Plataformas:** Debian, Ubuntu, SLES, RedHat/CentOS, Docker; agentes para 11 sistemas incluyendo Windows.
- **Desarrollador:** tribe29 GmbH (Múnich).
