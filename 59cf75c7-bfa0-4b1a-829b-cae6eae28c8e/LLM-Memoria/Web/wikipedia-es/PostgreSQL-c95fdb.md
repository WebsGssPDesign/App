# PostgreSQL

## Resumen
PostgreSQL es un sistema de gestión de bases de datos relacional orientado a objetos y de código abierto, desarrollado por la comunidad PGDG bajo licencias similares a BSD o MIT. Su origen se remonta al proyecto Ingres de 1982 en la Universidad de Berkeley, evolucionando hacia Postgres y finalmente adoptando el nombre PostgreSQL en 1996 para reflejar su soporte del estándar SQL.

## Datos clave
- **Licencia**: PostgreSQL (similar a BSD/MIT).
- **Gobernanza**: Comunidad PGDG (PostgreSQL Global Development Group), sin empresa central.
- **Origen**: Proyecto Ingres (1982, Berkeley) liderado por Michael Stonebraker.
- **Hitos históricos**: Versión 1 (1989), versión 6.0 formal (enero 1997), lanzamiento de código abierto (agosto 1996).
- **Característica técnica**: Soporte para tipos de datos complejos y relaciones automáticas desde sus inicios.
- **Limitación**: No tiene un gestor centralizado de errores, dificultando el seguimiento de bugs.
- **Comercialización**: Empresas como Great Bridge (2000) y Command Prompt, Inc. (2001) han apoyado su desarrollo y distribución.
