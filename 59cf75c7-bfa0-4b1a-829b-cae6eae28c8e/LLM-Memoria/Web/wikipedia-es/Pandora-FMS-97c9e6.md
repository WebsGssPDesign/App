# Pandora FMS

## Resumen
Pandora FMS es una solución de código abierto diseñada para el monitoreo de grandes entornos, permitiendo gestionar miles de sistemas mediante agentes o sin ellos. El software recopila datos históricos y eventos de diversos recursos, desde la carga del procesador hasta valores financieros, generando alertas automáticas ante anomalías detectadas.

## Datos clave
- **Componentes principales**: Servidor (procesamiento y base de datos), Consola (interfaz web) y Agente (recolección local).
- **Protocolos soportados**: ICMP, TCP, SNMP (v1, 2 y 3), WMI para Windows.
- **Agentes disponibles**: Para GNU/Linux, AIX, Solaris, HP-UX, BSD, Windows (NT4 a 10) y macOS.
- **Módulos**: Remotos (plugins para bases de datos como MySQL/PostgreSQL) y Locales (scripts en bash, Perl, Python).
- **Modelos de licencia**: GPL2 (Open Source) y versión comercial "Enterprise" bajo modelo openCore.
- **Funcionalidades**: Detección de caídas de red, ataques de defacement, monitorización ambiental (temperatura/humedad) e integración con JIRA o Salesforce.
