# Protocol Buffers

## Resumen
Los Protocol Buffers son un formato binario desarrollado por Google para el almacenamiento e intercambio eficiente de datos, diseñado como alternativa más rápida y simple que XML. Inicialmente creado para uso interno entre 2001 y 2008, se liberó al público en 2008 bajo licencias BSD y Apache, siendo fundamental para sistemas RPC como gRPC.

## Datos clave
- **Formato**: Binario (vs. textual XML).
- **Desarrollador**: Google Inc.
- **Licencias**: BSD 3 cláusulas (parcial) / Apache 2.0 (implementación oficial).
- **Lenguajes oficiales**: C#, C++, Go, Objective-C, Java, Python, Ruby.
- **Uso principal**: Almacenar datos estructurados y comunicación cliente-servidor en gRPC.
