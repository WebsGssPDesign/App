# Microsoft SQL Server

## Resumen
Microsoft SQL Server es un sistema de gestión de bases de datos relacional desarrollado por Microsoft que utiliza Transact-SQL (TSQL) para la manipulación y definición de datos. Aunque originalmente exclusivo para Windows, desde 2016 también funciona en GNU/Linux y Docker, ofreciendo modelos de licencia flexibles como "Server + CAL" o por núcleo.

## Datos clave
- **Lenguaje**: Transact-SQL (TSQL) para DML y DDL.
- **Competidores**: Oracle, MariaDB, MySQL, PostgreSQL.
- **Modelos de licencia**: Server + CAL (requiere licencias por usuario/dispositivo) vs Licencia por núcleo (4 núcleos mínimos desde 2019).
- **CAL**: License de acceso de cliente para usuarios o dispositivos.
- **Herramientas**: Management Studio, SQLCMD, osql, PowerShell.
- **Ediciones**: Versión completa y SQL Express Edition (gratuita).
- **Características**: Soporte transaccional, procedimientos almacenados, modo cliente-servidor.
