# Webpack

## Resumen
Webpack es una herramienta de código abierto que transforma módulos JavaScript y otros activos front-end en archivos estáticos optimizados para aplicaciones web. Funciona generando gráficos de dependencias y permite el desarrollo modular, configurándose mediante un archivo `webpack.config.js` o directamente desde la línea de comandos. Incluye un servidor de desarrollo integrado (dev server) que facilita la carga dinámica de módulos durante el proceso de creación.

## Datos clave
- **Requisito:** Node.js es obligatorio para su uso.
- **Configuración principal:** Archivo `webpack.config.js` donde se definen reglas, plugins y tareas personalizadas.
- **Funcionalidad:** Transforma JavaScript, HTML, CSS e imágenes mediante *loaders* específicos.
- **Servidor:** Proporciona un servidor HTTP integrado para servir archivos y permitir el reemplazo de módulos en tiempo real.
- **Estándar:** Utiliza la propuesta de "dynamic import" (importación dinámica) alineada con el Comité Técnico 39 de ECMAScript.
