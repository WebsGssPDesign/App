# Astro (framework)

## Resumen
Astro es un framework de código abierto diseñado para crear sitios web orientados al contenido priorizando la velocidad y el rendimiento mediante su arquitectura "Islas". A diferencia de otros frameworks, no inyecta JavaScript por defecto, manteniendo la mayoría del sitio estático e hidratando solo los componentes interactivos.

## Datos clave
- **Astro Islands**: Componentes interactivos incrustados en HTML estático que se hidratan de forma parcial tras la carga inicial.
- **Sin JavaScript por defecto**: El framework no genera código JS innecesario para evitar sobrecarga en el navegador del usuario.
- **Renderizado híbrido**: Soporta Generación Estática (SSG) y Renderizado en Servidor (SSR), activable vía `astro.config.mjs`.
- **Agnóstico a UI frameworks**: Permite integrar múltiples librerías como React, Vue o Svelte simultáneamente.
- **Integraciones oficiales**: Incluye herramientas para SEO (`astro-seo`), iconos (`astro-icon`) y traducción (`astro-i18n`).
