# Google Cloud

## Resumen
Google Cloud es una plataforma integral que centraliza las aplicaciones y servicios de desarrollo web de Google, ofreciendo soluciones basadas en la nube para almacenamiento, cómputo y análisis de datos. Esta infraestructura permite a los usuarios realizar tareas complejas mediante acceso virtual sin necesidad de hardware local, destacando por su rapidez y escalabilidad.

## Datos clave
- **Servicios principales**: App Engine (PaaS), Compute Engine (IaaS), Google Kubernetes Engine (GKE).
- **Almacenamiento**: Cloud Storage (objetos), Persistent Disk, Filestore.
- **Bases de datos**: Cloud SQL (MySQL, PostgreSQL), Bigtable (NoSQL), Spanner (relacional escalable).
- **Big Data y AI**: BigQuery (análisis empresarial), Dataproc (Hadoop/Spark), AutoML, TPU.
- **Redes**: VPC, Cloud Load Balancing, Cloud Armor (protección DDoS).
