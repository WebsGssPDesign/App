# Realidad virtual

## Resumen
La realidad virtual (RV) es una experiencia simulada mediante cascos y sensores que sumerge al usuario en un entorno tridimensional artificial. Este concepto, popularizado a finales de los 80, busca crear una ilusión perceptual de "estar allí" o telepresencia. Las aplicaciones abarcan desde entretenimiento hasta formación médica y reuniones empresariales.

## Datos clave
- **Definición**: Uso de modelado y simulación por computadora para interactuar con un entorno sensorial 3D artificial.
- **Conceptos**: Presencia (ilusión de "estar allí"), Inmersión (capacidad del sistema), Telepresencia.
- **Tipos de sistemas**: No inmersivos (basados en escritorio, ej. videojuegos), Semi-inmersivos (ej. CAVE con pantallas circundantes y sonido 3D).
- **Componentes**: Entorno del usuario, entorno virtual e interfaz (traductor entre ambos).
- **Dispositivos**: Casco de RV (HMD), sensores de movimiento, auriculares, guantes de datos, joysticks.
