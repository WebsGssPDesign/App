# Drools

## Resumen
Drools es un sistema de gestión de reglas de negocio (BRMS) de código abierto que utiliza un motor basado en el algoritmo Rete y soporta tanto encadenamiento progresivo como regresivo. El proyecto evolucionó desde su inicio en 2001 hasta convertirse en una solución empresarial integrada dentro del ecosistema JBoss, ofreciendo herramientas para la creación, gestión y ejecución de políticas organizacionales.

## Datos clave
- **Algoritmo**: Rete (implementación avanzada).
- **Lenguaje**: Drools Rule Language (DRL) con dialectos MVEL y Java.
- **Componentes principales**:
  - *Drools Expert*: Motor de inferencia para razonamiento.
  - *Guvnor*: Repositorio centralizado y gestor de bases de conocimiento con interfaz web.
  - *Drools Flow* (jBPM): Para flujos de trabajo y procesos de negocio.
  - *Drools Fusion*: Procesamiento temporal de eventos complejos.
  - *OptaPlanner*: Optimización de planificación automática (problemas NP-hard).
- **Licencia**: Apache.
- **Estándares**: JSR-94, JCR (JackRabbit), JAAS.
