# ReactOS

## Resumen
ReactOS es un sistema operativo libre para PC x86/x64 en desarrollo desde 1996, diseñado para ser compatible binariamente con Windows Server 2003 y posteriores. Actualmente se encuentra en fase alfa, permitiendo el funcionamiento de varias aplicaciones de Windows, aunque su uso está restringido a pruebas y evaluación por parte de desarrolladores.

## Datos clave
- **Estado actual:** Software alfa (octubre 2020).
- **Compatibilidad:** Binaria con programas y controladores de Windows Server 2003+.
- **Lenguajes principales:** C (núcleo) y C++ (Explorador de archivos).
- **Relación externa:** Colabora parcialmente con el proyecto Wine.
- **Historia:** Surgió en 1998 como reacción al monopolio de Microsoft, reemplazando al proyecto FreeWin95.
- **Controversia legal:** Incidente en 2006 sobre posible código derivado de Windows; se implementó auditoría interna y políticas estrictas de "sala limpia" de ingeniería inversa para evitar litigios.
