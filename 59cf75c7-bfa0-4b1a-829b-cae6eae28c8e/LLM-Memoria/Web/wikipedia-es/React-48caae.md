# React

## Resumen
React es una biblioteca JavaScript de código abierto mantenida por Facebook y la comunidad, diseñada para construir interfaces de usuario eficientes mediante un enfoque declarativo. Utiliza un Virtual DOM para optimizar las actualizaciones en el navegador y permite separar claramente la lógica de la vista del resto de la aplicación.

## Datos clave
- **Propósito:** Creación de interfaces de usuario (Vista) para aplicaciones de una sola página (SPA).
- **Componentes:** Unidades reutilizables que reciben datos inmutables llamados *props* y gestionan su propio estado (*state*).
- **Virtual DOM:** Representación interna que compara cambios entre la versión nueva y la almacenada para actualizar eficientemente el DOM real.
- **React Fiber:** Nuevo algoritmo de renderizado interno (desde 2017) que divide tareas en segmentos para mejorar el rendimiento en animaciones complejas.
- **Hooks:** Introducidos en React 16.8, son funciones que permiten usar estado y otras características avanzadas en componentes funcionales.
- **Ecosistema:** Incluye React Native para desarrollo móvil (iOS/Android) y herramientas como React Developer Tools.
