# argoproj/argo-cd

## Resumen
Argo CD es una herramienta de entrega continua declarativa diseñada específicamente para orquestar aplicaciones en entornos de Kubernetes. Se basa en los principios GitOps, donde la configuración y el estado deseado de las aplicaciones se almacenan como código en repositorios Git, automatizando así el ciclo de vida del despliegue.

## Datos clave
- **Conceptos principales**: GitOps, entrega continua declarativa, control de versiones para configuraciones.
- **Objetivos**: Automatizar, auditar y facilitar la gestión del ciclo de vida de las aplicaciones.
- **Recursos oficiales**: Documentación completa en ReadTheDocs, demo en vivo (cd.apps.argoproj.io) y lista oficial de usuarios.
- **Comunidad**: Canales de soporte incluyen GitHub Discussions, Slack (#argo-cd), reuniones de contribuyentes cada jueves y reuniones de usuarios el primer miércoles del mes.
