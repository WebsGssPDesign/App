# tchiotludo/akhq

## Resumen
AKHQ es una interfaz gráfica de usuario diseñada para gestionar Apache Kafka, permitiendo administrar temas, grupos de consumidores y registros de esquemas. La herramienta facilita la visualización y el control del ecosistema de Kafka a través de un panel web intuitivo. Cuenta con amplia adopción en diversas empresas que utilizan infraestructuras de mensajería distribuida.

## Datos clave
- **Funcionalidades principales**: Gestión de temas, datos de temas, grupos de consumidores, Schema Registry, Connect y componentes adicionales de Kafka.
- **Nombre anterior**: Conocida previamente como KafkaHQ.
- **Licencia**: Apache 2.0.
- **Desarrollador**: tchiotludo (ahora parte del ecosistema Kestra).
- **Usuarios destacados**: Archer Aviation, Klarna, BMW Group, Decathlon y Best Buy.
