# jeffwidman/sqlalchemy-postgresql-materialized-views

## Resumen
Este repositorio ofrece una receta de SQLAlchemy diseñada para gestionar vistas materializadas en PostgreSQL. La solución automatiza operaciones esenciales como la creación, eliminación, indexación y actualización (incluyendo refrescos concurrentes en segundo plano).

## Datos clave
- **Gestión completa**: Crear, borrar, crear índices y actualizar vistas.
- **Refrescos avanzados**: Soporte para actualizaciones concurrentes de fondo sin bloquear operaciones.
- **Recurso adicional**: Articulo de blog con detalles sobre la implementación.
