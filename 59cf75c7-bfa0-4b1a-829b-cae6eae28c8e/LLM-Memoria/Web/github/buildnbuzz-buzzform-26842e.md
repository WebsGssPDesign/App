# buildnbuzz/buzzform

## Resumen
BuzzForm es una librería de formularios impulsada por esquemas para React, diseñada para integrarse fácilmente con Next.js y shadcn/ui. Su arquitectura separa la lógica del estado (basada en TanStack Form) de los componentes visuales, permitiendo definir campos una vez con TypeScript seguro y obtener validación automática. Es ideal para crear dashboards y aplicaciones SaaS complejas sin boilerplate excesivo.

## Datos clave
- **Tecnologías base:** React 18/19, Next.js 16, TanStack Form.
- **Paquetes principales:** `@buildnbuzz/form-core` (lógica agnóstica), `@buildnbuzz/form-react` (adaptador).
- **Campo obsoleto:** `@buildnbuzz/buzzform` está marcado como DEPRECATED; migrar a los paquetes anteriores.
- **Instalación rápida (shadcn/ui):** `npx shadcn@latest add @buzzform/all`.
- **Tipos de campo:** Text, Number, Select, Date, Checkbox, Switch, Radio, Textarea, Tags, Array y más.
- **Características principales:** Inferencia de tipos automática, lógica condicional declarativa (sin callbacks) y validación derivada del esquema.
