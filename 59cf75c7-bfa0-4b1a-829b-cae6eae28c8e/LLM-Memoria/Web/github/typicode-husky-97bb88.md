# typicode/husky

## Resumen
Husky es una herramienta moderna y ligera para gestionar ganchos nativos de Git, diseñada para mejorar los flujos de trabajo de desarrollo al ejecutar scripts antes o después de las operaciones. Destaca por su rendimiento extremadamente rápido y su capacidad para soportar todos los ganchos del lado del cliente en múltiples sistemas operativos.

## Datos clave
- **Tamaño:** Solo 2 kB (comprimido) sin dependencias externas.
- **Rendimiento:** Ejecución en aproximadamente 1 ms.
- **Funcionalidad:** Soporta las 13 ganchos del lado del cliente de Git, incluyendo configuraciones específicas por rama y uso de POSIX shell para casos avanzados.
- **Compatibilidad:** Funciona en macOS, Linux y Windows, así como con gestores de versiones de Node y repositorios monolíticos o anidados.
- **Integración:** Se alinea con las mejores prácticas de npm mediante el script `prepare`.
