# sparckles/Robyn

## Resumen
Robyn es un framework web para Python de alto rendimiento que utiliza un motor escrito en Rust para garantizar velocidad y eficiencia. Destaca por su capacidad de manejar funciones síncronas y asíncronas, ofreciendo características avanzadas como WebSockets, autenticación y generación automática de documentación OpenAPI.

## Datos clave
- **Instalación**: `pip install robyn` o `conda install -c conda-forge robyn`.
- **Versión mínima de Python**: 3.10 (recomendado la última para mejor rendimiento).
- **Comandos principales**: `python3 app.py`, `--dev` (modo desarrollo), `--open-browser`.
- **Características destacadas**: Runtime multihilo, soporte WebSockets, inyección de dependencias, hot reloading y soporte experimental para io-uring.
- **Nuevas capacidades**: Soporte nativo para agentes de IA y protocolo MCP (Model Context Protocol).
