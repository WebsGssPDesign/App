# zszszszsz/.config

## Resumen
Este archivo es una configuración automática generada para el sistema de enrutadores OpenWrt, diseñada específicamente para hardware basado en la arquitectura AR71xx. El documento define los módulos de compilación y enumera exhaustivamente las variantes de dispositivos compatibles que pueden ser construidos a partir de esta base de código.

## Datos clave
- **Sistema operativo**: OpenWrt (versión con soporte de módulos).
- **Arquitectura objetivo configurada**: `CONFIG_TARGET_ar71xx=y`.
- **Subtarea seleccionada**: `CONFIG_TARGET_ar71xx_generic=y` (versión genérica estándar).
- **Dispositivos excluidos**: Se desactivan todas las otras arquitecturas (Sunxi, APM821xx, BCM27xx, etc.) y subvariantes específicas de AR71xx como NAND o Mikrotik.
- **Lista de dispositivos compatibles**: Incluye modelos como Antminer S1/S3, Antrouter R1, Alfa AP series, Buffalo WPJ series, D-link DIR/DHP series, y varios modelos Netgear (WZR, WPE) y TP-Link (Archer/TL).
