# supabase/supabase

## Resumen
Supabase es una plataforma de desarrollo basada en PostgreSQL que replica la experiencia del usuario de Firebase utilizando herramientas de código abierto. Proporciona servicios integrados como bases de datos alojadas, autenticación, APIs generadas automáticamente y almacenamiento de archivos sin necesidad de instalaciones complejas.

## Datos clave
- **Base de datos:** PostgreSQL con soporte para replicación y consultas avanzadas.
- **Servicios principales:** Autenticación (GoTrue), APIs REST/GraphQL, suscripciones en tiempo real, funciones de base de datos y edge functions.
- **Almacenamiento:** Gestión de archivos vía API RESTful compatible con S3.
- **Arquitectura modular:** Integra herramientas como PostgREST, Realtime, Storage-api y Envoy Proxy.
- **Implementación:** Disponible como plataforma alojada o para autoalojar localmente/self-hosting.
