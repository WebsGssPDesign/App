# cilium/cilium

## Resumen
Cilium es una solución integral de red, observabilidad y seguridad para entornos Kubernetes que utiliza eBPF como plano de datos. Permite crear redes planas a nivel 3, reemplaza funcionalidades de kube-proxy mediante balanceo de carga distribuido y ofrece visibilidad profunda sobre el tráfico L7.

## Datos clave
- **Tecnología base**: eBPF para inserción dinámica de código en el kernel Linux (redes, sockets, tracepoints).
- **Funcionalidades principales**: Balanceo de carga distribuido, políticas de red basadas en identidad (L3-L7), gateways integrados y gestión de banda ancha.
- **Arquitecturas soportadas**: AMD64 y AArch64.
- **Versiones estables activas**: v1.20, v1.19, v1.18 (con fechas de actualización 2026-10-15).
- **Seguridad**: Inclusion de Software Bill of Materials (SBOM) en formato SPDX desde la versión 1.13.0.
