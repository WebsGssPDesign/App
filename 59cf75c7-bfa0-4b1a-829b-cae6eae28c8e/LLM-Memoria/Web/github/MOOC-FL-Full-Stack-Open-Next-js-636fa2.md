# MOOC-FL/Full-Stack-Open-Next.js

## Resumen
Este curso enseña a desarrollar aplicaciones full stack utilizando Next.js y React Server Components. Se cubren temas esenciales como el App Router, componentes de servidor versus cliente, gestión de datos con Drizzle ORM y autenticación segura con NextAuth para entornos de producción.

## Datos clave
- **Tecnologías principales**: Next.js, React Server Components, TypeScript.
- **Gestión de datos**: Drizzle ORM, PostgreSQL (Vercel Postgres), migraciones, consultas relacionales.
- **Autenticación y seguridad**: NextAuth (JWT sessions), protección de rutas y acciones, validación con `useActionState`.
- **Conceptos clave**: App Router, layouts, Server Actions, caching/revalidation, streaming con Suspense.
- **Herramientas adicionales**: Vercel para despliegue, Tailwind CSS para estilos, logging y troubleshooting.
