# kubesphere/kubesphere

## Resumen
KubeSphere es un sistema operativo distribuido para la gestión de aplicaciones nativas en la nube, que utiliza Kubernetes como núcleo. Ofrece una arquitectura modular y multiinquilino con herramientas integradas para DevOps, observabilidad y gestión de clústeres múltiples. Su interfaz web facilita el despliegue rápido y la administración centralizada en entornos híbridos, multicloud o edge computing.

## Datos clave
- **Conceptos**: Sistema operativo distribuido, plataforma multiinquilino, arquitectura basada en plugins.
- **Funcionalidades**: Gestión de clústeres Kubernetes (multicloud/edge), DevOps con Jenkins y Argo CD, Service Mesh (Istio), App Store para Helm.
- **Integraciones**: KubeEdge para computación edge, soporte para instalación air-gapped.
- **Recursos**: Demo ambiente gratuito en kubesphere.cloud, instalación en 5 segundos.
