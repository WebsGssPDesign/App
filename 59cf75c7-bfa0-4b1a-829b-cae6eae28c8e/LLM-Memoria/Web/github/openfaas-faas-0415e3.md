# openfaas/faas

## Resumen
OpenFaaS es una plataforma para desplegar funciones serverless y microservicios en Kubernetes de forma sencilla, permitiendo escribir código en cualquier lenguaje sin boilerplate repetitivo. El sistema facilita el escalado automático hasta cero y ofrece tanto una edición comunitaria gratuita como versiones comerciales con soporte.

## Datos clave
- **Lenguajes soportados:** Node.js (`node20`), Python 3 (`python3-http`), Golang, entre otros mediante plantillas o Dockerfiles.
- **Comando principal:** `faas-cli new <nombre> --lang <plantilla>` para crear funciones rápidamente.
- **Licencia CE:** Uso individual y hobby; requiere licencia comercial para producción.
- **Requisitos de imagen:** Paquetes compatibles con OCI/Docker.
- **Recursos adicionales:** eBook "Serverless For Everyone Else" y portal de entrenamiento oficial.
