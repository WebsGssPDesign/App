# clearml/clearml-helm-charts

## Resumen
Este repositorio ofrece gráficos Helm para desplegar la infraestructura de ClearML en Kubernetes, facilitando la gestión unificada de experimentos y datos. Incluye componentes específicos para el servidor central, los agentes locales y el servicio de despliegue (serving). La solución está diseñada para optimizar flujos de trabajo de MLOps/LLMOps mediante una interfaz web y API RESTful.

## Datos clave
- **Componentes principales**: clearml-server (backend), clearml-agent (agentes locales), clearml-serving (despliegue de modelos).
- **Funcionalidades**: Gestión de experimentos, control de versiones, almacenamiento local de imágenes/modelos y orquestación.
- **Requisitos**: Kubernetes y Helm para la instalación.
