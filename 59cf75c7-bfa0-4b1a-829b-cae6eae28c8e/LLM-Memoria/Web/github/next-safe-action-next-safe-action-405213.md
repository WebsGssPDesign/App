# next-safe-action/next-safe-action

## Resumen
next-safe-action es una librería para proyectos Next.js que permite definir y ejecutar Server Actions con seguridad de tipos. Utiliza las últimas características de React, TypeScript y Next.js para garantizar validación end-to-end y manejo avanzado de errores en el servidor.

## Datos clave
- **Instalación**: `npm i next-safe-action`
- **Características principales**: Seguridad de tipos completa, soporte para Form Actions, sistema de middleware potente, validación de entrada/salida con múltiples librerías, manejo avanzado de errores y actualizaciones optimistas.
- **Migración**: Disponible guía de migración desde la versión 7 a la 8.
- **Documentación**: Disponible en el sitio web oficial (next-safe-action.dev).
