# rburgst/temporal-java-heartbeat-problem

## Resumen
Este repositorio muestra ejemplos de uso del SDK Java para Temporal, enfocándose en funcionalidades como actividades, workflows y correos cron. El texto detalla los requisitos de versión de Java y Spring Boot necesarios para ejecutar las muestras incluidas.

## Datos clave
- **Requisitos**: Java 1.8+ (Core/SpringBoot 2), Java 1.17+ (SpringBoot 3).
- **Comandos**: `git clone https://github.com/temporalio/samples-java`, `./gradlew build`.
- **Ejemplos destacados**: HelloActivityRetry, HelloLocalActivity, HelloSchedules, HelloSaga.
- **Integración**: Soporte para Spring Boot autoconfig y uso de CLI temporal local.
