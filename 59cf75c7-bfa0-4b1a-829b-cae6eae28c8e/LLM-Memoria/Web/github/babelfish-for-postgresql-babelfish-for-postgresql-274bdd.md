# babelfish-for-postgresql/babelfish-for-postgresql

## Resumen
Babelfish para PostgreSQL es un proyecto de código abierto que permite a la base de datos ejecutar aplicaciones diseñadas originalmente para Microsoft SQL Server sin necesidad de cambiar los controladores ni reescribir las consultas. Esta extensión traduce el protocolo TDS y el lenguaje T-SQL, facilitando una migración o interoperabilidad con mínimos cambios en el código existente.

## Datos clave
- **Funcionalidad principal:** Permite a PostgreSQL entender T-SQL (lenguaje de consulta) y el protocolo de comunicación TDS de SQL Server.
- **Beneficios:** Elimina la necesidad de cambiar drivers de base de datos o modificar aplicaciones escritas para SQL Server.
- **Repositorios asociados:** Contiene distribuciones de lanzamiento, código fuente en `babelfish_extensions`, PostgreSQL modificado y herramientas como "Babelfish Compass" para evaluar compatibilidad.
- **Licencias:** Distribuido bajo Apache 2.0 y la Licencia PostgreSQL.
