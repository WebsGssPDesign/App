# nytimes/openapi2proto

## Resumen
openapi2proto es una herramienta en Go que convierte especificaciones OpenAPI/Swagger en esquemas de Protobuf v3 y definiciones de servicios gRPC. Permite generar código de backend compatible con microservicios modernos a partir de documentación estándar.

## Datos clave
- **Instalación**: `go install github.com/NYTimes/openapi2proto/cmd/openapi2proto@latest` (Go 1.15+) o `go get` para versiones anteriores.
- **Bandera principal**: `-spec` para indicar el archivo de especificación OpenAPI (YAML o JSON).
- **Opciones útiles**: `-annotate` (para grpc-gateway), `-skip-rpcs`, y `-add-autogenerated-comment`.
- **Extensibilidad**: Uso de `x-proto-tag`, `x-global-options` y `x-extensions` para personalizar el código generado.
- **Comportamiento**: Los campos nulos se envuelven en tipos `google.protobuf.*Value`; las respuestas arrays se encapsulan en un mensaje con campo `items`.
