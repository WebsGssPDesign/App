# theplatformlab/CKA-Certified-Kubernetes-Administrator

## Resumen
Este repositorio es una guía de estudio práctica para la certificación CKA 2026 basada en Kubernetes v1.35, diseñada por un administrador que obtuvo 89% en el examen. Incluye 31 ejercicios manuales, exámenes simulados y plantillas YAML para preparar la prueba terminal sin preguntas de opción múltiple.

## Datos clave
- **Versión:** Kubernetes v1.35 (sin referencias a dockershim).
- **Contenido:** 31 laborios prácticos, 2 exámenes simulados de 2 horas y una hoja de trucos de `kubectl`.
- **Herramientas:** Scripts para inicializar clústeres con kind, validación YAML automática y configuración de entorno.
- **Estrategia:** Enfoque de dos pasos en el examen real y práctica intensiva con `killer.sh` antes del día D.
