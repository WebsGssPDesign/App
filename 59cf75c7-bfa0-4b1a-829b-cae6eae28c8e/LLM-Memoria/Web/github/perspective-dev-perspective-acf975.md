# perspective-dev/perspective

## Resumen
Perspective es un componente de visualización y análisis de datos abierto diseñado para grandes conjuntos de datos en tiempo real. Utiliza un motor de consulta de alto rendimiento compilado a WebAssembly que puede ejecutarse directamente en el navegador o conectarse remotamente mediante servidores virtuales. La herramienta permite crear tablas, gráficos interactivos y dashboards sin necesidad de copiar ni transformar los datos manualmente.

## Datos clave
- **Arquitectura**: Cliente/simétrico con soporte para WebAssembly (incluyendo builds de 64 bits), Python, Node.js y Rust.
- **Formatos de datos**: Soporte nativo para lectura/escritura/streaming de Apache Arrow, CSV y JSON.
- **Virtual Servers**: Capacidad de conectar directamente con motores externos como DuckDB, ClickHouse, PostgreSQL y Polars sin ETL.
- **Interfaz**: Componente Reactivo (Custom Element) con soporte para React, scroll virtualizado y mapas basados en WebGL.
- **Entornos**: Incluye un widget para JupyterLab y bibliotecas para análisis interactivo en notebooks.
