# dboudreau00/NocTORnal

## Resumen
NocTORnal es una plataforma de análisis de redes sociales y HUMINT diseñada para investigadores de ciberdelitos, enfocándose en mapear la confianza entre actores y entidades. A diferencia de herramientas visuales convencionales, este sistema ancla cada nodo y relación a un expediente legal inmutable (WORM), garantizando una cadena de custodia irrompible para evidencias digitales.

## Datos clave
- **Arquitectura:** FastAPI y Postgres 16 con pgvector.
- **Seguridad:** Control de dos personas, proxy único de salida y seguridad a nivel de fila.
- **Principio central:** Cada elemento del gráfico debe rastrearse a una afirmación graduada sobre un exhibidor bloqueado.
- **Advertencia legal:** El uso requiere revisión jurídica previa; la posesión de datos puede ser ilegal sin autorización.
- **Datos por defecto:** Se incluye un caso sintético (TLP:CLEAR) con actores y datos ficticios para pruebas iniciales.
