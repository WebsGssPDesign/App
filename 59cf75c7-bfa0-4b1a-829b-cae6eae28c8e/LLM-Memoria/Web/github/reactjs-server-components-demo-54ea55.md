# reactjs/server-components-demo

## Resumen
Esta página presenta una aplicación de demostración llamada "React Notes" diseñada para explorar la tecnología experimental de React Server Components. El documento aclara que esta característica es complementaria al renderizado en el servidor (SSR) y advierte sobre limitaciones actuales de rendimiento, como la falta de optimización en el empaquetado y la recarga completa de la aplicación al navegar.

## Datos clave
- **Estado experimental**: React Server Components no está listo para producción; usarlo conlleva riesgos.
- **Requisito técnico**: Se requiere Node.js 18 LTS.
- **Base de datos**: Utiliza Postgres (requiere instalación manual o forks alternativos con SQLite/Prisma).
- **Configuración**: Comandos principales son `npm install --legacy-peer-deps`, `npm start` y `npm run seed`.
- **Limitaciones**: No incluye renderizado en el servidor (SSR) ni estrategia de empaquetado eficiente actual.
