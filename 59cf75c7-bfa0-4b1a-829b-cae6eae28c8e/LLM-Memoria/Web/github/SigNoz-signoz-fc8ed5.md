# SigNoz/signoz

## Resumen
SigNoz es una plataforma de observabilidad de código abierto nativa en OpenTelemetry que centraliza logs, métricas y trazas para equipos y agentes de IA. Ofrece funcionalidades como APM, gestión de infraestructura y monitoreo específico para LLMs, disponible como servicio gestionado o autoalojado.

## Datos clave
- **Modelos de despliegue**: SigNoz Cloud (prueba gratuita de 30 días desde $49), Enterprise y Community (autoalojado en Docker/Kubernetes).
- **Funcionalidades principales**: APM (latencia, Apdex), gestión de logs con visual query builder, dashboards con PromQL/SQL ClickHouse.
- **Observabilidad IA**: Rastreo de pipelines RAG, tokens, latencias y costos; integración con agente nativo "Noz" (solo Cloud) y servidor MCP.
- **Monitoreo de infraestructura**: Métricas a nivel de clúster Kubernetes, nodos y contenedores.
