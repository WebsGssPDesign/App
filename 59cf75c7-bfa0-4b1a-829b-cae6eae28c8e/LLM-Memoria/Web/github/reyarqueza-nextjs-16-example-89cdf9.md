# reyarqueza/nextjs-16-example

## Resumen
Este repositorio es un ejemplo de aplicación Next.js 16 que integra características avanzadas como el App Router, React Server Components y las nuevas Cache Components. El proyecto sirve como colección de medios en línea y utiliza una base de datos PostgreSQL gestionada por Neon, desplegada a través de Vercel con integración de almacenamiento.

## Datos clave
- **Tecnologías**: Next.js 16 (App Router), React Server Components, Server Actions, Suspense para streaming.
- **Base de datos**: PostgreSQL en Neon (integrado vía Vercel Storage).
- **Comandos esenciales**: `pnpm install`, `pnpm run dev`.
- **Flujo de despliegue**: Crear integración de base de datos en Vercel > Ejecutar `database/setup.sql` en Neon.
- **URL de demo**: https://nextjs-16-example.vercel.app/
