# rramatchandran/big-o-performance-java

## Resumen
Este repositorio contiene una aplicación web sencilla creada con React para demostrar los costos de rendimiento de diferentes estructuras de datos. El proyecto se basa en la plantilla estándar "Create React App" y ofrece instrucciones detalladas sobre su configuración, estructura de archivos y comandos disponibles para el desarrollo y despliegue.

## Datos clave
- **Objetivo**: Demostrar costos de rendimiento (Big O) de estructuras de datos mediante una app HTML/React.
- **Comandos principales**: `npm install` (instalación), `npm start` (modo desarrollo en localhost:3000), `npm run build` (compilación para producción).
- **Estructura crítica**: Archivos obligatorios son `index.html`, `favicon.ico` y el punto de entrada `src/index.js`.
- **Comando `eject`**: Desacopla las dependencias del proyecto (Webpack, Babel) permitiendo control total; es una operación irreversible.
- **Herramientas**: Utiliza Webpack para el bundling, ESLint para linting y requiere archivos JS/CSS dentro de la carpeta `src`.
