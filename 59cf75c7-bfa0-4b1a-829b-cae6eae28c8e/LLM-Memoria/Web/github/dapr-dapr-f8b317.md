# dapr/dapr

## Resumen
Dapr es un runtime de código abierto diseñado para construir aplicaciones distribuidas, flujos de trabajo y agentes de IA que funcionen en la nube o en el borde. Su objetivo principal es proporcionar ejecución duradera, comunicación segura entre servicios y gestión de estado mediante una arquitectura orientada a eventos. Permite a los desarrolladores centrarse en la lógica empresarial sin preocuparse por la infraestructura subyacente.

## Datos clave
- **Funcionalidades principales**: Ejecución duradera (Dapr Workflows), comunicación seguro, gestión de estado y mensajería basada en eventos.
- **Recuperación automática**: Los flujos de trabajo se reinician automáticamente tras fallos, reinicios de contenedores o particiones de red, retomando desde el último paso completado.
- **Compatibilidad**: Funciona como sidecar soportando cualquier lenguaje con SDKs nativos para .NET, Java, Python, Go, JavaScript/TypeScript y Rust.
- **Entornos de despliegue**: Kubernetes, nube pública, edge o entornos locales (laptop).
