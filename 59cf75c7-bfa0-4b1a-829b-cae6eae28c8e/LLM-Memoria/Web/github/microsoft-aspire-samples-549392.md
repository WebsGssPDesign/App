# microsoft/aspire-samples

## Resumen
Este repositorio ofrece una colección de aplicaciones de ejemplo para demostrar la integración del framework Aspire en múltiples lenguajes y escenarios. Los proyectos ilustran cómo conectar front-ends, APIs, contenedores y bases de datos utilizando un AppHost centralizado. Las muestras cubran desde integraciones monolingüe hasta arquitecturas políglota que incluyen Python, Go, Java y JavaScript.

## Datos clave
- **Versión de Aspire:** 13.6.0 (CLI y SDK).
- **Idiomas soportados:** C#, JavaScript, TypeScript, Python, Go, Java.
- **Instalación del CLI:** `curl -fsSL https://aspire.dev/install.sh | bash -s -- --version 13.6.0`.
- **Componentes principales:** AppHost, YARP (reverse proxy), Docker Compose, Azure Functions.
- **Escenarios destacados:** Full-stack JavaScript/TypeScript, Polyglot full-stack, RAG Document Q&A, Go API, y terminales interactivos con SQL REPL.
