# lj2-prog/Updown

## Resumen
Updown es un proyecto educativo en TypeScript diseñado para demostrar patrones de orquestación de flujos de trabajo reales utilizando la plataforma Temporal. El repositorio explora conceptos clave como actividades, señales y versionamiento mediante escenarios empresariales simulados que incluyen gestión de inventario y aprobaciones. Un énfasis central del proyecto es la observabilidad, implementando un stack con Prometheus y Grafana para monitorear el rendimiento y la salud de los procesos en producción.

## Datos clave
- **Tecnologías**: TypeScript, Node.js, Temporal SDK, Docker, Prometheus, Grafana.
- **Conceptos cubiertos**: Actividades, señales (signals), consultas (queries), reintento (retries), cancelación, versionamiento y cron jobs.
- **Escenarios de negocio**: Procesamiento de pedidos, onboarding de clientes, flujos de aprobación y mantenimiento programado.
- **Herramientas de monitoreo**: Dashboards en Grafana para métricas de ejecución, tasas de error y latencia.
- **Enfoque**: Aprendizaje práctico mediante la implementación de procesos largos y complejos en lugar de ejemplos aislados.
