# Azure/Azure-Verified-Modules

## Resumen
Azure Verified Modules (AVM) es una iniciativa de Microsoft para estandarizar y consolidar módulos de Infraestructura como Código (IaC). El proyecto busca definir un único estándar de calidad que sea consistente entre diferentes lenguajes, como Bicep y Terraform. Su objetivo final es acelerar la implementación de recursos en Azure mediante una biblioteca confiable y bien arquitectada.

## Datos clave
- **Misión**: Proveer una fuente única de verdad respaldada por Microsoft para módulos de IaC alineados con el marco de arquitectura bien construida.
- **Lenguajes soportados**: Bicep, Terraform y otros (el repositorio centraliza la propuesta y documentación).
- **Repositorio principal**: azure/Azure-Verified-Modules (para propuestas, seguimiento de issues y docs).
- **Registros específicos**: Los módulos compilados se encuentran en los índices específicos de cada lenguaje (Bicep y Terraform) disponibles en el portal AVM.
- **Enlace clave**: aka.ms/AVM para documentación oficial y guía de contribución.
