# samsonajulor/workspace

## Resumen
Este repositorio de GitHub agrupa una serie de proyectos personales diseñados para mejorar las habilidades técnicas del autor, organizados en ramas dedicadas. Los proyectos abarcan el desarrollo frontend con React y tecnologías como Material UI, así como áreas de ciencia de datos e inteligencia artificial. Cada rama contiene descripciones específicas sobre los componentes, librerías y funcionalidades implementadas en cada proyecto individual.

## Datos clave
- **Ramas principales**: `ml-datascience`, `ds-algorithms`, `frontend`, `backend`, `languages`.
- **Proyectos destacados**: Clon de dashboard Matx, autenticación JWT, gráficos con React Charts, mapas de Google y carga diferida (lazy loading).
- **Tecnologías**: ReactJS, TypeScript, Redux, ContextAPI, Material UI, GraphQL, SASS.
- **Pruebas**: Implementación de React Testing Library y Jest en el proyecto `vetrina-dashboard`.
