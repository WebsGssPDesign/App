# VioletCranberry/coco-search

## Resumen
Coco-search es una herramienta de búsqueda semántica local-first que indexa repositorios de código en PostgreSQL utilizando embeddings generados por Ollama. Combina la búsqueda vectorial con búsquedas basadas en palabras clave mediante fusión RRF para ofrecer resultados precisos en más de 30 lenguajes de programación.

## Datos clave
- **Tecnología**: Indexación local-first, PostgreSQL + pgvector, Ollama.
- **Algoritmo**: Fusión RRF (Reciprocal Rank Fusion) que combina similaridad vectorial y búsqueda por palabras clave.
- **Soporte**: CLI, servidor MCP, panel web y REPL interactivo.
- **Idiomas**: Soporta 30+ lenguajes incluyendo Python, JavaScript, Rust, Java, Go, entre otros.
