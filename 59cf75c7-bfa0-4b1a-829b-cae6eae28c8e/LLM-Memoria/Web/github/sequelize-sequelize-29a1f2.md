# sequelize/sequelize

## Resumen
Sequelize es un ORM basado en promesas para Node.js y TypeScript que facilita la gestión de bases de datos relacionales. Ofrece soporte nativo para múltiples motores como PostgreSQL, MySQL, SQLite y Oracle, incluyendo características avanzadas como transacciones sólidas y carga diferida. El proyecto actualmente busca nuevos mantenedores para finalizar la versión 7 y mejorar su ecosistema.

## Datos clave
- **Soporte de bases de datos**: PostgreSQL (con JSON/JSONB), MySQL, MariaDB, SQLite, MS SQL Server, Snowflake, Oracle DB, DB2 y Db2 for IBM i.
- **Características principales**: Transacciones robustas, relaciones entre modelos, carga eager (eager loading) y lazy (lazy loading), replicación de lectura.
- **Versión actual**: Estable en la versión 6; la versión 7 está en fase alpha.
- **Mantenimiento**: El proyecto ofrece $2,500 por trimestre para nuevos mantenedores que ayuden a lanzar la versión mayor y mejorar el soporte TypeScript.
- **Herramientas asociadas**: CLI oficial, adaptadores para GraphQL, CockroachDB y YugabyteDB.
