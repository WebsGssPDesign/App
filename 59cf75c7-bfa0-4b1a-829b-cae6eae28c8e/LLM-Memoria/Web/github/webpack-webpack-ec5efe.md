# webpack/webpack

## Resumen
Webpack es un "bundler" de módulos diseñado principalmente para empaquetar archivos JavaScript y otros activos (como CSS o imágenes) para su uso en navegadores. Su capacidad principal reside en transformar dependencias complejas en uno o varios archivos optimizados, permitiendo la carga diferida de partes de la aplicación mediante code splitting.

## Datos clave
- **Comandos de instalación**: `npm install --save-dev webpack` y `yarn add webpack --dev`.
- **Formatos compatibles**: ES Modules, CommonJS, AMD, TypeScript, Handlebars, imágenes (convertidas a Base64).
- **Conceptos principales**: "Loaders" para preprocesar archivos durante la compilación; sistema de plugins altamente modular.
- **Compatibilidad**: Requiere navegadores ES5-compliant y soporte nativo de `Promise` para dinámicos imports (`import()`).
