# babelfish-for-postgresql/babelfish_extensions

## Resumen
Babelfish es una extensión para PostgreSQL que permite ejecutar aplicaciones diseñadas originalmente para Microsoft SQL Server sin necesidad de modificar el código ni cambiar los controladores. El proyecto incluye cuatro extensiones específicas que añaden sintaxis, funciones y tipos de datos compatibles con T-SQL al motor de base de datos.

## Datos clave
- **Compatibilidad**: Soporta el protocolo de red (wire-protocol) y el lenguaje procedimental T-SQL de SQL Server.
- **Objetivo principal**: Facilitar la migración desde SQL Server a PostgreSQL sin reescribir consultas de aplicaciones existentes.
- **Componentes**: El repositorio contiene cuatro extensiones que dependen de parches aplicados a la versión comunitaria de PostgreSQL.
- **Licencia**: Disponible bajo licencias duales Apache 2.0 y PostgreSQL.
- **Recurso base**: `babelfishpg_money` es una versión modificada del tipo de dato `fixeddecimal`.
