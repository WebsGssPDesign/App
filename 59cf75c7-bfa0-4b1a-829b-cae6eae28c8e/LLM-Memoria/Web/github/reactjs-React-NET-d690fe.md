# reactjs/React.NET

## Resumen
ReactJS.NET es una biblioteca para .NET que facilita el uso de React y JSX desde C# mediante la compilación en tiempo real con Babel. Permite tanto la renderización del lado del servidor como la integración con herramientas populares de empaquetado y minificación. La librería soporta múltiples sistemas operativos y versiones de ASP.NET, ofreciendo plantillas rápidas para iniciar nuevos proyectos.

## Datos clave
- **Compilación JSX**: Transforma código JSX a JavaScript usando Babel al vuelo.
- **Renderizado del servidor (SSR)**: Mejora el rendimiento inicial con soporte para CSS-in-JS, React Router y React Helmet.
- **Integración de empaquetado**: Compatible con ASP.NET Bundling, Cassette, Webpack y MSBuild.
- **Plataformas**: Funciona en Windows, OS X y Linux gracias a .NET Core y ChakraCore.
- **Compatibilidad ASP.NET**: Soporta versiones 4.0/4.5 y ASP.NET Core.
- **Comandos de inicio**: `dotnet new -i React.Template` o `dotnet new reactnet-vanilla`.
