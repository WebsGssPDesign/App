# hashicorp/terraform-foundational-policies-library

## Resumen
Este repositorio contiene una biblioteca de políticas Sentinel desarrolladas por HashiCorp para su uso directo en la plataforma Terraform Cloud, facilitando la adopción de políticas como código. El proyecto ha sido archivado y se recomienda buscar las políticas directamente en el Registro de Terraform.

## Datos clave
- **Estado del repositorio**: Archivado (archived).
- **Plataforma requerida**: Terraform Cloud (requiere plan "Governance and Policy Plan", que es de pago).
- **Requisitos previos**: Instalación del CLI de Sentinel, acceso a un proveedor de Control de Versiones (VCS) soportado y habilitación del plan de gobernanza.
- **Estructura**: Las políticas están organizadas por nubes (AWS, Azure, GCP), categorías (Compute, Databases) y estándares (ej. CIS).
- **Configuración**: Se utiliza un archivo `sentinel.hcl` para definir las políticas, copiando fragmentos de configuración desde la documentación específica de cada política.
