# windmill-labs/windmill

## Resumen
Windmill es una plataforma de código abierto diseñada para transformar scripts en interfaces web, flujos de trabajo y aplicaciones internas. Actúa como un motor de orquestación rápido y autoalojable que permite definir lógica en múltiples lenguajes sin necesidad de escribir código frontend adicional.

## Datos clave
- **Velocidad:** Motor de flujos 13 veces más rápido que Airflow.
- **Lenguages soportados:** Python, TypeScript, Go, Bash, SQL, GraphQL, PowerShell, Rust.
- **Funcionalidades principales:** Generación automática de UIs desde parámetros de scripts, composición de flujos (flows), y construcción de aplicaciones complejas sobre scripts existentes.
- **Despliegue:** Alternativa open-source a Retool, Pipedream y Temporal; soporta auto-hospedaje vía Docker o Kubernetes.
- **Licencia:** AGPLv3.
