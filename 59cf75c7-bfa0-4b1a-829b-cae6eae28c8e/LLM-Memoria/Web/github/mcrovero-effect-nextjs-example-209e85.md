# mcrovero/effect-nextjs-example

## Resumen
Este ejemplo demuestra una integración práctica y minimalista de la librería Effect con el App Router de Next.js. El proyecto ilustra cómo utilizar helpers tipados para middlewares, parámetros validados, server actions y caching en React.

## Datos clave
- **Librerías**: `@mcrovero/effect-nextjs` (helpers para páginas, layouts, acciones) y `@mcrovero/effect-react-cache` (utilidad de caché).
- **Requisitos**: Node.js 18+ y pnpm.
- **Comandos principales**:
    - Instalación: `pnpm install`
    - Desarrollo local: `pnpm dev` (abre http://localhost:3000)
    - Construcción y ejecución en producción: `pnpm build` seguido de `pnpm start`.
