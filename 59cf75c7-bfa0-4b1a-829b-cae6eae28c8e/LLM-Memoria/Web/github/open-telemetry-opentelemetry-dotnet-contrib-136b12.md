# open-telemetry/opentelemetry-dotnet-contrib

## Resumen
Este repositorio alberga componentes adicionales que extienden las funcionalidades del SDK de OpenTelemetry para .NET, incluyendo bibliotecas de instrumentación y exportadores. El proyecto ofrece herramientas independientes que no encajan estrictamente dentro del alcance del núcleo o la instrumentación automática del ecosistema OpenTelemetry .NET.

## Datos clave
- **Propósito**: Proveer utilidades y librerías basadas en OpenTelemetry fuera del alcance principal del SDK.
- **Distribución**: Los componentes se distribuyen a través de NuGet con diferentes niveles de madurez (Alpha, Beta, RC, Estable).
- **Estados de estabilidad**:
    - *Development*: No disponible en NuGet.
    - *Alpha/Beta/RC*: Disponibles para uso limitado o no crítico; pueden tener cambios rompedores.
    - *Stable*: Listos para disponibilidad general siguiendo SemVer V2.
    - *Deprecated*: Desarrollo detenido sin nuevas versiones planificadas.
- **Gestión**: Mantenido por un equipo de contribuyentes diversos con roles definidos (Triagers, Approvers, Maintainers).
