# ansible/awx-operator

## Resumen
El repositorio ansible/awx-operator contiene un operador de Kubernetes diseñado para instalar y gestionar el ciclo de vida de instancias de Ansible AWX. Este proyecto fue construido utilizando Operator SDK y Ansible, permitiendo su despliegue dentro del mismo clúster donde reside la aplicación.

## Datos clave
- **Tecnologías base**: Operator SDK y Ansible.
- **Funcionalidad principal**: Instalación y gestión del ciclo de vida de AWX en Kubernetes.
- **Ubicación de instalación**: Se despliega en el clúster de destino dentro del mismo namespace que la instancia de AWX.
- **Licencia**: Apache 2.0.
- **Autores originales**: Jeff Geerling (2019) y actualmente mantenido por el equipo de Ansible.
- **Recursos adicionales**: Documentación disponible en ansible.readthedocs.io y documentación de Helm charts en la comunidad.
