# BankkRoll/solana-starter

## Resumen
Este repositorio ofrece una plantilla inicial para aplicaciones en la red Solana que utiliza Next.js y TypeScript. La herramienta está diseñada principalmente para extraer información de los tenedores (holders) de un contrato específico, integrando componentes modernos de interfaz como shadcn/ui.

## Datos clave
- **Tecnologías:** Next.js (renderizado del lado del servidor), TypeScript, Tailwind CSS y shadcn/ui.
- **Librerías Blockchain:** `solana/wallet-adapter-react` para conectividad de billetera y `solana/web3.js` para consultas de datos.
- **Funcionalidad principal:** Herramienta de instantánea simple que consulta la blockchain Solana para obtener listas de holders desde una dirección de creador dada.
- **Requisitos externos:** Necesita una clave API de Helius, obtenida en su dashboard, configurada en un archivo `.env`.
- **Comandos de instalación y uso:** `git clone`, `npm install`, renombrar `.env.example` a `.env`, y ejecutar `npm run dev` para iniciar el servidor local.
