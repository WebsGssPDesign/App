# alibaba/loongsuite-java

## Resumen
LoongSuite Java es una biblioteca de utilidad para la telemetría de Inteligencia Artificial Generativa en aplicaciones Java, construida sobre las Convenciones Semánticas de GenAI de OpenTelemetry. Proporciona gestión del ciclo de vida de telemetría y sirve como componente clave dentro del ecosistema unificado de observabilidad de Alibaba.

## Datos clave
- **Base técnica**: OpenTelemetry GenAI Semantic Conventions v1.41.1.
- **Componentes principales**: `GenAiTelemetryHandler`, `InferenceInvocation`.
- **Maven dependency**: `<groupId>com.alibaba.loongsuite</groupId>` con artifactId `otel-util-genai`.
- **Requisitos**: Java 8+, OpenTelemetry API (SDK y exportador opcionales).
- **Funcionalidad**: Instrumentación de llamadas a LLMs, manejo de mensajes de entrada/salida y streaming.
