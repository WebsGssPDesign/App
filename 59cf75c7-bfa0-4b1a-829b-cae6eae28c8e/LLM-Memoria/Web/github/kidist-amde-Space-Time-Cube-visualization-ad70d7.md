# kidist-amde/Space-Time-Cube-visualization

## Resumen
Este proyecto visualiza el comportamiento humano mediante cubos espacio-temporales para analizar patrones de movilidad y actividades de tres sujetos. Combina datos GPS con diarios temporales auto-reportados para crear narrativas visuales en 2D, 3D y 4D aplicables a la planificación urbana y ciencias sociales.

## Datos clave
- **Objetivos**: Visualizar trayectorias (2D/3D), cubos espacio-temporales (3D) e integrar datos de estado de ánimo o compañía (4D).
- **Datos**: GPS de 3 sujetos durante 13 días y diarios temporales recolectados vía app iLog-mobile.
- **Herramientas**: Python, Plotly (visualización interactiva), mplot3d, Geopandas, Numpy, Pandas.
- **Librerías adicionales**: cartopy, keplergl, movingpandas, topojson, kaleido, scikit-image.
- **Concepto clave**: El cubo espacio-temporal proyecta geografía en el plano XY y tiempo en el eje Z (Hägerstrand).
