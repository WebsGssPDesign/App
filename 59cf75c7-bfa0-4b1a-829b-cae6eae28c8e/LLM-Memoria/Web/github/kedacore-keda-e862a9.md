# kedacore/keda

## Resumen
KEDA es un componente de escalado automático impulsado por eventos para cargas de trabajo en Kubernetes, funcionando como un servidor de métricas que permite definir reglas de escalado mediante recursos personalizados. Este proyecto graduado de la CNCF opera tanto en entornos cloud como edge sin depender de componentes externos, integrándose nativamente con el Horizontal Pod Autoscaler.

## Datos clave
- **Funcionalidad principal**: Escalado fino (hasta cero) basado en eventos para contenedores Kubernetes.
- **Mecanismo**: Actúa como servidor de métricas y utiliza definiciones de recursos personalizados (CRD).
- **Entornos compatibles**: Cloud y Edge, sin dependencias externas.
- **Integración nativa**: Funciona junto con el Horizontal Pod Autoscaler (HPA) de Kubernetes.
- **Estado del proyecto**: Graduado por la Cloud Native Computing Foundation (CNCF).
- **Recursos disponibles**: QuickStarts para RabbitMQ, Azure Functions y Kafka; documentación en keda.sh.
