# hashicorp/terraform

## Resumen
Terraform es una herramienta de código abierto para crear, modificar y mejorar infraestructuras de forma segura mediante la codificación de APIs en archivos declarativos. Permite gestionar proveedores de servicios populares y soluciones personalizadas utilizando un enfoque de "Infraestructura como Código". Su arquitectura incluye un motor principal que descarga automáticamente plugins (proveedores) desde el registro oficial.

## Datos clave
- **Funcionalidad principal**: Infraestructura como código, planes de ejecución y automatización de cambios complejos.
- **Gestión de dependencias**: Construcción de grafos de recursos para paralelizar la creación no dependiente.
- **Arquitectura**: El repositorio contiene solo el núcleo (CLI y motor); los proveedores son plugins externos descargables automáticamente.
- **Documentación**: Disponible en `developer.hashicorp.com/terraform` con guías de inicio, tutoriales y certificación asociada.
