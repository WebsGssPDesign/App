# apache/apisix

## Resumen
Apache APISIX es una pasarela de API nativa en la nube y para IA, construida sobre NGINX y etcd. Destaca por su capacidad de gestión dinámica de tráfico, hot-loading de plugins y soporte multiplataforma. Además, se adapta como puerta de entrada para cargas de trabajo de inteligencia artificial mediante un sistema flexible de proxying.

## Datos clave
- **Arquitectura**: Basada en NGINX y etcd.
- **Funciones principales**: Balanceo de carga, liberaciones canario (canary release), control de circuitos, autenticación y observabilidad.
- **Instalación rápida**: `curl -sL https://run.api7.ai/apisix/quickstart | sh` (requiere Docker).
- **Puertos clave**: 9080 (servicio web), 9180 (API de administración).
- **Protocolos soportados**: HTTP, TCP, UDP, Dubbo y MQTT.
- **Características IA**: Proxying a LLMs, limitación por tokens para control de costos y seguridad robusta.
