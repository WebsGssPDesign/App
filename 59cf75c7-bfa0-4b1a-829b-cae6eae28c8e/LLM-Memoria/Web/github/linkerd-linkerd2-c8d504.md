# linkerd/linkerd2

## Resumen
Linkerd es una red de servicios ultraligera y centrada en la seguridad diseñada para Kubernetes. Este proyecto de la fundación CNCF añade características críticas de observabilidad, fiabilidad y seguridad a las aplicaciones sin requerir cambios en el código. El repositorio principal gestiona el plano de control y la línea de desarrollo 2.x del software.

## Datos clave
- **Descripción**: Red de servicios (service mesh) ultraligera y segura para Kubernetes.
- **Afiliación**: Proyecto de la Cloud Native Computing Foundation (CNCF).
- **Componentes principales**: Plano de control, CLI y proxy de plano de datos (`linkerd2-proxy`).
- **Características**: Seguridad, observabilidad y fiabilidad sin modificaciones de código.
- **Licencia**: Apache License, Version 2.0.
- **Recursos**: Guías de inicio rápido, documentación completa y auditorías de seguridad de terceros.
