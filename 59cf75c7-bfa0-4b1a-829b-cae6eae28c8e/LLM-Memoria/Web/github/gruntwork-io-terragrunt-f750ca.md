# gruntwork-io/terragrunt

## Resumen
Terragrunt es una herramienta de orquestación flexible diseñada para escalar proyectos de Infraestructura como Código basados en OpenTofu o Terraform. El software permite gestionar configuraciones complejas manteniendo la compatibilidad con versiones recientes de los motores subyacentes. Los detalles completos sobre instalación y documentación están disponibles en sus sitios web oficiales.

## Datos clave
- **Compatibilidad**: Requiere OpenTofu >= 1.6.0 o Terraform >= 0.12.0.
- **Propósito principal**: Escalabilidad de código de infraestructura mediante orquestación.

- **Repositorio**: gruntwork-io/terragrunt en GitHub.
