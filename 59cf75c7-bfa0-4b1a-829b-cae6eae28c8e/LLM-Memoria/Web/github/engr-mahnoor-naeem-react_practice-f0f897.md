# engr-mahnoor-naeem/react_practice

## Resumen
Este repositorio es una plantilla de proyecto para iniciar aplicaciones con React y Vite, incluyendo reglas de ESLint y soporte para recarga rápida. El autor documenta un curso que cubre desde los fundamentos de componentes y estado hasta técnicas avanzadas como SSR y SSG. Además, se incluyen configuraciones prácticas para TailwindCSS y limpieza de código inicial.

## Datos clave
- **Tecnologías**: React, Vite, ESLint, Babel, SWC.
- **Conceptos cubiertos**: Componentes, Estado (State), Hooks, JSX.
- **Patrones de renderizado**: SPA (Single Page Application), SSR (Server-Side Rendering), SSG (Static Site Generation).
- **Herramientas adicionales**: TailwindCSS, Fast Refresh.
- **Plugins oficiales**: `@vitejs/plugin-react` y `@vitejs/plugin-react-swc`.
