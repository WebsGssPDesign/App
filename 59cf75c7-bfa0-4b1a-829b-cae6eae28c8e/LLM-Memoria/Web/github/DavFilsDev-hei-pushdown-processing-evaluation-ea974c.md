# DavFilsDev/hei-pushdown-processing-evaluation

## Resumen
Este repositorio recopila ejercicios de evaluación para el curso PROG3 de la HEI, centrados en el patrón de procesamiento empujado (push-down). Los ejercicios utilizan consultas SQL y Java con Spring JDBC para analizar estadísticas de reparaciones automotrices y ventas de repuestos.

## Datos clave
- **Ejercicio 1**: Estadísticas de reparación para FORD, GMC y DODGE; conteo de reparaciones, porcentajes y costos por mecánico.
- **Ejercicio 2**: Ventas de repuestos para KIA, HYUNDAI y DAEWOO; valor total de ventas de KIA.
- **Ejercicio 3**: Seguimiento de ventas con fechas para KIA y DAEWOO; cálculo de porcentajes antes de una fecha límite.
- **Tecnologías**: PostgreSQL (tipos ENUM, agregaciones, COALESCE) y Java con Spring JDBC Template.
