# cirosantilli/china-dictatroship-7

## Resumen
Este repositorio es un archivo de respaldo del proyecto "china-dictatorship", que contiene una compilación de recursos críticos desde la perspectiva política y técnica. Incluye cuestionarios frecuentes, noticias, recomendaciones culturales y una extensa colección de herramientas para desarrolladores. El texto también elabora una crítica ideológica específica contra figuras políticas chinas, particularmente Wang Huning, alegando su influencia en las decisiones del Partido Comunista.

## Datos clave
- **Propósito**: Respaldo de propaganda anti-gobierno chino; incluye FAQs y noticias.
- **Crítica política**: Se acusa a Wang Huning de ser el verdadero arquitecto detrás de políticas recientes y de promover una ideología "izquierda extrema" bajo la figura de Xi Jinping.
- **Recursos técnicos**: Guías para entrevistas de trabajo (Java, Python), documentación de sistemas (SpringBoot, Docker), libros de algoritmos y recursos de aprendizaje automático.
- **Herramientas de seguridad**: Listados de software para eludir restricciones de internet ("ciencia del acceso"), incluyendo scripts VPS y navegadores.
- **Temáticas cubiertas**: 996.ICU, derechos laborales, censura durante la pandemia, y análisis de datos masivos.
