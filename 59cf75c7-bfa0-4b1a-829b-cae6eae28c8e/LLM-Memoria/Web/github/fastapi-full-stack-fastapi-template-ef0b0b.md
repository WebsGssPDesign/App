# fastapi/full-stack-fastapi-template

## Resumen
Este repositorio ofrece una plantilla completa para aplicaciones web full-stack que integra FastAPI como backend con React, TypeScript y Vite en el frontend. La solución incluye gestión de bases de datos con SQLModel y PostgreSQL, autenticación JWT, pruebas automatizadas y despliegue facilitado mediante Docker Compose o servicios en la nube.

## Datos clave
- **Backend**: FastAPI, SQLModel (ORM), Pydantic para validación.
- **Frontend**: React, TypeScript, Vite, Tailwind CSS, shadcn/ui.
- **Base de datos**: PostgreSQL.
- **Autenticación y seguridad**: JWT, hash de contraseñas seguro, recuperación por correo.
- **Herramientas adicionales**: Playwright (E2E tests), Mailpit (testing local de correos), Traefik (proxy inverso con HTTPS).
- **Despliegue**: Docker Compose para auto-hospedaje o FastAPI Cloud.
