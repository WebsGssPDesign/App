# strands-agents/samples

## Resumen
Este repositorio contiene ejemplos educativos de agentes de IA construidos con el SDK de Strands Agents. El material está diseñado para demostrar conceptos y técnicas fundamentales utilizando un enfoque impulsado por modelos en Python o TypeScript, aunque no se recomienda su uso directo en entornos de producción sin pruebas adicionales.

## Datos clave
- **Lenguajes soportados:** Python 3.10+ y TypeScript/Node.js 18+.
- **Instalación principal (Python):** `pip install strands-agents strands-agents-tools`.
- **Instalación alternativa (uv):** `uv pip install strands-agents strands-agents-tools`.
- **Ejemplo básico Python:** Crear un objeto `Agent` e invocar una solicitud de texto.
- **Ejemplo básico TypeScript:** Usar `new Agent()` con un `systemPrompt` y llamar a `agent.invoke()`.
- **Categorías de muestras:** Tutoriales básicos, patrones de despliegue (Lambda/Fargate), integraciones con AWS y casos de uso industriales.
