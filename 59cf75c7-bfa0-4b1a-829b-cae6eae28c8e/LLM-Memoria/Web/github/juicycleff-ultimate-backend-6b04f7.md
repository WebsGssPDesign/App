# juicycleff/ultimate-backend

## Resumen
Este repositorio presenta un kit inicial para arquitecturas de backend escalables y multiinquilino, basado en el patrón CQRS y GraphQL Federation. El proyecto está diseñado como un prototipo ligero enfocado en la producción, integrando microservicios con GRPC y soporte para event sourcing.

## Datos clave
- **Patrones**: Command Query Responsibility Segregation (CQRS), Event Sourcing, Multi-Tenancy.
- **APIs**: GraphQL (Apollo Federation) y gRPC.
- **Stack tecnológico**: NestJS, Node.js, TypeScript, Express/Fastify.
- **Persistencia y caché**: MongoDB, Redis, Event Store.
- **Autenticación**: Sesiones stateful, OAuth2 (Google, Github, Facebook).
- **Infraestructura**: Docker, Kubernetes, Consul para discovery de servicios.
- **Pagos**: Integración con Stripe para planes SaaS.
