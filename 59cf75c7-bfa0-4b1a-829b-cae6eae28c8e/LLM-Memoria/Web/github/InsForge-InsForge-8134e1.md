# InsForge/InsForge

## Resumen
InsForge es una plataforma de backend todo en uno y de código abierto diseñada específicamente para el desarrollo impulsado por agentes de IA. Proporciona servicios integrales como autenticación, bases de datos, almacenamiento y computación para permitir que los agentes construyan aplicaciones full-stack de extremo a extremo.

## Datos clave
- **Interfaces de agente**: Servidor MCP (autoalojado o nube) e interfaz CLI + Skills (nube).
- **Servicios principales**: Autenticación, base de datos PostgreSQL, almacenamiento S3-compatible, Gateway de modelos LLM y funciones serverless en el edge.
- **Capacidades operativas**: Los agentes pueden leer contexto del backend (esquemas, logs) y configurar recursos primarios (migraciones, buckets, proveedores de auth).
- **Licencia**: Apache 2.0.
- **Plataforma de hosting**: Vercel OSS Program.
