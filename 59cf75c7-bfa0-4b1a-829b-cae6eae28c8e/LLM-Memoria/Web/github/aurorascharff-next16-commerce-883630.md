# aurorascharff/next16-commerce

## Resumen
Este repositorio es una demostración de comercio electrónico diseñada para explorar las capacidades avanzadas de Next.js 16, como los componentes con caché y el pre-carga parcial. El proyecto ilustra cómo combinar patrones de servidor y cliente para optimizar el rendimiento en aplicaciones modernas utilizando React Server Components.

## Datos clave
- **Tecnologías:** Next.js (canary), React 19, Tailwind CSS v4, Prisma, PostgreSQL/SQLite, TypeScript.
- **Características principales:** Uso de `'use cache'` y `'use cache: private'`, pre-carga parcial (`prefetch={true}`), directiva `ensureStatic` para garantizar salida estática, Server Functions con invalidación de etiquetas mediante `updateTag`.
- **Optimizaciones de React:** React Compiler (memoización automática), View Transitions, Suspense y hooks asíncronos como `useOptimistic` y `useTransition`.
- **Comandos esenciales:** `pnpm install`, `pnpm run prisma.push`, `pnpm run dev`, `pnpm test:e2e`.
