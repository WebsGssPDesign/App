# GTOVD/nuspeakaws

## Resumen
Este proyecto es un sitio web de intercambio de enlaces para redes sociales, optimizado para la velocidad y la experiencia del usuario. Utiliza una arquitectura moderna basada en AWS (Cognito, DynamoDB, AppSync) y Next.js con estrategias avanzadas de renderizado.

## Datos clave
- **Tecnologías principales**: Next.js, React Hook Form, Material-UI.
- **Servicios AWS**: Amazon Cognito (autenticación), DynamoDB (base de datos), Amazon AppSync (GraphQL API), S3 Buckets (almacenamiento).
- **Características de renderizado**: Generación estática (SSG), Regeneración incremental estática (ISR) y Renderizado del lado del servidor (SSR).
- **Comandos de configuración**: `npx create-next-app`, `amplify init`, `amplify add api`, `npm install aws-amplify`.
- **Enlaces útiles**: localhost:3000 para desarrollo, documentación oficial de Next.js y Amplify.
