# TykTechnologies/tyk

## Resumen
Tyk es una pasarela de API y IA de código abierto, nativa en la nube y orientada a entornos empresariales. Diseñada para ser extremadamente rápida desde 2014, soporta múltiples protocolos incluyendo REST, GraphQL, TCP, gRPC y el reciente MCP. Ofrece un ecosistema completo con opciones de despliegue flexibles, desde contenedores Docker hasta plataformas SaaS gestionadas.

## Datos clave
- **Protocolos soportados:** REST, GraphQL, TCP, gRPC, MCP (Model Context Protocol).
- **Licencia:** MPL 2.0.
- **Instalación rápida:** Se puede ejecutar en menos de 2 minutos usando Docker y Docker Compose con el archivo `tyk.conf`.
- **Comando de inicio:** `docker compose up -d` para arrancar la pasarela junto a Redis.
- **Endpoint de prueba:** `curl localhost:8080/hello` devuelve el estado de la versión (`5.x.x`).
- **Plataformas disponibles:** Tyk Cloud (SaaS), Tyk Self Managed (On-premise) y Tyk Open Source Gateway.
- **Herramientas adicionales:** Se puede usar `tyk-install` para probar el ciclo de vida completo de gestión empresarial con licencias.
