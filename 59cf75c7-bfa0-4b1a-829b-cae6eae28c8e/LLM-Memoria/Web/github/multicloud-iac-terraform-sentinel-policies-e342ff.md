# multicloud-iac/terraform-sentinel-policies

## Resumen
Este repositorio ofrece políticas de ejemplo para HashiCorp Sentinel, diseñadas específicamente para su integración con Terraform Enterprise. El objetivo es demostrar cómo implementar estrategias de "Policy as Code" mediante conjuntos de políticas gestionados a través de la integración VCS.

## Datos clave
- **Tecnología**: HashiCorp Sentinel y Terraform Enterprise.
- **Concepto principal**: Policy as Code (Política como Código).
- **Mecanismo de gestión**: Definición de políticas como "Policy Sets".
- **Integración**: Uso de la integración VCS (Control de Versiones) de Terraform Enterprise.
- **Herramientas mencionadas**: Sentinel Simulator para pruebas, directorio `governance` en los guías oficiales de Terraform.
