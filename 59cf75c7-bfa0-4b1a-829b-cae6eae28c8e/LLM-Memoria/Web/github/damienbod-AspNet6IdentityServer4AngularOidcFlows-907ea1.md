# damienbod/AspNet6IdentityServer4AngularOidcFlows

## Resumen
Este repositorio proporciona ejemplos de implementación para flujos de autenticación OpenID Connect (Code Flow y Implicit Flow) utilizando ASP.NET Core 6 como proveedor de identidad (IdentityServer4) y Angular como aplicación cliente. El proyecto documenta la evolución tecnológica a través de un historial detallado de actualizaciones, asegurando compatibilidad con las versiones más recientes de .NET y librerías de autenticación.

## Datos clave
- **Tecnologías**: ASP.NET Core 6, Angular, IdentityServer4, OpenID Connect (OIDC).
- **Flujos soportados**: Authorization Code Flow con PKCE e Implicit Flow.
- **Funcionalidades documentadas**: Renovación silenciosa de tokens, gestión de sesiones, descargas seguras de archivos y autenticación externa multi-inquilino (Azure AD).
- **Actualizaciones recientes**: Migración a .NET 6, actualización de paquetes NuGet y corrección de nombres de espacio de nombres en febrero de 2022.
