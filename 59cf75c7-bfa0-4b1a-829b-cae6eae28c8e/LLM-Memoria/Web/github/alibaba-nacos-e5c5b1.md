# alibaba/nacos

## Resumen
Nacos es una plataforma de Alibaba diseñada para facilitar el descubrimiento dinámico de servicios, la gestión de configuraciones y la administración de servicios en aplicaciones cloud nativas. Funciona como un ciudadano de primera clase que soporta diversos tipos de servicios y ofrece cuatro funciones principales: salud de servicios, configuración dinámica, DNS dinámico y gestión de metadatos.

## Datos clave
- **Funciones principales**: Descubrimiento de servicios y chequeo de salud, Gestión de configuración dinámica (sin necesidad de redesplegar), Servicio DNS dinámico (ruteo ponderado) y Dashboard para metadatos.
- **Tipos de servicios soportados**: Dubbo/gRPC, Spring Cloud RESTful y Kubernetes.
- **Comandos de arranque**: `sh startup.sh -m standalone` (Linux/Mac) o `startup.cmd -m standalone` (Windows).
- **Licencia**: Apache 2.0.
- **Documentación oficial**: Disponible en nacos.io.
