# firdaus/awesome-cadence-temporal-workflow

## Resumen
Este documento es una recopilación curada de recursos esenciales para los motores de orquestación de flujos de trabajo Cadence y Temporal. Incluye enlaces a documentación oficial, clientes SDKs disponibles en múltiples lenguajes, herramientas de visualización y ejemplos de código prácticos. La lista también abarca proyectos de integración con frameworks populares y artículos técnicos que ilustran casos de uso reales en empresas como Uber y Box.

## Datos clave
- **Motores principales**: Cadence (desarrollado por Uber) y Temporal.
- **Lenguajes soportados**: Java, Golang, Python, PHP, Ruby, C#.
- **Herramientas de UI**: `Cadence Web` y `Temporal Web` para depuración visual.
- **Recursos comunitarios**: Canales en Slack, foros de Discourse y etiquetas en Stack Overflow.
- **Integraciones destacadas**: Spring Starter para Cadence Java Client.
- **Casos de uso**: Gestión de tickets, procesamiento de archivos, despliegue de Kubernetes y microservicios.
