# YeamimHossainSajid/Veridian

## Resumen
Veridian es una plataforma de alta frecuencia (HFT) que demuestra arquitectura distribuida avanzada, optimización JVM y sistemas resilientes. El sistema simula entornos financieros reales con baja latencia sub-milisegundo y alto throughput, utilizando un diseño CQRS/ES y transacciones Saga para garantizar la consistencia estricta.

## Datos clave
- **Rendimiento:** +100,000 operaciones/segundo, latencia < 1ms, disponibilidad 99.99%.
- **Tecnologías:** Java 21 (ZGC), Spring Boot 4.0.2, Kubernetes, Istio Service Mesh.
- **Patrones de arquitectura:** LMAX Disruptor, Kafka Streams CEP, CQRS/ES, Saga, Polyglot Persistence.
- **Componentes:** Gateway multi-protocolo (REST/gRPC/FIX), Motor de conciliación con Aeron UDP, Motores de riesgo y volatilidad en tiempo real.
- **Almacenamiento:** PostgreSQL, MySQL, Redis, Elasticsearch, ClickHouse, Cassandra, MongoDB, S3, Memcached.
