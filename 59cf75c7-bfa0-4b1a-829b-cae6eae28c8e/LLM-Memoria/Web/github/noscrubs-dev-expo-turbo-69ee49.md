# noscrubs-dev/expo-turbo

## Resumen
Expo Turbo es un proyecto generado por IA que traslada la arquitectura de navegación impulsada por el servidor de Rails (Turbo) a aplicaciones React Native, manteniendo una interfaz nativa. Utiliza un protocolo basado en XML para que Rails renderice actualizaciones y Expo las interprete como componentes React Native registrados. El objetivo es permitir flujos de trabajo completos con formularios, Frames y Streams sin depender del DOM del navegador.

## Datos clave
- **Tecnologías**: Expo React Native, Ruby on Rails, TypeScript.
- **Protocolo**: Intercambio de documentos XML entre servidor (Rails) y cliente (Expo).
- **Versión actual**: Candidata a versión 0.4.0 (preparada el 18/08/2026).
- **Compatibilidad**: Basado en la semántica de Turbo 8.0.23.
- **Instalación**: `bun add expo-turbo` y uso del gem `expo_turbo-rails`.
- **Restricciones**: No se aceptan Pull Requests; los reportes deben incluir contexto y evidencia de reproducción, no parches de código.
