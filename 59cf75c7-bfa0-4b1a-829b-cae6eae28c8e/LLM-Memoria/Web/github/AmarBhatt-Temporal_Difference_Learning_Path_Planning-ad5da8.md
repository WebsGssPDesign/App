# AmarBhatt/Temporal_Difference_Learning_Path_Planning

## Resumen
El proyecto explora cómo los sistemas robóticos autónomos pueden aprender a navegar en entornos desconocidos utilizando aprendizaje por refuerzo y datos sensoriales simulados. Se evalúan dos algoritmos de aprendizaje temporal (Q-Learning y Sarsa) para encontrar la ruta óptima hacia un objetivo, priorizando distancia, seguridad y tipo de terreno. Los experimentos concluyen que Q-Learning es más fiable y eficiente en mapas con estados desiguales.

## Datos clave
- **Algoritmos probados**: Q-Learning (off-policy) y Sarsa (onpolicy).
- **Sensores simulados**: ultrasónicos, de humedad, codificadores, choque, presión y pendiente.
- **Escenario**: Entorno abierto post-desastre natural sin conocimiento previo del mapa o terreno.
- **Objetivo**: Navegación autónoma basada en prueba y error con recompensas/punimientos.
- **Hallazgo principal**: Q-Learning supera a Sarsa en fiabilidad y eficiencia para mapas conocidos con estados desiguales.
