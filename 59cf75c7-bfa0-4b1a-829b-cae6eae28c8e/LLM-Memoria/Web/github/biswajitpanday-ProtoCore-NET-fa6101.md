# biswajitpanday/ProtoCore.NET

## Resumen
ProtoCore.NET es una plantilla moderna para .NET 7 que facilita el desarrollo de servicios gRPC integrando herramientas esenciales como Entity Framework Core y AutoMapper. El proyecto sigue principios de arquitectura limpia, separando la lógica de negocio, acceso a datos y puntos de entrada gRPC en capas distintas. Incluye soporte dual para comunicación RESTful y documentación automática mediante Swagger.

## Datos clave
- **Tecnologías**: .NET 7 SDK, Entity Framework Core 7, Serilog, AutoMapper, Protocol Buffers (gRPC).
- **Arquitectura**: Capas de Aplicación, Infraestructura y gRPC para escalabilidad y mantenibilidad.
- **Mapeo personalizado**: Transformaciones seguras entre Protos, entidades de base de datos y DTOs.
- **Requisitos**: Visual Studio 2022 o posterior, configuración de cadena de conexión en `appsettings.json`.
- **Ejecución**: Requiere múltiples proyectos de inicio (`ProtoCore.NET.Api` y `ProtoCore.NET.Client`) para probar el servidor y cliente simultáneamente.
