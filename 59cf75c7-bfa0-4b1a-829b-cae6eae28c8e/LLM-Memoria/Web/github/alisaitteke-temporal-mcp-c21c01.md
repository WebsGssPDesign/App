# alisaitteke/temporal-mcp

## Resumen
Temporal MCP es un servidor independiente que permite a asistentes de IA gestionar workflows de Temporal mediante el Protocolo de Contexto del Modelo (MCP). Exponiendo operaciones como herramientas, facilita iniciar ejecuciones, consultar estados y enviar señales sin necesidad de código personalizado. Ofrece tres niveles de exposición de herramientas para equilibrar funcionalidad y eficiencia en el contexto del modelo.

## Datos clave
- **Herramientas disponibles**: 36 en total, con un conjunto predeterminado de 11 esenciales.
- **Niveles de herramientas (`TEMPORAL_TOOLS`)**: `essential` (11), `standard` (23) y `all`.
- **Variables de entorno críticas**: `TEMPORAL_ADDRESS`, `TEMPORAL_NAMESPACE`, `TEMPORAL_API_KEY`.
- **Integraciones soportadas**: Cursor, Claude Desktop y Claude Code.
- **Requisitos**: Node.js >= 18 y un servidor Temporal activo.
