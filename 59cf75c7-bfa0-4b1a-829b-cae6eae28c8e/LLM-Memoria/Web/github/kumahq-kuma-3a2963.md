# kumahq/kuma

## Resumen
Kuma es una red de servicio moderna basada en Envoy diseñada para funcionar en contenedores, Kubernetes y máquinas virtuales. Como proyecto CNCF Sandbox, ofrece soporte nativo multi-zona y multi-malla que sincroniza políticas automáticamente entre diferentes clusters y nubes sin requerir experiencia específica en Envoy.

## Datos clave
- **Arquitectura**: Control plane universal (Kubernetes/VM) y data plane ligero con Envoy.
- **Capacidades**: Conectividad L4-L7, descubrimiento de servicios, seguridad (zero-trust), observabilidad y enrutamiento.
- **Ventajas principales**: Soporte multi-zona automático, sincronización de políticas entre mallas, cumplimiento PCI/GDPR mediante atributos personalizados.
- **Licencia**: Apache 2.0.
- **Estado**: Proyecto CNCF Sandbox donado originalmente por Kong.
