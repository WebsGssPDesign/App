# agentarea/agentarea

## Resumen
AgentArea es una plataforma de código abierto para organizar equipos donde los agentes de IA asumen roles reales y gestionan flujos de trabajo autónomos. El sistema permite conectar múltiples fuentes de datos como Slack o GitHub a través de corrientes de eventos, asignando tareas específicas a agentes con reglas estrictas de seguridad y aprobación humana cuando es necesario.

## Datos clave
- **Conceptos**: Agentes nativos, organizaciones sin intervención humana, bundles (paquetes de configuración), MCP servers.
- **Flujo de trabajo**: Fuentes (Telegram, GitHub, etc.) → Streams de eventos → Disparadores/Procesadores → Agentes.
- **Mecanismos de control**: Reglas de datos verificadas antes de cada llamada, aprobaciones manuales para ciertas herramientas, límites presupuestarios mensuales.
- **Configuración**: Todo el entorno se define en un único archivo YAML que incluye modelos, servidores MCP, canales y políticas.
