# hashicorp/policy-library-nist-policy-set-for-aws-terraform

## Resumen
Este repositorio ofrece una biblioteca de políticas Sentinel preescritas diseñadas para facilitar la verificación de cumplimiento con el estándar NIST SP 800-53 Revisión 5 en entornos AWS. El objetivo es ayudar a organizaciones, especialmente del sector público, a implementar controles de seguridad y privacidad sin necesidad de desarrollarlas desde cero.

## Datos clave
- **Estándar:** NIST SP 800-53 Revisión 5.
- **Herramientas:** Sentinel (versión 0.26.x o superior) integrado con HCP Terraform o Terraform Enterprise (v202312-1+).
- **Niveles de aplicación:** `advisory` (por defecto), `soft-mandatory`, `hard-mandatory`.
- **Requisitos previos:** Cuenta de usuario con permisos "owners" o "Manage Policies", y credenciales de acceso a AWS configuradas.
- **Métodos de implementación:** Uso del Terraform Registry o clonación directa desde el repositorio público de GitHub.
