# GRB-Workspace/Nextjs-15-Intro

## Resumen
Este repositorio es un proyecto de demostración diseñado para ilustrar las características principales y mejores prácticas de Next.js 15. Cubre temas esenciales como la distinción entre componentes del lado del servidor y del cliente, enrutamiento basado en archivos, acciones de servidor y autenticación mediante Clerk.

## Datos clave
- **Tecnologías**: Next.js 15, React, TypeScript, Node.js, Clerk.
- **Características principales**: React Server Components (RSC), File-Based Routing, Layouts, Route Handlers, Server Actions (`use server`), Data Fetching strategies.
- **Autenticación**: Implementada con Clerk para gestión de sesiones y protección de rutas vía middleware.
- **Requisitos del sistema**: Node.js v20+, npm o yarn.
- **Comandos esenciales**: `git clone`, `npm install`, `npm run dev`.
- **Estructura**: Uso de carpetas dentro de `/app` para definir rutas y layouts anidados.
