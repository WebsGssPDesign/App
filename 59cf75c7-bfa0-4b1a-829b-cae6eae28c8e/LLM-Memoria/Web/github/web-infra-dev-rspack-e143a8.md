# web-infra-dev/rspack

## Resumen
Rspack es un compilador web rápido desarrollado en Rust que moderniza la API de Webpack para ofrecer una experiencia de desarrollo más eficiente sin sacrificar compatibilidad. Su arquitectura permite reemplazar a Webpack con velocidades de compilación extremadamente rápidas y soporte nativo para Hot Module Replacement (HMR).

## Datos clave
- **Lenguaje:** Rust (velocidad superior).
- **Compatibilidad:** Soporta plugins y loaders del ecosistema de Webpack.
- **Características principales:** Inicio rápido, HMR incremental, optimización de producción (tree shaking) y soporte para Module Federation.
- **Ecosistema Rstack:** Parte de una suite unificada que incluye Rsbuild (herramienta de construcción), Rslib (desarrollo de librerías), Rspress (generador de sitios estáticos) y Rsdoctor (analizador).
