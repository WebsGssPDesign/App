# cankocagil/Cognitive-Computational-Modelling-for-Spatio-Temporal-fMRI-in-Ventral-Temporal-Cortex

## Resumen
Este proyecto presenta un marco de modelado cognitivo y computacional para analizar imágenes de resonancia magnética funcional (fMRI) en el córtex temporal ventral. Utiliza análisis de patrones multivociales con aprendizaje automático y profundo para decodificar la categoría de estímulos visuales basándose en la actividad cerebral registrada.

## Datos clave
- **Dataset**: Haxby dataset (representación de caras y objetos).
- **Métodos de pre-análisis**: Análisis eco-planar, regiones de interés (RoI), mapas estadísticos y análisis de conectividad funcional.
- **Técnicas de reducción de dimensionalidad**: Aprendizaje de variedades (manifold learning) para extraer representaciones latentes espaciotemporales.
- **Algoritmos de ML/DL**: Perceptrones, redes MLP, CNN 2D/3D y vision transformers espacialmente orientados.
- **Enfoque final**: Ensamblaje de modelos regularizados para lograr el mejor rendimiento en decodificación robusta.
