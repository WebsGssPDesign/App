# k8tz/k8tz

## Resumen
k8tz es un controlador de admisión y una herramienta CLI diseñada para inyectar zonas horarias estandarizadas en Pods y CronJobs de Kubernetes. Soluciona el problema de que los contenedores no heredan la zona horaria del host, garantizando consistencia mediante el montaje de archivos TZif en `/etc/localtime` sin necesidad de instalar datos de tiempo en las imágenes base.

## Datos clave
- **Instalación (Helm):** `helm install k8tz k8tz/k8tz --set timezone=Europe/London`.
- **Comandos CLI:** `k8tz inject --timezone=<zona> <archivo.yaml>` o `kubectl get deploy -oyaml | k8tz inject -`.
- **Estrategias de inyección:** `hostPath` (requiere archivos en los nodos), `initContainer` (método predeterminado usando `emptyDir`) y `imageVolume` (Kubernetes 1.33+).
- **Requisito técnico:** Los contenedores necesitan el archivo TZif montado en `/etc/localtime`.
- **Idempotencia:** El proceso de inyección es idempótico; múltiples aplicaciones no generan efectos acumulativos.
