# rajakotid007/nextjs-shopify-storefront

## Resumen
Este proyecto es una tienda headless de Shopify construida con Next.js 15 y React 19, diseñada para superar las limitaciones de rendimiento y personalización del tema nativo de Liquid. La arquitectura separa el frontend (alojado en Vercel) de la lógica comercial de Shopify, comunicándose mediante la API GraphQL Storefront y webhooks para revalidación de caché.

## Datos clave
- **Tecnologías principales**: Next.js 15, React 19, TypeScript 5.8, Tailwind CSS 4.
- **Características técnicas**: Uso extensivo de React Server Components (RSC), Server Actions para mutaciones del carrito y revalidación de caché bajo demanda vía webhooks.
- **Funcionalidades**: Galerías de productos, selección de variantes, búsqueda en tiempo real, filtros por precio/título y carrito persistente con actualizaciones optimistas.
- **Infraestructura**: Hosting en Vercel (CDN edge) para caching rápido y gestión de variables de entorno.
