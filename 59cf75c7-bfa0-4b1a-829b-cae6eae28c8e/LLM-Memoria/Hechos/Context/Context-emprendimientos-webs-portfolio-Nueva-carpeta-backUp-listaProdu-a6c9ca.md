# listaProductos.md

## Resumen
Este archivo detalla el catálogo de productos disponibles para la tienda online, organizados por categorías como mascotas, cuidado personal y electrónica. Sirve como referencia interna para gestionar inventario, precios en UYU y códigos de producto antes de su implementación final en la web.

## Datos clave
- **Categorías**: Accesorios para mascotas, cuidado personal (aparatos eléctricos), electrónica e informática (cables, monitores, pendrives).
- **Moneda**: Todos los precios están expresados en UYU (Uruguayos).
- **Estructura de imágenes**: Las rutas de las imágenes siguen un patrón específico por categoría (`/img/Acc para mascotas/`, `/img/cuidadoPersonal/`, etc.).
- **Productos destacados**: Monitores portátiles Arzopa Z1FC y PM-18FPC, estación de carga 4 en 1 (TQ-6295) y cortapelos inalámbricos.
- **Formato**: Tabla Markdown con columnas para código, imagen, nombre del producto y precio.
