# Model.md

## Resumen
Este archivo registra la respuesta de una API que lista modelos de lenguaje disponibles en un entorno empresarial o premium. Sirve como referencia técnica para comparar capacidades, límites de contexto y costos de tokenización entre diferentes versiones de modelos de Anthropic.

## Datos clave
- **Modelos identificados**: Claude Fable 5, Claude Opus 4.7, Claude Opus 4.8-fast (entre otros).
- **Proveedores**: Todos bajo el vendor "Anthropic".
- **Límites técnicos**: Ventana de contexto máxima de 1 millón de tokens; salida máxima de 64k tokens.
- **Capacidades compartidas**: Soporte para visión, llamadas a herramientas, salidas estructuradas y streaming.
- **Restricciones de acceso**: Todos los modelos listados requieren planes "pro_plus", "business", "enterprise" o "max".
- **Precios de tokens (ejemplo Fable 5)**: Entrada $1000, Salida $5000 por millón; caché lectura/escritura a $100/$1250.
- **Endpoints soportados**: `/v1/messages` y `/chat/completions`.
