# prompt-sose-transporte.md

## Resumen
Este documento define las especificaciones técnicas para desarrollar una landing page corporativa para "Sose Transporte", enfocada en servicios de mudanzas y logística en Uruguay. El diseño debe seguir un estilo visual claro con elementos neumórficos y de vidrio esmerilado, utilizando exclusivamente fotografías reales y evitando ilustraciones o renders.

## Datos clave
- **Proyecto**: Landing Page Sose Transporte (Uruguay).
- **Tecnologías**: HTML5, CSS3, JavaScript puro (sin dependencias externas salvo logo).
- **Diseño**: Fondo degradado azul claro con bokeh; paneles de vidrio (`backdrop-filter: blur(18px)`); tipografía Plus Jakarta Sans/Inter.
- **Tarifas reales**: Camión chico $1.250, mediano $1.550, grande $1.750 (más IVA por hora, mínimo 2 horas).
- **Recursos visuales**: Fotos propias del cliente en prioridad; prohibido usar SVGs de camiones o ilustraciones.
- **Entregables**: `index.html`, `styles.css`, `script.js`, `README.md` y carpeta `img/`.
- **Comandos/Pasos**: Configurar enlaces a WhatsApp (`wa.me/59896779565`) y asegurar que el README documente el origen de las imágenes.
