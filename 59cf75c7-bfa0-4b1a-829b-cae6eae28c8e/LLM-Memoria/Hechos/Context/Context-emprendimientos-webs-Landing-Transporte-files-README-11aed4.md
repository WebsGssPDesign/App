# README.md

## Resumen
Este archivo README documenta la estructura y los pasos de personalización necesarios para publicar la landing page de "Sose Transporte". Sirve como guía técnica para actualizar activos visuales, configurar datos de contacto y validar información comercial antes del despliegue final.

## Datos clave
- **Archivos principales**: `index.html`, `styles.css`, `script.js` y carpeta `img/`.
- **Configuración de logo**: Debe guardarse como `img/logo.png`; si falta, se muestra texto alternativo.
- **Actualización de testimonios**: Reemplazar imágenes (`testimonio_1.jpg`, etc.) y textos por datos reales del cliente.
- **Contacto WhatsApp**: Modificar la variable `WA_NUMBER` en `script.js` y el número en el footer de `index.html`.
- **Fuentes personalizadas**: Copiar archivos `.woff2` a `fonts/` y descomentar las reglas `@font-face` en `styles.css`.
- **Validación comercial**: Confirmar tarifas por tamaño de camión (desde $1.250) y ajustar los logos de medios de pago según la realidad del negocio.
