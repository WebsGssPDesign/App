# Latin.txt

## Resumen
Este archivo contiene una lista de palabras en latín utilizadas como "stopwords" para el procesamiento de lenguaje natural, específicamente dentro del paquete `justext`. Su función es filtrar términos comunes y frecuentes que no aportan valor semántico significativo al análisis de textos históricos o académicos.

## Datos clave
- **Proyecto**: Paquete Python `justext` para extracción de párrafos en documentos antiguos.
- **Tecnologías**: Python, procesamiento de texto, NLP (Natural Language Processing).
- **Contenido**: Lista extensa de palabras latinas (ej: *et*, *in*, *est*, *anno*) y algunas formas conjugadas o nombres propios mezclados.
- **Ubicación**: Carpeta `stoplists` dentro del entorno virtual del proyecto (`venv_proyecto`).
- **Uso**: Se carga en memoria para ser ignorada durante la tokenización de corpus latinos.
