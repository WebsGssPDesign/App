# scrap.md

## Resumen
Este archivo contiene el código fuente de la interfaz de usuario (frontend) para "PrecioManager v2", una aplicación web diseñada para gestionar precios. Utiliza un diseño oscuro con acentos dorados y verdes, implementando una estructura de rejilla para estadísticas, formularios de entrada y tablas de datos interactivas.

## Datos clave
- Proyecto: PrecioManager v2 (GSSP).
- Tecnologías: HTML5, CSS3 (CSS Grid, Flexbox, Variables CSS), fuentes personalizadas (DM Mono, Syne, Inter) importadas desde Google Fonts.
- Decisiones de diseño: Paleta de colores personalizada con variables (`--bg`, `--gold`, etc.) para consistencia; enfoque en modo oscuro.
- Componentes UI: Barra superior con indicador de tasa, barra lateral de navegación activa, tarjetas de estadísticas, formularios con estados de error y tablas responsivas.
- Estilos específicos: Uso intensivo de clases utilitarias para bordes redondeados (`--radius`), transiciones suaves en botones y efectos hover en filas de tabla.
