# Marathi.txt

## Resumen
Este archivo es una lista de palabras clave (stopwords) en idioma marathi, utilizada para filtrar términos comunes y sin significado semántico durante el preprocesamiento de texto. Su función principal es mejorar la eficiencia de algoritmos de análisis de datos o modelos de IA al reducir el ruido lingüístico antes del procesamiento.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de procesamiento de lenguaje natural).
- **Tecnologías**: Python, librería `justext` (paquete de análisis de texto).
- **Decisión técnica**: Inclusión de palabras en inglés (ej. "the", "and") junto con las marathíes ("आहे", "व"), indicando que el filtro debe manejar código mixto o multilingüe.
- **Contenido específico**: Lista de 50+ términos frecuentes como preposiciones, artículos y verbos auxiliares (ej. "काही", "म्हणजे", "is").
- **Ubicación**: `venv_proyecto/Lib/site-packages/justext/stoplists/Marathi.txt`.
