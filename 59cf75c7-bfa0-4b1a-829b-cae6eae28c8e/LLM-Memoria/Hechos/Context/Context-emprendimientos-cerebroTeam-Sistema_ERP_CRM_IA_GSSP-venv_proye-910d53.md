# Bosnian.txt

## Resumen
Este archivo contiene una lista de palabras en bosnio utilizadas como "stopwords" para el procesamiento de lenguaje natural. Su función es filtrar términos comunes y frecuentes que no aportan significado semántico al análisis de textos, optimizando así algoritmos de extracción de información o minería de datos.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de procesamiento de texto).
- **Tecnologías**: Python (`justext` library), PLN (Procesamiento del Lenguaje Natural).
- **Decisiones**: Inclusión de palabras específicas como "Bosna", "BiH", "Hercegovine" y nombres propios locales ("Sarajevo") junto con conectores estándar.
- **Contenido**: Listado extenso de artículos, preposiciones, verbos auxiliares y pronombres en minúsculas y mayúsculas (ej: `je`, `od`, `BiH`, `Godine`).
