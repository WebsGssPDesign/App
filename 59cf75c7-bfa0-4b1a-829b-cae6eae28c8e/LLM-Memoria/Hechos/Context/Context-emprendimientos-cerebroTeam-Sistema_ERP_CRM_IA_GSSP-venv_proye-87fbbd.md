# Romanian.txt

## Resumen
Este un archivo de texto que contiene una lista de palabras en rumano, identificadas como "stopwords" o palabras vacías. Su función principal es servir como referencia para procesadores de lenguaje natural y algoritmos de análisis de texto, permitiendo filtrar términos comunes sin significado semántico específico durante tareas como la extracción de temas o el cálculo de TF-IDF.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (contexto del proyecto).
- **Tecnologías**: `justext` (librería Python para análisis de texto), entorno virtual (`venv_proyecto`).
- **Contenido**: Lista de palabras frecuentes en rumano (ej. "de", "în", "și", "România") y algunos nombres propios geográficos o históricos mezclados ("București", "Germania").
- **Decisión técnica**: Inclusión de términos específicos como meses ("ianuarie"), números ("doi", "trei") y entidades locales ("județul", "comuna") en la lista de exclusión.
