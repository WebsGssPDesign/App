# prompt-sose-transporte.md

## Resumen
Este documento define las especificaciones técnicas para el desarrollo de una landing page corporativa para "Sose Transporte", enfocada en servicios de mudanzas y logística. Su objetivo es crear un sitio visualmente impactante que combine estilos neumórficos y glassmorphism, priorizando el uso de fotografías reales sobre ilustraciones para generar confianza.

## Datos clave
- **Cliente:** Sose Transporte (Uruguay).
- **Estilo:** Neumorphic Glass Corporate (modo oscuro con relieves suaves y paneles translúcidos).
- **Paleta de colores:** Azul oscuro base (`#0A0F1C`), acento naranja (`#F97316`) y verde WhatsApp (`#25D366`).
- **Tipografía:** Plus Jakarta Sans (títulos) e Inter (cuerpo).
- **Tarifas reales:** Camión Chico ($1.250/h), Mediano ($1.550/h) y Grande ($1.750/h), con mínimo de 2 horas.
- **Requisito crítico:** Uso exclusivo de fotos reales de camiones y mudanzas; prohibido el uso de SVGs o renders 3D como imágenes principales.
- **Entrega:** Archivos separados (`index.html`, `styles.css`, `script.js`) y carpeta `/img/`.
