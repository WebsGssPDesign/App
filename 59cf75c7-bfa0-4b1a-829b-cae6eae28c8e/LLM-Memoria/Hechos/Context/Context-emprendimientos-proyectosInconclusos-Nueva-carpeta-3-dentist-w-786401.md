# robots.txt

## Resumen
Este archivo de robots.txt permite que todos los bots de búsqueda indexen y rastreen todo el contenido del sitio web sin restricciones. Su función principal es facilitar la visibilidad de las páginas en motores como Google, asegurando un acceso total al catálogo dental.

## Datos clave
- Proyecto: Sitio web para clínica dental (dentist-website).
- Configuración: `User-agent: *` aplica a todos los agentes; `Disallow:` está vacío, permitiendo el rastreo completo de todas las rutas.
- Ubicación: `/public/robots.txt`.
