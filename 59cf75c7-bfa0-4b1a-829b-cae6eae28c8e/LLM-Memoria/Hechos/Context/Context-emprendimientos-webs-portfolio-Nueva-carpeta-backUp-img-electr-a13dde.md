# costos.txt

## Resumen
Este documento es un listado de precios al por menor para una variedad de accesorios electrónicos y periféricos, incluyendo cables de carga y datos, monitores portátiles y dispositivos de almacenamiento. Sirve como referencia comercial para consultar el costo unitario con impuestos (IVA) y los códigos internos de cada producto disponible en el inventario.

## Datos clave
- **Proyecto**: Catálogo de precios de accesorios electrónicos (TREQA).
- **Productos destacados**: Monitores gamer y portátiles, estaciones de carga 4/5 en 1, pendrives USB 3.0 y lectores de tarjetas universales.
- **Categorías principales**: Cables HDMI/Premium 4K, adaptadores de audio/video, combinados teclado/mouse y calculadoras científicas.
- **Formato de precio**: Todos los valores están expresados en USD más IVA (ej: USD3,50 +IVA).
- **Identificación**: Cada ítem posee un código único específico (ej: CA-8974, Z1FC, UP03-64) para su referencia interna.
