# LandingPageN8N.md

## Resumen
Este documento define un prompt universal para crear landing pages premium en modo oscuro. Su función es guiar a una IA para que primero genere imágenes coherentes (logo, servicios, hero) y luego construya el sitio web basándose en respuestas del usuario sobre su negocio y sector.

## Datos clave
- **Proyecto:** Generación de Landing Page Premium Dark Mode.
- **Flujo obligatorio:** Recoger 3 preguntas (Negocio, Sector/Estilo, Color) -> Generar imágenes antes del código -> Crear la web.
- **Tecnologías implícitas:** IA generativa de imágenes (Midjourney/DALL-E), desarrollo web frontend.
- **Decisiones de diseño:** Estética "Dark Luxury", fondos oscuros, uso de color de acento específico en todos los activos visuales.
- **Estructura de archivos:** `/images/` con nombres específicos (`logo.png`, `service_1.png`, `hero_visual.png`).
- **Requisitos técnicos:** Resolución mínima 800px, formatos PNG/WebP, sin texto dentro de las imágenes generadas (excepto logo).
