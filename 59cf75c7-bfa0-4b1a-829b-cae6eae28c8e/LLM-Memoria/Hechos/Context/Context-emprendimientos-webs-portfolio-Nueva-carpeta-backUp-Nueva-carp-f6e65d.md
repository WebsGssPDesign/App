# costos.txt

## Resumen
Este archivo es un inventario de precios en dólares estadounidenses para una variedad de accesorios informáticos y electrónicos, incluyendo cables, cargadores, periféricos y dispositivos portátiles. Su función principal es servir como referencia comercial o base de datos interna para la gestión de costos y ventas del emprendimiento.

## Datos clave
- **Proyecto**: Gestión de catálogo de productos "Informática".
- **Decisiones**: Precios listados en USD más IVA; códigos de producto específicos (ej. CA-8974, TQ-6318).
- **Productos destacados**: Monitores portátiles Arzopa Z1FC ($140), Estaciones de carga 5 en 1 ($25) y Pendrives USB 3.0 de 32GB a 64GB.
- **Categorías principales**: Cables HDMI/USB, adaptadores, teclados/mouses, calculadoras y memorias flash.
