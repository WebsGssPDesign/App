# Latvian.txt

## Resumen
Este archivo contiene una lista de palabras en latín (stopwords) utilizadas para el procesamiento de texto en idioma letón. Su función principal es filtrar términos comunes y sin significado semántico durante tareas de análisis de datos, extracción de información o entrenamiento de modelos de inteligencia artificial.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de procesamiento lingüístico).
- **Tecnologías**: Python (paquete `justext`), NLP (Natural Language Processing).
- **Decisiones**: Selección de un diccionario específico para el idioma letón (`Latvian.txt`) dentro del entorno virtual del proyecto.
- **Contenido**: Lista extensa de artículos, preposiciones y conectores frecuentes en latín (ej: *un*, *ir*, *ar*, *no*, *par*, *viņš*, *var*).
- **Uso técnico**: Se utiliza para limpiar corpus textuales antes de la indexación o análisis semántico.
