# French.txt

## Resumen
Este archivo contiene una lista de palabras en francés identificadas como "stopwords" o términos comunes. Su función principal es filtrar estas palabras frecuentes durante el procesamiento de texto para mejorar la eficiencia y precisión en tareas de análisis lingüístico, como la extracción de temas o la búsqueda de información relevante.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de procesamiento de lenguaje natural).
- **Tecnologías**: Python (`justext` library), análisis de texto en francés.
- **Decisiones**: Inclusión de palabras específicas como nombres propios ("Paris", "France"), meses ("janvier", "juin") y conceptos generales ("guerre", "politique") para su eliminación automática.
- **Contenido**: Lista extensa de artículos, preposiciones, verbos auxiliares y sustantivos comunes en francés (ej: "de", "la", "être", "homme").
