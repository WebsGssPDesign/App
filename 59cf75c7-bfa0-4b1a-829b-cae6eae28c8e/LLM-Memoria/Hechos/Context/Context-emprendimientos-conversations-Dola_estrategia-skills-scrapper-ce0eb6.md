# skills-scrapper.md

## Resumen
Este documento detalla el perfil técnico y estratégico necesario para desarrollar una aplicación web de e-commerce y automatización de datos. Su propósito es guiar al equipo en la selección de tecnologías, desde el frontend hasta las funciones de scraping y gestión financiera.

## Datos clave
- **Frontend:** HTML5, CSS3 (Tailwind/Bootstrap), JavaScript ES6+, Service Workers para modo offline.
- **Backend & DB:** Supabase (PostgreSQL, Auth, Storage) con Edge Functions recomendadas para la lógica del scraper.
- **Scraping:** Uso de Cheerio o Puppeteer en Node.js; manejo de selectores CSS/XPath y estrategias anti-bloqueo.
- **Negocio:** Estrategia de precios, cálculo de márgenes, análisis de competencia y gestión de gastos operativos.
- **Infraestructura:** Control de versiones con Git e integración con APIs de tipo de cambio.
