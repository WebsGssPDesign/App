# README.md

## Resumen
Este archivo documenta una plantilla de proyecto para aplicaciones React integradas en Vite, diseñada para ofrecer un entorno de desarrollo minimalista y rápido. Sirve como punto de partida estándar que incluye configuración básica de HMR (Hot Module Replacement) y reglas de ESLint para asegurar la calidad del código desde el inicio.

## Datos clave
- **Proyecto**: Plantilla oficial React + Vite (`create-vite`)
- **Tecnologías**: React, Vite, Babel o SWC (para compilación rápida), ESLint
- **Plugins oficiales disponibles**: `@vitejs/plugin-react` y `@vitejs/plugin-react-swc`
- **React Compiler**: Deshabilitado por defecto debido a impactos en el rendimiento de desarrollo y construcción; requiere configuración manual si se desea activar.
- **Recomendación para producción**: Se sugiere usar la plantilla TypeScript (`template-react-ts`) para habilitar reglas de linting con tipos.
