# costos.txt

## Resumen
Este documento actúa como un inventario de precios y códigos para productos de cuidado personal, específicamente electrodomésticos pequeños. Sirve como referencia interna para la gestión de costos o la configuración del catálogo en el sitio web del emprendimiento.

## Datos clave
- **Proyecto**: Catálogo de productos "Cuidado Personal" para la web del portfolio.
- **Tecnologías/Formato**: Texto plano estructurado con nombre, precio (USD + IVA) y código único.
- **Decisiones**: Se listan múltiples modelos de afeitadoras eléctricas con precios variables entre 1 y 2 USD.
- **Rutas**: El archivo se encuentra en una estructura profunda de carpetas de respaldo (`backUp/Nueva carpeta`).
- **Pasos importantes**: Identificar productos duplicados (ej. "MINI AFEITADORA ELECTRICA" aparece tres veces con códigos distintos) y validar la consistencia de los precios antes de subirlos al sistema.
