# costos.txt

## Resumen
Este archivo detalla un inventario de productos electrónicos y accesorios informáticos, listando descripciones, precios en dólares estadounidenses con IVA, códigos internos y categorías como cables, periféricos y dispositivos portátiles. Su función principal es servir como catálogo de referencia para la gestión de stock, cotizaciones comerciales o control de costos en una tienda minorista especializada.

## Datos clave
- **Proyecto:** Catálogo de precios para emprendimiento de electrónica.
- **Tecnologías/Productos destacados:** Cables HDMI (1.5m a 10m), adaptadores USB-C y Lightning, monitores portátiles (Arzopa Z1FC, PM-18FPC), smartwatch T20 Ultra, pendrives USB 3.0 y lectores de tarjetas universales.
- **Decisiones:** Se incluyen precios base en USD más IVA para cada ítem; se registran múltiples variantes de longitud y especificación (ej. carga rápida vs estándar).
- **Códigos de referencia:** Rango desde CA-8974 hasta Z1FC, con prefijos como TQ, HDTV, MD, KT, UP y AUX.
