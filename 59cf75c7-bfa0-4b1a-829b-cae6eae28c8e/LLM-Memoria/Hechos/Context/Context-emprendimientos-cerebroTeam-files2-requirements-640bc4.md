# requirements.txt

## Resumen
Este archivo lista las dependencias de Python necesarias para ejecutar la aplicación del proyecto cerebroTeam. Permite instalar las librerías requeridas para el procesamiento de datos, la búsqueda semántica y el despliegue del servicio web.

## Datos clave
- **Proyecto**: cerebroTeam (contexto: emprendimientos).
- **Tecnologías**: Python, FastAPI, ChromaDB, sentence-transformers.
- **Decisiones**: Se seleccionó `sentence-transformers` para embeddings y `chromadb` para gestión de vectores; se optó por `uvicorn` como servidor ASGI.
- **Herramientas de scraping**: `beautifulsoup4`, `trafilatura`, `requests`.
- **Utilidades**: `schedule` para tareas programadas, `pydantic` para validación de datos.
