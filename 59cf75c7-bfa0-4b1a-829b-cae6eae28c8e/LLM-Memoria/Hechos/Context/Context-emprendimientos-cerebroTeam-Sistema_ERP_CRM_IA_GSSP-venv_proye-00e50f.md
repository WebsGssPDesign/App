# Albanian.txt

## Resumen
Este archivo contiene una lista de palabras en albanés utilizadas como "stopwords" para el procesamiento de lenguaje natural. Su función es filtrar términos gramaticales frecuentes (como artículos, preposiciones y pronombres) durante la limpieza de datos textuales antes del análisis o indexación.

- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de texto).
- **Tecnologías**: Python (`justext`), librería `stoplists`.
- **Contenido**: Lista de 300+ palabras albanesas en minúsculas y mayúsculas (ej: të, e, në, dhe, i).
- **Ubicación**: Ruta `/venv_proyecto/Lib/site-packages/justext/stoplists/Albanian.txt`.
