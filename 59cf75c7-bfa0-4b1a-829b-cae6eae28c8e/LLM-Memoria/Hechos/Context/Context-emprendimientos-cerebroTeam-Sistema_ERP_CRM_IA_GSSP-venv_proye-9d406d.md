# Haitian.txt

## Resumen
Este archivo es una lista de palabras en haitiano (criollo) utilizada como diccionario de "stopwords" para el procesamiento de lenguaje natural. Su función principal es filtrar términos comunes y sin significado semántico específico antes de analizar textos o realizar minería de datos en este idioma.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de análisis lingüístico).
- **Tecnologías**: Python, librería `justext`.
- **Idioma**: Haitiano (criollo haitiano).
- **Contenido**: Lista de palabras frecuentes como "se", "an", "peyi" y nombres propios como "Ayiti" que deben ser excluidos del análisis.
