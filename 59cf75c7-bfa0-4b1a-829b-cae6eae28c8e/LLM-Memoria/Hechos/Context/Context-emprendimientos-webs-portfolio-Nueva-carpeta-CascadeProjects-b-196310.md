# costos.txt

## Resumen
Este archivo detalla el catálogo de costos y códigos internos para una variedad de productos de cuidado personal y belleza. Sirve como referencia administrativa para la gestión de inventario, facturación o control de precios en dólares estadounidenses más impuestos.

## Datos clave
- **Proyecto**: Gestión de costos para emprendimientos de cuidado personal.
- **Productos listados**: Masajeador de cuello, limpiador facial exfoliante, rizadores automáticos, planchas de pelo (mini y estándar), depiladoras recargables, afeitadoras eléctricas y cortapelos inalámbricos con diversos accesorios o diseños grabados.
- **Formato de precio**: Todos los ítems incluyen el valor base en USD seguido del indicador "+IVA".
- **Identificación**: Cada producto posee un código único alfabético-numérico (ej: MX-6, MU-006, KM-9831).
- **Observación**: Se detectan duplicados de descripción ("MINI AFEITADORA ELECTRICA") con códigos distintos y precios variables.
