# Icelandic.txt

## Resumen
Este archivo contiene la lista de palabras en noruego (aunque el contenido es islandés) que deben ser excluidas durante el proceso de extracción y análisis de texto. Su función principal es filtrar artículos, preposiciones, conjunciones y nombres propios comunes para permitir a herramientas como Justext centrarse únicamente en los términos significativos del documento.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de procesamiento de lenguaje natural).
- **Tecnologías**: Python, librería `justext`.
- **Decisión técnica**: Se utiliza un archivo de listas de parada específico para el idioma islandés (`Icelandic.txt`) dentro del entorno virtual del proyecto.
- **Contenido procesado**: La lista incluye palabras como "og", "er", "íslenskt" y nombres propios comunes como "Reykjavík", "Jón", "Alþingi" y meses ("janúar", "febrúar"). También contiene referencias a entidades históricas y geográficas de Islandia.
- **Uso**: Alimentar el algoritmo de segmentación de párrafos para mejorar la calidad del análisis semántico posterior.
