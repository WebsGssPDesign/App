# README.md

## Resumen
Este archivo documenta el despliegue local de una aplicación de inteligencia artificial desarrollada en Google AI Studio, permitiendo ejecutarla en un entorno de desarrollo personal antes de su implementación final. Sirve como guía técnica para configurar los requisitos previos y lanzar la herramienta utilizando las claves de API correspondientes.

## Datos clave
- Proyecto: Aplicación de IA (AI Studio)
- Tecnologías: Node.js, Google Gemini API
- Decisiones: Uso de entorno local con variables de configuración en `.env.local`
- Rutas/Comandos: `npm install`, `npm run dev`
- Variables críticas: `GEMINI_API_KEY`
