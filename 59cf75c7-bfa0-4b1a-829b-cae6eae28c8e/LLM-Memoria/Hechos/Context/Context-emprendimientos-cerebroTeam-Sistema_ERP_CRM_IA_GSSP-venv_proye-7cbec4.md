# Hebrew.txt

## Resumen
Este archivo contiene una lista de palabras en hebreo identificadas como "stopwords" o palabras vacías, utilizadas comúnmente para filtrar el vocabulario básico antes del procesamiento de lenguaje natural. Su función principal es mejorar la eficiencia y precisión de algoritmos de análisis de texto al eliminar términos que aportan poco significado semántico.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de procesamiento de texto).
- **Tecnologías**: Python (`justext`), Hebreo.
- **Decisiones**: Selección de un diccionario específico para normalización lingüística en hebreo.
- **Contenido**: Lista de 300+ términos comunes (ej: "של", "את", "הוא") y algunas palabras en inglés ("of", "The", "de").
