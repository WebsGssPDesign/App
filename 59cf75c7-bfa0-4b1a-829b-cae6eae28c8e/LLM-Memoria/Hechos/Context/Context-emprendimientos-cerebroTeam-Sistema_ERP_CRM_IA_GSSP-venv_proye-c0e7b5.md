# Igbo.txt

## Resumen
Este archivo es una lista de palabras clave (stopwords) en idioma Igbo utilizada para el preprocesamiento de texto. Su función principal es filtrar términos comunes y sin significado semántico específico antes de analizar documentos o datos lingüísticos en este dialecto.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de procesamiento de lenguaje natural).
- **Tecnologías**: Python, librería `justext`.
- **Decisiones**: Inclusión de términos mixtos como "Gregorian", "leap year" y nombres propios ("Wikipedia", "Amerika") dentro del corpus de stopwords.
- **Ruta**: `/venv_proyecto/Lib/site-packages/justext/stoplists/Igbo.txt`.
