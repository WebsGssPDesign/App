## Resumen
Este archivo detalla un inventario de productos de hogar y cocina, listando descripciones breves, precios en dólares estadounidenses con IVA y sus códigos internos únicos. Sirve como referencia comercial para gestionar el stock, realizar cotizaciones o actualizar catálogos de venta de artículos de limpieza, almacenamiento y electrodomésticos pequeños.

- **Proyecto**: Gestión de catálogo de productos "Hogar".

- **Decisiones**: Todos los precios incluyen IVA; se utiliza la moneda USD.
- **Rutas/Categorías**: Hogar, Cocina, Limpieza, Almacenamiento.
