# robots.txt

## Resumen
Este archivo `robots.txt` instruye a los bots de búsqueda para que accedan a todo el sitio web y les proporciona la ubicación del mapa del sitio principal. Su función es facilitar el rastreo e indexación correcta de las páginas por motores como Google.

## Datos clave
- Proyecto: CascadeProjects (gsspminimarketuy.com)
- Tecnologías: Protocolo HTTP, estándar robots.txt
- Rutas permitidas: `/` (todo el sitio)
- Comandos importantes: `User-agent: *`, `Allow: /`
- Recursos externos: Sitemap index en `https://gsspminimarketuy.com/sitemap-index.xml`
