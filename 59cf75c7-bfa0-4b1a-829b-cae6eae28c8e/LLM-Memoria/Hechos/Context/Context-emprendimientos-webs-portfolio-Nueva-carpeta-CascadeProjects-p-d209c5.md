# EDGE_FUNCTIONS_DEPLOY.md

## Resumen
Este documento detalla el despliegue de funciones serverless (Edge Functions) para el proyecto MinimarketUy utilizando Supabase y Deno. Su objetivo es reemplazar las rutas API del frontend estático, permitiendo acceso seguro a secretos y escalado automático sin necesidad de servidores Node.js.

## Datos clave
- **Proyecto**: MinimarketUy (`qoamfkvhmefuefobdzll`).
- **Tecnologías**: Supabase Edge Functions, Deno Deploy, TypeScript.
- **Funciones creadas**: `checkout`, `contact`, `webhook`.
- **Secretos configurados**: `MP_ACCESS_TOKEN` y `SITE_URL`.
- **Métodos de despliegue**: Dashboard (manual) o CLI (`supabase functions deploy`).
- **Comandos importantes**: `winget install Supabase.CLI`, `supabase link --project-ref qoamfkvhmefuefobdzll`, `supabase secrets set`.
