## Resumen
Este archivo documenta la configuración inicial de una aplicación web tipo Landing Page construida con React y Vite. Sirve como guía rápida para instalar dependencias, iniciar el entorno en modo desarrollo y generar la versión optimizada lista para producción.

- **Proyecto**: Landing page en React.
- **Tecnologías**: React, Vite.
- **Comandos principales**: `npm install` (instalación), `npm run dev` (desarrollo), `npm run build` (compilación).
- **Rutas de archivos**: Datos editables en `src/data.js`, estilos en `src/styles.css` y activos en `public/assets`.
