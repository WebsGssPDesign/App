# crm.md

## Resumen
Este archivo define la estructura visual y el diseño de interfaz para un sistema CRM llamado GSSP, enfocado en la gestión de leads. Establece una paleta de colores basada en tonos azul oscuro y acentos vibrantes, junto con tipografías específicas para asegurar una estética moderna y coherente.

## Datos clave
- **Proyecto:** GSSP CRM (Sistema de Gestión de Leads).
- **Tecnologías:** HTML5, CSS3 moderno (Grid, Flexbox, Variables CSS `:root`).
- **Decisiones de diseño:** Uso de fuentes 'DM Mono', 'Fraunces' y 'DM Sans'; esquema de colores con variables para consistencia.
- **Componentes principales:** Barra superior (`topbar`) con indicadores de estado animados; barra lateral (`sidebar`) con navegación activa y badges; panel principal (`main`) con tarjetas estadísticas (`stat-grid`).
- **Estilos específicos:** Animación `pulse-dot` para indicadores verdes/naranjas; efectos de brillo (`glow`) en fondos azules y naranjas; diseño responsivo con scrollbars personalizados.
