# German.txt

## Resumen
Este archivo contiene una lista de palabras en alemán (stopwords) utilizadas para filtrar términos comunes y sin valor semántico durante el procesamiento de texto. Su función principal es optimizar algoritmos de análisis lingüístico, como la extracción de temas o la clasificación de documentos, al eliminar ruido estadístico del corpus original.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de procesamiento de lenguaje natural).
- **Tecnologías**: Python (`justext`), análisis de texto en alemán.
- **Decisiones**: Inclusión de formas flexionadas y nombres propios frecuentes (ej: "Berlin", "Deutschland", "Jahr") para mejorar la precisión del filtrado en contextos históricos o biográficos.
- **Pasos importantes**: Carga del archivo `German.txt` dentro del entorno virtual (`venv_proyecto`) para inicializar el diccionario de exclusiones antes de ejecutar scripts de limpieza de datos.
