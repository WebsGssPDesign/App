# Finnish.txt

## Resumen
Este archivo contiene una lista de palabras en finés (y algunas en inglés) identificadas como "stopwords" o palabras vacías. Sirve para filtrar el vocabulario común y frecuente durante procesos de análisis de texto, limpieza de datos o preparación de corpus lingüísticos para mejorar la precisión en tareas de procesamiento del lenguaje natural.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de análisis de texto).
- **Tecnologías**: Python (`justext` library), Procesamiento de Lenguaje Natural (NLP).
- **Decisiones**: Inclusión de palabras en mayúsculas y minúsculas para cubrir variaciones gramaticales.
- **Contenido**: Lista extensa de artículos, preposiciones, verbos auxiliares y conectores comunes en finés (ej: *ja*, *on*, *että*) junto con términos como "The", "New" o nombres propios genéricos ("John", "David").
