# Korean.txt

## Resumen
Este archivo contiene una lista de palabras en coreano identificadas como "stopwords" o términos de alto frecuencia, comúnmente utilizados para filtrar el ruido léxico durante el procesamiento y análisis de texto. Su función principal es mejorar la eficiencia de algoritmos de IA al excluir palabras sin significado semántico sustancial antes de tareas como la clasificación o la extracción de temas.

## Datos clave
- **Proyecto**: Sistema ERP CRM con integración de Inteligencia Artificial (IA).
- **Tecnologías**: Python (entorno `venv_proyecto`), librería `justext`.
- **Decisiones**: Implementación de listas de detener específicas para el idioma coreano dentro del paquete de procesamiento de texto.
- **Contenido**: Lista extensa de palabras comunes como "있다" (existir), "그" (él/eso), nombres de años (ej. 2008 년, 1995 년) y meses (ej. 3 월).
