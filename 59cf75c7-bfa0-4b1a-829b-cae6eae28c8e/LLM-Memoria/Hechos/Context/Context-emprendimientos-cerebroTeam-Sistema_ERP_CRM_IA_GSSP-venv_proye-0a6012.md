# Norwegian_Bokmal.txt

## Resumen
Este archivo contiene una lista de palabras en noruego (bokmål) identificadas como comunes o de alto frecuencia. Su función principal es servir como diccionario de "stopwords" para filtrar términos irrelevantes durante el procesamiento y análisis de textos, mejorando la precisión en tareas de minería de datos o NLP.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de preprocesamiento de texto).
- **Tecnologías**: Python (paquete `justext`), idioma Noruego Bokmål.
- **Decisiones**: Inclusión de palabras con mayúsculas iniciales (ej: "I", "Det") y términos específicos como meses ("januar"), nombres propios ("Oslo", "Norge") y siglas ("OL", "VM").
- **Contenido**: Aproximadamente 400 tokens que incluyen verbos auxiliares, artículos, preposiciones y conectores.
