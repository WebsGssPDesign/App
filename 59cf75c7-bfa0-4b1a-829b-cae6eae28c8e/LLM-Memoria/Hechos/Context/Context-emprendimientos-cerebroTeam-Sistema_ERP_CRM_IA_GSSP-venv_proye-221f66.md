# Estonian.txt

## Resumen
Este archivo contiene una lista de palabras en estonio que funcionan como "stopwords" o términos comunes, frecuentemente utilizados para filtrar contenido irrelevante durante el procesamiento y análisis de texto. Su propósito principal es optimizar algoritmos de búsqueda, clasificación temática o minería de datos al eliminar ruido léxico.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de análisis de texto).
- **Tecnologías**: Python (`justext`), procesamiento de lenguaje natural (NLP).
- **Decisiones**: Inclusión de nombres propios locales (Eesti, Tallinna, Tartu) y entidades geográficas específicas en la lista de exclusión.
- **Contenido**: Lista extensa de artículos, preposiciones, verbos auxiliares y conectores estonios (ej: "ja", "oli", "kui").
