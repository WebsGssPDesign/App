# README.md

## Resumen
Este archivo documenta el inicio de un proyecto web para una clínica dental creado con Create React App. Sirve como guía para ejecutar scripts locales, construir la aplicación en producción y acceder a documentación oficial sobre React y despliegue.

## Datos clave
- **Proyecto**: Sitio web para dentista (dentist-website).
- **Tecnologías**: React, Create React App, Webpack, Babel, ESLint.
- **Comandos principales**: `npm start` (modo desarrollo en localhost:3000), `npm test` (ejecución de pruebas), `npm run build` (compilación para producción).
- **Decisión importante**: El comando `npm run eject` es irreversible; tras ejecutarlo, las dependencias de configuración se copian al proyecto y el usuario pierde la gestión automática del entorno.
