# Maltese.txt

## Resumen
Este archivo es una lista de palabras en malglo (idioma maltés) utilizada para filtrar términos comunes y frecuentes durante el procesamiento de texto. Su función principal es mejorar la calidad del análisis lingüístico al eliminar ruido estadístico, permitiendo centrarse en vocabulario significativo para tareas como la extracción de entidades o la clasificación temática.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de procesamiento de lenguaje natural).
- **Tecnologías**: Python (`justext`), análisis de texto, filtrado léxico.
- **Decisiones**: Inclusión de términos específicos de biología (ej. "Mammalia", "marsupial") y deportes ("Futbol", "Premier League") que aparecen con alta frecuencia en los datos de entrenamiento o contexto del sistema.
- **Contenido**: Lista de stopwords maltesas como 'u', 'li', 'kien', 'meta', entre otras, mezcladas con fragmentos de texto contextual (ej. referencias a Manchester United, opossums).
