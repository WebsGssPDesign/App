# Italian.txt

## Resumen
Este archivo contiene una lista de palabras en italiano identificadas como "stopwords", es decir, términos muy frecuentes que no aportan significado semántico relevante. Sirve para filtrar el ruido léxico durante procesos de análisis de texto o procesamiento del lenguaje natural (NLP), permitiendo centrarse en las palabras clave informativas.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de preprocesamiento de datos).
- **Tecnologías**: Python, librería `justext`.
- **Contenido**: Lista de 350+ tokens comunes (artículos, preposiciones, verbos auxiliares) como "di", "e", "il", "la", "in", "che".
- **Decisiones**: Inclusión de variantes con mayúsculas iniciales ("Il", "La") y palabras en inglés mezcladas ("of", "the", "New").
- **Uso**: Eliminación automática de estos términos al indexar o analizar documentos corporativos.
