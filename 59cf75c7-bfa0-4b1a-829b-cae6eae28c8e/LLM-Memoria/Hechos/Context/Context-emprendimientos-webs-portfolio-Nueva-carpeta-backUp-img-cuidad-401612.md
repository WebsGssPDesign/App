# costos.txt

## Resumen
Este archivo detalla una lista de precios para diversos productos de cuidado personal y belleza importados, especificando costos en dólares estadounidenses más IVA junto con sus códigos internos. Sirve como referencia comercial o inventario para el emprendimiento que gestiona estas ventas.

## Datos clave
- **Proyecto**: Gestión de catálogo de productos de belleza y afeitado.
- **Productos listados**: Masajeador de cuello, limpiador facial exfoliante, rizadores, planchas de pelo, depiladoras recargables, afeitadoras eléctricas (mini y estándar) y cortapelos inalámbricos con diseños grabados o accesorios.
- **Rango de precios**: Desde USD 1 hasta USD 9 más IVA.
- **Identificadores únicos**: Códigos alfanuméricos asociados a cada ítem (ej: MX-6, MU-006, KM-9831, HL-020).
