# Aragonese.txt

## Resumen
Este archivo es una lista de palabras en aragonés, específicamente un conjunto de "stopwords" o términos frecuentes que se eliminan durante el procesamiento de lenguaje natural. Su función principal es optimizar algoritmos de análisis de texto al filtrar vocabulario común que no aporta significado semántico relevante para tareas como la búsqueda de información o el modelado lingüístico en esta lengua romance.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de procesamiento de lenguaje).
- **Tecnologías**: Biblioteca `justext` dentro del entorno virtual Python (`venv_proyecto`).
- **Contenido**: Lista de 120+ términos aragoneses (ej: "de", "en", "que", "población") y algunos datos geográficos como "km²" o "habitants".
- **Decisión técnica**: Inclusión de variantes ortográficas y formas contraídas (ej: "d'a", "d'o", "l'anyo") para mejorar la precisión del filtrado en textos aragoneses.
