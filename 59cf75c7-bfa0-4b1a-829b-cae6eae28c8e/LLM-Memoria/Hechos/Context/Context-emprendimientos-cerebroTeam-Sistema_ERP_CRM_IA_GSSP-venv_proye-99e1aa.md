# Macedonian.txt

## Resumen
Este archivo contiene una lista de palabras en macedonio identificadas como "stopwords" o palabras vacías. Su función principal es optimizar el procesamiento de texto al permitir a los algoritmos ignorar términos comunes y frecuentes que no aportan significado semántico relevante para tareas de análisis de datos, filtrado o indexación.

## Datos clave
- **Proyecto**: Sistema de extracción de texto (`justext`) dentro del entorno virtual `venv_proyecto`.
- **Tecnologías**: Python (paquete `justext`), idioma macedonio.
- **Decisiones**: Inclusión de palabras con mayúsculas iniciales y variaciones ortográficas (ej: "година", "година.").
- **Contenido**: Lista extensa de preposiciones, artículos, pronombres y conectores comunes en el idioma macedonio.
