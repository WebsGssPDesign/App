# costos.txt

## Resumen
Este documento detalla un catálogo de precios para diversos artículos de iluminación solar y LED, incluyendo focos exteriores con sensores, paneles encastrables y guías decorativas. Sirve como referencia comercial para la adquisición de estos componentes en proyectos de emprendimiento o construcción.

## Datos clave
- **Proyecto**: Iluminación exterior e interior (escaleras, áreas comunes).
- **Tecnologías**: LED solar con sensor de movimiento, RGB con control remoto/app, paneles cuadrados y redondos (frío/cálido), módulos hexagonales táctiles.
- **Decisiones de compra**: Selección basada en potencia (12W a 50W), tipo de instalación (encastrable vs. superficie) y funcionalidad (sensor, app).
- **Rutas/Identificadores**: Códigos específicos para cada ítem (ej. SE-864, FXCOB-50, LEC-24WC).
- **Comandos/Pasos**: Verificar precios en USD + IVA antes de solicitar cotización formal.
