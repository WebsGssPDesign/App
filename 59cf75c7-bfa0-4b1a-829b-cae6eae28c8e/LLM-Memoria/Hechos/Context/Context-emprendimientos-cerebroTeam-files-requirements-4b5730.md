# requirements.txt

## Resumen
Este archivo lista las dependencias de Python necesarias para ejecutar la aplicación del proyecto cerebroTeam. Sirve como referencia técnica para instalar el entorno y garantizar que todas las librerías requeridas estén disponibles antes de iniciar los servicios o realizar análisis de datos.

## Datos clave
- **Proyecto**: cerebroTeam
- **Tecnologías principales**: FastAPI (backend), ChromaDB (base de datos vectorial), Sentence Transformers (procesamiento de lenguaje natural).
- **Herramientas de scraping**: BeautifulSoup4, Trafilatura para la extracción web.
- **Utilidades**: Requests para peticiones HTTP, Schedule para tareas programadas, Pydantic para validación de datos.
- **Servidor**: Uvicorn como servidor ASGI para ejecutar FastAPI.
