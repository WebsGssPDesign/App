# costos.txt

## Resumen
Este archivo detalla el catálogo de productos para la línea Hogar, especificando nombres comerciales, precios en dólares estadounidenses con IVA y códigos internos únicos. Su función principal es servir como referencia comercial o base de datos interna para gestionar inventario y facturación de artículos de cocina, limpieza y almacenamiento.

- **Identificación**: Cada ítem posee un código único (ej. YH6616-2, KR65, BM-3L) para su rastreo específico.
