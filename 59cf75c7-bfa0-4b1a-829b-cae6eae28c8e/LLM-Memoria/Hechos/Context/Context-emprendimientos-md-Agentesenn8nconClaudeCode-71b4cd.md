# Agentesenn8nconClaudeCode.md

## Resumen
Este archivo es una guía técnica sobre la creación de agentes autónomos utilizando la herramienta n8n y el modelo de lenguaje Claude Code. Su propósito principal es enseñar a los usuarios cómo diseñar prompts efectivos para orquestar flujos de trabajo complejos que automatizan tareas empresariales mediante inteligencia artificial.

## Datos clave
- **Proyecto:** Curso "IA Founders Skool", Módulo 6 sobre agentes en n8n con Claude Code.
- **Tecnologías:** Plataforma de automatización n8n, modelo de IA Claude Code (Anthropic), HTML/CSS para la interfaz de documentación.
- **Decisiones y Estructura:** El contenido está organizado mediante un sistema de pestañas (tabs) para separar diferentes tipos de prompts o escenarios. Se utiliza una paleta de colores morada (`#6D28D9`) como color primario en el diseño.
- **Contenido Técnico:** Incluye bloques de código con fondo oscuro (`#1E1E2F`) y tipografía monoespaciada ('JetBrains Mono') para mostrar los prompts maestros. Se destacan etiquetas visuales como "Badge" (primaria, éxito, advertencia) para clasificar la información.
- **Pasos importantes:** La guía detalla la configuración de ventanas de chat dentro del entorno n8n y proporciona ejemplos listos para copiar y pegar de instrucciones detalladas para el agente.
