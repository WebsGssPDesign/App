# entry_points.txt

## Resumen
Este archivo define los puntos de entrada para scripts de consola y especificaciones del sistema de archivos proporcionados por la librería `huggingface_hub`. Permite ejecutar comandos CLI oficiales, herramientas obsoletas y agentes de inferencia, además de habilitar el acceso a recursos remotos mediante un sistema de archivos virtual.

## Datos clave
- **Scripts de consola**: `hf`, `huggingface-cli` (obsoleto), `tiny-agents`.
- **Especificaciones FSSpec**: Mapeo del protocolo `hf` al objeto `HfFileSystem`.
- **Módulos involucrados**: `huggingface_hub.cli.hf`, `huggingface_hub.inference._mcp.cli`.
