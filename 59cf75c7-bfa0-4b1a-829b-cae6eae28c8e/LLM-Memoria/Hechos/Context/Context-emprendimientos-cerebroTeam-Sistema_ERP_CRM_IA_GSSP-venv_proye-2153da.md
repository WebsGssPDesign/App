# Galician.txt

## Resumen
Este archivo contiene una lista de palabras en gallego identificadas como "stopwords" o palabras vacías. Sirve para filtrar términos frecuentes y sin significado semántico específico durante el preprocesamiento de texto, optimizando así algoritmos de análisis de datos, búsqueda o minería de textos en la lengua gallega.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de procesamiento de lenguaje natural).
- **Tecnologías**: Python (paquete `justext`), biblioteca de extracción de texto.
- **Decisiones**: Inclusión de formas flexionadas y nombres propios comunes (ej: "San", "Santiago", meses del año) para reducir el ruido léxico en documentos históricos o administrativos gallegos.
- **Contenido**: Aproximadamente 300 términos, desde artículos ("de", "a") hasta sustantivos genéricos ("historia", "poboación").
