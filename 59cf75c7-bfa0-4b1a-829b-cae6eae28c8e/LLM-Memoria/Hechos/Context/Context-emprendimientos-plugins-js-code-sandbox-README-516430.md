# README.md

## Resumen
Este archivo documenta un entorno de ejecución aislado para código JavaScript y TypeScript impulsado por Deno, diseñado para permitir a los modelos de lenguaje ejecutar scripts de forma segura. Su función principal es facilitar la integración de capacidades de programación en sistemas basados en LLM mediante una arquitectura modular.

## Datos clave
- **Proyecto**: Sandbox de código para JS/TS dentro del ecosistema `lms`.
- **Tecnologías**: Deno, JavaScript, TypeScript.
- **Ruta del código fuente**: Directorio `src/`.
- **Comando principal**: `lms dev` (modo desarrollo).
