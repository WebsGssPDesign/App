# listaProductos.md

## Resumen
Este archivo define la estructura HTML de una cuadrícula de productos para un sitio web, mostrando artículos de dos categorías principales: accesorios para mascotas y cuidado personal. Cada tarjeta incluye título, código interno, precio en pesos uruguayos (UYU) e imagen, funcionando como catálogo visual para redirigir a la compra en MercadoLibre.

## Datos clave
- **Proyecto**: Catálogo web de productos (Portfolio).
- **Categorías**: Accesorios para mascotas y cuidado personal.
- **Moneda**: Pesos uruguayos (UYU).
- **Plataforma destino**: Enlaces externos a `https://www.mercadolibre.com`.
- **Estructura HTML**: Uso de clases como `.products-grid`, `.product-card` y `.btn`.
- **Imágenes**: Rutas relativas como `/img/Acc para mascotas/FF147.jpg`.
