# README.md

## Resumen
Este documento describe la arquitectura y configuración del sitio web "MiniMarketUy GSSP", una tienda online minimalista que integra Supabase para gestión de datos en tiempo real, MercadoPago para pagos y funciona como una PWA. Su propósito es facilitar el comercio electrónico con un panel administrativo completo y optimización SEO, utilizando un diseño responsive inspirado en ledstar.com.uy.

## Datos clave
- **Proyecto**: MiniMarketUy GSSP (Ecommerce).
- **Tecnologías**: HTML, TailwindCSS, TypeScript, Supabase (Auth, DB, Realtime), MercadoPago, PWA Service Worker.
- **Decisiones de diseño**: Paleta blanca/verde oliva/dorado; enfoque mobile-first; inspiración en ledstar.com.uy.
- **Rutas administrativas**: `/admin/products/`, `/admin/orders/`, `/admin/payments/`, entre otras para gestión de contenido y estadísticas.
- **Comandos principales**: `npm install`, `npm run dev` (desarrollo), `npm run build` (producción).
- **Configuración crítica**: Variables de entorno en `js/config.js` con credenciales de Supabase y MercadoPago; tablas requeridas (`products`, `orders`, `cart`).
