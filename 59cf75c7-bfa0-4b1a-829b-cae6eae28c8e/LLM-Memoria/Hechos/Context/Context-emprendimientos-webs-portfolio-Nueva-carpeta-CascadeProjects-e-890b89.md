# requirements.txt

## Resumen
Este archivo lista las dependencias de Python necesarias para ejecutar el backend de inteligencia artificial del proyecto CascadeProjects, específicamente diseñado para una aplicación de comercio electrónico. Su función es garantizar que todas las librerías requeridas por la arquitectura basada en FastAPI y LangChain estén instaladas correctamente en el entorno virtual.

## Datos clave
- **Proyecto**: CascadeProjects (ecommerce-app)
- **Tecnologías principales**: Python, FastAPI, LangChain, OpenAI
- **Decisiones de arquitectura**: Uso de `langgraph` para flujos de agentes y `uvicorn` como servidor ASGI.
- **Gestión de configuración**: Dependencia `python-dotenv` para variables de entorno.
- **Optimización de datos**: Inclusión de `orjson`, `ormsgpack` y `zstandard` para serialización eficiente.
- **Comando típico**: `pip install -r requirements.txt`
