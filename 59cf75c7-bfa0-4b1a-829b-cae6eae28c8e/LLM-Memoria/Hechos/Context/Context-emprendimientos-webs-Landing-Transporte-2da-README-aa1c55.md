# README.md

## Resumen
Este archivo documenta la estructura y requisitos de pre-publicación para una página web de aterrizaje dedicada a "Sose Transporte". Su función es guiar al desarrollador en la preparación final del sitio, asegurando que todos los activos visuales, textos y configuraciones estén listos antes de lanzar el servicio.

## Datos clave
- **Archivos principales**: `index.html`, `styles.css`, `script.js` y carpeta `img/`.
- **Imágenes requeridas**: `hero_camion.jpg` (relación 4:3), seis imágenes de servicios (`servicio_1.jpg` a `servicio_6.jpg`) con relación 3:2, tres testimonios y el logo. El sitio es robusto ante la falta de alguna imagen.
- **Configuraciones**: El número de WhatsApp se actualiza en `script.js` (variable `WA_NUMBER`) y en el pie de página; las fuentes personalizadas requieren copiar archivos `.woff2` a `fonts/`.
- **Tarifas definidas**: Camión chico ($1.250), mediano ($1.550) y grande ($1.750), todos con IVA por hora y mínimo 2 horas; el almacenamiento requiere consulta.
- **Medios de pago**: Se deben verificar y confirmar los métodos reales (Visa, Mastercard, MercadoPago, OCA, Transferencia, Efectivo).
