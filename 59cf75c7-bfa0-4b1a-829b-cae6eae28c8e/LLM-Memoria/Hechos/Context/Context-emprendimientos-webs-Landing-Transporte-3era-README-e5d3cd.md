# README.md

## Resumen
Este archivo documenta la estructura y los requisitos pendientes para la landing page de Sose Transporte, diseñada con un estilo Neumorphic Glass Corporate. Su objetivo es guiar al desarrollador sobre qué imágenes provisionales deben reemplazarse por fotos reales del cliente y qué información comercial debe completarse antes del lanzamiento.

## Datos clave
- **Archivos principales**: `index.html`, `styles.css`, `script.js` y la carpeta `img/`.
- **Imágenes a reemplazar**: `hero_camion.jpg`, `equipo_cajas.jpg`, `equipo_camion.jpg` y los servicios (`servicio_1.jpg` a `servicio_6.jpg`). El sistema debe manejar gracefully si faltan imágenes.
- **Tarifas definidas**: Camión chico ($1.250), mediano ($1.550) y grande ($1.750), más IVA por hora con mínimo de 2 horas.
- **Puntos pendientes**: Agregar testimonios reales (sin fotos inventadas), confirmar medios de pago y actualizar el número de WhatsApp en `script.js` (`WA_NUMBER`) y el footer.
