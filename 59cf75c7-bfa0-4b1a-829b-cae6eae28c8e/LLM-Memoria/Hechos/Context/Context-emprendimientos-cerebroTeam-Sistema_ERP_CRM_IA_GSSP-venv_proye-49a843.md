# Cebuano.txt

## Resumen
Este archivo es una lista de palabras en la lengua cebuana utilizada para filtrar términos comunes y frecuentes durante el procesamiento de texto. Su función principal es mejorar la calidad del análisis al eliminar ruido léxico antes de extraer temas o entidades clave.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de procesamiento lingüístico).
- **Tecnologías**: Python, librería `justext`.
- **Contenido**: Lista de stopwords en Cebuano (ejemplos: sa, ka, Ang, ug, usa, may, Kini).
- **Uso**: Configuración del diccionario de exclusión para análisis de sentimientos o extracción de temas.
