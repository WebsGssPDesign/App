# robots.txt

## Resumen
Este archivo `robots.txt` define las reglas de acceso para motores de búsqueda sobre el sitio web del proyecto. Su función principal es permitir el rastreo general mientras restringe específicamente directorios administrativos, recursos estáticos y archivos temporales para evitar un índice innecesario. Además, declara la ubicación oficial del mapa del sitio para facilitar la navegación por los bots.

## Datos clave
- **Proyecto**: windsurf-project-7 (sitio web de gsspminimarketuy.com).
- **Restricciones**: Bloqueo de directorios `/admin/`, `/js/`, `/css/` y archivos terminados en `.json$` o `.xml$`.
- **Permisos**: Acceso total para `Googlebot`, `Bingbot` y `Slurp`; acceso permitido a `/sitemap.xml` y `/robots.txt`.
- **Configuración omitida**: La directiva de retraso de rastreo (`Crawl-delay`) está comentada.
- **Ubicación del mapa del sitio**: https://gsspminimarketuy.com/sitemap.xml
