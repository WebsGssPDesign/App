# costos.txt

## Resumen
Este documento detalla el catálogo de precios y códigos para un surtido de productos de iluminación LED solar, decorativa y funcional. Sirve como referencia comercial para la adquisición de materiales en proyectos de iluminación exterior e interior, especificando costos unitarios en dólares estadounidenses con impuestos incluidos.

## Datos clave
- **Proyecto**: Iluminación para escaleras y espacios interiores/exteriores (Código: SE-864).
- **Tecnologías**: Paneles LED solares, focos COB, módulos hexagonales RGB, drivers y sensores de movimiento.
- **Decisiones de precio**: Rangos desde USD 1,50 para drivers hasta USD 8,50 para kits completos o lámparas con brazo articulado.
- **Códigos clave**: SE-864 (Set escalera), FXCOB-50 (Foco exterior potente), PX-10100 (Guía RGB con app).
- **Pasos de adquisición**: Verificar si el producto requiere instalación encastrable o redonda, y distinguir entre luz fría y cálida según la necesidad del espacio.
