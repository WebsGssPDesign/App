# README.md

## Resumen
Este archivo documenta la configuración inicial de un proyecto frontend basado en React, TypeScript y Vite. Sirve como guía para configurar plugins oficiales, ajustar reglas de ESLint con soporte tipado e instalar extensiones específicas para linting de componentes React.

## Datos clave
- **Tecnologías**: React, TypeScript, Vite.
- **Plugins disponibles**: `@vitejs/plugin-react` (usando Oxc) o `@vitejs/plugin-react-swc`.
- **React Compiler**: No está habilitado por defecto debido a impactos en el rendimiento de desarrollo y compilación; requiere configuración manual si se desea activar.
- **Configuración ESLint**: Se recomienda usar configuraciones `recommendedTypeChecked`, `strictTypeChecked` o `stylisticTypeChecked` para aplicaciones de producción.
- **Plugins adicionales sugeridos**: `eslint-plugin-react-x` y `eslint-plugin-react-dom` para reglas específicas del ecosistema React.
- **Archivos de configuración TypeScript**: Se referencia el uso de `tsconfig.node.json` y `tsconfig.app.json`.
