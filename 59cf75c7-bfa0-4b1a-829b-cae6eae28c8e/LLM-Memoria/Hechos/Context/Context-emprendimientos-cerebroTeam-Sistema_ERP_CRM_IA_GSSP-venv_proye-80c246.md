# entry_points.txt

## Resumen
Este archivo define el punto de entrada para la consola del paquete `charset_normalizer`, permitiendo ejecutar scripts externos que detectan automáticamente las codificaciones de caracteres en archivos. Su función principal es habilitar la herramienta `normalizer` desde la línea de comandos dentro del entorno virtual del proyecto ERP/CRM con IA.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (cerebroTeam).
- **Tecnología**: Python, paquete `charset_normalizer` v3.4.7.
- **Comando disponible**: `normalizer`.
- **Función**: Ejecuta la función `cli_detect` del módulo `charset_normalizer.cli`.
