# entry_points.txt

## Resumen
Este archivo define los puntos de entrada para la integración del extractor de internacionalización de Jinja2 dentro del entorno virtual del proyecto. Su función es permitir que el sistema extraiga mensajes traducibles directamente desde las plantillas de Jinja2, facilitando la implementación de soporte multilingüe en la aplicación.

## Datos clave
- Proyecto: Sistema ERP CRM IA GSSP (cerebroTeam)
- Tecnología: Jinja2 3.1.6
- Decisión técnica: Configuración del extractor `babel_extract[i18n]` para el módulo `jinja2.ext` bajo la sección `[babel.extractors]`.
