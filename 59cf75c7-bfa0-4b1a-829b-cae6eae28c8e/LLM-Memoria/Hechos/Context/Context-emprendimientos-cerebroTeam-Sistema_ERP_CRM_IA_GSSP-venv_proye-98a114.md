# Luxembourgish.txt

## Resumen
Este archivo contiene una lista de palabras en idioma luxemburgués, identificadas como "stopwords" o términos comunes. Su función principal es servir como referencia para filtrar estas palabras frecuentes al procesar textos y extraer información relevante mediante análisis lingüístico o minería de datos.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de procesamiento de lenguaje natural).
- **Tecnologías**: Python, librería `justext` para análisis de texto.
- **Decisiones**: Inclusión de términos específicos como nombres propios ("Lëtzebuerg", "Jean Kinnek"), meses ("Januar", "Februar") y conceptos administrativos ("Kanton", "Gemeng").
- **Contenido**: Lista de palabras en minúsculas y mayúsculas (ej. "an", "De", "Dës") que deben ser excluidas durante la tokenización o ponderación de documentos.
