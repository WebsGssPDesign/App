# AgentedeVoz.md

## Resumen
Este documento define el rol y guion para un agente de voz automatizado que contacta a leads cualificados de una agencia de IA. Su objetivo es realizar llamadas consultivas para comprender las necesidades empresariales, identificar puntos de dolor operativos y, si existe compatibilidad, agendar una reunión estratégica sin presionar ventas ni discutir precios.

## Datos clave
- **Proyecto:** Automatizado Agency (soluciones B2B de automatización e IA).
- **Tecnologías:** Variables dinámicas (`{{nombre_usuario}}`) para personalizar la apertura.
- **Decisiones críticas:** No prometer resultados, no discutir precios ni forzar reuniones si no hay interés genuino.
- **Rutas de conversación:** Apertura natural -> Descubrimiento consultivo (contexto, procesos, visión) -> Evaluación interna silenciosa -> Cierre (agendar reunión o dar las gracias).
- **Comandos/Pasos:** Utilizar preguntas abiertas para fomentar respuestas reflexivas sobre ineficiencias y escalabilidad.
