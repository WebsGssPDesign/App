# entry_points.txt

## Resumen
Este archivo define el punto de entrada para la herramienta `datasets-cli`, un script de línea de comandos incluido en la librería Python `datasets`. Su función es permitir a los usuarios ejecutar operaciones relacionadas con conjuntos de datos directamente desde la terminal.

## Datos clave
- Proyecto: Librería `datasets` (versión 4.3.0)
- Tecnología: Python, sistema de paquetes distribuidos (`dist-info`)
- Comando importante: `datasets-cli`
- Funcionalidad: Acceso a comandos principales vía consola mediante el módulo `datasets.commands.datasets_cli`
