# Example_README.md

## Resumen
Esta guía explica cómo gestionar una base de datos en la nube utilizando Supabase mediante archivos de migración SQL locales. Su objetivo es enseñar a los desarrolladores a escribir código de base de datos localmente y sincronizarlo automáticamente con el entorno en la nube, evitando ediciones manuales directas.

## Datos clave
- **Proyecto**: Estudio práctico para configurar un backend con Supabase Cloud.
- **Tecnologías**: Node.js, Supabase CLI (`npx supabase`), SQL.
- **Comandos principales**: `supabase init`, `supabase login`, `supabase link`, `migration new <nombre>`, `db push`.
- **Flujo de trabajo**: Crear carpeta local → Inicializar proyecto → Enlazar con la nube → Escribir SQL en archivos de migración → Ejecutar `db push` para aplicar cambios.
- **Reglas críticas**: Nunca editar tablas manualmente en el dashboard; los archivos de migración son la única fuente de verdad.
