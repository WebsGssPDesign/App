# costos.txt

## Resumen
Este documento detalla el catálogo de precios y códigos para una variedad de productos de iluminación LED, tanto solares como interiores. Sirve como referencia comercial para la venta de focos, paneles, drivers y sistemas decorativos RGB con sus respectivas especificaciones técnicas básicas.

## Datos clave
- **Proyecto:** Inventario de productos de iluminación para el sitio web del emprendimiento.
- **Tecnologías:** LED solar, RGB con control remoto/app, módulos hexagonales táctiles.
- **Decisiones:** Se listan precios en USD más IVA junto al código único de cada ítem (ej: SE-864, LAC-12W).
- **Categorías principales:** Iluminación solar exterior, paneles LED cuadrados y redondos (fríos/cálidos), drivers y guías RGB.
