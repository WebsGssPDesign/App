# Norwegian_Nynorsk.txt

## Resumen
Este archivo contiene una lista de palabras en noruego (variante Nynorsk) identificadas como "stopwords". Sirve para filtrar términos comunes y frecuentes del lenguaje natural durante procesos de análisis de texto, limpieza de datos o preparación de corpus para modelos de inteligencia artificial.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de procesamiento lingüístico).
- **Tecnologías**: Biblioteca `justext` en Python (ruta: `venv_proyecto/Lib/site-packages/justext`).
- **Contenido**: Lista de 250+ tokens (palabras como "og", "av", "er") y algunas entidades geográficas o nombres propios ("Noreg", "Oslo", "Russland").
- **Características**: Incluye tanto palabras en minúsculas como en mayúscula inicial, reflejando el uso real en textos noruegos.
