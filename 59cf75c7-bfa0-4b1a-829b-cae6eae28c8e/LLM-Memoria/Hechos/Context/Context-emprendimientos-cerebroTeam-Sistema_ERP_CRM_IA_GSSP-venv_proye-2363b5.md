# entry_points.txt

## Resumen
Este archivo define los puntos de entrada del paquete Babel 2.18.0, un módulo esencial para la internacionalización (i18n) y localización (l10n) en Python. Permite configurar herramientas para extraer, compilar y actualizar archivos de traducción, así como ejecutar comandos de línea específicos para gestionar catálogos de mensajes.

## Datos clave
- **Proyecto**: Babel 2.18.0 dentro del entorno virtual `venv_proyecto`.
- **Tecnologías**: Python, distutils, setuptools.
- **Comandos disponibles**: `pybabel` (principal), `compile_catalog`, `extract_messages`, `init_catalog`, `update_catalog`.
- **Extractors configurados**: Soporte para JavaScript y Python; opción de ignorar extracción (`extract_nothing`).
