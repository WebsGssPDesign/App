# Crearwebstitch.md

## Resumen
Este documento define la hoja de ruta para transformar un sitio web actual en una aplicación web educativa centrada en Inteligencia Artificial con fuerte componente comunitario. Su objetivo es guiar el rediseño visual, la arquitectura del catálogo de cursos y las nuevas funcionalidades sociales para mejorar la experiencia de aprendizaje.

## Datos clave
- **Proyecto**: Evolución a plataforma EdTech de IA con enfoque comunitario.
- **Diseño**: Mantener branding actual pero aplicar estética 'AI-First' (bordes suaves, glassmorphism, fondos oscuros).
- **Catálogo**: Grid dinámico con tarjetas que incluyen metadatos, badges de acceso ('Gratis'/'Premium') y portadas generadas por IA.
- **Lógica de venta**: Botones diferenciados para cursos gratuitos (inicio directo) y premium (simulación de pasarela Stripe).
- **Comunidad**: Sidebar de actividad en vivo con hilos sobre LLMs y feed central de noticias del sector.
- **Navegación**: Header reestructurado con accesos a Cursos, Progreso, Comunidad, Herramientas IA y Perfil.
- **UX**: Enfoque Mobile-First con scroll infinito para el catálogo en móviles.
