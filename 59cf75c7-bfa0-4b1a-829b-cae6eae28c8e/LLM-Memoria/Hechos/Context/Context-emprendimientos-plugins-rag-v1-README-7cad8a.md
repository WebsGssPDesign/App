# README.md

## Resumen
Este archivo describe una plantilla inicial para desarrollar plugins de LM Studio utilizando TypeScript. Sirve como punto de partida para crear, ejecutar en modo desarrollo y publicar extensiones dentro del ecosistema de la plataforma.

## Datos clave
- **Proyecto**: Scaffold para plugins de LM Studio (LM Studio Plugin Scaffold).
- **Tecnologías**: TypeScript.
- **Rutas importantes**: El código fuente se encuentra en el directorio `src/`.
- **Comandos principales**:
  - `lms dev`: Ejecuta la extensión en modo desarrollo.
  - `lms push`: Publica la extensión al LM Studio Hub o actualiza una existente.
- **Recursos externos**: Repositorio GitHub (lmstudio-js), documentación oficial, servidor Discord y Twitter de la comunidad.
