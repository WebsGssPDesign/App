# Belarusian.txt

## Resumen
Este archivo contiene una lista de palabras en idioma bielorruso utilizadas como "stopwords" para el procesamiento de texto. Su función principal es filtrar términos comunes y de alto frecuencia (como preposiciones, artículos y conectores) al analizar documentos, permitiendo a los algoritmos centrarse en las palabras con mayor relevancia semántica.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de análisis de texto).
- **Tecnologías**: Python (`justext` library), Bielorruso.
- **Decisiones**: Selección de un diccionario específico para normalizar el idioma bielorruso antes del análisis de sentimientos o extracción de temas.
- **Contenido**: Lista extensa de tokens como "і" (y), "на" (en), "быў" (fue), "горад" (ciudad), entre otros, incluyendo variaciones con mayúsculas y puntuación básica.
