# robots.txt

## Resumen
Este archivo `robots.txt` configura las reglas de acceso para los motores de búsqueda en el sitio web del proyecto E-commerce. Permite que todos los bots (definido por `User-agent: *`) indexen y rastreen cualquier página del dominio, ya que la directiva `Disallow:` está vacía.

## Datos clave
- **Proyecto**: E-commerce desarrollado con Node.js.
- **Ubicación**: Carpeta pública (`client/public`) de la aplicación frontend.
- **Configuración**: Acceso total permitido para todos los agentes de usuario; no hay restricciones de rastreo.
- **Referencia**: Enlace a la documentación oficial de robots.txt incluida en el encabezado del archivo.
