# Ido.txt

## Resumen
Este archivo contiene una lista de palabras en la lengua ido (ido), un idioma artificial basado en el esperanto, utilizada como diccionario de palabras a ignorar. Su función principal es filtrar términos comunes y sin significado semántico específico durante el análisis de textos para mejorar la precisión del procesamiento lingüístico.

## Datos clave
- Proyecto: Sistema ERP CRM IA GSSP (módulo de análisis de texto).
- Tecnologías: Python (librería `justext`), idioma Ido.
- Decisiones: Selección de un vocabulario específico para normalización de datos textuales.
- Contenido: Lista de stopwords en minúsculas y mayúsculas, incluyendo términos como "la", "de", "en" y palabras compuestas o con errores tipográficos ("familii", "povreso-lineo").
