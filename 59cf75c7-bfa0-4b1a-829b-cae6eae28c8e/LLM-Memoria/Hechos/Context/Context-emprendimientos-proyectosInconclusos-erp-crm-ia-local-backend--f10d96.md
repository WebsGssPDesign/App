# requirements.txt

## Resumen
Este archivo lista las dependencias de Python necesarias para ejecutar el backend de un proyecto ERP/CRM con capacidades de IA local. Define versiones específicas para frameworks web, bases de datos, autenticación y herramientas de procesamiento de lenguaje natural.

## Datos clave
- **Proyecto**: Backend de sistema ERP/CRM con integración de IA local.
- **Tecnologías principales**: FastAPI (servidor), SQLAlchemy (ORM), PostgreSQL (psycopg2-binary).
- **IA y LLMs**: LangChain, Ollama (para modelos locales), Selenium y Playwright (automatización web).
- **Seguridad**: python-jose y passlib para gestión de tokens y contraseñas.
- **Datos**: Pandas y NumPy para análisis de datos.
- **Configuración**: pydantic-settings y python-dotenv para variables de entorno.
