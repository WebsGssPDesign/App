# modelcard_template.md

## Resumen
Este archivo es una plantilla de Markdown para generar "Model Cards" en la plataforma Hugging Face. Su función estandarizar la documentación de modelos de IA, detallando su descripción, uso, riesgos, métricas de evaluación e impacto ambiental.

## Datos clave
- **Tecnología:** Plantilla de Jinja2 (`{{ variable }}`) integrada en Markdown.
- **Estructura:** Secciones obligatorias como "Model Details", "Uses" y "Bias, Risks, and Limitations".
- **Recursos externos:** Enlaces a la especificación oficial del Hub Docs y calculadoras de impacto ambiental (MLCO2).
- **Variables críticas:** `model_id`, `license`, `training_data`, `testing_metrics`, `co2_emitted`.
