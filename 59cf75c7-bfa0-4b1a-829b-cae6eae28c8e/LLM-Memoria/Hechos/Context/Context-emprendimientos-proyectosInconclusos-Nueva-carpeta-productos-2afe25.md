# productos.md

## Resumen
Este archivo JSON detalla un inventario de productos infantiles, principalmente cámaras digitales y juguetes deportivos, listos para su carga en el sistema. Sirve como referencia técnica para verificar costos de proveedores, niveles mínimos de stock y enlaces a catálogos externos antes de la implementación comercial.

## Datos clave
- **Proyecto**: Carga de catálogo de productos infantiles (sección `productosInconclusos`).
- **Tecnologías**: Formato JSON con arrays de objetos.
- **Decisiones**: Todos los ítems tienen stock actual en 0 y estado "ACTIVE".
- **Rutas**: Los enlaces a imágenes y detalles del proveedor apuntan al dominio `ledstar.com.uy`.
- **Pasos importantes**: Identificar SKUs únicos (ej. KC, TQ-6327) y costos por proveedor (ID "01").
