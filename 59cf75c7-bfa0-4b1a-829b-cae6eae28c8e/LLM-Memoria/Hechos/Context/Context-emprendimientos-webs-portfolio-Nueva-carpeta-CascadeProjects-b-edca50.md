# costos.txt

## Resumen
Este archivo detalla un inventario de productos de hogar y cocina, listando descripciones breves, precios en dólares estadounidenses con IVA y códigos internos únicos para cada ítem. Su función principal es servir como referencia comercial o base de datos para la gestión de stock y facturación de estos artículos.

## Datos clave
- **Proyecto**: Catálogo de productos de hogar (Organizadores, electrodomésticos, limpieza).
- **Decisiones**: Todos los precios incluyen IVA; se utiliza una nomenclatura específica por código (ej. YH6616-2, BM-3L).
- **Rutas/Contexto**: Archivo ubicado en la estructura de respaldo de imágenes del proyecto CascadeProjects.
- **Productos destacados**: Freidoras Boma (3L y 6L), batidora industrial, percheros organizadores y mopa trapeadora plegable.
