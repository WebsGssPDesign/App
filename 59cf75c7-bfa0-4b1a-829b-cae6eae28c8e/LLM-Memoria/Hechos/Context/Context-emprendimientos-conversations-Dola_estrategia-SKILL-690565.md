# SKILL.md

## Resumen
Este documento define una habilidad técnica para desarrollar interfaces frontend de producción con un diseño distintivo y de alta calidad. Su objetivo es evitar la estética genérica típica de las IA, fomentando direcciones conceptuales audaces (como brutalismo o minimalismo refinado) que sean memorables y funcionales.

## Datos clave
- **Propósito**: Crear componentes web, páginas y aplicaciones visuales impactantes.
- **Enfoque de diseño**: Seleccionar una dirección estética extrema e intencional antes de codificar (ej. retro-futurista, orgánico).
- **Tipografía**: Evitar fuentes genéricas como Arial o Inter; usar combinaciones únicas de fuentes de exhibición y cuerpo.
- **Paleta de colores**: Utilizar variables CSS para consistencia, priorizando colores dominantes con acentos afilados sobre gradientes típicos.
- **Movimiento**: Priorizar animaciones CSS nativas y momentos de alto impacto (cargas de página escalonadas) en lugar de micro-interacciones dispersas.
- **Composición espacial**: Fomentar asimetría, superposiciones y ruptura de cuadrículas para evitar layouts predecibles.
- **Detalles visuales**: Aplicar texturas, gradientes mesh, transparencias y efectos de grano para crear profundidad y atmósfera.
