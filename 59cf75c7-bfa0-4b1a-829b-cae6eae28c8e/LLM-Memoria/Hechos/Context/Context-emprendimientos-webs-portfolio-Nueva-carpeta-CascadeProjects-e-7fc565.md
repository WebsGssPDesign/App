# README.md

## Resumen
Este archivo describe BasicTechShop, una tienda online de hardware para computación desarrollada con Next.js 16 y TypeScript. La aplicación permite a los usuarios comprar productos, gestionar sus perfiles y ofrece paneles administrativos para la gestión del negocio. Sirve como guía técnica para configurar el entorno, ejecutar migraciones de base de datos e iniciar el servidor de desarrollo o producción.

## Datos clave
- **Proyecto**: BasicTechShop (E-commerce de componentes de computación).
- **Tecnologías**: Next.js 16 (App Router), TypeScript, Tailwind CSS v4, shadcn/ui, Prisma, PostgreSQL, Zustand, NextAuth.js.
- **Pasos de instalación**: Clonar repositorio, ejecutar `npm install`, copiar y editar `.env` desde el ejemplo, iniciar base de datos con Docker (`docker-compose up -d`) y aplicar migraciones (`npx prisma migrate dev`).
- **Scripts principales**: `npm run dev` (desarrollo), `npm run build` (producción), `npm run start` (servidor prod).
- **Estructura**: Rutas organizadas en carpetas `(shop)`, `(admin-panel)` y `(auth)` dentro de `src/app`.
