# Kurdish.txt

## Resumen
Este archivo contiene una lista de palabras en idioma kurdo (kurmancî) identificadas como "stopwords" o términos comunes, utilizadas para filtrar el ruido léxico en procesos de análisis de texto. Su función principal es optimizar algoritmos de procesamiento de lenguaje natural al excluir palabras frecuentes que aportan poco valor semántico.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de NLP).
- **Tecnologías**: Python, librería `justext`.
- **Decisión**: Inclusión de una lista específica de stopwords para el idioma kurdo dentro del entorno virtual del proyecto.
- **Ruta**: `/venv_proyecto/Lib/site-packages/justext/stoplists/Kurdish.txt`.
- **Contenido**: Lista de palabras frecuentes (ej: "bi", "ji", "ku", "ye") y nombres propios geográficos/históricos (ej: "Kurdistanê", "Amedê", "Şêx").
