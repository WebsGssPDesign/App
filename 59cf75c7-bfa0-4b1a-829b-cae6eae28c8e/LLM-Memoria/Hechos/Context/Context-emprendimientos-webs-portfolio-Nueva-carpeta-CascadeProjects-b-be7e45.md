# robots.txt

## Resumen
Este archivo de robots.txt configura las reglas de rastreo para el sitio web gsspminimarketuy.com, permitiendo a los motores de búsqueda indexar la mayoría del contenido mientras bloquea accesos al panel de administración y recursos estáticos como hojas de estilo o scripts. Su función principal es optimizar el rendimiento del crawler evitando que descargue archivos innecesarios y señalando explícitamente la ubicación del archivo sitemap para facilitar la indexación.

## Datos clave
- **Proyecto**: windsurf-project-7 (parte de CascadeProjects).
- **Dominio objetivo**: gsspminimarketuy.com.
- **Reglas de exclusión**: Bloqueo total de directorios `/admin/`, `/js/`, `/css/` y archivos terminados en `.json$` o `.xml$`.
- **Excepciones permitidas**: Acceso explícito a `sitemap.xml` y `robots.txt`.
- **Motores específicos**: Reglas generales para Googlebot, Bingbot y Slurp que permiten el rastreo completo de la raíz.
- **Configuración pendiente**: La directiva `Crawl-delay: 1` está comentada y no activa actualmente.
