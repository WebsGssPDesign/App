# README.md

## Resumen
Este documento describe la aplicación web "ExpoCasa", una plataforma inmobiliaria completa desarrollada con Next.js 15 que incluye un sitio público y un panel administrativo. Su función principal es gestionar propiedades, agentes y consultas de clientes mediante una arquitectura full-stack que integra MongoDB para el almacenamiento de datos.

## Datos clave
- **Proyecto**: Inmobiliaria ExpoCasa (Next.js 15, React, TypeScript).
- **Tecnologías**: NextAuth.js para autenticación, Nodemailer para correos, Tailwind CSS y Lucide React.
- **Base de datos**: MongoDB con colecciones `properties`, `agents`, `inquiries` y `configurations`.
- **Rutas principales**: `/admin/login` (acceso restringido), `/propiedades/[id]`, `/contacto`.
- **Comandos esenciales**: `npm install`, `npm run dev` (desarrollo), `npm run build` y `npm start` (producción).
- **Pasos de configuración**: Crear `.env.local` con credenciales de MongoDB, NextAuth y SMTP; habilitar App Password en Gmail.
