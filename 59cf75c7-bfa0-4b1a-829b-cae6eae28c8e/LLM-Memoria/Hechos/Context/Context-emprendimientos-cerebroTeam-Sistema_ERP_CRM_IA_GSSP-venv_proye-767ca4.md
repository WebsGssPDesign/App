# Hindi.txt

## Resumen
Este archivo contiene una lista de palabras en hindi (sanskrit) y algunos términos en inglés que funcionan como "stopwords" o palabras vacías. Su utilidad principal es filtrar estos elementos durante el preprocesamiento de texto para análisis lingüístico, minería de datos o entrenamiento de modelos de IA, mejorando así la precisión al centrarse en las palabras con significado semántico.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (contexto del proyecto padre).
- **Tecnologías**: Python (inferido por la ruta `venv_proyecto` y el paquete `justext`).
- **Decisiones**: Selección de un conjunto específico de stopwords para normalización de texto en hindi.
- **Contenido**: Lista de 200+ palabras comunes como "के", "में", "है" mezcladas con términos genéricos en inglés ("the", "and", "of").
