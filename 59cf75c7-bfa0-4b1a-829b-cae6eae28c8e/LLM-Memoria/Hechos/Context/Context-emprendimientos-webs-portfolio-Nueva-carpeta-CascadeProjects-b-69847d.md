# listaProductos.md

## Resumen
Este archivo detalla el catálogo de productos disponibles para una tienda online, organizados por categorías como mascotas y cuidado personal. Sirve como referencia interna para gestionar inventario, precios en moneda uruguaya (UYU) y códigos de identificación únicos para cada ítem.

## Datos clave
- **Categorías principales**: Accesorios para mascotas, cuidado personal y electrónica/informática.
- **Productos destacados**: Dispensadores automáticos, cortapelos inalámbricos, cables Treqa, monitores portátiles Arzopa y smartwatch T20 Ultra.
- **Estructura de datos**: Tabla con columnas `Cod`, `Imagen` (rutas relativas), `Nombre del producto` y `Precio de venta`.
- **Rutas de imágenes**: Las imágenes se almacenan en carpetas específicas como `/img/Acc para mascotas/`, `/img/cuidadoPersonal/` y `/img/electronicaInformatica/`.
- **Moneda**: Todos los precios están expresados en UYU (pesos uruguayos).
