# Irish.txt

## Resumen
Este archivo contiene una lista de palabras en irlandés (Gaeilge) identificadas como "stopwords", es decir, términos frecuentes y comunes que suelen eliminarse durante el preprocesamiento de texto para análisis lingüístico o computacional. Su función principal es reducir el ruido en los datos al filtrar artículos, preposiciones y verbos auxiliares que aportan poco valor semántico a la búsqueda o clasificación automática.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de procesamiento de texto).
- **Tecnologías**: Python (librería `justext`), idioma irlandés (Gaeilge).
- **Decisión**: Inclusión de una lista específica de stopwords para normalizar corpus textuales en contexto irlandés.
- **Contenido**: Lista alfabética de palabras como "an", "de", "tá", "bhí", "gach" y nombres propios como "John".
