# Lithuanian.txt

## Resumen
Este archivo contiene una lista de palabras en lituano que funcionan como stopwords, utilizadas comúnmente por algoritmos de procesamiento de lenguaje natural para filtrar términos frecuentes y sin significado semántico. Su propósito es optimizar análisis de texto, extracción de temas o clasificación al reducir el ruido léxico antes del entrenamiento de modelos de IA.

## Datos clave
- **Proyecto**: Sistema ERP CRM con integración de Inteligencia Artificial (GSSP).
- **Tecnologías**: Python (entorno `venv_proyecto`), librería `justext`.
- **Decisión técnica**: Implementación de listas de stopwords específicas para el idioma lituano dentro del paquete de análisis de texto.
- **Contenido crítico**: Incluye formas gramaticales comunes (ir, yra, tai), nombres propios geográficos y históricos (Vilniaus, Lietuvos, Kauno) y términos administrativos que deben ser excluidos durante la limpieza de datos.
