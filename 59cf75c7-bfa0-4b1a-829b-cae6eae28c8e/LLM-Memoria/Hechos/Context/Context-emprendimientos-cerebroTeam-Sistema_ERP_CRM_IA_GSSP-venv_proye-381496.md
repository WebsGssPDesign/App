# README.md

## Resumen
Este directorio centraliza la telemetría del proyecto ChromaDB, separando los datos de uso anónimos recolectados por el equipo de desarrollo de las configuraciones locales para OpenTelemetry. Su función es permitir tanto al proveedor como a los administradores analizar el comportamiento y rendimiento del sistema sin comprometer la privacidad de los usuarios finales.

## Datos clave
- **Directorios principales**: `product/` (telemetría anónima enviada al equipo) y `opentelemetry/` (configuración local para métricas y trazas).
- **Tecnologías**: ChromaDB, OpenTelemetry.
- **Decisión de diseño**: Separación estricta entre datos enviados externamente y métricas locales utilizables por el operador.
- **Recursos externos**: Enlaces a la documentación oficial sobre telemetría y la guía de inicio en Python para OpenTelemetry.
