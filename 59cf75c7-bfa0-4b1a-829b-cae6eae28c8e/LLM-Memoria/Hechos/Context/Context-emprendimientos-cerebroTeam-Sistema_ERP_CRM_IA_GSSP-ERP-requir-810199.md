# requirements.txt

## Resumen
Este archivo lista las dependencias de Python necesarias para construir un sistema ERP y CRM impulsado por inteligencia artificial. Su función es garantizar que el entorno de desarrollo tenga instaladas las librerías requeridas para manejar datos, procesar lenguaje natural y servir la aplicación web.

## Datos clave
- **Proyecto**: Sistema ERP/CRM con IA para GSSP (cerebroTeam).
- **Tecnologías**: Python, FastAPI, uvicorn (servidor web), Pydantic (validación de datos).
- **IA y Vectorización**: chromadb (base de datos vectorial), sentence-transformers (modelos de embeddings).
- **Procesamiento de datos**: requests, beautifulsoup4, trafilatura (extracción web), Schedule (tareas programadas).
