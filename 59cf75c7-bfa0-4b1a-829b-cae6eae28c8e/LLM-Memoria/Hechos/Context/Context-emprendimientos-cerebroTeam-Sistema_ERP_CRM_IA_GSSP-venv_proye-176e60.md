## Resumen
Este archivo contiene una lista de palabras en persa (farsi) identificadas como "stopwords" o palabras vacías. Sirve para filtrar términos comunes y frecuentes del idioma antes de procesarlos en tareas de análisis de texto, extracción de entidades o minería de datos.

- **Tecnologías**: Python (paquete `justext`), formato de lista plana de texto.
- **Decisiones**: Inclusión de formas verbales y sustantivos comunes como "است" (ser/estar), "که" (que), "این" (este) para reducir el ruido en corpus textuales.
