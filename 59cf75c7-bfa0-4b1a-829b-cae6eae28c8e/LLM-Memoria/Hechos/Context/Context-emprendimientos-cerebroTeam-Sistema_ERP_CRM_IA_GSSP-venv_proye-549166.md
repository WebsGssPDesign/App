# Quechua.txt

## Resumen
Este archivo es una lista de palabras en quechua utilizada para filtrar términos comunes durante el procesamiento de lenguaje natural o la extracción de texto estructurado. Su función principal es mejorar la calidad del análisis al eliminar ruido léxico específico de esta lengua indígena.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de procesamiento lingüístico).
- **Tecnologías**: Python, librería `justext` (paquete de extracción de texto).
- **Decisiones**: Inclusión de vocabulario específico para distinguir conceptos administrativos y geográficos en quechua (ej. "distritu", "pruwinsyapi", "mama").
- **Contenido**: Lista de tokens como `huk`, `nisqaqa`, `Piruw`, `Simikuna` y términos híbridos o transliterados.
