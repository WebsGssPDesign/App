# Newar.txt

## Resumen
Este archivo es una lista de palabras en nepalí (Devanagari) que funciona como un diccionario de stopwords para el procesamiento de lenguaje natural. Su utilidad radica en filtrar términos frecuentes y sin significado semántico específico al analizar textos sobre la región del Himalaya, la cultura nepalesa o temas lingüísticos relacionados con India y Nepal.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de análisis de texto).
- **Tecnologías**: Python (`justext`), formato de texto plano (.txt).
- **Decisiones**: Selección manual o automática de vocabulario nepalí para normalización de datos.
- **Contenido específico**: Incluye términos geográficos (Uttarakhand, Kumaon, Chhattisgarh), religiosos (Hindu, Sanskrit) y lingüísticos (Bharatiya, Hindi).
- **Observación**: La lista mezcla caracteres nepalíes con algunas palabras en inglés ("the", "English") y números romanos.
