# listaProductos.md

## Resumen
Este archivo define la estructura HTML de una cuadrícula de productos para un sitio web, mostrando artículos de mascotas y cuidado personal. Cada tarjeta incluye título, código interno, precio en pesos uruguayos (UYU) e imagen, con enlaces directos a MercadoLibre para la compra.

## Datos clave
- **Proyecto**: Catálogo de productos "CascadeProjects" enfocado en accesorios para mascotas y cuidado personal.
- **Tecnologías**: HTML5 semántico (`<main>`, `<article>`, `<div>`).
- **Decisiones de diseño**: Uso de clases CSS específicas como `products-grid` y `product-card`.
- **Rutas de imágenes**: `/img/Acc para mascotas/...` y `/img/cuidadoPersonal/...`.
- **Moneda**: UYU (Pesos Uruguayos).
- **Pasos importantes**: Los botones redirigen a `https://www.mercadolibre.com` con el atributo `target="_blank"`.
