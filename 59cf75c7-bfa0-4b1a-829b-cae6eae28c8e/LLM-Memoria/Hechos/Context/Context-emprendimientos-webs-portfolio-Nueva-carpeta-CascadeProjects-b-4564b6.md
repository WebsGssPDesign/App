# costos.txt

## Resumen
Este archivo detalla el catálogo de iluminación exterior y decorativa disponible para un proyecto, listando productos como focos solares, paneles LED y guías RGB. Su función principal es registrar los precios en dólares estadounidenses (con IVA), códigos internos y descripciones técnicas breves para facilitar la gestión de inventario o cotizaciones comerciales.
