# README.md

## Resumen
Este archivo documenta la configuración inicial de una página web tipo landing desarrollada con React y Vite. Su propósito es guiar al equipo sobre cómo instalar dependencias, iniciar el entorno en modo desarrollo y generar la versión optimizada para producción.

## Datos clave
- Proyecto: Landing page en React (Vite).
- Tecnologías: React, Vite.
- Comandos importantes: `npm install` (instalación), `npm run dev` (desarrollo), `npm run build` (producción).
- Rutas de archivos: `src/data.js` (contenido editable), `src/styles.css` (estilos), `public/assets` (imágenes).
