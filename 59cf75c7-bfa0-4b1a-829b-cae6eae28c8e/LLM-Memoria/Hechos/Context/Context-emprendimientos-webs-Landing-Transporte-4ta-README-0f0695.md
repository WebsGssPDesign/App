# README.md

## Resumen
Este archivo documenta el desarrollo de una landing page para "Sose Transporte" con diseño Neumorphic Glass en modo oscuro, lista para integrar imágenes reales del cliente. Su objetivo es presentar servicios logísticos y mudanzas en Montevideo e interior, incluyendo tarifas base y métodos de pago.

## Datos clave
- **Proyecto**: Landing page Sose Transporte (versión 4ta).
- **Archivos**: `index.html`, `styles.css`, `script.js`.
- **Imágenes requeridas**: `hero_camion.png`, `equipo_cajas.jpg`, `servicio_1.jpg` a `6.jpg`, `logo.png`.
- **Tarifas definidas**: Camión chico ($1.250), mediano ($1.550) y grande ($1.750). Mínimo 2 horas.
- **Contacto**: Tel. 096 779 565, Instagram @sosetransporte.
- **Pasos pendientes**: Subir fotos a la carpeta `img/`, reemplazar testimonios de ejemplo y configurar el número de WhatsApp en `script.js`.
