# README.md

## Resumen
Este archivo documenta los pasos necesarios para ejecutar y desplegar localmente una aplicación de IA desarrollada en Google AI Studio. Su función principal es guiar al usuario desde la instalación de dependencias hasta el inicio del servidor de desarrollo utilizando claves de API específicas.

## Datos clave
- Proyecto: Aplicación de IA (AI Studio) alojada en `googleai`.
- Tecnologías: Node.js, Gemini API.
- Decisiones y pasos importantes:
  - Instalar dependencias mediante `npm install`.
  - Configurar la variable de entorno `GEMINI_API_KEY` en el archivo `.env.local`.
  - Iniciar la aplicación localmente ejecutando `npm run dev`.
- Rutas/Enlaces: Visualización del app en AI Studio (https://ai.studio/apps/1cd1b8f4-e9a4-4c14-84c7-d0607deecc80).
