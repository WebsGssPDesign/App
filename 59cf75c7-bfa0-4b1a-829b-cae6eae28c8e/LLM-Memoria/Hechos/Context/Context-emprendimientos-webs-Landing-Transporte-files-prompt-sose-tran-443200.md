# prompt-sose-transporte.md

## Resumen
Este documento define las especificaciones para desarrollar una landing page corporativa para "Sose Transporte" con estética Neumorphic Glass y modo oscuro. Su objetivo es presentar servicios de logística y mudanzas optimizados para la conversión directa a través de WhatsApp, utilizando tarifas reales y un diseño visual específico.

## Datos clave
- **Proyecto:** Landing Page Sose Transporte (https://sosetransporte.uy/).
- **Estética:** Neumorphic Glass Corporate (fondo azul oscuro `#0A0F1C`, acento naranja `#F97316`).
- **Imágenes requeridas:** Logo, hero visual y 6 servicios específicos (`service_1.png` a `service_6.png`) más testimonios.
- **Tarifas exactas:** Camión Chico ($1.250), Mediano ($1.550) y Grande ($1.750) + IVA por hora, mínimo 2 horas. Servicios sin precio deben mostrar "Consultar".
- **Enlace WhatsApp:** `https://wa.me/59896779565` (usado en botones y mensaje prellenado).
- **Entregables:** Archivos separados (`index.html`, `styles.css`, `script.js`) y carpeta `/img/`.
- **Tipografía:** "Plus Jakarta Sans" para títulos e "Inter" para cuerpo, cargadas localmente.
