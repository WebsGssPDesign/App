# Hungarian.txt

## Resumen
Este archivo contiene una lista de palabras en húngaro identificadas como "stopwords" o palabras vacías. Sirve para filtrar términos comunes y frecuentes (como artículos, preposiciones y conectores) durante el procesamiento de lenguaje natural, limpieza de datos textuales o análisis de sentimientos en documentos en húngaro.

## Datos clave
- **Proyecto**: Sistema ERP CRM IA GSSP (módulo de texto).
- **Tecnologías**: Python (`justext`), librería de análisis de texto.
- **Contenido principal**: Lista de 500+ palabras húngaras (ej: *a, és, az, nem*) y algunos términos en inglés/otros idiomas mezclados (*of, the, New*).
- **Decisión técnica**: Inclusión de variantes con mayúsculas/minúsculas y puntuación básica para normalización.
- **Uso esperado**: Eliminación de ruido antes de entrenar modelos de IA o generar resúmenes automáticos en húngaro.
