# costos.txt

## Resumen
Este archivo actúa como un catálogo de precios detallado para una variedad de artículos de organización y electrodomésticos pequeños, principalmente bajo la marca Boma. Su función es listar cada producto con su descripción, precio en dólares estadounidenses (más IVA) y código único de referencia para gestión de inventario o ventas.

## Datos clave
- **Proyecto**: Listado de precios de productos de hogar.
- **Tecnologías/Marcas**: Boma (electrodomésticos), códigos propios (ej. YH6616, KR65).
- **Decisiones**: Todos los precios incluyen IVA.
- **Rutas/Categorías**: Organizador de cocina, percheros, freidoras, batidoras, jarras eléctricas y mopas trapeadoras.
- **Pasos importantes**: Identificar el código (ej. BM-3L para freidora 3L) al consultar el precio correspondiente.
