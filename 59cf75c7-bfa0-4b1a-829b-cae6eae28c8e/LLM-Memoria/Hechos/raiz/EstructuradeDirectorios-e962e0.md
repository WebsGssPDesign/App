# EstructuradeDirectorios.md

## Resumen
Este archivo define la estructura de directorios para un entorno de automatización llamado "homeLab". Organiza los recursos en carpetas lógicas como SOPs para procedimientos, Guidelines para normas técnicas y Contexto para datos activos del proyecto. Sirve como mapa de navegación para mantener el orden y facilitar el acceso a documentación específica dentro del sistema.

## Datos clave
- **Proyecto**: homeLab (ubicado en `F:\automatizaciones\`)
- **Estructura principal**:
  - `SOPs/`: Contiene procedimientos paso a paso (`sop-lead-intake.md`, `sop-deployment.md`).
  - `Guidelines/`: Almacena directrices técnicas y de marca.
  - `Context/`: Gestiona datos activos, incluyendo información personal y detalles del proyecto Alpha.
  - `modelos/`: Réplica de la sección Guidelines para normas y marcas.
