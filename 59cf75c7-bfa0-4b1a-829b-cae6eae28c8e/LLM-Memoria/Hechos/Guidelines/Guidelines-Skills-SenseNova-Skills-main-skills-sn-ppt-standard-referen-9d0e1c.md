# design-styles.md

## Resumen
Este documento actúa como una biblioteca de referencia para definir la identidad visual de presentaciones, guiando a los usuarios en la selección de estilos, tonos y colores principales. Su objetivo es asegurar que el diseño final refleje fielmente el propósito del proyecto (breve) mediante la aplicación sistemática de estos elementos en variables CSS (`base.css`).

## Datos clave
- **Proyecto**: SenseNova-Skills (Guías de estilo para presentaciones).
- **Tecnologías**: Variables CSS (`--accent`, `--bg`, `--ink`), diseño visual.
- **Decisiones de diseño**: Selección basada en el "brief" del proyecto (ej.党政风 para gobierno, Cyberpunk para tecnología).
- **Estructura de estilos**: 74 estilos divididos en 13 grupos (Tech, Minimalist, Chinese, etc.), 22 tonos y 29 colores principales.
- **Flujo de trabajo**: Consultar el directorio -> elegir un grupo -> definir tono y color -> aplicar tokens a `base.css`.
- **Ruta crítica**: Solo leer una sección relevante; consultar "Sistemas de coordinación" solo si se requiere armonía completa.
