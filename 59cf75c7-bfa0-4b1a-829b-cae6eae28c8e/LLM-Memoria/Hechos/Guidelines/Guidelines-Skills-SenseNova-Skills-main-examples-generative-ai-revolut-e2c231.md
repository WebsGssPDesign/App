# README.md

## Resumen
Este ejemplo demuestra la capacidad de SenseNova-Skills para generar presentaciones PPT completas utilizando únicamente un prompt, sin archivos de entrada previos. El sistema crea automáticamente diapositivas con contenido, diseño y assets visuales listos para abrir o editar.

## Datos clave
- **Proyecto**: Generación de presentaciones con IA (SenseNova-Skills).
- **Prompt de ejemplo**: "Build an 8-page Chinese PPT titled '生成式AI革命：从聊天机器人到内容生产引擎'..."
- **Flujo de trabajo**: El agente genera secuencialmente archivos de metadatos (`info-pack.json`, `style-spec.json`), HTML por página, imágenes y notas de revisión.
- **Artifacts finales**: Archivo `.pptx` listo para usar y un `.zip` con el código fuente editable (HTML) y artefactos intermedios.
