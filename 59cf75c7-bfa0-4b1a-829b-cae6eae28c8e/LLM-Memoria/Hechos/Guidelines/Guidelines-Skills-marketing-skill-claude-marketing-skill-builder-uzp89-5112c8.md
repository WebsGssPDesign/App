# SKILL.md

## Resumen
Esta guía define un flujo de trabajo para crear secuencias de correos electrónicos coherentes y narrativas (como campañas de bienvenida o nutrimiento). Su objetivo es generar una serie de correos conectados, cada uno con un propósito específico en el arco general, incluyendo tiempos de envío, líneas de asunto, texto previo y llamadas a la acción únicas.

## Datos clave
- **Proyecto**: `marketing-skill-claude-marketing-skill-builder` (Habilidad: email-sequence).
- **Tecnologías/Tools**: Read, Grep, Glob, WebFetch, Write.
- **Ruta crítica**: `${CLAUDE_PLUGIN_ROOT}/references/brand-voice.md`.
- **Pasos importantes**:
  1. Verificar configuración en `brand-voice.md` (tono, audiencia, palabras prohibidas).
  2. Confirmar alcance: objetivo de la secuencia, número de correos y material fuente.
  3. Diseñar el arco narrativo antes de redactar (ej. gancho -> prueba -> objeción -> urgencia).
  4. Redactar cada correo siguiendo una estructura estricta con línea única de CTA.
- **Reglas**: No inventar datos, mantener la voz de marca y asegurar que los asuntos sean distintos entre correos.
