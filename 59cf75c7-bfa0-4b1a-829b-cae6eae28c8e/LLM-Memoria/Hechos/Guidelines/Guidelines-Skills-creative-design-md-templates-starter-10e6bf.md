# starter.md

## Resumen
Este archivo define una plantilla de diseño visual para la marca "MyBrand", estableciendo reglas estrictas sobre colores, tipografía y componentes. Sirve como guía normativa para garantizar consistencia en la identidad gráfica y facilitar el desarrollo rápido de interfaces coherentes.

## Datos clave
- **Proyecto:** MyBrand (versión alpha).
- **Paleta de colores:** Azul oscuro (`#0F172A`), gris azulado (`#64748B`) y azul brillante (`#2563EB`) como primarios; blanco y gris claro para neutros.
- **Tipografía:** Fuente "Inter" para todos los elementos, donde el peso y tamaño definen la jerarquía.
- **Escala de espaciado:** Basada en 4px (xs: 4px, sm: 8px, md: 16px, lg: 24px, xl: 48px).
- **Componentes clave:** `button-primary` como única acción de alto énfasis y `card` sin sombras por defecto.
- **Reglas críticas:** Usar referencias de tokens (`{colors.primary}`) en lugar de hexadecimales literales; evitar anidar variantes de componentes (ej. el hover debe ser hermano, no hijo).
