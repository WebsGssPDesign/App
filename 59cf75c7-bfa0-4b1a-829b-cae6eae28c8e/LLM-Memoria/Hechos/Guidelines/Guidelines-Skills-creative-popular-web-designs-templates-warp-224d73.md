# warp.md

## Resumen
Este documento define el sistema de diseño visual para la web de Warp, enfocándose en una estética cálida y orgánica que contrasta con los tonos fríos típicos de las herramientas de desarrollo. Su objetivo es transmitir confianza y calma mediante un uso restringido del color, tipografía distintiva y fotografía natural integrada.

## Datos clave
- **Tipografía:** Uso principal de la fuente 'Matter' (Regular) para humanizar la interfaz; sustitutos web 'Geist' y 'Geist Mono' vía CDN.
- **Paleta de colores:** Fondo "Deep Void" (negro cálido), texto "Warm Parchment" (#faf9f6) y botones "Earth Gray" (#353534).
- **Estilo visual:** Monocromía cálida, ausencia de gradientes, bordes semitransparentes ("Mist Border") y espaciado negativo en títulos.
- **Implementación:** Generación de HTML autocontenido usando `write_file`, despliegue con `generative-widgets` y verificación visual con `browser_vision`.
