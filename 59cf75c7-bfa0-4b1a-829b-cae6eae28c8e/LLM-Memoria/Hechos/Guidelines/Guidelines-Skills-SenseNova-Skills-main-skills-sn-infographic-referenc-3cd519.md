# hard-alignment.md

## Resumen
Este documento define el estilo "hard-alignment", una guía de diseño donde todos los bordes de los elementos se alinean perfectamente a una cuadrícula compartida para lograr un aspecto preciso y ordenado. Está diseñado específicamente para documentación técnica, referencias con mucha data y contenido corporativo donde la rigurosidad visual refuerza la credibilidad institucional.

## Datos clave
- **Principio central**: Alineación estricta de bordes a una línea de cuadrícula común sin elementos flotantes.
- **Mejor uso**: Documentación de ingeniería, materiales de referencia intensivos en datos y contenido corporativo/institucional.
- **Elementos visuales**: Espaciado consistente (múltiplos de 8px), decoración mínima y líneas de cuadrícula sutiles opcionales.
- **Tipografía**: Todo el texto alineado a la misma cuadrícula con alineación izquierda o centrada uniforme.
- **Combinaciones recomendadas**: `technical-schematic`, `ui-wireframe` y `corporate-memphis`.
