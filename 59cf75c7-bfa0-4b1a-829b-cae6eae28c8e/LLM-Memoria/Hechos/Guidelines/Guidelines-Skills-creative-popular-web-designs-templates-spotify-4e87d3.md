# spotify.md

## Resumen
Este documento define el sistema de diseño visual de Spotify, enfocándose en una estética oscura inmersiva donde la interfaz se desvanece para resaltar el contenido multimedia. Establece reglas estrictas sobre paletas de colores, tipografía y geometría de botones para crear una experiencia táctil y premium. Sirve como guía técnica para replicar fielmente la atmósfera visual de la plataforma web en nuevos proyectos.

## Datos clave
- **Colores principales:** Fondo casi negro (`#121212`), verde marca (`#1ed760`) y superficies oscuras (`#181818`, `#1f1f1f`).
- **Tipografía:** Fuentes propietarias `SpotifyMixUI` con fuentes CDN de respaldo como `DM Sans`.
- **Geometría:** Botones tipo píldora (radio 500px–9999px) y controles circulares (50%).
- **Sombras:** Sombras pesadas (`rgba(0,0,0,0.5)`) para elementos elevados y combinaciones de bordes internos.
- **Herramientas sugeridas:** Uso de `write_file`, `generative-widgets` y `browser_vision` para implementación y verificación.
