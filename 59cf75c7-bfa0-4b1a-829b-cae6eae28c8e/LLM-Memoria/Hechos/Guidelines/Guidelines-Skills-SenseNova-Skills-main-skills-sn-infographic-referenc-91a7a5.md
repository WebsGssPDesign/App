# binary-comparison.md

## Resumen
Este documento define las pautas de diseño para crear infografías de comparación binaria, estructuradas verticalmente para contrastar dos elementos, estados o conceptos. Su objetivo es facilitar la evaluación visual rápida mediante layouts espejo y distinciones claras entre lados opuestos. Sirve como referencia técnica para aplicar variantes específicas según el tipo de análisis requerido.

## Datos clave
- **Estructura**: Divisor vertical central que separa el lado izquierdo (Item A/Before/Pro) del derecho (Item B/After/Con).
- **Variantes principales**: Before-After (transformación temporal), A vs B (contraste de características) y Pro-Con (evaluación equilibrada).
- **Elementos visuales**: Línea divisoria fuerte o degradado, colores contrastantes por lado, símbolo "VS" y flechas de transformación.
- **Colocación de texto**: Título centrado arriba, etiquetas laterales alineadas horizontalmente con los puntos correspondientes.
- **Estilos recomendados**: `corporate-memphis` para negocios, `high-contrast-ad` para comparaciones dramáticas y `paper-collage` para explicaciones amigables.
