# SKILL.md

## Resumen
Esta guía define el protocolo para manipular archivos `.pptx`, cubriendo su lectura, edición y creación desde cero. Su objetivo es estandarizar flujos de trabajo técnicos mediante scripts específicos y establecer principios de diseño visual robustos para evitar presentaciones genéricas o aburridas.

## Datos clave
- **Herramientas**: `python -m markitdown` (extracción de texto), `thumbnail.py` (vista previa), `unpack.py` (desempaquetado XML).
- **Flujo de edición**: Analizar plantilla → Desempaquetar → Manipular diapositivas → Limpiar → Empaquetar.
- **Creación desde cero**: Referencia a `pptxgenjs.md`.
- **Diseño visual**: Paletas temáticas específicas (ej. "Midnight Executive"), jerarquía de colores 60/30/10, y tipografía personalizada (evitar Arial por defecto).
- **Reglas estrictas**: Evitar diapositivas solo con texto, usar márgenes mínimos de 0.5", alinear cuerpo a la izquierda y mantener consistencia en el espaciado.
