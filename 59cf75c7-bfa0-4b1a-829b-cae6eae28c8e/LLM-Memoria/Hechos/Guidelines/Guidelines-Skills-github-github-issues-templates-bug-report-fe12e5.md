# bug-report.md

## Resumen
Este archivo define una plantilla estandarizada para reportar errores en el proyecto GitHub Skills. Su función es guiar a los usuarios para que proporcionen información estructurada y completa sobre fallos detectados, facilitando la depuración por parte del equipo de desarrollo.

## Datos clave
- **Proyecto**: GitHub Skills (sección de plantillas de issues).
- **Tecnologías/Entorno**: Python, navegadores web, sistemas operativos genéricos.
- **Pasos importantes**: La plantilla exige describir el comportamiento esperado vs. real, listar los pasos para reproducir el error y adjuntar salidas de errores o contexto adicional como capturas de pantalla.
