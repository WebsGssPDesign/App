# spacex.md

## Resumen
Esta guía define el sistema de diseño de SpaceX, enfocado en una experiencia cinematográfica que prioriza la fotografía a pantalla completa sobre elementos de interfaz tradicionales. Su objetivo es crear una estética industrial y militar mediante tipografía en mayúsculas, espaciado amplio y un minimalismo radical sin contenedores ni sombras. Sirve como referencia técnica para replicar el estilo visual único de la marca utilizando fuentes web accesibles como sustitutos de las propietarias originales.

## Datos clave
- **Tipografía:** Sustituto `Inter` (principal) y pila monoespaciada del sistema; uso obligatorio de mayúsculas universales (`text-transform: uppercase`).
- **Paleta de colores:** Fondo negro puro (`#000000`) y texto blanco espectral (`#f0f0fa`); botones "fantasma" con fondo `rgba(240, 240, 250, 0.1)`.
- **Estructura visual:** Secciones a pantalla completa sin tarjetas ni contenedores; texto directo sobre imágenes.
- **Implementación:** Usar `write_file` para generar HTML y verificar con `browser_vision`; evitar sombras o bordes excepto en botones.
