# base-prompt.md

## Resumen
Este archivo define las directrices para generar infografías profesionales utilizando plantillas parametrizadas. Su función es estandarizar la creación visual de contenido técnico, asegurando coherencia en diseño, tipografía y jerarquía de información sin depender de códigos hexadecimales.

## Datos clave
- **Proyecto**: SenseNova-Skills (creación de infografías).
- **Tecnologías/Formato**: Markdown con variables parametrizadas ({{LAYOUT}}, {{STYLE}}, etc.).
- **Decisiones de diseño**: Uso exclusivo de nombres descriptivos de colores; prohibición de códigos hexadecimales.
- **Requisitos visuales**: Inclusión obligatoria de ilustraciones primarias, marcadores distintivos por sección y uso abundante de espacio en blanco.
- **Manejo de datos**: Números, fechas y nombres propios deben destacarse mediante negritas o cajas de llamada visual.
- **Contenido sensible**: Si hay figuras protegidas, se deben crear alternativas estilísticamente similares.
