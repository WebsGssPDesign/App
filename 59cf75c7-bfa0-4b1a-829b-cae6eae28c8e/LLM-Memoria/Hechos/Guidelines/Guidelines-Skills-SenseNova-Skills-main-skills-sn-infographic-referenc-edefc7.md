# bridge.md

## Resumen
Este archivo define las directrices de diseño para crear diagramas tipo "puente", utilizados para visualizar la transición desde un estado actual o problema hacia una solución deseada. Sirve como referencia visual para ilustrar brechas, desafíos y los pasos metodológicos necesarios para cerrar dicha distancia estratégica.

## Datos clave
- **Concepto central**: Estructura de puente que conecta dos plataformas (lado izquierdo: estado actual/problema; lado derecho: estado futuro/solución).
- **Elementos visuales obligatorios**: Brecha o abismo visible, estructura del puente con soportes, iconos para cada extremo y elementos intermedios como piedras o tablas.
- **Ubicación de texto**: Título en la parte superior, etiquetas "From" (Izquierda) y "To" (Derecha), descripción de la brecha debajo.
- **Estilos recomendados**: `crayon-hand-drawn` para viajes amigables, `corporate-memphis` para transformaciones empresariales y `origami` para transiciones técnicas.
