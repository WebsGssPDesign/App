# typography.md

## Resumen
Este documento técnico documenta las capacidades de tipografía en p5.js, cubriendo la carga de fuentes (sistema y personalizadas), el renderizado básico y avanzado, y técnicas creativas como texto a partículas o máscaras. Sirve como referencia para implementar efectos visuales dinámicos, animaciones de escritura y manipulación geométrica del texto en proyectos interactivos.

## Datos clave
- **Carga de fuentes**: Uso de `loadFont()` para OTF/TTF (requiere servidor local) vs Google Fonts vía CSS (limitado a `text()`).
- **Propiedades críticas**: `textAlign`, `textSize`, `textLeading` y `textWrap` para control preciso.
- **Métricas**: Funciones `textWidth`, `textAscent`, `textDescent` y `textBounds` para cálculos espaciales.
- **Texto a partículas**: Conversión de texto a puntos con `font.textToPoints()` para animaciones complejas.
- **Efectos visuales**: Implementación de efectos "wave text", máquina de escribir ("typewriter") y animación carácter por carácter.
- **Máscaras**: Uso de buffers gráficos (`createGraphics`) para crear máscaras de texto.
