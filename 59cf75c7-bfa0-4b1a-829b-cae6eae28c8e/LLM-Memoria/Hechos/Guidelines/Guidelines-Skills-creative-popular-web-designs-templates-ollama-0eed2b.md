# ollama.md

## Resumen
Este documento define el sistema de diseño del sitio web de Ollama, caracterizado por un minimalismo radical en escala de grises y una estética "soft" basada en formas redondeadas. Su objetivo es guiar a los desarrolladores para crear interfaces que reflejen la simplicidad esencial del producto, utilizando exclusivamente tonos monocromáticos sin degradados ni sombras.

## Datos clave
- **Tipografía:** Fuentes `Inter` (primaria) y `JetBrains Mono` (monoespaciada) como sustitutos de las fuentes propietarias originales.
- **Geometría:** Uso exclusivo de bordes redondeados tipo píldora (`9999px`) para elementos interactivos y `12px` para contenedores.
- **Paleta de colores:** Estrictamente monocromática (blanco puro, negro puro y tonos grises) con la única excepción del azul anillo (`#3b82f6`) para accesibilidad por teclado.
- **Herramientas sugeridas:** Generación de HTML vía `write_file`, despliegue mediante `generative-widgets` y verificación visual con `browser_vision`.
- **Restricciones:** Prohibido el uso de degradados, sombras o colores cromáticos; la profundidad se logra solo mediante cambios sutiles en los fondos.
