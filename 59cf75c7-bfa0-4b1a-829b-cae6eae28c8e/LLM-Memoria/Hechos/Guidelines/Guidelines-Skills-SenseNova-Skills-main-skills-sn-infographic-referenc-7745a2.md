# three-tier.md

## Resumen
Este documento define la estructura del diseño de tres niveles (header, body, footer) para infografías y reportes. Sirve como guía técnica para organizar el contenido visualmente en bandas horizontales con roles específicos, asegurando una separación clara y un flujo lógico de información.

## Datos clave
- **Estructura**: Tres bandas apiladas verticalmente (ej. 20% / 60% / 20%) con separación visual definida.
- **Variantes principales**: "Header-Body-Footer" para estructuras estándar y "Intro-Detail-Summary" para flujos educativos.
- **Elementos visuales**: Uso de colores/texturas distintos por banda, reglas horizontales o divisores decorativos, e íconos ancladores.
- **Colocación de texto**: Título/gancho arriba, contenido principal en el medio y resumen/CTA abajo.
- **Estilos recomendados**: `corporate-memphis` (reportes), `chalkboard` (educativo) y `aged-academia` (contenido histórico).
