# neon-futurism.md

## Resumen
Este documento define una guía de estilo visual para un diseño futurista basado en neón puro, evitando elementos distópicos o decadentes. Su propósito es estandarizar la apariencia óptica para proyectos que buscan transmitir innovación, tecnología limpia y optimismo hacia el futuro.

## Datos clave
- **Paleta de colores**: Neón rosa, azul eléctrico, cian y púrpura sobre fondos con degradados oscuros y negros profundos.
- **Elementos visuales**: Contornos neón limpios, superficies pulidas, haces de luz, formas geométricas y transiciones de color sin texturas sucias o grunge.
- **Tipografía**: Letras sans-serif brillantes, ligeras y con efectos de degradado para evocar una atmósfera futurista y aireada.
- **Aplicaciones ideales**: Conceptos futuros, productos tecnológicos, temas de innovación y contenido orientado a lo avanzado.
