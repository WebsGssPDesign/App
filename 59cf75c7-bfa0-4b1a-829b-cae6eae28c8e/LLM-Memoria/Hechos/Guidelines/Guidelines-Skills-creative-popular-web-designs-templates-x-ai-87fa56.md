# x.ai.md

## Resumen
Este documento define el sistema de diseño para la web de xAI, caracterizado por un minimalismo brutalista oscuro y tipografía monoespaciada extrema. Su objetivo es transmitir credibilidad técnica mediante una estética austera que prioriza la infraestructura sobre los elementos decorativos. Sirve como guía visual para replicar fielmente el estilo único del sitio utilizando herramientas específicas de desarrollo web.

## Datos clave
- **Proyecto**: Diseño del sitio web de xAI (Hermes Agent).
- **Tecnologías**: Tailwind CSS con valores arbitrarios, Heroicons SVG, Google Fonts CDN.
- **Decisiones de diseño**: Uso de `Geist Mono` como fuente principal para títulos a escala extrema (320px) y botones en mayúsculas; fondo casi negro (`#1f2228`) con texto blanco puro.
- **Paleta de colores**: Exclusivamente blanco y tonos oscuros, sin gradientes ni sombras decorativas.
- **Pasos de implementación**: Generar HTML con `write_file`, servir mediante `generative-widgets` (túnel cloudflared) y verificar visualmente con `browser_vision`.
