# craft-handmade.md

## Resumen
Este documento define la estética "craft-handmade", una guía para crear infografías con un estilo dibujado a mano y artesanal que evoca calidez y organicidad. Su propósito es estandarizar el uso de elementos visuales imperfectos, colores pastel y tipografía casual para contenidos educativos o lúdicos, asegurando que toda la ilustración mantenga una coherencia cartoon estricta sin incluir fotografías realistas.

## Datos clave
- **Estilo visual**: Líneas ligeramente imperfectas, formas orgánicas, sombras de capas (para variante de papel cortado) y bordes desgarrados.
- **Paleta de colores**: Tonos pastel cálidos, colores saturados suaves, tonos de papel artesanal, fondo crema (#FFF8F0) y acentos en colores de cartulina.
- **Tipografía**: Fuentes manuscritas o casuales; letras estilo recorte para la variante de papel.
- **Restricciones críticas**: Prohibido el uso de elementos realistas o fotográficos; todos los personajes e iconos deben ser ilustraciones cartoon.
- **Uso recomendado**: Contenido educativo, explicaciones generales, infografías amigables y jerarquías juguetonas para niños.
