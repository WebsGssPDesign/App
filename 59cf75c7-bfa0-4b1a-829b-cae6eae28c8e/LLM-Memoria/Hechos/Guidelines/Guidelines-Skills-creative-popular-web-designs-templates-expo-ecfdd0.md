# expo.md

## Resumen
Este documento define el sistema de diseño visual para la plataforma Expo, estableciendo una estética luminosa y monocrómica centrada en la claridad técnica. Su objetivo es guiar a los desarrolladores en la implementación de interfaces que se sientan tan pulidas como las aplicaciones construidas con sus herramientas, utilizando un esquema de colores específico y geometrías orgánicas.

## Datos clave
- **Tipografía:** Sustitución de fuentes propietarias por `Inter` (principal) y `JetBrains Mono` (monoespaciado) vía CDN.
- **Paleta de colores:** Fondo principal "Cloud Gray" (`#f0f0f3`) con textos en negro puro (`#000000`) y grises azulado; acentos limitados a cobalto, azul legal y cian.
- **Geometría:** Uso exclusivo de bordes redondeados tipo píldora (24px–9999px) para botones, contenedores e imágenes.
- **Tipografía masiva:** Títulos grandes (64px) con espaciado entre letras negativo extremo (-1.6px a -3px).
- **Flujo de trabajo:** Generación de HTML mediante `write_file`, despliegue local con `generative-widgets` y verificación visual usando `browser_vision`.
