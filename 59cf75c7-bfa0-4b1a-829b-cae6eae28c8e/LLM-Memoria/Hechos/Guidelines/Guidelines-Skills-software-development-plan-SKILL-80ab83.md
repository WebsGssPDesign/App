# SKILL.md

## Resumen
Este documento define el "Modo Plan" para un agente de desarrollo, instruyéndolo a generar planes de implementación detallados en lugar de ejecutar código directamente. Su objetivo es crear guías accionables y granulares (tareas de 2-5 minutos) que permitan una ejecución segura y estructurada mediante subagentes o desarrolladores humanos.

## Datos clave
- **Proyecto**: Hermes Agent (adaptación de obra/superpowers).
- **Tecnologías/Formato**: Markdown, Git (`git add`, `git commit`), pytest.
- **Rutas críticas**: `.hermes/plans/YYYY-MM-DD_HHMMSS-<slug>.md`.
- **Comandos clave**: `write_file`, `search_files`, `read_file`.
- **Pasos del flujo**: 1. Entender requisitos, 2. Explorar código (lectura solo), 3. Diseñar arquitectura, 4. Escribir tareas paso a paso con pruebas y commits específicos.
