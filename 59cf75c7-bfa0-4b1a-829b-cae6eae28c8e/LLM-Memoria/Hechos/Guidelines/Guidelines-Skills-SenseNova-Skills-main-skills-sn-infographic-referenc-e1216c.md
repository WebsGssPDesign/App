# conflict-contrast.md

## Resumen
Este documento define la técnica de "conflicto-contraste" para infografías, diseñada para visualizar narrativas que oponen dos estados o ideas mediante una composición visual tensa y dramática. Sirve como guía práctica para crear diseños que resalten diferencias marcadas, como problemas versus soluciones o paradigmas antiguos frente a nuevos, utilizando límites irregulares y contrastes de color intensos.

## Datos clave
- **Concepto central**: Juxtaposición de dos estados opuestos (ej. negativo vs positivo) enfocada en el conflicto, no en la comparación neutral.
- **Estructura visual**: Lienzo dividido en dos zonas con fuerte contraste de color/textura y un límite dinámico o irregular entre ellas.
- **Elementos clave**: Tensión en el borde central, etiquetas dentro de cada zona y título superior; opción de incluir un elemento de conflicto central.
- **Casos de uso ideales**: Narrativas problema/solución, evolución temporal (viejo vs nuevo) y contrastes ideológicos.
- **Combinaciones recomendadas**: `high-contrast-ad`, `neon-futurism` y `chalkboard`.
