# pr-body-feature.md

## Resumen
Este archivo es una plantilla de Markdown diseñada para estandarizar el cuerpo de las pull requests en GitHub. Su función principal es guiar a los desarrolladores para que documenten claramente la motivación, los cambios realizados y el plan de pruebas antes de solicitar revisión del código.

## Datos clave
- **Proyecto**: Flujos de trabajo (workflows) de contribución a proyectos de código abierto.
- **Tecnologías**: Markdown, GitHub Pull Requests.
- **Pasos importantes**: Incluir puntos clave en "Summary", cerrar issues relacionados en "Motivation" y verificar la ejecución de pruebas unitarias (`pytest`) en el apartado "Test Plan".
