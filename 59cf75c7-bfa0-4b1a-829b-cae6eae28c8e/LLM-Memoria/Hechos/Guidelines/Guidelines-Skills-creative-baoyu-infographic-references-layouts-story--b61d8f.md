# story-mountain.md

## Resumen
Este documento define la estructura visual de un diagrama tipo "montaña" para representar arcos narrativos o ciclos de proyectos. Sirve como guía técnica para diseñar infografías que muestren claramente el desarrollo, el clímax y la resolución de una historia o proceso mediante curvas ascendentes y descendentes.

## Datos clave
- **Proyecto**: Visualización de estructuras narrativas (story-mountain).
- **Tecnologías/Estilos recomendados**: `storybook-watercolor` para viajes narrativos, `cartoon-hand-drawn` para diagramas educativos y `graphic-novel` para arcos dramáticos.
- **Elementos visuales**: Curva de montaña o arco con puntos clave (campamentos base, hitos) y el clímax enfatizado visualmente.
- **Ubicación del texto**: Título en la parte superior, etiquetas de etapas a lo largo del camino y descripciones breves en los puntos críticos.
