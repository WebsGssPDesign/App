# jigsaw.md

## Resumen
Este documento define las directrices de diseño para infografías tipo rompecabezas, detallando su estructura visual y casos de uso ideales. Sirve como referencia técnica para ilustrar relaciones entre componentes, ajustes de equipo o estrategias mediante piezas interconectadas que pueden mostrarse ensambladas o desmontadas.

## Datos clave
- **Concepto central**: Piezas entrelazadas donde cada una representa un componente con conexiones visibles.
- **Casos de uso**: Relaciones de componentes, ajuste de equipos/habilidades, piezas estratégicas y evaluaciones de integridad.
- **Elementos visuales**: Formas clásicas de rompecabezas, colores distintivos por pieza, bordes entrelazados visibles e iconos o etiquetas.
- **Colocación de texto**: Título superior, etiquetas dentro o junto a las piezas, descripciones de conexiones y explicaciones sobre piezas faltantes.
- **Combinaciones recomendadas**: `crayon-hand-drawn` (conceptos amigables), `paper-collage` (sensación táctil) y `corporate-memphis` (estrategias empresariales).
