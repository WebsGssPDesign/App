# SKILL.md

## Resumen
Este documento describe Hermes Agent, un marco de trabajo de agentes de IA autónomos que ejecuta tareas en terminales, aplicaciones nativas y entornos de desarrollo. Su función principal es permitir la configuración, extensión y contribución al sistema mediante habilidades acumulables, memoria persistente entre sesiones y compatibilidad con múltiples proveedores de modelos de lenguaje.

## Datos clave
- **Proyecto**: Hermes Agent (Nous Research).
- **Tecnologías**: Python, CLI, TUI (Ink), Electron, MCP servers, integraciones con Telegram/Discord/Slack.
- **Decisiones**: Soporte multiplataforma (Linux, macOS, Windows) y agnóstico de proveedores (OpenRouter, Anthropic, etc.).
- **Comandos/Rutas importantes**: `hermes --help`, `hermes setup` (asistente interactivo), `hermes model` (selección de modelos), `hermes doctor` (diagnóstico), `hermes config edit`.
- **Instalación**: Script oficial (`install.sh`) o vía PyPI (`pip install hermes-agent`).
