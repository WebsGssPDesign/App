# notion.md

## Resumen
Este documento define el sistema de diseño visual de la web de Notion, enfocado en replicar su estética minimalista y cálida mediante una paleta de neutros con tonos amarillos-marrones y tipografía personalizada. Sirve como guía técnica para implementar interfaces que utilicen fuentes alternativas vía CDN y sigan reglas estrictas de espaciado, bordes sutiles y jerarquías tipográficas específicas.

## Datos clave
- **Proyecto**: Hermes Agent (implementación de sitios web).
- **Tecnologías**: HTML, CSS, Google Fonts (`Inter`), `generative-widgets`, `browser_vision`.
- **Decisiones de diseño**: Sustitución de fuentes propietarias por `Inter`; uso de opacidad 95% en texto negro para suavizar; bordes ultra-delgados (0.1 opacidad).
- **Paleta de colores**: Blanco puro (`#ffffff`), Negro cálido (`rgba(0,0,0,0.95)`), Azul Notion (`#0075de`) como único color saturado principal, y escala de grises cálidos (`#f6f5f4`, `#31302e`).
- **Tipografía**: Espaciado negativo agresivo (-2.125px) en títulos a 64px; uso de características OpenType `"lnum"` y `"locl"`.
- **Comandos/Skills**: `write_file` para generar HTML, `browser_vision` para verificación visual.
