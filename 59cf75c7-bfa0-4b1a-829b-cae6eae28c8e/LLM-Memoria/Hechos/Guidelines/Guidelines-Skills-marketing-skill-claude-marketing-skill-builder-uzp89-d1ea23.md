# marketing-setup.md

## Resumen
Este archivo define un flujo de configuración conversacional para establecer las preferencias iniciales de una habilidad de marketing. Su función es capturar prioridades de tareas, tipos de contenido, audiencia y tono, guardándolas en un archivo central (`brand-voice.md`) para que otras herramientas del plugin utilicen estos parámetros por defecto sin necesidad de repetición constante.

## Datos clave
- **Archivo objetivo:** `references/brand-voice.md` (se actualiza con la fecha y marca de configuración).
- **Paso 1:** Leer el archivo existente; si ya está configurado, mostrar valores actuales para permitir actualizaciones parciales.
- **4 Preguntas obligatorias:** Prioridad de tarea, tipos de contenido, audiencia/tono y formato de salida por defecto.
- **Opcional:** Configuración de lista de palabras prohibidas y, si hay video, propuesta de identidad sonora (género, tempo, hook) basada en `references/sound-guide.md`.
- **Restricciones:** No inventar respuestas; mantener la estructura exacta de encabezados del archivo original.
- **Herramientas permitidas:** Read, Write.
