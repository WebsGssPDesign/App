# material-design.md

## Resumen
Este documento define las directrices de diseño visual basadas en Material Design de Google, enfocándose en una metáfora de papel y tinta con profundidad y sombras. Sirve como referencia técnica para crear interfaces de usuario coherentes dentro del ecosistema Android y documentación de sistemas de diseño.

## Datos clave
- **Proyecto**: SenseNova Skills (sección de infografías).
- **Tecnologías/Estilos**: Material Design, paleta de colores primarios y acentos, sistema de elevación (z-depth), botones flotantes y tarjetas.
- **Tipografía**: Fuente Roboto o similar sans-serif humanista con una escala clara (Display, Headline, Body).
- **Sistema de cuadrícula**: Espaciado basado en 8dp.
- **Elementos visuales**: Sombras de caída, indicadores de movimiento tipo "ripple" e iconos gruesos.
- **Uso recomendado**: Explicaciones de UI/UX, documentación del ecosistema Android y diagramas de procesos técnicos.
