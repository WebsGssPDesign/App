# pixel-art.md

## Resumen
Este documento define una guía de estilo para crear infografías con estética de videojuegos retro 8-bit. Su propósito es estandarizar el uso de paletas de colores limitadas, elementos visuales pixelados y tipografía bloqueante para evocar nostalgia en temas relacionados con gaming o tecnología antigua.

## Datos clave
- **Estética**: Retro 8-bit (estilo NES/SNES).
- **Paleta de colores**: Fondo negro o azul oscuro (opcional: líneas de barrido), acentos brillantes y efecto de brillo CRT.
- **Elementos visuales**: Cuadrícula de píxeles visible, dithering para gradientes, bordes perfectamente pixelados.
- **Tipografía**: Fuentes pixeladas con formas de letras bloqueantes y estilo de interfaz de usuario de juegos (puntuaciones/estadísticas).
- **Uso recomendado**: Temas de gaming, contenido nostálgico, audiencias de desarrolladores y temas de tecnología retro.
