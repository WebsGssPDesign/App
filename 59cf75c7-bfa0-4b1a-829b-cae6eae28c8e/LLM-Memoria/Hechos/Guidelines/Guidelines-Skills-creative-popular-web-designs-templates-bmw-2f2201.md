# bmw.md

## Resumen
Este documento define el sistema de diseño de la web de BMW, enfocado en transmitir precisión e ingeniería alemana mediante una estética angular y minimalista. Sirve como guía técnica para replicar la identidad visual CI2020, especificando tipografías, paleta de colores y reglas de composición para entornos digitales.

## Datos clave
- **Tipografía:** Uso principal de `BMWTypeNextLatin` (Light 300 para titulares gigantes en mayúsculas, Regular para cuerpo). Fallbacks: Helvetica, Arial, Hiragino, Meiryo.
- **Paleta de colores:** Blanco puro (`#ffffff`) y Negro cercano (`#262626`) como base; Azul BMW (`#1c69d4`) exclusivo para interactividad; Grises metálicos para texto secundario.
- **Geometría:** Cero `border-radius` en botones, tarjetas y contenedores; diseño angular y geométrico estricto.
- **Espaciado:** Líneas muy comprimidas (1.15–1.30) para dar sensación de eficiencia industrial.
- **Implementación:** Sustitución de fuentes propietarias por `DM Sans` vía CDN Google Fonts para HTML autocontenido; uso de variables CSS (`--site-context-*`) para temas multi-marca.
