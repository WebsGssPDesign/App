# sn-motion-html_cn.md

## Resumen
Este documento describe una metodología para crear historias web inmersivas que avanzan con el desplazamiento, utilizando un flujo de trabajo automatizado basado en Python y generación de video. Sirve como guía técnica para estructurar proyectos desde la planificación creativa hasta la entrega final, asegurando consistencia visual y funcionalidad responsive.

## Datos clave
- **Proyecto**: `sn-motion-html` para narrativas visuales interactivas.
- **Tecnologías**: Python, FFmpeg, Seedance (modelo `doubao-seedance-2-5-260628`), JSON (`content/story.json`).
- **Comandos principales**: `init_project.py` para configuración inicial; `seedance_pipeline.py` para generar planos y conexiones; `verify_media.py` y `contact_sheet.py` para validación.
- **Flujo crítico**: Aprobación de estilo y guion antes de la generación de video real (dry-run obligatorio).
- **Requisitos**: Archivo `.env` local con credenciales Ark, compatibilidad con navegadores modernos y soporte para modos reducidos de movimiento.
