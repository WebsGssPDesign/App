# isometric-map.md

## Resumen
Este documento define las directrices para crear mapas isométricos que representan layouts espaciales, arquitecturas de sistemas o trayectorias de usuario mediante una perspectiva tridimensional. Sirve como referencia técnica para diseñar visualizaciones claras donde los edificios y rutas conecten puntos clave desde un ángulo de 30 grados.

## Datos clave
- **Proyecto**: SenseNova-Skills (layout isométrico).
- **Estructura**: Perspectiva isométrica, ubicaciones como edificios/monumentos, caminos conectores y relaciones espaciales visibles.
- **Mejor uso**: Layouts de oficinas/campus, mapas de ciudades/ecosistemas, mapas de viaje del usuario, arquitectura de sistemas y paisajes de procesos.
- **Elementos visuales**: Ángulo consistente (30°), edificios u objetos 3D, senderos, etiquetas flotantes y mini escenas en ubicaciones.
- **Ubicación de texto**: Título en esquina superior, etiquetas de ubicación sobre objetos, etiquetas de ruta a lo largo de los caminos, leyenda de símbolos e indicador de escala si aplica.
- **Pares recomendados**: `origami` (mapas técnicos limpios), `pixel-art` (estilo retro) y `lego-brick` (mapas lúdicos).
