# SKILL.md

## Resumen
Este documento define un sistema de plantillas para estructurar informes de investigación basándose en la tarea cognitiva del lector (panorama, comparación, investigación o cronología) y el dominio específico. Su función es estandarizar la organización del contenido para garantizar que los resultados sean claros, comparables y adaptables a contextos como académico, médico, legal o político.

## Datos clave
- **Lógica de selección**: Se decide primero si el informe es "dominio exclusivo" (ej. legal) o por "tarea cognitiva" principal (ej. comparación).
- **Plantillas principales**: Panorama narrativo, Comparación/Selección, Investigación de entidad y Seguimiento temporal.
- **Formatos visuales obligatorios**: Uso forzado de Mermaid (`pie`, `graph`, `timeline`) para datos específicos; prohibido usar texto plano para matrices o líneas de tiempo.
- **Disciplina de ejecución**: Los resúmenes deben ser autónomos, las conclusiones deben incluir nivel de certeza y los informes compuestos deben comprimir sub-intenciones en un solo capítulo.
