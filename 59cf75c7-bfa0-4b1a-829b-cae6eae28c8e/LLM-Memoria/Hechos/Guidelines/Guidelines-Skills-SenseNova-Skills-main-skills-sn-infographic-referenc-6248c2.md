# analysis-framework.md

## Resumen
Este documento establece un marco de análisis profundo para la creación de infografías basado en principios de diseño instruccional. Su objetivo es guiar al creador para que identifique objetivos de aprendizaje claros, clasifique el tipo de contenido y seleccione las combinaciones óptimas de estructura y estilo visual sin alterar los datos originales.

## Datos clave
- **Principios**: Comprensión profunda, enfoque centrado en el aprendiz, narrativa visual y carga cognitiva reducida.
- **Clasificación de contenido**: Mapea 20 tipos (ej. línea de tiempo, proceso, jerarquía) con sus mejores estructuras (lineal-progression, matriz) y estilos (swiss-style, data-visualization).
- **Objetivos de aprendizaje**: Deben ser específicos, medibles y redactados desde la perspectiva del espectador ("después de ver...").
- **Análisis de audiencia**: Evaluar nivel de conocimiento, contexto, expectativas y preferencias visuales.
- **Evaluación de complejidad**: Clasifica el contenido en simple (3-5 puntos), moderado (6-8) o complejo (9+) para elegir la densidad del diseño.
- **Mapeo visual**: Convierte elementos como estadísticas, comparaciones y procesos en tratamientos visuales específicos (números grandes, flechas, pirámides).
