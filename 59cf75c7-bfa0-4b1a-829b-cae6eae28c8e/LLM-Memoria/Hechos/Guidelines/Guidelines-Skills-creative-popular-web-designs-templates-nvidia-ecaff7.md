# nvidia.md

## Resumen
Este documento define el sistema de diseño para sitios web inspirados en NVIDIA, enfocándose en una estética industrial de alto contraste con fondo negro y acentos verdes específicos. Sirve como guía técnica para replicar la atmósfera visual precisa, incluyendo paletas de colores, reglas tipográficas estrictas y estados interactivos mediante HTML y React.

## Datos clave
- **Colores principales:** NVIDIA Green (#76b900) solo para bordes y acentos; fondo negro (#000000) y texto blanco.
- **Tipografía:** Fuente primaria 'NVIDIA-EMEA' (con fallbacks Arial/Helvetica); Inter para versiones autocontenidas en CDN.
- **Estilo visual:** Líneas de altura ajustadas (1.25), radios de borde mínimos (1-2px) y sombras sutiles.
- **Herramientas sugeridas:** PrimeReact, Fluent UI, Element Plus; verificación con `browser_vision`.
- **Iconografía:** Font Awesome 6 Pro/Sharp con pesos específicos para nitidez.
