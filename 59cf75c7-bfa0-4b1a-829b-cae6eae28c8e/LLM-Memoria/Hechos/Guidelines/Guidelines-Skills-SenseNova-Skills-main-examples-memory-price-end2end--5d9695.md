# README.md

## Resumen
Este documento detalla un flujo de trabajo completo que transforma datos crudos de precios de chips en una presentación profesional estilo revista. El proceso valida tendencias de precios mediante análisis, investiga las causas subyacentes con investigación profunda y genera automáticamente diapositivas visuales listas para uso editorial.

## Datos clave
- **Entrada**: Archivo `芯片价格汇总.csv` (1.835 registros de 2026-01 a 2026-04).
- **Habilidades encadenadas**: `sn-da-excel-workflow` (análisis), `sn-deep-research` (investigación externa) y `sn-ppt-standard` (generación de PPTX).
- **Flujo de trabajo**: Limpieza de datos → Informe Markdown/HTML → Investigación de causas (volatilidad por IA/supply) → Presentación final con estilo "red and gold".
- **Salidas principales**: `半导体存储市场研究报告_20260426_015200.pptx` y archivos HTML fuente.
