# SKILL.md

## Resumen
Este documento describe un flujo de trabajo en Python para visualizar datos estructurados mediante gráficos de líneas, integrando limpieza avanzada y análisis estadístico. Su objetivo es generar reportes multidimensionales que incluyan tendencias, distribuciones y agrupamientos automáticos para facilitar la toma de decisiones basada en datos complejos.

## Datos clave
- **Proyecto**: Visualización de datos con Excel (SN-DA).
- **Tecnologías**: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn.
- **Decisiones**: Conversión a Parquet para archivos >10k filas; detección dinámica de encabezados.
- **Pasos importantes**: Normalización con `StandardScaler`, clustering K-Means (3 grupos), mapeo de categorías y generación de 4 gráficos (tendencia, histograma, pastel, dispersión).
