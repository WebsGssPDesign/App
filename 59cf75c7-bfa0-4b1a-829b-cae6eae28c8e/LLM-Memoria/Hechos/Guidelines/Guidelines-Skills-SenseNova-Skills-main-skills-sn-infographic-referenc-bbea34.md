# instructional-visual.md

## Resumen
Este documento define las directrices de diseño para crear ilustraciones instruccionales claras y universales. Su propósito es estandarizar la creación de guías paso a paso mediante el uso de visuales simples que prioricen la claridad sobre el realismo fotográfico, facilitando la comprensión rápida en manuales técnicos o procedimientos de seguridad.

## Datos clave
- **Paleta de colores**: Base neutra con 2–3 colores funcionales; fondo blanco/gris claro; acentos para acciones (azul/verde) y advertencias (naranja/rojo).
- **Elementos visuales**: Ilustraciones de línea simple (manos, objetos), indicadores numerados en círculos o cuadrados negritas, conectores con flechas y pares "hacer/no hacer".
- **Tipografía**: Sans-serif clara y mediana; etiquetas imperativas cortas ("Presionar", "Insertar"); números grandes.
- **Estilo general**: Siluetas claras, consistencia en personajes/objetos, sin realismo fotográfico para mantener universalidad.
- **Casos de uso ideales**: Instrucciones de ensamblaje, guías de uso, procedimientos de seguridad y flujos de incorporación.
