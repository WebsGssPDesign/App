# comparison-matrix.md

## Resumen
Este documento define una matriz de comparación basada en rejillas para evaluar múltiples elementos según diversos criterios. Sirve como guía visual y estructural para presentar datos comparativos de forma clara, facilitando la toma de decisiones en evaluaciones de productos o herramientas.

## Datos clave
- **Estructura**: Tablas con filas (ítems), columnas (criterios) y celdas (puntuaciones o marcas).
- **Uso ideal**: Comparación de características de productos, evaluación de software y hojas de especificaciones.
- **Elementos visuales**: Líneas de cuadrícula claras, uso de checkmarks/X, codificación por colores e iconos para categorías.
- **Emparejamientos sugeridos**: `corporate-memphis` (herramientas empresariales), `ui-wireframe` (matrices técnicas) y `blueprint` (comparaciones de especificaciones).
