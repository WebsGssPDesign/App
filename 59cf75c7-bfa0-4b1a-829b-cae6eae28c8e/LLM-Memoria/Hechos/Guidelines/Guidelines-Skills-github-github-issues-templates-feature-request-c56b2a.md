# feature-request.md

## Resumen
Este documento define una plantilla estandarizada para solicitar nuevas funcionalidades en proyectos de GitHub. Su objetivo es estructurar las propuestas para que sean claras, completas y fáciles de evaluar por los mantenedores del proyecto.

## Datos clave
- **Proyecto**: Plantillas de issues de GitHub (feature-request).
- **Estructura requerida**: Descripción de la función, motivación del problema, solución propuesta con ejemplos de código o mockups, alternativas consideradas, estimación de esfuerzo y contexto adicional.
- **Secciones críticas**: "Proposed Solution" para detalles técnicos y "Scope / Effort Estimate" para priorización (Small/Medium/Large).
