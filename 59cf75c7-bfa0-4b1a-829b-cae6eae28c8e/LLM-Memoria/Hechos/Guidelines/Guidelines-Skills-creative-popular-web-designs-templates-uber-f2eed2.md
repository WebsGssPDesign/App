# uber.md

## Resumen
Esta guía define el sistema de diseño minimalista de Uber, basado en una dualidad estricta entre negro puro y blanco, sin degradados ni tonos grises intermedios. Su objetivo es replicar la estética confiable y eficiente de la marca mediante tipografía geométrica, elementos con bordes redondeados (píldoras) y un uso intensivo de fotografía a todo color.

## Datos clave
- **Tipografía:** Fuentes propietarias `UberMove` (títulos) y `UberMoveText` (cuerpo), sustituidas por `DM Sans` y pilas del sistema para HTML autocontenido vía CDN.
- **Paleta de colores:** Fondo blanco (`#ffffff`) y texto/navegación negro (`#000000`). Estados interactivos usan grises muy claros (`#e2e2e2`, `#f3f3f3`) o medios (`#4b4b4b`).
- **Formas:** Todos los elementos interactivos (botones, chips) utilizan un radio de borde de 999px para crear una apariencia táctil.
- **Sombras:** Efectos sutiles con opacidad baja (`rgba(0,0,0,0.12)` a `0.16`) para elevar tarjetas sin romper la estética plana.
- **Herramientas sugeridas:** Uso de `write_file` para generar HTML y `browser_vision` para verificar la fidelidad visual del diseño.
