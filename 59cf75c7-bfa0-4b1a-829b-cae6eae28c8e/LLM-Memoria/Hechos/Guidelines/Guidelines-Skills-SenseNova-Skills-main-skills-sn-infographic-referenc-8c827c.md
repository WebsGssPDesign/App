# double-exposure.md

## Resumen
Este documento define las directrices visuales para crear efectos de doble exposición, una técnica que fusiona dos imágenes en un solo marco mediante siluetas y texturas superpuestas. Su propósito es facilitar la creación de contenido visual poético y emocionalmente resonante para narrativas de marca o temas introspectivos.

## Datos clave
- **Técnica principal**: Fusión de dos imágenes (silueta + paisaje/textura) usando modos de fusión suaves como *screen*, *multiply* o *overlay*.
- **Paleta de colores**: Uso estricto de duotono o paletas limitadas (2-3 colores), con fondos blanco, negro o degradados.
- **Tipografía**: Fuentes sans-serif minimalistas colocadas fuera del área mezclada para garantizar alto contraste.
- **Aplicaciones ideales**: Historias emocionales, temas ambientales/naturales, poesía y literatura visual, así como identidad de marca narrativa.
