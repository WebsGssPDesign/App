# glitch-art.md

## Resumen
Este documento define una guía de estilo para la estética "glitch-art", enfocada en crear visuales que imiten datos corruptos y errores digitales. Sirve como referencia técnica para diseñadores que buscan integrar arte digital experimental con temas cibernéticos o marcas audaces dirigidas a audiencias jóvenes.

## Datos clave
- **Paleta de colores**: Separación de canales RGB (cian-magenta), fondo negro con fragmentos de imágenes corruptas y acentos de pixel sorting.
- **Elementos visuales**: Desplazamiento de píxeles, líneas de escaneo, ruido digital, bloques de datos corrompidos, distorsión de fotogramas congelados y artefactos de compresión JPEG.
- **Tipografía**: Texto con efecto glitch, letras separadas por RGB, caracteres parcialmente visibles y mensajes de error digitales.
- **Uso recomendado**: Contenido tecnológico, diseño experimental, temas cibernéticos y branding "edgy".
