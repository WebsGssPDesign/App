# deconstruction.md

## Resumen
Este documento define la técnica de "deconstrucción" para infografías, explicando cómo descomponer y recomponer elementos visuales. Sirve como guía práctica para diseñar composiciones fragmentadas que analicen conceptos complejos o presenten estructuras anatómicas mediante el uso de piezas dispersas y líneas de conexión.

## Datos clave
- **Concepto central**: Desensamblaje, dispersión y recombinación de elementos en una composición fragmentada.
- **Casos de uso ideales**: Análisis de anatomía, desglose de conceptos complejos, presentaciones artísticas y temas filosóficos abstractos.
- **Elementos visuales recomendados**: Elementos explosivos o rotos, líneas conectoras (flechas), orientaciones variadas y contornos fantasma del todo original.
- **Ubicación del texto**: Etiquetas en fragmentos individuales, instrucciones de ensamblaje y títulos en zonas estables fuera de los elementos dispersos.
- **Estilos sugeridos**: `cartoon-flat`, `neon-futurism` (estilo glitch) y `origami`.
