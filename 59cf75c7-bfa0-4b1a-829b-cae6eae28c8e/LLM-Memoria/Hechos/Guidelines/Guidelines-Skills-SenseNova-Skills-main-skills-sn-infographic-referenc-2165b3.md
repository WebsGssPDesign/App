# op-art.md

## Resumen
Este documento establece las directrices de diseño para crear arte óptico (op-art), definiendo cómo utilizar patrones geométricos y contrastes visuales para generar ilusiones de movimiento y profundidad. Sirve como referencia técnica para diseñadores que buscan visualizar conceptos abstractos o temas relacionados con la percepción psicológica mediante efectos visuales impactantes.

## Datos clave
- **Estilo visual**: Patrones geométricos repetitivos, formas concéntricas, patrones de interferencia Moiré y líneas convergentes.
- **Paleta de colores**: Alto contraste blanco/negro o pares complementarios (rojo/verde, azul/naranja) para maximizar el efecto vibrante; fondo con patrón alterno sin color único.
- **Tipografía**: Mínima, tipografías sans-serif en negrita ubicadas en zonas neutras, solo en blanco o negro y de gran tamaño simple.
- **Aplicaciones ideales**: Temas de percepción y psicología, contenido científico óptico, portadas llamativas y educación artística.
