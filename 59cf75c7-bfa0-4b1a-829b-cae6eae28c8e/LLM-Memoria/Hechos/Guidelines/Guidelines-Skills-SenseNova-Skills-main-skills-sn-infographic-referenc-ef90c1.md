# spiral-vortex.md

## Resumen
Este documento define la estructura y el propósito del diseño visual "spiral-vortex", una composición donde los elementos giran hacia un centro focal. Sirve para guiar narrativas que van de lo general a lo específico o visualizar procesos cíclicos con creciente profundidad, utilizando gradientes de tamaño y color para crear convergencia.

## Datos clave
- **Concepto**: Estructura espiral que converge al centro; elementos externos representan el contexto amplio y los internos el núcleo.
- **Uso ideal**: Enfocar narrativas, profundizar en detalles ("drilling down") o visualizar conceptos abstractos.
- **Elementos visuales**: Nodo central focal, etiquetas a lo largo del camino espiral, título en el borde exterior.
- **Estilos recomendados**: `neon-futurism`, `origami` y `high-contrast-ad`.
