# data-visualization.md

## Resumen
Este documento establece las directrices para crear visualizaciones de datos profesionales que prioricen la claridad y precisión sobre el diseño estético. Sirve como referencia técnica para diseñar gráficos estadísticos coherentes en informes científicos, dashboards empresariales y análisis comparativos dentro del proyecto SenseNova.

## Datos clave
- **Paleta de colores**: Uso de paletas secuenciales o divergentes impulsadas por datos; fondo blanco (#F8F9FA) o gris muy claro; acentos en naranja, rojo o turquesa.
- **Elementos visuales**: Gráficos permitidos incluyen barras, líneas, dispersión, pastel, treemap y mapas de calor. Se exige evitar "basura gráfica" (chart junk) para que cada píxel codifique información.
- **Tipografía**: Fuentes monoespaciadas como Roboto Mono o IBM Plex Mono para números tabulares; jerarquía estricta entre títulos, etiquetas de ejes y notas al pie.
- **Mejores usos**: Ideal para informes estadísticos, hallazgos de investigación, dashboards de negocio y visualización de tendencias científicas.
