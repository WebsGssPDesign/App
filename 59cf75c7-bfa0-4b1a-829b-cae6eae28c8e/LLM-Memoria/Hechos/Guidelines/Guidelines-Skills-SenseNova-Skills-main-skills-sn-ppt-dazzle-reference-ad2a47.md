# style-families.md

## Resumen
Este documento define una biblioteca de familias estilísticas para presentaciones, estableciendo un flujo de trabajo que prioriza la selección del estilo según el contexto (formal o libre) y exige la creación manual de paletas hexadecimales. Establece prohibiciones estrictas contra estilos genéricos como el minimalismo suizo o fondos cálidos estándar para garantizar una identidad visual única y profesional en cada diapositiva.

## Datos clave
- **Proyecto**: sn-ppt-dazzle (librería de estilos).
- **Reglas de selección**: Primero filtrar por solemnidad del escenario, luego elegir familia; evitar la inercia de repetir el mismo estilo.
- **Tecnologías y herramientas**: Three.js para escenarios 3D reales (≥10 entidades), fuentes específicas como JetBrains Mono, Playfair, Cormorant, Sora.
- **Decisiones críticas**: Prohibido usar Swiss Typographic/International Style; prohibido fondo crema (#FBF7F0) o texturas de papel antiguo; paletas deben ser ajustadas manualmente por tema.
- **Familias destacadas (★dazzle)**: cyberpunk_neon, immersive_3d (solo para temas espaciales), maximalist_collage, memphis_playful, comic_pop, retrofuturism_y2k.
- **Comandos/Referencias**: Consultar SKILL.md §3 y fancy-cookbook para ejemplos de código 3D; usar `scene.fog` para unificar niebla y fondo en 3D.
