# SKILL.md

## Resumen
Este documento describe un conjunto de herramientas CLI y APIs para crear arte ASCII, banners decorativos y efectos visuales en terminales sin necesidad de claves API. Sirve como guía práctica para generar gráficos de texto personalizados utilizando programas locales o servicios web remotos.

## Datos clave
- **Herramientas principales**: `pyfiglet` (banners con 571 fuentes), `asciified.thelicato.io` (API REST sin instalación), `cowsay` (mensajes con personajes), `boxes` (marcos decorativos) y `toilet` (texto coloreado).
- **Comandos de instalación**: `pip install pyfiglet`, `apt install cowsay/boxes/toilet`, `brew install cowsay`.
- **Uso de API**: `curl -s "https://asciified.thelicato.io/api/v2/ascii?text=Texto&font=Fuente"`.
- **Combinación avanzada**: Piping para integrar arte en marcos (ej: `pyfiglet ... | boxes`).
- **Fuentes recomendadas**: `slant` (limpio), `doom` (negrita), `cyberlarge` (tech).
