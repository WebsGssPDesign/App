# README.md

## Resumen
Este repositorio contiene un conjunto de habilidades para modelos de IA que amplían capacidades de oficina, como análisis de datos y generación de presentaciones. Sirve para integrar estos módulos en entornos de agentes autónomos compatibles con el estándar Agent Skills.

## Datos clave
- **Proyecto**: SenseNova-Skills (integración con Raccoon).
- **Tecnologías**: Modelos SenseNova 6.7 Flash y U1, API Internacional y China.
- **Agentes compatibles**: OpenClaw (`~/.openclaw/skills/`) y hermes-agent (`~/.hermes/skills/`).
- **Instalación recomendada**: Clonar repositorio y pedir al agente que instale las habilidades automáticamente.
- **Comandos de instalación manual**: `git clone ...`, `mkdir -p ~/.openclaw/skills`, `cp -r SenseNova-Skills/skills/* ~/.openclaw/skills/`.
- **Capacidades principales**: Generación de imágenes, análisis Excel, creación de PPT y gráficos informativos.
