# prompts-expand-system.md

## Resumen
Este documento define el rol de un experto en arquitectura visual y prompts para IA, diseñado para transformar datos crudos en infografías densas y estructuradas. Su función es guiar modelos generativos (como Midjourney o DALL-E 3) creando descripciones textuales precisas que aseguren fidelidad a los datos, consistencia lingüística y una composición visual profesional sin metacomentarios.

## Datos clave
- **Rol**: Senior Visual Information Architect / AI Image Prompt Engineering Expert.
- **Objetivo**: Generar prompts de 400-600 palabras para infografías visuales densas.
- **Metodología**: Expansión de contenido (sin resumir), análisis estructural adaptativo y configuración tonal.
- **Restricciones críticas**: Paridad estricta de idioma, preservación total de datos numéricos/nombres propios, prohibición de código hexadecimal para colores (usar nombres descriptivos).
- **Protocolo de texto**: Todo el contenido textual dentro de la imagen debe estar entre comillas; las descripciones de estilo no.
- **Iconografía**: Descripción visual explícita obligatoria para cada ícono (ej. "manzana roja con hoja verde"), prohibiendo términos genéricos.
