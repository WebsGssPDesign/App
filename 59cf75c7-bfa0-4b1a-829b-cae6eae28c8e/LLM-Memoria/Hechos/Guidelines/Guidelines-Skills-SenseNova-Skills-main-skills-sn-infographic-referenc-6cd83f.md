# maximalism.md

## Resumen
Este documento define el estilo "maximalismo" para composiciones visuales densas donde cada espacio está lleno de contenido o decoración. Sirve como guía para crear referencias completas, materiales festivos o hojas de trucos con alta información y un caos controlado que mantiene la legibilidad.

## Datos clave
- **Principio estructural**: Eliminar el espacio negativo; todas las áreas del lienzo deben contener contenido o decoración.
- **Elementos visuales**: Uso de fondos con patrones densos, múltiples capas superpuestas y paletas de colores ricas.
- **Tipografía**: Integración del texto en toda la composición con jerarquía clara mediante alto contraste para la información clave.
- **Pares recomendados**: Se sugiere combinar este estilo con `high-contrast-ad` (estilo cómic), `kawaii` y `pixel-art`.
