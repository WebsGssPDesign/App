# holographic.md

## Resumen
Este documento define una guía de estilo para crear un estético holográfico con efectos iridiscentes y superficies metálicas brillantes. Sirve como referencia visual para diseñadores que buscan aplicar este look futurista en contenido de moda, lanzamientos de productos premium o material dirigido a la Generación Z.

## Datos clave
- **Paleta de colores**: Gradientes espectrales (rosa → púrpura → cian → dorado) sobre fondos negros, blancos o plateados metálicos.
- **Elementos visuales**: Texturas de lámina iridiscente, difracción de luz prismática, reflejos cromáticos y planos translúcidos superpuestos.
- **Tipografía**: Texto con efecto metálico cromático o holográfico, tipografías sans-serif limpias con rellenos degradados y efectos de relieve tipo sello de lámina.
- **Uso recomendado**: Contenido de belleza, lanzamientos de productos, marcas premium, música y reportes de tendencias.
