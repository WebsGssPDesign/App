# center-focus.md

## Resumen
Esta guía define la estructura y mejores prácticas para el diseño de composiciones visuales centradas en un sujeto principal. Sirve como referencia técnica para crear infografías, revelados de productos o diagramas que dirigen la atención del usuario hacia un concepto clave mediante elementos radiales y alto contraste.

## Datos clave
- **Estructura**: El sujeto central debe estar en el centro geométrico; los elementos circundantes deben converger hacia él.
- **Elementos visuales**: Uso de líneas, flechas o formas que apunten al interior, junto con gradientes radiales o vinetas para reforzar el foco.
- **Contraste**: Diferencia marcada entre un elemento central de alto contraste y elementos periféricos más pequeños y desaturados.
- **Ubicación del texto**: La etiqueta principal va en el centro; el texto secundario se irradia hacia afuera y el título queda fuera de la zona focal superior.
- **Combinaciones recomendadas**: Se sugiere emparejar con estilos *knolling*, diagramas esquemáticos técnicos o patrones geométricos tipo origami.
