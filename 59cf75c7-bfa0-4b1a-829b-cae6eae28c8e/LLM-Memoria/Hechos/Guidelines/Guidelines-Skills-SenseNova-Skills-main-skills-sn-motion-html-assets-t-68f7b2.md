# 01-opening-to-destination.txt

## Resumen
Esta guía define las directrices técnicas para generar una transición visual continua de cuatro segundos entre dos imágenes límite (salida y destino). Su función es asegurar que la animación mantenga coherencia estética, identidad narrativa y estabilidad en los extremos sin introducir cortes o distorsiones violentas.

## Datos clave
- **Entorno**: Debe ser apropiado para la historia específica.
- **Restricciones de movimiento**: Prohibido el corte, texto extra, sujetos adicionales, morfosis violenta o rodaje de cámara (camera roll).
- **Estabilidad**: Los primeros y últimos momentos del clip deben permanecer estables.
- **Consistencia**: Se debe preservar la identidad recurrente, la paleta de colores y el lenguaje material entre ambas imágenes.
