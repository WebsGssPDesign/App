# raycast.md

## Resumen
Este documento define el sistema de diseño visual de Raycast, enfocándose en una estética oscura inspirada en herramientas de precisión y nativas de macOS. Su objetivo es guiar la implementación de interfaces que transmitan velocidad, minimalismo y confianza mediante un uso específico de sombras, tipografía y colores semánticos.

## Datos clave
- **Colores principales**: Fondo azul casi negro (`#07080a`), texto blanco puro (`#ffffff`) y acento "Raycast Red" (`#FF6363`).
- **Tipografía**: Fuente principal `Inter` con espaciado positivo (0.2px–0.4px) para legibilidad en modo oscuro; monoespaciada `Geist Mono`.
- **Sistema de sombras**: Uso de múltiples capas de `box-shadow` y resaltados internos (`inset`) para simular profundidad física tipo cristal.
- **Componentes UI**: Basado en primitivas de Radix UI con bordes semitransparentes (0.06–0.1 opacidad).
- **Estilo teclado**: Gradiente lineal desde `#121212` hasta `#0d0d0d` para simular relieve físico de las teclas.
