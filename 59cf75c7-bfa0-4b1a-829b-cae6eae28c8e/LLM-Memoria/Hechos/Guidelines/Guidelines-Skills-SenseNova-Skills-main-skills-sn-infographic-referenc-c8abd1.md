# technical-schematic.md

## Resumen
Este documento define las directrices de diseño para diagramas técnicos con precisión ingenieril y geometría limpia. Sirve como referencia visual para crear esquemas arquitectónicos, especificaciones de sistemas y representaciones tridimensionales coherentes dentro del proyecto SenseNova.

## Datos clave
- **Paleta de colores**: Azul real (#2563EB), azules oscuros (#1E3A5F) para fondos, acentos en ámbar (#F59E0B) y cian.
- **Variantes principales**: Estilo "Blueprint" (blanco sobre azul con cuadrícula) y estilo "Isométrico" (bloques a 30°).
- **Elementos visuales**: Líneas de dimensión, símbolos técnicos, formas vectoriales limpias y pesos de trazo consistentes.
- **Tipografía**: Fuentes estancil o sans-serif limpias, etiquetas en mayúsculas y anotaciones flotantes para isometría.
- **Uso recomendado**: Arquitectura técnica, diagramas de sistemas, especificaciones de ingeniería y visualización de datos.
