# nine-grid.md

## Resumen
Esta guía define las especificaciones para crear un diseño de infografía basado en una cuadrícula de 3x3, ideal para organizar colecciones de nueve elementos o modelos conceptuales. Su propósito es estandarizar la estructura visual mediante celdas uniformes y jerarquías claras, facilitando la presentación equilibrada de información como iconos, fotos o características de productos.

## Datos clave
- **Estructura**: Cuadrícula 3x3 con celdas de tamaño igual y relleno consistente; la celda central suele actuar como punto focal o título principal.
- **Contenido por celda**: Título del elemento seguido de una breve descripción debajo.
- **Elementos visuales**: Bordes uniformes, ilustraciones específicas por celda y codificación de color opcional por filas o columnas.
- **Títulos**: El título general debe colocarse encima de toda la cuadrícula.
- **Estilos recomendados**: `pixel-art` (iconos retro), `corporate-memphis` (catálogos corporativos) y `cartoon-flat`.
