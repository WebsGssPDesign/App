# isometric-tech-stack.md

## Resumen
Este documento define un sistema de apilamiento visual en perspectiva isométrica 2.5D para representar jerarquías técnicas u organizacionales. Sirve como guía para crear diagramas claros que muestren componentes de software, infraestructura o estructuras departamentales mediante capas horizontales conectadas verticalmente.

## Datos clave
- **Proyecto**: `isometric-tech-stack` dentro del repositorio SenseNova-Skills.
- **Variantes principales**: "Tech Stack" (software/hardware) y "Organization Stack" (equipos/roles).
- **Estructura visual**: Perspectiva isométrica de 30°, plataformas distintivas con etiquetas y conectores verticales.
- **Elementos gráficos**: Uso de iconos específicos para cada capa y texto colocado en la plataforma o dentro del área.
- **Casos de uso ideales**: Diagramas de arquitectura de software, resúmenes de stacks tecnológicos y jerarquías de componentes de sistema.
- **Estilos recomendados**: `technical-schematic`, `neon-futurism` y `pixel-art`.
