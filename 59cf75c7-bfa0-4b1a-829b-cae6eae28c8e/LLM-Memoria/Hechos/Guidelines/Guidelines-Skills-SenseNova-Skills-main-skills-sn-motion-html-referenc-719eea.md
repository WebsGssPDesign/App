# prompting.md

## Resumen
Este documento define patrones estandarizados para generar imágenes estáticas y secuencias de movimiento coherentes en entornos de IA. Su objetivo es mantener la consistencia visual de personajes y estilos mediante bloques reutilizables, evitando cambios no deseados entre tomas o escenas.

## Datos clave
- **Proyecto**: SenseNova-Skills (módulo sn-motion-html).
- **Tecnologías**: Generación de prompts para herramientas de imagen y video.
- **Decisiones**: Separar el bloque de estilo (`style-preamble.txt`) del contenido narrativo; usar bloques de identidad para personajes recurrentes.
- **Rutas/Archivos**: `prompts/style-preamble.txt`, `prompts/style-motion.txt`.
- **Pasos importantes**: Definir paleta, cámara y materiales en el preámbulo; crear hojas de referencia neutra antes de las escenas; usar "Dive motion" para movimientos sutiles dentro de una imagen y "Connector motion" para transiciones entre dos imágenes.
