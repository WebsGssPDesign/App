# top-image-bottom-text.md

## Resumen
Este documento define la estructura de diseño para un formato de infografía donde una imagen dominante ocupa la parte superior y el contenido textual se sitúa debajo. Sirve como guía técnica para crear tarjetas informativas, artículos o anuncios visuales que combinen ilustraciones con texto claro y llamadas a la acción.

## Datos clave
- **Estructura**: 50-70% de ancho completo para imagen arriba; 30-50% para texto abajo.
- **Elementos**: Línea divisoria horizontal clara o transición natural entre zonas.
- **Ordenamiento**: Título justo debajo de la imagen, seguido del cuerpo y finalmente el CTA/caption.
- **Estilos recomendados**: `corporate-memphis` (editorial), `storybook-watercolor` (ilustrado) y `paper-collage` (educativo).
- **Uso ideal**: Cubiertas de artículos, lanzamientos de productos y publicaciones en redes sociales.
