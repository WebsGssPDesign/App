# breaking-the-grid.md

## Resumen
Esta guía define la técnica de diseño "breaking-the-grid", donde los elementos principales se extienden más allá del contenedor para generar profundidad y dinamismo. Es ideal para presentaciones de productos, introducción de personajes o cualquier contenido que requiera una energía visual intensa mediante el contraste entre elementos rotos y contenidos.

## Datos clave
- **Concepto**: Elementos primarios que "rompen" los límites del marco o fondo visible.
- **Uso recomendado**: Showcases de productos dinámicos, introducciones de mascotas/personajes y contenido de acción.
- **Elementos visuales**: Sombra proyectada (drop shadow), superposición de capas, líneas de movimiento y efectos de energía.
- **Colocación de texto**: El título debe estar dentro del área contenida; la etiqueta del sujeto cerca del elemento que rompe el marco; el texto secundario interno.
- **Combinaciones sugeridas**: `high-contrast-ad`, `claymation` (figuras 3D) y estilos `kawaii`.
