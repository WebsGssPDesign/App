# README.md

## Resumen
Este archivo describe un plugin de 12 habilidades para Claude Code diseñado para automatizar tareas de marketing digital. Permite generar desde análisis competidores y calendarios de contenido hasta guiones para videos cortos y secuencias de correo, asegurando que ninguna publicación se envíe sin la aprobación explícita del usuario.

## Datos clave
- **Instalación:** `claude plugin add marcosmodly/marketing-skill` seguido de `claude plugin install marketing-skill@marketing-skill`.
- **Habilidades principales:** Análisis competidores (SWOT), calendarios sociales, repurposing de contenido, breves SEO sin datos falsos, copias para anuncios A/B y secuencias de email.
- **Flujo de trabajo:** Todas las habilidades generan borradores que requieren aprobación antes de publicar en plataformas como LinkedIn, X, n8n o Make.
- **Generación de video:** Incluye creación de guiones y renderizado de videos verticales con música personalizada si se conectan herramientas externas.
- **Personalización:** Uso de un archivo único `brand-voice` para mantener la consistencia en todas las salidas.
