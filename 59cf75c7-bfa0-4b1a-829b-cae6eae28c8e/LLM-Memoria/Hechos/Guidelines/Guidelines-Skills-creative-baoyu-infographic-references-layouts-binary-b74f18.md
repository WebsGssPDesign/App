# binary-comparison.md

## Resumen
Este documento establece las directrices para crear infografías de comparación binaria, diseñadas para mostrar contrastes visuales entre dos elementos, estados o conceptos. Sirve como referencia técnica para estructurar diseños que faciliten la evaluación rápida de diferencias, transformaciones temporales o análisis de ventajas y desventajas mediante un layout simétrico.

## Datos clave
- **Estructura**: Divisor vertical central que separa el lado izquierdo (Antes/Pro) del derecho (Después/Con).
- **Variantes principales**: Before-After (transformación temporal), A vs B (comparación de características) y Pro-Con (evaluación equilibrada).
- **Elementos visuales**: Líneas divisorias fuertes, gradientes, colores contrastantes por lado, símbolo "VS" y flechas de transformación.
- **Alineación**: Títulos centrados en la parte superior, etiquetas laterales claras y puntos correspondientes alineados horizontalmente.
- **Estilos recomendados**: `corporate-memphis` para negocios, `bold-graphic` para alto contraste y `craft-handmade` para explicaciones amigables.
