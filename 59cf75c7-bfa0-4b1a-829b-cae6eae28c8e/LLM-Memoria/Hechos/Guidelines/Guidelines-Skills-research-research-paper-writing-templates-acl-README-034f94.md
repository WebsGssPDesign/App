# README.md

## Resumen
Este directorio alberga las plantillas oficiales en LaTeX para los conferencias de la ACL, asegurando el cumplimiento estricto de sus normas de formato. Sirve como recurso central tanto para autores que preparan sus manuscritos como para comités organizadores que necesitan adaptar o actualizar los estilos.

## Datos clave
- **Proyecto**: ACL Style Files (archivos de estilo de la Asociación para el Procesamiento del Lenguaje Computacional).
- **Tecnologías**: LaTeX, Git, Overleaf.
- **Decisiones y restricciones**: Los autores no pueden modificar estos archivos ni usar plantillas de otras conferencias; las modificaciones deben enviarse mediante pull requests o forking del repositorio.
- **Rutas y recursos importantes**:
    - Repositorio principal: `acl-org/acl-style-files`.
    - Archivo de ejemplo: `acl_latex.tex`.
    - Plantilla en Overleaf: `https://www.overleaf.com/latex/templates/association-for-computational-linguistics-acl-conference/jvxskxpnznfj`.
    - Guía general de formato: `https://acl-org.github.io/ACLPUB/formatting.html`.
- **Pasos para actualizar en Overleaf**: Fusionar pull requests o empujar cambios a GitHub, luego hacer un `git pull` local y finalmente `git push` al proyecto de Overleaf (`5f64f1fb97c4c50001b60549`) antes de solicitar la actualización de la plantilla.
