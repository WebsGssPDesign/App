# parametric-design.md

## Resumen
Esta guía establece las normas visuales para crear infografías sobre diseño paramétrico, fusionando precisión matemática con complejidad orgánica. Su propósito es asegurar una estética coherente que destaque la innovación tecnológica y los conceptos generativos mediante el uso de algoritmos y formas geométricas precisas.

## Datos clave
- **Paleta de colores**: Fondos negros (#000000) o oscuros profundos; acentos con espectros brillantes, gradientes algorítmicos y brillos iridiscentes.
- **Elementos visuales**: Curvas y superficies generadas matemáticamente (Voronoi, Delaunay), estructuras recursivas, mallas de gradiente suaves y generación de formas impulsada por datos.
- **Tipografía**: Sans-serif geométrico (Futura, Avenir) para textos principales; fuentes monoespaciadas exclusivamente para etiquetas de datos.
- **Uso recomendado**: Contenido sobre tecnología, arte generativo, ciencia de datos, arquitectura y marcas futuristas.
