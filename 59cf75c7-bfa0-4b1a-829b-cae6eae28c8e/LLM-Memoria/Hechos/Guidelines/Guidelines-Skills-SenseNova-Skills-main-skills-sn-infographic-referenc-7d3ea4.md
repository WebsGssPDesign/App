# strong-perspective.md

## Resumen
Este documento define la técnica de "perspectiva fuerte" para ilustraciones, donde las líneas convergen hacia el sujeto principal para generar profundidad en un lienzo bidimensional. Sirve como guía visual para diseñar escenas arquitectónicas, rutas o productos que requieran una sensación inmersiva y tridimensional clara.

## Datos clave
- **Concepto central**: Líneas de perspectiva convergentes que dirigen la mirada hacia el sujeto ubicado en el punto de fuga.
- **Estructura visual**: Elementos del primer plano más grandes que los del fondo, con degradado de tamaño para simular 3D.
- **Uso recomendado**: Contenido arquitectónico, metáforas de viaje/rutas y presentaciones de productos inmersivos.
- **Elementos gráficos**: Carriles, pasillos o estanterías convergentes; niebla atmosférica opcional para reforzar la profundidad.
- **Ubicación del texto**: Títulos en la parte superior o primer plano; etiquetas del sujeto cerca del punto de fuga.
- **Combinaciones sugeridas**: `origami` (diseños espaciales), `neon-futurism` (corredores futuristas) y `storybook-watercolor` (escenas pintorescas).
