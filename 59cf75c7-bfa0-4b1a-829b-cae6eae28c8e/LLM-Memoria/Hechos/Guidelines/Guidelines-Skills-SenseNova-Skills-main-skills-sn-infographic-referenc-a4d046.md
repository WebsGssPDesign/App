# origami.md

## Resumen
Este documento define una guía de estilo visual para representar conceptos geométricos y temas japoneses mediante la estética del origami. Sirve como referencia para diseñadores que buscan aplicar texturas de papel, sombras realistas y tipografía angular en interfaces o infografías.

## Datos clave
- **Tema**: Estética de origami con precisión geométrica.
- **Paleta de colores**: Papel sólido (rojo, azul, verde, dorado), fondo blanco/gris suave con sombras sutiles.
- **Elementos visuales**: Formas plegadas, líneas de pliegue visibles, texturas de papel y aspecto low-poly.
- **Tipografía**: Fuentes geométricas limpias, letras angulares y efecto de texto doblado.
- **Uso recomendado**: Conceptos geométricos, temas de transformación, cultura japonesa y representaciones abstractas.
