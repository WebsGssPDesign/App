# left-text-right-image.md

## Resumen
Este documento define la estructura y mejores prácticas para un diseño de infografía con texto a la izquierda e imagen a la derecha. Sirve como guía técnica para crear paneles informativos claros, ideales para explicar características o describir productos en formatos horizontales.

## Datos clave
- **Estructura**: Columna izquierda (40-50%) para texto y columna derecha (50-60%) para imagen o ilustración.
- **Alineación**: Ambos elementos deben estar centrados verticalmente; el separador vertical es opcional.
- **Jerarquía visual**: El título va en la esquina superior izquierda, seguido del cuerpo del texto con etiquetas o viñetas.
- **Estilos recomendados**: `corporate-memphis` para diapositivas de negocios, `technical-schematic` para documentación técnica y `ikea-manual` para instrucciones paso a paso.
