# clickhouse.md

## Resumen
Este documento define el sistema de diseño visual para la interfaz de ClickHouse, caracterizado por un esquema oscuro de alto contraste que evoca velocidad y potencia técnica. Su propósito es guiar la implementación de una web autocontenida utilizando fuentes CDN específicas, paletas de colores neón sobre negro puro y tipografía pesada para transmitir rendimiento extremo.

## Datos clave
- **Proyecto:** Diseño del sitio web de ClickHouse ("Hermes Agent").
- **Tecnologías:** HTML, CSS (Next.js), Google Fonts (`Inter`, `JetBrains Mono`).
- **Decisiones de diseño:** Fondo negro puro (`#000000`), acento neón amarillo-verde (`#faff69`) y tipografía extra-gruesa (Inter 900) hasta 96px.
- **Paleta de colores:** Incluye verde bosque secundario (`#166534`), gris carbón para tarjetas (`#414141`) y texto blanco/plateado.
- **Herramientas sugeridas:** `write_file`, `generative-widgets`, `browser_vision`.
