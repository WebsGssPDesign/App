# replicate.md

## Resumen
Este documento define el sistema de diseño visual para la interfaz de Replicate, caracterizado por una estética audaz y de alto contraste inspirada en festivales musicales. Su objetivo es guiar a los desarrolladores en la implementación de una experiencia que combine tipografía masiva, geometría redondeada y una paleta de colores vibrante para destacar modelos de IA.

## Datos clave
- **Tipografía:** Fuentes `Inter` (primaria) y `JetBrains Mono` (código) como sustitutos CDN para fuentes propietarias; uso de pesos gruesos (700) y tamaños gigantes (hasta 128px).
- **Geometría:** Exclusivo uso de bordes redondeados con un radio extremo de 9999px en todos los elementos.
- **Paleta de colores:** Ancla naranja-rojo-magenta (`#ea2804`), fondo oscuro `#202020`, texto blanco y acentos verdes para estados operativos (`#2b9a66`).
- **Implementación:** Generación de HTML mediante la habilidad `write_file`, servicio vía túnel `cloudflared` y verificación visual con `browser_vision`.
