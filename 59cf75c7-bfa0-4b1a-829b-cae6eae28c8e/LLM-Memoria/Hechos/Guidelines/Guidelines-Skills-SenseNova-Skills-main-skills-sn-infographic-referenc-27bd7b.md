# vintage-poster.md

## Resumen
Este documento define una guía de estilo para crear diseños gráficos con estética de póster vintage. Sirve como referencia técnica para aplicar técnicas de impresión antigua, tipografía específica y elementos visuales que evocan nostalgia en campañas publicitarias o contenido histórico.

## Datos clave
- **Paleta de colores**: Máximo 3–5 colores (estilo litográfico), fondo crema envejecido (#F2E8D0) o tonos tierra profundos, con acentos desalineados intencionalmente.
- **Elementos visuales**: Ilustración gráfica audaz, patrones de puntos halftone para sombras, bordes ornamentales, texturas de papel viejo y elementos tipo sello o distintivo.
- **Tipografía**: Títulos en serif decorativo o slab serif, letras condensadas o expandidas, texto apilado y uso predominante de mayúsculas (ALL CAPS).
- **Casos de uso ideales**: Contenido histórico, temas de viaje y cultura, promociones de eventos, marcas con herencia y líneas de tiempo informativas.
