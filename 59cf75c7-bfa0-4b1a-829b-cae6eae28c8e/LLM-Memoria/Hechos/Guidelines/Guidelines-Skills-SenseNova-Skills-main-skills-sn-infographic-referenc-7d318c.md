# text-wrap.md

## Resumen
Este documento define la técnica de "text-wrap" para que el texto se ajuste estrechamente a los contornos de imágenes o formas, creando una integración orgánica. Sirve como guía para diseñadores que buscan layouts editoriales donde imagen y texto tengan igual importancia visual.

## Datos clave
- **Tecnología/Formato**: Markdown (`.md`) dentro del repositorio `SenseNova-Skills-main`.
- **Estructura recomendada**: Imagen o forma dentro de un bloque de texto con flujo alrededor del contorno.
- **Casos de uso ideales**: Artículos ilustrados, informes y narrativas visuales estilo revista.
- **Elementos visuales clave**: Contornos claros en la imagen, ancho de columna consistente y opcionalmente mayúsculas ornamentales o citas destacadas.
- **Configuraciones sugeridas**: Paletas `aged-academia`, `storybook-watercolor` y `crayon-hand-drawn`.
