# vaporwave.md

## Resumen
Este archivo define una paleta de colores y elementos visuales para el estilo estético vaporwave, fusionando la nostalgia de los años 80-90 con el retrofuturismo. Sirve como guía técnica para diseñar contenido visual enfocado en cultura internet, música y temas de tecnología antigua.

## Datos clave
- **Paleta de colores**: Rosa (#FF71CE), cian (#01CDFE) y púrpura (#B967FF).
- **Elementos visuales**: Gráficos retro (Windows 95/Mac), estatuas griegas, palmeras, suelos a cuadros y paisajes de rejilla neón.
- **Tipografía**: Fuentes de computadora antigua, texto estilo VCR y letras distorsionadas con katakana japonés.
- **Uso recomendado**: Visuales musicales, contenido nostálgico para la Generación Z y memes.
