# README_CN.md

## Resumen
Este repositorio define un conjunto de habilidades (skills) para modelos SenseNova, transformándolos en capacidades de oficina end-to-end como generación de PPT, análisis de Excel y creación de infografías. Sirve como biblioteca modular que sigue el estándar Agent Skills, permitiendo a los agentes integrar estas funciones directamente en flujos de trabajo complejos sin necesidad de configuración manual extensa.

## Datos clave
- **Proyecto**: SenseNova-Skills (integración con OpenClaw y hermes-agent).
- **Tecnologías**: Agent Skills standard, Python, API de SenseNova (versión 6.8/U1), HTML/PPTX export.
- **Decisiones**: Uso de `SKILL.md` para declarar condiciones y límites; separación por categorías (imagen, PPT, datos).
- **Rutas importantes**: `~/.openclaw/skills/`, `~/.hermes/skills/`.
- **Comandos clave**: `git clone ... --depth=1`, `cp -r SenseNova-Skills/skills/* ~/.openclaw/skills/`.
