# one-way-flow.md

## Resumen
Esta guía define el estilo de diseño "one-way-flow", donde todos los elementos visuales se orientan en una sola dirección para transmitir progreso, momentum y propósito. Es ideal para diagramas de procesos, embudos de conversión y narrativas que enfatizan el avance hacia un objetivo final.

## Datos clave
- **Estructura**: Todos los elementos (flechas, formas, texto) deben reforzar un único movimiento sin contradipciones direccionales.
- **Mejor uso**: Narrativas de progreso, flujos de conversión y mensajes de "avanzar".
- **Elementos visuales**: Flechas o chevrons consistentes, elementos más grandes al frente para sugerir velocidad, gradientes de color y líneas de movimiento opcionales.
- **Ubicación del texto**: Etiquetas alineadas con el flujo, título al inicio y resultado al final.
- **Estilos recomendados**: `corporate-memphis` (para flujos empresariales), `cartoon-flat` (diseños de alta energía) e `ikea-manual` (instrucciones claras).
