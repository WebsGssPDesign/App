# SKILL.md

## Resumen
Este documento describe una habilidad técnica para realizar búsquedas de imágenes utilizando la API de Serper.dev, proporcionando metadatos como URLs y títulos. Su función principal es identificar candidatos visuales relevantes para consultas específicas sin procesar los archivos directamente.

## Datos clave
- **Proyecto**: SenseNova Skills (sn-search-image).
- **Tecnologías**: Python 3, Serper.dev API.
- **Variables de entorno**: Requiere `SERPER_API_KEY`.
- **Comandos principales**: Ejecución directa del script `serper_image_search.py` con argumentos como `--num`, `--image-urls-only`, `--json` o `--save-json`.
- **Restricciones**: No usar redirección de salida, tuberías ni envoltorios de shell; incluir flags `--gl` y `--hl` para sesgo geográfico o lingüístico.
