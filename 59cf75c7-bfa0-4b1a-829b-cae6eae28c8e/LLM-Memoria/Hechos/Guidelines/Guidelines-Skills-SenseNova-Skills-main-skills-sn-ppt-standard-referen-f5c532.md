# design-rules.md

## Resumen
Este documento establece las reglas de diseño visual y los límites técnicos para presentaciones, definiendo cómo aplicar principios estéticos según el contexto (ej. gubernamental vs. comercial). Su función es garantizar la legibilidad, coherencia temática y calidad técnica mediante un sistema de decisiones basado en casos específicos más que en plantillas genéricas.

## Datos clave
- **Principios ortogonales**: La densidad visual se define por dos ejes independientes: "tono" (formalidad del contexto) y "volumen visual" (necesidad de contenido), evitando confundirlos con una sola variable de "restricción".
- **Contraste obligatorio**: Texto cuerpo ≥4.5:1 y títulos grandes ≥3:1; el script `render.py` valida esto automáticamente bajo la regla `⚠ CONTRAST`.
- **Manejo de texto sobre imágenes**: Se permite superponer texto en gráficos o fotos, pero exige uso local de *scrim*, tablas de soporte o bordes para asegurar legibilidad sin oscurecer toda la imagen.
- **Paleta de colores**: Prohibido usar fondos crema por defecto; se deben definir historias de color específicas (ej. rojo/dorado para temas políticos) y evitar combinaciones genéricas como azul oscuro con neón.
- **Tipografía**: Para contextos formales (gubernamentales), priorizar fuentes serif rectas sobre estilos cursivos o "tech". Ajustes finos en espaciado son preferibles a cambiar la familia de fuente completa.
