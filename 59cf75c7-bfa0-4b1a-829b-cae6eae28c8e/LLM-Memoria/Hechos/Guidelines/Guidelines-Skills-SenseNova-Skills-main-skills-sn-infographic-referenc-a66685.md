# cartoon-flat.md

## Resumen
Este documento define las directrices de estilo visual para un diseño gráfico plano y caricaturesco. Sirve como referencia técnica para crear ilustraciones limpias, coloridas y amigables, ideales para narrativas dirigidas a niños o contenido lúdico.

## Datos clave
- **Estilo**: Formas cartoon planas con colores saturados vibrantes.
- **Elementos visuales**: Rellenos sin degradados, contornos gruesos simples, ilustraciones de personajes y formas geométricas básicas.
- **Tipografía**: Fuentes redondeadas o estilo caricatura con etiquetas claras y fuertes; uso de globos de diálogo para el texto.
- **Restricciones**: Prohibido usar sombras, efectos 3D o gradientes.
- **Uso recomendado**: Contenido infantil, guías protagonizadas por mascota y presentaciones divertidas.
