# claymation.md

## Resumen
Este documento define una guía de estilo para crear infografías con estética de animación en arcilla (claymation). Su función es estandarizar el uso de texturas, colores y tipografía para lograr un aspecto tridimensional, juguetón y nostálgico mediante stop-motion.

## Datos clave
- **Estética**: Textura de plastilina con imperfecciones como marcas de dedos; formas redondeadas y escultóricas.
- **Paleta de colores**: Colores primarios saturados pero ligeramente apagados, fondo neutro con degradados suaves y acentos brillantes.
- **Tipografía**: Letras extruidas en arcilla, dimensionales, redondeadas y voluminosas, integradas dentro de las escenas.
- **Uso recomendado**: Explicaciones lúdicas, contenido infantil, narrativas de stop-motion y procesos amigables.
