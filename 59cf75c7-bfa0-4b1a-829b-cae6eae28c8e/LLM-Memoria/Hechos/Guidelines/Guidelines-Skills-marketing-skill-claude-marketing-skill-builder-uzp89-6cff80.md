# SKILL.md

## Resumen
Esta guía define un sistema automatizado para redactar correos fríos B2B personalizados, asegurando que cada mensaje sea único y cumpla con normativas de envío. Su función principal es gestionar la prospección diaria sin enviar correos automáticamente, sino creando borradores listos para aprobación tras validar datos del perfil ideal y evitar duplicados mediante un registro actualizado en tiempo real.

## Datos clave
- **Proyecto**: email-outreach (parte de marketing-skill-builder).
- **Tecnologías**: Gmail MCP tools, WebSearch, WebFetch, Grep, Glob.
- **Decisiones críticas**: El sistema nunca envía correos por sí mismo; solo genera borradores o los cola para aprobación humana.
- **Rutas y archivos clave**: `${CLAUDE_PLUGIN_ROOT}/references/brand-voice.md`, `outreach-strategy.md` y `state/outreach-log.md`.
- **Pasos importantes**: Verificar estado de configuración (onboarding), revisar la estrategia de outreach cada 30 días para ajustes mensuales, sincronizar bandeja de entrada para detectar rebotes o bajas automáticamente, y filtrar duplicados antes de redactar.
