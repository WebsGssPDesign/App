# hub-spoke.md

## Resumen
Este documento define la estructura y mejores prácticas para crear diagramas de tipo "hub-spoke", donde un concepto central se conecta con elementos relacionados. Sirve como guía visual para diseñar mapas mentales, ecosistemas o roles de equipo que requieren una distribución equilibrada alrededor de un tema principal.

## Datos clave
- **Estructura**: Nodo central prominente conectado por líneas claras a nodos periféricos (spokes) con etiquetas y descripciones breves.
- **Casos de uso ideales**: Mapeo de ecosistemas, características de productos, roles del equipo y mapas mentales.
- **Estilos recomendados**: `cartoon-hand-drawn` para conceptos amigables, `corporate-memphis` para negocios y `subway-map` para redes complejas.
- **Elementos visuales**: Uso de iconos representativos en cada nodo y colores opcionales para agrupar elementos.
