# sanity.md

## Resumen
Este documento define el sistema de diseño visual del sitio web de Sanity, orientado a una estética oscura y técnica. Su objetivo es guiar la implementación de interfaces que reflejen precisión ingenieril mediante una paleta de colores estricta y tipografías específicas. Sirve como referencia para recrear fielmente la atmósfera de "centro de comando" nocturno característico de la marca en entornos web autocontenidos.

## Datos clave
- **Tipografía:** Sustitución de fuentes propietarias por `Space Grotesk` (principal) e `IBM Plex Mono` (código), cargadas vía Google Fonts CDN.
- **Paleta de colores:** Fondo base casi negro (`#0b0b0b`), escala de grises acromáticas y acentos vibrantes: verde neón, azul eléctrico (`#0052ef`) para estados hover/activos, y coral-rojo (`#f36458`) para CTAs.
- **Detalles tipográficos:** Uso de espaciado negativo extremo (tracking) en tamaños grandes para lograr un aspecto "mecanizado".
- **Formas geométricas:** Botones primarios con radio extremadamente alto (píldora) frente a rectángulos sutiles para acciones secundarias.
- **Flujo de trabajo sugerido:** Generar HTML, servir mediante `generative-widgets` y verificar visualmente con `browser_vision`.
