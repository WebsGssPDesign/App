# 04-review-angles.md

## Resumen
Este documento establece un protocolo riguroso para auditar la calidad técnica y estética de reportes convertidos a HTML. Su objetivo es garantizar que el contenido final sea fiel al original, visualmente coherente con su tema específico y accesible, evitando errores comunes como datos inventados o diseños genéricos.

## Datos clave
- **Principio central**: Verificar ángulos específicos (fidelidad, estética, tipografía) en lugar de solo confirmar la finalización.
- **Fidelidad estricta**: Prohibido inventar números, fechas o conclusiones; las lagunas deben etiquetarse como "datos faltantes".
- **Diseño contextual**: Evitar plantillas genéricas (gradientes púrpuras/azules); el estilo debe derivarse directamente del dominio del tema.
- **Tipografía y rejilla**: Uso de proporciones escalables, fuentes diferenciadas por rol (display/body) y una sola medida para párrafos continuos.
- **Visualización de datos**: Priorizar gráficos posicionales sobre los circulares; evitar "chartjunk" y 3D innecesario.
- **Accesibilidad**: Uso correcto de etiquetas semánticas HTML (`header`, `nav`, etc.), contraste adecuado y soporte para `prefers-reduced-motion`.
- **Validación visual**: Requisito de capturas de pantalla en escritorio y móvil para detectar superposiciones o cortes de contenido.
