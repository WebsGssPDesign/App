# scene-unfolding.md

## Resumen
Este documento define la estructura y mejores prácticas para crear infografías panorámicas que revelan un entorno completo. Su propósito es facilitar la exploración visual de ecosistemas, narrativas cotidianas o sistemas complejos mediante una composición rica en detalles y capas de profundidad.

## Datos clave
- **Proyecto**: SenseNova-Skills (Guías de habilidades visuales).
- **Tecnologías/Estilos recomendados**: `storybook-watercolor`, `origami` (entornos isométricos 3D), `crayon-hand-drawn`.
- **Elementos visuales**: Ilustración detallada, múltiples personajes/objetos, etiquetas con líneas de llamada y capas de profundidad (primer plano, fondo).
- **Ubicación del texto**: Títulos en la parte superior o cielo, leyendas al final.
- **Enfoque**: Fomenta la exploración no lineal en lugar de una lectura secuencial.
