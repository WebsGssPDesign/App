# fashion-editorial.md

## Resumen
Este documento define el lenguaje visual de revistas de alta costura, caracterizado por una dirección artística audaz y aspiracional. Sirve como guía para crear contenido editorial que combine imágenes impactantes con tipografía elegante y un uso estratégico del espacio en blanco.

## Datos clave
- **Estilo**: Imágenes heroicas con recortes seguros, iluminación dramática y sombras marcadas.
- **Paleta de colores**: Neutros sofisticados o monocromáticos fuertes; fondo blanco limpio o oscuro dramático; un color de acento potente.
- **Tipografía**: Serifas de alta costura (estilo Didot o Bodoni), titulares grandes con espaciado reducido y jerarquía mediante mezcla de pesos.
- **Uso ideal**: Marcas de lujo, belleza, moda, lifestyle, presentaciones de productos premium e informes de tendencias.
