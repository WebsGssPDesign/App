# bauhaus.md

## Resumen
Este documento define las directrices visuales para aplicar el estilo Bauhaus, caracterizado por la función que sigue a la forma y el uso de geometrías básicas. Sirve como referencia técnica para crear infografías educativas sobre arquitectura, diseño industrial e historia modernista con precisión industrial.

## Datos clave
- **Estilo**: Form follows function, sin ornamentación decorativa.
- **Paleta de colores**: Primarios puros (rojo, amarillo, azul), fondo blanco o negro, acentos en grises para estructura.
- **Elementos visuales**: Círculos, triángulos y rectángulos; líneas gruesas y planos planos sobre una estricta cuadrícula.
- **Tipografía**: Fuentes sans-serif geométricas con jerarquía clara por tamaño y peso; el texto actúa como elemento visual funcional.
