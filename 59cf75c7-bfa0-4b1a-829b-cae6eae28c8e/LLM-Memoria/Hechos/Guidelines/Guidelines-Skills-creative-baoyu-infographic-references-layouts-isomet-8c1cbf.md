# isometric-map.md

## Resumen
Este documento define las pautas para crear mapas isométricos que representan layouts espaciales, arquitecturas de sistemas o trayectorias de usuarios mediante una perspectiva tridimensional. Sirve como referencia técnica para diseñar visualizaciones claras donde los edificios y rutas conecten puntos clave desde un ángulo de pájaro.

## Datos clave
- **Proyecto**: baoyu-infographic (sección de referencias de layouts).
- **Tecnologías/Estilos**: Isometric 3D, Pixel-art, Lego-brick.
- **Decisiones de diseño**: Ángulo isométrico fijo de 30°, etiquetas flotantes sobre objetos y leyendas incluidas.
- **Elementos visuales**: Edificios como hitos, caminos conectores, escenas miniatura en ubicaciones.
- **Uso recomendado**: Maquetas de oficinas/campus, mapas de ecosistemas, diagramas de arquitectura de sistemas.
