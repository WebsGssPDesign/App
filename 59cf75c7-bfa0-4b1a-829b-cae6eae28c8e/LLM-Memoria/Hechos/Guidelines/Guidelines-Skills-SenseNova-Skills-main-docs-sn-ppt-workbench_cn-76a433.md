# sn-ppt-workbench_cn.md

## Resumen
Esta guía detalla el uso del Workbench de PPT en SenseNova-Skills para generar, editar y exportar presentaciones mediante una interfaz web. Permite monitorear la creación paso a paso, realizar ajustes finos con IA sobre elementos específicos y descargar los archivos finales en formatos estándar o PDF.

## Datos clave
- **Rutas principales**: `/progress` (monitoreo de generación) y `/editor` (edición final).
- **Flujo de trabajo**: Solicitar tema al agente -> Obtener URL de progreso -> Revisar páginas generadas -> Ingresar a editor -> Ajustar elementos o pedir análisis IA -> Exportar.
- **Herramientas de edición**: Selección manual, redimensionamiento, comandos de IA contextuales ("solo optimizar título seleccionado") y modo de presentación.
- **Exportación**: Soporta PPTX (con advertencia de compatibilidad), PDF e imágenes; incluye descarga de assets HTML/JSON para revisión técnica.
