# iceberg.md

## Resumen
Este documento define la estructura y el diseño de un diagrama tipo "iceberg" para visualizar la diferencia entre factores superficiales y causas ocultas. Sirve como guía técnica para ilustrar contrastes como síntomas versus problemas raíz o trabajo visible frente a invisible, asegurando que la masa subyacente sea visualmente más prominente.

## Datos clave
- **Concepto central**: Metáfora del iceberg (parte visible vs. masa oculta).
- **Aplicaciones ideales**: Análisis de causa raíz, comparación entre aspectos públicos y privados, y distinción entre síntomas e issues subyacentes.
- **Elementos visuales**: Línea de agua clara, degradado de profundidad, textura de olas; la parte sumergida debe ser más grande y oscura que la emergente.
- **Colocación de texto**: Títulos arriba, elementos superficiales sobre la línea y elementos ocultos debajo con mayor tamaño.
- **Estilos recomendados**: `crayon-hand-drawn` (metáfora amigable), `storybook-watercolor` (profundidad artística) o `cartoon-flat` (revelación dramática).
