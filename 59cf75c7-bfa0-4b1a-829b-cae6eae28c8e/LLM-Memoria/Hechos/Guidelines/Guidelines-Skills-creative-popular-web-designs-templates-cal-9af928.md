# cal.md

## Resumen
Este documento detalla el sistema de diseño del sitio web de Cal.com, enfocado en una estética monocromática y minimalista inspirada en Uber. Su objetivo es guiar la implementación visual mediante reglas estrictas de tipografía, paleta de colores grises y un sofisticado sistema de sombras para crear profundidad sin usar color.

## Datos clave
- **Tipografía:** Cal Sans (títulos con espaciado muy ajustado) combinada con Inter (cuerpo). Sustitutos web: `Inter` y `Roboto Mono`.
- **Paleta de colores:** Base monocromática (#242424, #111111, #ffffff). El único color semántico es el azul para enlaces (`#0099ff`).
- **Sistema de elevación:** 11 definiciones de sombra multicapa que combinan bordes anillos y sombras difusas; sin degradados.
- **Herramientas:** Construido en Framer. Implementación sugerida usando `write_file`, `generative-widgets` y verificación con `browser_vision`.
- **Detalles técnicos:** Escala de radio de borde desde 2px hasta 9999px (píldora). Uso de CDN para fuentes Google Fonts.
