# sn-infographic-examples.md

## Resumen
Este documento presenta una galería de inspiración con casi 100 ejemplos de infografías generadas por IA utilizando la herramienta `sn-infographic`. Su función principal es servir como catálogo visual que incluye los prompts detallados ("Expanded Prompt") necesarios para replicar diseños técnicos y futuristas, facilitando el aprendizaje y la creación de nuevos materiales visuales.

## Datos clave
- **Proyecto**: SenseNova-Skills (módulo sn-infographic).
- **Tecnologías**: `sn-image-base`, generación de imágenes por IA.
- **Decisiones de diseño**: Uso de estilos como "glassmorphism", diagramas de explosión técnica y estética sci-fi oscura.
- **Pasos importantes**: Los usuarios deben hacer clic en "Expanded Prompt" para acceder a las recetas secretas (prompts) detrás de cada imagen maestra.
- **Ejemplos destacados**: Diagrama de estructura interna de cámara y presentación del modelo SenseNova-U1 con arquitectura NEO-Unify.
