# SKILL.md

## Resumen
Este documento define una habilidad técnica para analizar datos categóricos en Excel mediante Python. Permite extraer y limpiar etiquetas, calcular distribuciones estadísticas y generar informes visuales de alta resolución que combinan gráficos de barras, líneas y tortas.

## Datos clave
- **Proyecto**: SenseNova-Skills (sn-da-excel-workflow).
- **Tecnologías**: Python, pandas, matplotlib.
- **Pasos principales**:
  1. Limpieza de datos: Eliminación de valores nulos y reemplazo de marcadores como '--' o '代码'.
  2. Estadística: Cálculo de conteos y porcentajes por categoría.
  3. Visualización básica: Gráfico dual (barras + curva de porcentaje) guardado a 300 DPI.
  4. Reporte completo: Generación de subplots con torta y barras, más un gráfico horizontal con mapeo dinámico de colores basado en palabras clave.
- **Rutas de salida**: `category_distribution.png`, `category_pie_bar.png`, `category_hbar.png`.
