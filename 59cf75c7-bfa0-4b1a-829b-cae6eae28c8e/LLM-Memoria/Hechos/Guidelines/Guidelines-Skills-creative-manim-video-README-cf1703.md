# README.md

## Resumen
Este archivo describe un flujo de trabajo para generar videos animados estilo educativo utilizando la edición comunitaria de Manim. Su función principal es automatizar todo el proceso, desde la planificación creativa hasta el renderizado final, permitiendo crear explicaciones visuales complejas a partir de prompts de texto.

## Datos clave
- **Proyecto**: Pipeline de producción de videos animados matemáticos y técnicos con Manim Community Edition.
- **Tecnologías**: Python 3.10+, Manim CE, LaTeX, ffmpeg.
- **Decisiones**: El agente gestiona el ciclo completo: planificación creativa, generación de código Python, renderizado, ensamblaje de escenas y refinamiento iterativo.
- **Rutas**: `skills/creative/manim-video/scripts/setup.sh`.
- **Comandos**: `pip install manim` para la instalación inicial y ejecución del script de configuración proporcionado.
