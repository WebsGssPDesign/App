# SKILL.md

## Resumen
Este documento detalla un flujo de trabajo en Python para analizar datos de Excel mediante clasificación personalizada y evaluación multidimensional de contenido. Sirve para generar estadísticas distribucionales, visualizar resultados con gráficos interactivos y asignar niveles de dificultad o calidad basados en métricas como longitud y densidad de términos técnicos.

## Datos clave
- **Tecnologías**: Python, Pandas, Matplotlib, NumPy.
- **Funciones principales**: `load_excel_data` (carga con saltos), `analyze_and_visualize` (gráficos combinados), `analyze_content_difficulty` (algoritmo de puntuación).
- **Métricas de evaluación**: Longitud del texto, conteo de términos técnicos, presencia de números y conceptos complejos.
- **Gráficos generados**: Histogramas, diagramas de pastel, tablas cruzadas apiladas y dispersión de tendencias.
- **Configuración**: Uso de fuentes chinas (`SimHei`) para visualización correcta y guardado de imágenes en alta resolución (300 dpi).
