# containerization.md

## Resumen
Esta guía define las directrices para el diseño de contenedores visuales en infografías, asegurando que todo el contenido se coloque dentro de bordes o bloques de fondo definidos. Su propósito es organizar múltiples temas, datos estructurados y referencias mediante una separación clara y consistente entre diferentes secciones.

## Datos clave
- **Estructura**: Todo el contenido debe estar encerrado en contenedores distintos (tarjetas, cajas o paneles) con estilos coherentes; los contenedores pueden anidarse para subgrupos.
- **Elementos visuales**: Uso de bordes visibles, rellenos de fondo, espaciado interno uniforme y sombras o esquinas redondeadas para dar profundidad.
- **Ubicación del texto**: El título de la sección va en el encabezado del contenedor, el contenido dentro del cuerpo y el título general por encima de todos los contenedores.
- **Aplicaciones ideales**: Infografías multitema, tarjetas de referencia, hojas de trucos (cheat sheets) y diseños tipo panel de control.
- **Combinaciones recomendadas**: Se sugiere emparejar este estilo con `ui-wireframe`, `corporate-memphis` o `technical-schematic`.
