# caption_rewrite.md

## Resumen
Este documento define un prompt para ingenieros visuales que reescriben descripciones de imágenes manteniendo estrictamente el estilo y la composición original mientras cambian el contenido semántico solicitado. Su función es garantizar que las imágenes generadas imiten fielmente la jerarquía visual, la estructura de bloques y la paleta del referente, adaptando solo los datos o mensajes específicos.

## Datos clave
- **Proyecto**: SenseNova-Skills (módulo `sn-image-imitate`).
- **Tecnologías**: Ingeniería de prompts para generación de imágenes.
- **Decisiones críticas**: Mantener la topología macro, el ritmo de espaciado y la familia de gráficos; eliminar contenido temático antiguo salvo indicación expresa.
- **Restricciones de salida**: Texto plano sin marcas de formato (markdown), explicaciones o metadatos adicionales.
