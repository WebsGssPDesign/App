# chapter-layout.md

## Resumen
Este documento define una estructura de diseño para capítulos tipo libro, ideal para infografías educativas largas o guías completas. Establece el uso de barras de encabezado numeradas y separadores visuales para organizar el contenido de forma clara y secuencial. Sirve como referencia técnica para aplicar este estilo en proyectos que requieran una jerarquía visual definida entre secciones.

## Datos clave
- **Proyecto**: SenseNova-Skills (layout de infografías)
- **Tecnologías/Estilos**: `aged-academia`, `corporate-memphis`, `chalkboard`
- **Elementos visuales**: Barras de encabezado con número y título, reglas o bandas de color como divisores, iconos opcionales.
- **Flujo de lectura**: De arriba hacia abajo a través de los capítulos.
- **Uso recomendado**: Informes multi-tématicos, materiales de referencia estructurados y guías completas.
