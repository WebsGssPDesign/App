# dogfood-report-template.md

## Resumen
Este archivo es una plantilla de informe para pruebas de calidad (QA) automatizadas realizadas por un agente llamado "Hermes". Su función estandarizar el reporte de errores, incluyendo resúmenes ejecutivos, detalles técnicos de fallos y cobertura de pruebas.

## Datos clave
- **Proyecto**: Dogfood QA Report Template.
- **Tecnologías**: Markdown (`.md`), plantillas con variables dinámicas (ej. `{target_url}`, `{severity}`).
- **Decisiones**: Uso de tablas para resúmenes visuales y jerarquización de errores por severidad (Crítico, Alto, Medio, Bajo).
- **Pasos importantes**: La sección "Issues" debe repetirse para cada hallazgo; se incluyen campos obligatorios como URL, pasos de reproducción y capturas de pantalla.
