# winding-roadmap.md

## Resumen
Este documento define la estructura y los elementos visuales para crear infografías de tipo "mapa de ruta serpenteante". Sirve como guía de diseño para representar trayectorias, hitos y progresos en proyectos, carreras o viajes del cliente mediante una composición curva con marcadores claros.

## Datos clave
- **Proyecto**: Diseño de plantillas visuales (winding-roadmap).
- **Tecnologías/Estilos sugeridos**: `storybook-watercolor` para viajes fantásticos, `cartoon-hand-drawn` para mapas amigables e `isometric-3d` para rutas técnicas.
- **Elementos estructurales**: Curva en forma de S o camino serpenteante, hitos (milestones), puntos de inicio y destino, indicadores de progreso y elementos laterales como obstáculos o ayudantes.
- **Ubicación del texto**: Título superior, etiquetas de hitos en cada punto, nombres de secciones del camino y descripción del destino final.
