# composio.md

## Resumen
Este documento define el sistema de diseño visual para la interfaz de Composio, orientada a desarrolladores con una estética oscura y terminal. Establece reglas estrictas para tipografía, paleta de colores y efectos visuales que evocan un centro de comando nocturno. Su objetivo es guiar la implementación de páginas HTML autocontenidas que transmitan autoridad técnica mediante el uso de fuentes monoespaciadas y acentos cian bioluminiscentes.

## Datos clave
- **Proyecto:** Design System: Composio (Hermes Agent).
- **Tecnologías:** Fuentes CDN (`DM Sans`, `JetBrains Mono`), HTML, CSS.
- **Decisiones de diseño:** Canvas negro profundo (`#0f0f0f`), líneas de título ultra-compresas (altura 0.87), sombras offset brutales (`4px 4px`).
- **Paleta crítica:** Azul Cobalt (`#0007cd`) para marca, Cian Eléctrico (`#00ffff`) para acentos, Gris Carbón (`#2c2c2c`) para bordes.
- **Pasos de implementación:** Usar `write_file` para generar HTML, servir vía `generative-widgets`, y validar visualmente con `browser_vision`.
