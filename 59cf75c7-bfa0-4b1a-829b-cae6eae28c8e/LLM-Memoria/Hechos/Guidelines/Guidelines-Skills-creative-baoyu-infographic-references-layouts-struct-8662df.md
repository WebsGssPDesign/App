# structural-breakdown.md

## Resumen
Este documento define las directrices para crear infografías de descomposición estructural, ideal para explicar componentes internos o capas de un sistema. Sirve como referencia visual para ilustrar relaciones entre partes mediante vistas explosivas o secciones transversales.

## Datos clave
- **Proyecto**: baoyu-infographic (sección de layouts).
- **Tipos de vista**: Exploded (partes separadas) y Cross-section (vista cortada).
- **Elementos visuales**: Líneas de llamada con puntos/flechas, cajas de etiquetas, límites de capas.
- **Ubicación del texto**: Título superior, descripciones breves en las cajas de llamadas y leyenda para sistemas numerados.
- **Estilos recomendados**: technical-schematic, aged-academia, craft-handmade.
