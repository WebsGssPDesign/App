# chinese-guochao.md

## Resumen
Este archivo define una guía de estilo visual que fusiona elementos tradicionales chinos con la estética del diseño moderno. Sirve como referencia para crear contenido cultural, marcas locales y productos de belleza que reflejen la identidad nacional contemporánea.

## Datos clave
- **Paleta de colores**: Rojo chino (#E60012), dorado, negro tinta, crema papel arroz, verde jade, amarillo imperial y cinabrio.
- **Elementos visuales**: Motivos nubes, olas y montañas; caligrafía china; patrones de corte de papel; criaturas mitológicas (dragón, fénix); sobres rojos y linternas.
- **Tipografía**: Estilo inspirado en caligrafía, mezcla de fuentes tradicionales y modernas, arreglos verticales opcionales y caracteres grandes como gráficos.
- **Uso recomendado**: Contenido cultural chino, marcas domésticas, festivales tradicionales, temas de herencia y productos C-beauty.
