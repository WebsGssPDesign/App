# venn-diagram.md

## Resumen
Este documento define la estructura y mejores prácticas para crear diagramas de Venn, los cuales sirven para visualizar relaciones, superposiciones y diferencias entre conceptos o categorías mediante círculos solapados. Es especialmente útil para analizar habilidades compartidas, segmentos de mercado y hallar puntos en común entre grupos distintos.

## Datos clave
- **Estructura**: Utilizar 2 a 3 círculos solapados donde el centro representa elementos comunes a todos y las áreas únicas muestran exclusividad.
- **Elementos visuales**: Emplear rellenos translúcidos, colores distintivos por círculo, iconos dentro de las regiones y etiquetas claras en los bordes.
- **Colocación de texto**: El título va arriba, las etiquetas de los círculos fuera o en el borde, y los ítems listados en sus respectivas zonas de solapamiento.
- **Estilos recomendados**: `cartoon-hand-drawn` para conceptos amigables, `corporate-memphis` para análisis de negocios y `pop-art` para comparaciones de alto contraste.
