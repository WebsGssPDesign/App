# emotional-gradient.md

## Resumen
Este documento define la estructura y los elementos visuales para crear infografías que representen un viaje emocional o una progresión de intensidad mediante gradientes. Sirve como guía técnica para diseñar composiciones donde el color, la densidad y la complejidad visual evolucionan desde un estado inicial hasta uno final, ideal para narrativas de transformación o espectros de tono de marca.

## Datos clave
- **Estructura**: Disposición lineal que transita de un estado emocional a otro (ej. frío a cálido).
- **Elementos visuales**: Paleta de colores suave, ilustraciones que reflejan el estado y aumento progresivo de la complejidad hacia el final.
- **Ubicación del texto**: Etiquetas emocionales en puntos clave, título en el inicio neutral y conclusión en el estado intenso.
- **Pares recomendados**: `storybook-watercolor`, `crayon-hand-drawn` y `kawaii`.
