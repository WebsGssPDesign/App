# claymation.md

## Resumen
Este documento define una guía de estilo visual para crear un estético tridimensional inspirado en la animación de plastilina (claymation). Su función es estandarizar el uso de texturas, colores y tipografía para generar contenido amigable y narrativo con encanto artesanal.

## Datos clave
- **Estética**: Textura de plastilina o arcilla en todos los objetos, formas redondeadas y escultóricas.
- **Detalles**: Marcas de huellas dactilares, imperfecciones deliberadas y sombras suaves.
- **Paleta de colores**: Colores primarios saturados pero ligeramente apagados; fondos neutros con degradados suaves; acentos brillantes complementarios.
- **Tipografía**: Letras extruidas en 3D, redondeadas, volumétricas e integradas dentro de las escenas de arcilla.
- **Aplicación ideal**: Explicaciones divertidas, contenido infantil, narrativas de stop-motion y procesos amigables.
