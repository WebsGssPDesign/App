# scene-planning.md

## Resumen
Este documento establece una guía técnica para planificar la narrativa y estructura visual de videos educativos creados con Manim. Proporciona patrones de arco narrativo, transiciones entre escenas, tiempos estimados y una plantilla de marcado para asegurar consistencia en el diseño y la duración del contenido final.

## Datos clave
- **Arquitectura**: Se definen cuatro estructuras narrativas principales: Discovery Arc (el más común), Problem-Solution Arc, Comparison Arc y Build-Up Arc.
- **Transiciones**: Se especifican tres tipos de transición (`Clean Break`, `Carry-Forward`, `Transform Bridge`) con ejemplos de código Python para manipulación de objetos visuales.
- **Consistencia**: Se establecen constantes globales para colores (ej. `#1C1C1C`), tamaños de fuente y velocidades de animación al inicio del archivo.
- **Checklist**: Incluye requisitos obligatorios como subtítulos en cada animación, uso de capas de opacidad y limitación a 5-6 elementos visibles simultáneamente.
- **Duración**: Tabla de referencia para tiempos de escena (ej. introducción de concepto: 10-20s, momento "Aha": 15-30s).
- **Plantilla**: Formato Markdown estandarizado para documentar el título, audiencia, paleta de colores y secuencia detallada de cada escena.
