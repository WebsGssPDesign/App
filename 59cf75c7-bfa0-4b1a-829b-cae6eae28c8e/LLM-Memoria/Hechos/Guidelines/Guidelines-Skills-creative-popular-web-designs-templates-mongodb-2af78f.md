# mongodb.md

## Resumen
Este documento define el sistema de diseño visual del sitio web de MongoDB, centrado en una estética que combina la oscuridad de un bosque con terminales de código. Su propósito es guiar a los desarrolladores para replicar fielmente la atmósfera única de la marca mediante una paleta de colores específica y reglas tipográficas estrictas.

## Datos clave
- **Colores principales**: Fondo "Forest Black" (#001e2b) y acento "MongoDB Green" (#00ed64).
- **Tipografía**: Uso de `MongoDB Value Serif` para titulares heroicos, `Euclid Circular A` para cuerpo y UI, y `Source Code Pro` para código.
- **Estilo visual**: Sombras con tinte teal (`rgba(0, 30, 43, 0.12)`) y botones de forma píldora (radio 100px–999px).
- **Implementación**: Sustitución de fuentes propietarias por CDN (Inter y Source Code Pro) para HTML autocontenido.
- **Flujo de trabajo**: Generar con `write_file`, servir vía `generative-widgets` y verificar con `browser_vision`.
