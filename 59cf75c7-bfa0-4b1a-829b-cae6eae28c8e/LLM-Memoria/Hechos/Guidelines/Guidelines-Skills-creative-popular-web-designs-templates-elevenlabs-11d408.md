# elevenlabs.md

## Resumen
Este documento define el sistema de diseño visual del sitio web de ElevenLabs, enfocado en una estética elegante y minimalista que prioriza la tipografía y espacios en blanco cálidos. Sirve como guía técnica para replicar fielmente la atmósfera premium de la marca utilizando fuentes específicas y paletas de colores sutiles.

## Datos clave
- **Fuentes:** `Waldenburg` (300) para títulos etéreos, `Inter` con espaciado positivo (0.14–0.18px) para cuerpo, y `JetBrains Mono` o `Geist Mono` para código.
- **Paleta de colores:** Fondos casi blancos (`#ffffff`, `#f5f5f5`) con toques cálidos de piedra (`#f5f2ef`). Sombras tintadas en marrón cálido (`rgba(78,50,23,0.04)`).
- **Detalles visuales:** Botones tipo píldora (9999px) y sombras multicapa con opacidades inferiores a 0.1 para crear profundidad sutil.
- **Implementación:** Usar `write_file` para generar HTML y validar visualmente con `browser_vision`. Sustituir fuentes propietarias por CDN de Google Fonts.
