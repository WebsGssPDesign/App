# aged-academia.md

## Resumen
Este archivo define las directrices de estilo para ilustraciones científicas con una estética de papel envejecido. Su propósito es guiar la creación de visuales que evoquen academias históricas mediante paletas de colores específicos, texturas y tipografías manuscritas.

## Datos clave
- **Proyecto:** SenseNova-Skills (estilo `aged-academia`).
- **Paleta de colores:** Tono sepia principal (#704214), fondo pergamino (#F4E4BC) y acentos en rojo desvanecido.
- **Variantes visuales:** "Notebook" para bocetos personales con notas al margen; "Specimen" para clasificación científica con diagramas numerados y etiquetas latinas.
- **Elementos gráficos:** Textura de papel amarillento, trazos cruzados detallados, anotaciones en tinta de galena y precisión ilustrativa.
- **Tipografía:** Fuentes cursivas o serif manuscritas, uso de mayúsculas pequeñas para etiquetas e itálicas para nombres científicos.
- **Uso recomendado:** Educación científica, biología, explicaciones históricas y documentación de la naturaleza.
