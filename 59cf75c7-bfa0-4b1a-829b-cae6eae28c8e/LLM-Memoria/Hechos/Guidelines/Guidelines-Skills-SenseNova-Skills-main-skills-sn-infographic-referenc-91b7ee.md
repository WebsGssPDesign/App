# flat-design.md

## Resumen
Este documento establece las directrices para un diseño gráfico plano (flat design) enfocado en la claridad y la modernidad. Sirve como referencia visual para crear infografías, flujos de procesos y materiales educativos utilizando bloques de color sólido, formas geométricas simples y tipografía sans-serif sin sombras ni texturas.

## Datos clave
- **Estilo visual**: Cero sombras, bevels o texturas; uso exclusivo de colores planos sólidos.
- **Paleta de colores**: Limitada a 3–5 colores complementarios con fondos neutros o sólidos.
- **Tipografía**: Fuentes sans-serif limpias (Roboto, Open Sans, Nunito) con pesos negritas y alto contraste.
- **Elementos gráficos**: Iconos e ilustraciones geométricas simples que reemplazan la fotografía; cada elemento debe tener un propósito claro.
- **Casos de uso recomendados**: Infografías para interfaces de aplicaciones (App UI), guías paso a paso, contenido para redes sociales y materiales educativos modernos.
