# requirements.txt

## Resumen
Este archivo lista las dependencias de Python necesarias para un módulo de búsqueda financiera dentro del proyecto SenseNova. Su función es garantizar que el entorno tenga instaladas las librerías requeridas para acceder y analizar datos financieros públicos y privados.

## Datos clave
- **Proyecto**: SenseNova (módulo `sn-search-finance`)
- **Tecnologías**: Python, pip
- **Paquetes**: `yfinance` (para datos de mercado público), `mootdx[all]` (para acceso a datos de la Bolsa Mexicana de Valores)
- **Comando de instalación típico**: `pip install -r requirements.txt`
