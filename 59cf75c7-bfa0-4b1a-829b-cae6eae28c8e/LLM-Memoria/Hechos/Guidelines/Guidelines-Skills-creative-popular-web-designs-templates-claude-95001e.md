# claude.md

## Resumen
Este documento define el sistema de diseño del producto Claude, enfocándose en una estética cálida y literaria que evoca papel premium en lugar de tecnología fría. Establece reglas estrictas para la paleta de colores con tonos tierra, tipografía serif personalizada y un enfoque en la experiencia humana sobre lo futurista. Sirve como guía técnica para replicar fielmente el ambiente visual único de Anthropic en implementaciones web.

## Datos clave
- **Tipografía:** Fuentes primarias `Inter` (sans-serif) y `JetBrains Mono` (monoespaciado) vía CDN, con fallback a `Georgia`.
- **Paleta de colores:** Fondo principal "Parchment" (`#f5f4ed`) y acento de marca "Terracotta" (`#c96442`). Todos los neutros tienen subtonos amarillos/marrones.
- **Herramientas sugeridas:** Uso de `write_file` para generar HTML, `generative-widgets` para servir el sitio (túnel cloudflared) y `browser_vision` para verificación visual.
- **Estilo visual:** Ilustraciones orgánicas manuales, ausencia de gradientes tradicionales y sombras tipo anillo (`0px 0px 0px 1px`).
