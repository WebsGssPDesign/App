# deconstructivism.md

## Resumen
Este documento define las directrices visuales para aplicar el estilo deconstructivista en infografías y contenido gráfico. Su objetivo es crear composiciones deliberadamente disruptivas que rompan con las reglas tradicionales del diseño mediante fragmentación, capas y tensión visual. Sirve como referencia técnica para diseñadores que buscan transmitir conceptos de arquitectura, teoría crítica o declaraciones de marca innovadoras.

## Datos clave
- **Estilo**: Composiciones fragmentadas, superpuestas y desequilibradas.
- **Paleta de colores**: Combinaciones chocantes, fondos rotos sin unificación y contrastes repentinos.
- **Elementos visuales**: Formas rotas o inclinadas, estructuras expuestas (cuadrículas visibles), texto en ángulos inesperados y elementos que rompen los contenedores.
- **Tipografía**: Mezcla intencional de fuentes, letras fragmentadas u ocultas y uso del texto como elemento gráfico puro.
- **Casos de uso ideales**: Arquitectura, diseño experimental, teoría crítica y comentarios culturales.
