# 02-layout-and-content-design.md

## Resumen
Este documento establece las directrices de diseño para transformar contenido estructural en experiencias visuales informativas, priorizando la claridad sobre la estética. Su función es definir cómo organizar la información (topología, esqueleto) y presentar datos complejos mediante tablas y diagramas específicos que reflejen relaciones reales, evitando diseños decorativos o confusos.

## Datos clave
- **Principio central**: La estructura es información; todo elemento visual debe comunicar una relación real de datos.
- **Topologías**: Selección entre scroll único, múltiples vistas, dashboards o guías según si el usuario lee o usa la herramienta.
- **Esqueletos**: Opciones como columna única, con barra lateral, grilla amplia o texto restringido con imágenes a pantalla completa.
- **Reglas de navegación**: Uso de TOC, scrollspy o pestañas basado en la longitud del contenido y la complejidad de la IA (5-7 ítems arriba vs. 9+ en barra lateral).
- **Formas de contenido**: Mapeo específico para mostrar evolución temporal, comparaciones, jerarquías o datos numéricos mediante líneas, matrices o gráficos de barras desde cero.
- **Restricciones visuales**: Prohibición de "paredes" de texto, tablas excesivas o tarjetas sin contexto; los gráficos cuantitativos deben tener base cero y usar posición/longitud sobre colores.
- **Evidencia**: Las fuentes, unidades y limitaciones deben estar pegadas a las afirmaciones clave, no escondidas en el final.
