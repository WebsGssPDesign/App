# supabase.md

## Resumen
Este documento define el sistema de diseño visual para la plataforma Supabase, enfocándose en una estética nativa de modo oscuro que evoca editores de código premium. Establece reglas estrictas para tipografía, paleta de colores basada en HSL y jerarquías visuales para garantizar consistencia en interfaces desarrolladas con herramientas como Hermes Agent.

## Datos clave
- **Tipografía**: Fuentes primarias 'Inter' (substituta de Circular) y monoespaciada 'Source Code Pro'.
- **Paleta de colores**: Fondos negros profundos (`#0f0f0f`, `#171717`) con acentos esmeralda (`#3ecf8e`). Uso intensivo de tokens HSL con canales alfa para capas translúcidas.
- **Formas y botones**: Botones primarios con radio infinito (píldora) vs secundarios con 6px; bordes sutiles en lugar de sombras profundas.
- **Flujo de implementación**: Generar HTML vía `write_file`, servir mediante `generative-widgets` y validar visualmente con `browser_vision`.
