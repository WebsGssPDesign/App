# SKILL.md

## Resumen
Este documento describe SenseNova Team Harness, una plataforma auto-alojada que permite a equipos humanos y agentes de IA colaborar en un espacio compartido para gestionar proyectos y tareas. Su función principal es transformar conversaciones simples en flujos de trabajo auditables donde los resultados se almacenan como artefactos independientes y seguros localmente.

## Datos clave
- **Proyecto**: SenseNova Team Harness (auto-alojado).
- **Tecnologías**: Node.js 24, npm, SQLite (implícito), frontend en localhost:5173.
- **Conceptos centrales**: Workspace, Project, Conversation, Agent, WorkItem, Resource, Artifact, Local Computer.
- **Comandos de inicio**: `git clone`, `npm ci`, `npm run dev` o `npm run build`.
- **Flujo crítico**: Crear Workspace -> Invitar miembros -> Asignar WorkItems a Agents -> Generar Artifacts auditables.
- **Restricciones**: No incluye Docker, imágenes precompiladas ni migraciones de base de datos; requiere configuración manual de seguridad para producción.
