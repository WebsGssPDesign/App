# gallery-style.md

## Resumen
Este documento define el estilo "gallery-style" para presentaciones visuales, caracterizado por márgenes amplios y una disposición independiente de elementos. Su propósito es resaltar colecciones artísticas o productos premium mediante un diseño limpio que trata cada ítem como una obra individual.

## Datos clave
- **Estilo**: Márgenes blancos anchos, elementos centrados con espacio generoso.
- **Uso ideal**: Portafolios, exposiciones de fotografía y catálogos de lujo.
- **Elementos visuales**: Títulos superiores con espaciado amplio, subtítulos pequeños debajo de cada ítem, bordes mínimos.
- **Combinaciones recomendadas**: `aged-academia` (estilo museo), `knolling` (plano organizado) y `luxury-minimal`.
