# multi-scale.md

## Resumen
Este documento define una estructura de infografía jerárquica que conecta vistas macro y micro mediante enlaces visuales. Sirve para explicar detalles técnicos complejos, arquitecturas de sistemas o relaciones científicas utilizando paneles de aumento conectados a líneas punteadas.

## Datos clave
- **Estructura**: Vista general simultánea con paneles de inserción (inset) que muestran detalles.
- **Conectores**: Uso obligatorio de líneas punteadas o flechas para vincular niveles de escala.
- **Elementos visuales**: Indicadores de escala, etiquetas en el diagrama principal y dentro de los paneles detallados.
- **Casos de uso recomendados**: Diagramas esquemáticos técnicos (`technical-schematic`), vistas de especímenes científicos (`aged-academia`) y zooms de componentes de interfaz (`ui-wireframe`).
