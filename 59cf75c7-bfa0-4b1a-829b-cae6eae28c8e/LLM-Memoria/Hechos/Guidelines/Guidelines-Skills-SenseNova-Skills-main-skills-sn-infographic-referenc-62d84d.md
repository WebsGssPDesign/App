# generous-margins.md

## Resumen
Este documento define la plantilla "generous-margins", diseñada para layouts donde el contenido ocupa solo el 40-60% del lienzo, dejando márgenes amplios intencionales. Su propósito es evocar lujo y calma, ideal para marcas premium o presentaciones editoriales minimalistas que requieren espacio visual.

## Datos clave
- **Proyecto**: SenseNova-Skills (guías de diseño).
- **Estructura**: Bloque centralizado con márgenes grandes (blancos, coloreados o texturizados).
- **Elementos visuales**: Opcional borde sutil en el margen y elementos decorativos mínimos.
- **Ubicación del texto**: Todo el contenido principal dentro de la zona central; solo pequeños créditos opcionales en los márgenes.
- **Parejas recomendadas**: `aged-academia`, `luxury-minimal`.
