# README_CN.md

## Resumen
Este ejemplo demuestra cómo utilizar la capacidad de "investigación profunda" de SenseNova-Skills para generar un informe profesional sobre el sector de la inteligencia encarnada. El sistema realiza una búsqueda autónoma en internet, sintetiza datos clave como cuota de mercado y financiación, y produce un informe visual completo sin necesidad de archivos de entrada previos.

## Datos clave
- **Proyecto**: SenseNova-Skills (ejemplo de investigación profunda).
- **Tecnologías**: `sn-deep-research` (búsqueda/grabado/síntesis), `sn-md-to-html-report` (renderizado).
- **Flujo de trabajo**: Iniciar con un prompt simple → Generar informe Markdown + 5 gráficos → Convertir a HTML visual.
- **Salida**: Archivo `result/具身智能行业调研.zip` conteniendo `report.html`, `report.md` y cinco imágenes de análisis (tendencia, cuota, financiación, costes, hoja de ruta).
