# marker-style.md

## Resumen
Este documento define las directrices visuales para crear ilustraciones de marcadores con un estilo vibrante y plano. Sirve como referencia técnica para diseñar contenido enfocado en audiencias juveniles, deportes y cultura urbana mediante el uso específico de colores saturados, trazos negros y tipografía manuscrita.

## Datos clave
- **Estilo visual**: Colores primarios saturados, bordes visibles del marcador, fugas de color sutiles y textura estriada.
- **Tipografía**: Letras a mano o con pincel grueso, bloques con contorno o relleno y líneas base ligeramente irregulares.
- **Paleta**: Fondo blanco o papel claro, acentos en negro y resaltados neón.
- **Uso recomendado**: Infografías sociales, promociones de eventos, temas de fitness y cultura callejera.
