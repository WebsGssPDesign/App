# kawaii.md

## Resumen
Este documento define las directrices de estilo visual "kawaii" para el proyecto SenseNova, especificando una paleta de colores pastel y elementos gráficos tiernos. Su propósito es estandarizar la apariencia de tutoriales infantiles y contenido educativo para asegurar un tono amigable y atractivo.

## Datos clave
- **Estilo**: Kawaii japonés con ojos grandes, mejillas sonrosadas y formas redondeadas.
- **Paleta de colores**: Rosa suave (#FFB6C1), menta (#98D8C8) y lavanda (#E6E6FA).
- **Tipografía**: Fuentes redondeadas y burbujeantes con decoraciones como corazones y estrellas.
- **Elementos visuales**: Personajes animales en proporción chibi, brillos (sparkles) y formas de corazón.
- **Uso recomendado**: Tutoriales divertidos, educación infantil y contenido de estilo de vida.
