# pixel-art.md

## Resumen
Este documento define una guía de estilo para crear contenido visual con estética de videojuegos retro 8-bit. Sirve como referencia técnica para diseñar paletas de colores, elementos gráficos y tipografías que evoquen la era de consolas como NES o SNES.

## Datos clave
- **Estética**: Retro 8-bit gaming (NES/SNES).
- **Paleta de colores**: Fondo negro o azul oscuro con líneas de escaneo; acentos brillantes y efecto CRT.
- **Elementos visuales**: Cuadrícula de píxeles visible, límite estricto de colores por sprite, bordes perfectos y dithering para gradientes.
- **Tipografía**: Fuentes pixeladas con formas de letras bloqueantes, estilo UI de juego (puntuaciones/estadísticas).
- **Uso recomendado**: Temas de gaming, contenido nostálgico, audiencias de desarrolladores y tecnología retro.
