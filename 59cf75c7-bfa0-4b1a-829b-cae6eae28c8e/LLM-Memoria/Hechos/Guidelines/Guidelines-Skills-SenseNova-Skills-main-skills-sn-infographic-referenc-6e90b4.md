# impressionism.md

## Resumen
Este documento define las directrices de diseño para aplicar el estilo pictórico impresionista en infografías y contenido visual. Su función es guiar la creación de piezas que prioricen la captura de luz, atmósfera y pinceladas sueltas sobre el detalle preciso, ideal para temas naturales o artísticos.

## Datos clave
- **Estilo visual**: Pinceladas rotas, colores vibrantes puros colocados lado a lado, bordes indefinidos y perspectiva atmosférica.
- **Paleta de colores**: Tonos azules luminosos del cielo, calidez dorada solar y toques complementarios para generar vibración.
- **Tipografía**: Letras con serifa ligeramente desenfocadas o estilo acuarela integradas naturalmente en la escena.
- **Casos de uso recomendados**: Naturaleza, clima, historia del arte, viajes, paisajes, bienestar y narrativas de datos impresionistas.
