# README_CN.md

## Resumen
Este documento detalla un flujo de trabajo end-to-end que integra análisis de datos, investigación profunda y generación de presentaciones. Su objetivo es transformar datos crudos de precios de chips en informes ejecutivos de alto nivel con estilo editorial, combinando evidencia cuantitativa con contexto cualitativo para apoyar la toma de decisiones estratégicas.

## Datos clave
- **Entrada**: Archivo `result/芯片价格汇总.csv` (1835 registros de 2026-04-21).
- **Herramientas**: `sn-da-excel-workflow` (análisis), `sn-deep-research` (investigación externa), `sn-ppt-standard` (generación PPTX).
- **Hallazgos clave**: Aumento de precios impulsado por contracción de oferta, demanda de servidores AI y control de producción; tendencia estructural alcista.
- **Salidas**: Informe HTML visualizado, archivo ZIP con gráficos y presentación final `半导体存储市场研究报告_20260426_015200.pptx` (16 diapositivas).
