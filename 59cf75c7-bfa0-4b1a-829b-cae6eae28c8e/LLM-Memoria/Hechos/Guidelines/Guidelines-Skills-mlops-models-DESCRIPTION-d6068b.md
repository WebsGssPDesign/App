# DESCRIPTION.md

## Resumen
Este archivo describe arquitecturas de modelos específicos y herramientas para tareas de segmentación de imágenes con SAM y generación de audio con AudioCraft/MusicGen. Sirve como referencia técnica para identificar las capacidades principales del sistema, mientras que otras habilidades como CLIP o Whisper se ofrecen como módulos opcionales según la necesidad.

## Datos clave
- Modelos principales: Segment Anything (SAM), AudioCraft, MusicGen.
- Habilidades opcionales disponibles: CLIP, Stable Diffusion, Whisper, LLaVA.
- Áreas de especialización: segmentación de imágenes y generación de audio.
