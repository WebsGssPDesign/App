# subway-map.md

## Resumen
Este documento define las directrices de diseño para crear diagramas de tránsito estilo mapa del metro. Sirve como referencia visual para generar mapas de viaje, flujos de procesos y explicaciones de rutas utilizando una estética limpia y jerárquica.

## Datos clave
- **Estilo**: Líneas coloreadas con ángulos de 45° y 90°, sin curvas.
- **Paleta de colores**: Rojo, azul, verde, amarillo y naranja para las líneas; fondo blanco o gris claro.
- **Elementos visuales**: Círculos para estaciones, símbolos de intercambio y jerarquía de grosor de línea.
- **Tipografía**: Sans-serif limpia con etiquetas horizontales o inclinadas.
- **Uso recomendado**: Mapas de viaje, diagramas de red y explicaciones de rutas simplificadas.
