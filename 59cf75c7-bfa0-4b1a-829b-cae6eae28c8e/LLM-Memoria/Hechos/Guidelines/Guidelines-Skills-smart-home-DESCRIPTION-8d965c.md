# DESCRIPTION.md

## Resumen
Este documento describe las habilidades necesarias para controlar dispositivos de hogares inteligentes, como luces, interruptores y sensores. Su propósito es servir como guía técnica para la implementación y gestión de sistemas de automatización residencial.

## Datos clave
- **Proyecto**: Automatización del hogar (Smart Home).
- **Tecnologías**: Dispositivos IoT, iluminación inteligente, sensores.
- **Componentes principales**: Luces, interruptores, sensores y sistemas de automatización.
