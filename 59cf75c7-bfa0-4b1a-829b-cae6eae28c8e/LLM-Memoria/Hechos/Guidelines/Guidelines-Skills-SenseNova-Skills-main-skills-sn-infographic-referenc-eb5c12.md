# frame-composition.md

## Resumen
Este documento define la técnica de composición con marco para infografías, donde elementos visuales rodean al sujeto principal para dirigir la atención hacia él. Es ideal para presentaciones formales o perfiles que requieren contexto ambiental y separación clara entre el contenido central y los bordes decorativos.

## Datos clave
- **Técnica**: Composición con marco (foreground elements, decorative borders, negative space).
- **Estructura**: El sujeto debe ubicarse en el centro o zona focal, rodeado por un marco que atraiga la mirada hacia adentro.
- **Uso recomendado**: Infografías de estilo retrato, presentaciones ceremoniales y contenido donde el contexto refuerza el mensaje.
- **Elementos visuales**: Separación clara entre marco y sujeto, contraste máximo para el tema central y etiquetas dentro del área del marco.
- **Colocación de texto**: La etiqueta del sujeto va dentro del marco; el título se coloca arriba o fuera del mismo.
- **Combinaciones sugeridas**: `aged-academia` (clásico), `crayon-hand-drawn` (dibujado a mano) y `storybook-watercolor` (marcos naturales ilustrados).
