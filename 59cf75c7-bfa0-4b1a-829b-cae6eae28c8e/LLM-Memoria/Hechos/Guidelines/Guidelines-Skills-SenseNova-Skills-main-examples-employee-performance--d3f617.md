# README.md

## Resumen
Este ejemplo demuestra el uso de la capacidad de análisis de datos de SenseNova-Skills para procesar diez hojas de cálculo de revisiones mensuales del personal. El objetivo es generar un informe visualizado que identifique tendencias generales, comparaciones por rol y empleados en mejora continua o que requieren atención.

## Datos clave
- **Proyecto**: Análisis de rendimiento de empleados (unidad de negocio de energía eólica).
- **Tecnologías**: `sn-da-excel-workflow` para lectura, limpieza y agregación de datos; `sn-md-to-html-report` para renderizado visual.
- **Entrada**: Archivo `风电事业部月度绩效考核表.zip` con 10 archivos xlsx (dic 2024 - sep 2025).
- **Salidas principales**: Informe Word (`...绩效分析报告.docx`) y paquete HTML final (`员工绩效分析-output.zip`).
- **Pasos críticos**: Descomprimir la entrada, ejecutar el flujo de análisis con instrucciones detalladas sobre capítulos y gráficos, luego convertir el resultado a HTML.
