# ultra-minimalist.md

## Resumen
Este documento define la estructura y principios del diseño "ultra-minimalista", enfocado en presentar un único elemento central sobre un fondo vacío para maximizar el impacto visual. Sirve como guía técnica para crear presentaciones de marca, revelaciones o comunicaciones premium que eliminan cualquier distracción decorativa o textual secundaria.

## Datos clave
- **Concepto**: Lienzo casi vacío con un solo elemento central (logo, palabra o icono).
- **Espaciado**: Uso extremo del espacio negativo alrededor del contenido principal.
- **Restricciones**: Sin texto de apoyo, bordes, marcos ni elementos secundarios.
- **Uso ideal**: Presentaciones de identidad de marca, declaraciones de conceptos únicos y comunicaciones de lujo.
- **Combinaciones recomendadas**: `luxury-minimal`, `gallery-like` y `knolling`.
