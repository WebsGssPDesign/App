# cyberpunk.md

## Resumen
Este archivo define una paleta de colores y elementos visuales para un estilo estético "cyberpunk" que combina alta tecnología con vida baja en entornos distópicos. Sirve como guía de diseño para crear atmósferas futuristas, narrativas tecnológicas y contenidos de videojuegos mediante el uso de neones brillantes sobre fondos oscuros y texturas urbanas desgastadas.

## Datos clave
- **Paleta de colores**: Rosa neón (#FF00FF), cian (#00FFFF), verde ácido; fondo negro profundo (#0A0A0A) y morado oscuro.
- **Elementos visuales**: Reflejos de lluvia, circuitos, patrones tecnológicos, decadencia urbana, anuncios holográficos y caracteres asiáticos opcionales.
- **Tipografía**: Texto con efecto neón brillante, fuentes digitales con glitch y letras aumentadas cibernéticamente mezclando inglés y scripts asiáticos.
- **Uso recomendado**: Conceptos futuristas, contenido de gaming, narrativas tecnológicas, temas distópicos y estética nocturna.
