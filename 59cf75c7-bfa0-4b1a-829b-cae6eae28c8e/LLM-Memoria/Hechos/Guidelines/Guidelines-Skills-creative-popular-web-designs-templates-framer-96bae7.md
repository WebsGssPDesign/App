# framer.md

## Resumen
Este documento define el sistema de diseño visual del sitio web de Framer, enfocado en una estética oscura y cinematográfica que utiliza pantallas de producto como arte principal. Sirve como guía técnica para replicar la atmósfera precisa, tipografía agresiva y paleta de colores exclusiva mediante sustituciones de fuentes CDN y reglas CSS específicas.

## Datos clave
- **Proyecto:** Guía de implementación del sistema de diseño Framer (Hermes Agent).
- **Tecnologías:** HTML, CSS, Google Fonts (Inter, Azeret Mono), generative-widgets skill.
- **Decisiones de diseño:** Canvas negro puro (`#000000`) en lugar de gris oscuro; uso exclusivo del azul Framer (`#0099ff`) como acento eléctrico.
- **Tipografía crítica:** Fuente GT Walsheim con espaciado negativo extremo (-5.5px) para titulares; Inter Variable para cuerpo con características OpenType avanzadas.
- **Comandos y pasos:** Usar `write_file` para generar HTML, servir vía `generative-widgets`, y verificar visualmente con `browser_vision`.
