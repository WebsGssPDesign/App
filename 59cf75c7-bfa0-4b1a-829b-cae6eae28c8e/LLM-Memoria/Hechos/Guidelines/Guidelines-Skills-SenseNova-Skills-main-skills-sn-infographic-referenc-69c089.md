# structural-breakdown.md

## Resumen
Este documento define las directrices para crear infografías de descomposición estructural que visualizan la composición interna de objetos, sistemas o cuerpos. Sirve como referencia técnica para diseñar diagramas explodidos o en corte transversal que clarifiquen relaciones entre componentes y capas mediante etiquetas y líneas de llamada.

## Datos clave
- **Proyecto**: SenseNova-Skills (sección de infografías).
- **Tipos de vista**: Exploded (partes separadas) y Cross-section (vista en corte).
- **Elementos visuales**: Líneas de llamada con puntos o flechas, cajas de etiquetas, límites de capas y títulos superiores.
- **Uso recomendado**: Desglose de productos, explicaciones anatómicas, componentes de sistemas y análisis de material.
- **Estilos sugeridos**: technical-schematic, aged-academia, paper-collage.
