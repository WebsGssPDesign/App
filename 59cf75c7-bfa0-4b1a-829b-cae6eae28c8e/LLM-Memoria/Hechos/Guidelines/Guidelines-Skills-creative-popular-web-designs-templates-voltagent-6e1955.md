# voltagent.md

## Resumen
Este documento define el sistema de diseño visual para VoltAgent, una plataforma de ingeniería de agentes IA con estética de terminal oscuro. Su objetivo es crear una interfaz técnica y confiable que utilice fuentes nativas y un esquema de colores específico basado en negro profundo y verde esmeralda. Sirve como guía para desarrolladores al implementar HTML autocontenido y asegurar la coherencia visual mediante paletas precisas y tipografía dual.

## Datos clave
- **Proyecto:** VoltAgent (Hermes Agent implementation).
- **Tecnologías:** `system-ui`, `JetBrains Mono`, Tailwind CSS, `generative-widgets` skill, `browser_vision`.
- **Decisiones de diseño:** Sustitución de fuentes propietarias por CDN para portabilidad; uso exclusivo del verde esmeralda (`#00d992`) como acento energético.
- **Paleta crítica:** Fondo "Abyss Black" (`#050507`), texto principal "Snow White" (`#f2f2f2`), bordes cálidos "Warm Charcoal" (`#3d3a39`).
- **Pasos de implementación:** Generar HTML con `write_file`, servir vía túnel, y verificar visualmente con visión del navegador.
