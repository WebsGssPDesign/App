# knolling.md

## Resumen
Este documento define las directrices visuales para el estilo "knolling", una técnica de fotografía de plano superior que organiza objetos en ángulos rectos y con espaciado uniforme. Sirve como referencia estándar para crear composiciones limpias, simétricas y ordenadas, ideales para mostrar colecciones de productos o inventarios de herramientas sin superposiciones.

## Datos clave
- **Concepto central**: Disposición plana (flat-lay) vista desde arriba con objetos alineados a 90°.
- **Paleta de colores**: Colores naturales del objeto sobre fondos sólidos (negro, blanco u otros), usando sombras sutiles para profundidad.
- **Tipografía**: Etiquetas limpias ubicadas fuera de los objetos, conectadas mediante líneas, estilo minimalista tipo catálogo.
- **Restricciones clave**: Prohibida la superposición de elementos; se exige simetría y orden estricto.
- **Casos de uso recomendados**: Colecciones de productos, inventarios de herramientas y vistas generales organizadas.
