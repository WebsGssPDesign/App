# periodic-table.md

## Resumen
Este documento define una estructura de cuadrícula rectangular para organizar colecciones categorizadas, como tablas periódicas o matrices de habilidades. Sirve como guía visual para diseñar referencias claras mediante celdas uniformes con colores y símbolos destacados.

## Datos clave
- **Proyecto**: Diseño de infografía "baoyu" sobre la tabla periódica.
- **Tecnologías/Estilos sugeridos**: `pop-art`, `pixel-art`, `corporate-memphis`.
- **Elementos visuales**: Celdas uniformes, leyenda de categorías, icono pequeño por celda, colores codificados.
- **Contenido textual**: Título superior, símbolo y nombre en la celda, notas al pie para casos especiales.
- **Uso recomendado**: Catálogos de herramientas, guías de referencia y matrices de competencias.
