# visual-first.md

## Resumen
Este documento define una estrategia de diseño centrada en la imagen, donde un elemento visual dominante (70-85% del lienzo) transmite el mensaje principal con texto mínimo. Su objetivo es crear infografías impactantes y atmosféricas ideales para redes sociales o carteles minimalistas que detengan el desplazamiento del usuario.

## Datos clave
- **Estructura**: Imagen central de alta calidad con 1-3 etiquetas breves; sin descripciones largas.
- **Uso recomendado**: Contenido emocional, metáforas visuales únicas y posts para redes sociales.
- **Elementos clave**: Espacio negativo limpio, fuerte metáfora visual y titular corto arriba o abajo.
- **Estilos sugeridos**: `storybook-watercolor` (escenas pintadas), `cartoon-flat` (declaraciones de imagen única) y `knolling` (diseños limpios).
