# collage-glitch.md

## Resumen
Este documento define la estética "collage-glitch", una técnica visual que combina fragmentos de imágenes o texturas con efectos de distorsión digital. Sirve como guía para crear presentaciones artísticas, contenido tecnológico disruptivo e infográficos experimentales mediante el ensamblaje de elementos visuales rotos y alterados.

## Datos clave
- **Estilo**: Fragmentos ensamblados con bordes rasgados o cortados.
- **Efectos**: Desplazamiento de píxeles, aberración cromática, líneas de escaneo y ruido superpuesto.
- **Tipografía**: Texto integrado como elemento del collage, a menudo distorsionado para impacto visual.
- **Uso ideal**: Temas digitales, marcas no convencionales y presentaciones abstractas.
- **Combinaciones recomendadas**: `neon-futurism`, `high-contrast-ad` y `paper-collage`.
