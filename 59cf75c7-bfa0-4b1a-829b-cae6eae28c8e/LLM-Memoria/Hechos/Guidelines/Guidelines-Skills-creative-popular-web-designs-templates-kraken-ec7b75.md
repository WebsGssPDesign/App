# kraken.md

## Resumen
Este documento define el sistema de diseño "Kraken" para replicar la identidad visual de un exchange criptográfico, estableciendo reglas estrictas sobre paleta de colores, tipografía y componentes. Su objetivo es guiar a agentes de desarrollo en la creación de interfaces HTML fieles al sitio original utilizando fuentes CDN y estilos específicos.

## Datos clave
- **Colores principales**: Kraken Purple (`#7132f5`), Near Black (`#101114`) y Green (`#149e61`).
- **Tipografía**: Sustitución de fuentes propietarias por `Inter` (display) y pila monoespaciada del sistema.
- **Componentes**: Botones con radio de 12px, sombras sutiles y etiquetas de éxito en verde.
- **Herramientas sugeridas**: Uso de `write_file`, `generative-widgets` y verificación con `browser_vision`.
- **Responsive**: Puntos de quiebre desde 375px hasta 1536px.
