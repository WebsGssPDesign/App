# SKILL.md

## Resumen
Esta guía describe cómo usar la herramienta CLI `nano-pdf` para editar texto, corregir errores tipográficos y modificar títulos en archivos PDF mediante instrucciones de lenguaje natural. El documento detalla los requisitos previos, el comando principal de uso y ejemplos prácticos para realizar cambios específicos en páginas seleccionadas.

## Datos clave
- **Proyecto**: nano-pdf (versión 1.0.0).
- **Tecnologías**: CLI, LLM subyacente, Python (`uv` o `pip`).
- **Comandos principales**: `uv pip install nano-pdf`, `nano-pdf edit <file.pdf> <page_number> "<instruction>"`.
- **Consideraciones importantes**: Los números de página pueden ser 0-based o 1-based; es necesario verificar la salida del PDF tras editar. La herramienta requiere una clave de API configurada.
