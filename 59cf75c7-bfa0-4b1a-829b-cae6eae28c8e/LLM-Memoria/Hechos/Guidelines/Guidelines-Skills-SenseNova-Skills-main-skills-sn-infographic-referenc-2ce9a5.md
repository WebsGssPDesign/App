# diagonal-composition.md

## Resumen
Esta guía define la composición diagonal como una técnica de diseño que alinea elementos en ejes inclinados para generar dinamismo y energía visual. Sirve como referencia práctica para aplicar esta estructura en proyectos que requieren romper la monotonía de las cuadrículas tradicionales, especialmente en temas de acción o tecnología.

## Datos clave
- **Estructura**: Eje primario desde arriba-izquierda a abajo-derecha; elementos dispuestos paralelos o perpendiculares al eje.
- **Tipografía**: Títulos alineados con la diagonal, pero el texto corporal debe mantenerse horizontal para legibilidad.
- **Elementos visuales**: Bandas diagonales de fondo, flechas reforzantes y alto contraste a lo largo del eje.
- **Pares recomendados**: `neon-futurism`, `high-contrast-ad` y `corporate-memphis`.
- **Aplicaciones ideales**: Deportes, tecnología, narrativas con flujo direccional y diseños de alto impacto.
