# resume.md

## Resumen
Este documento define una plantilla rígida para generar portafolios-resumen con un diseño editorial vertical, dividiendo la página en tres zonas fijas: portada heroica, información del perfil y navegación de servicios. Además, establece reglas estrictas para detectar el idioma predominante del usuario y mantener la coherencia lingüística en todo el contenido generado.

## Datos clave
- **Estructura fija**: Portada (título grande + retrato), Sección central (perfil, educación, experiencia) y Navegación inferior.
- **Detección de idioma**: El sistema debe identificar automáticamente si la entrada es chino, inglés, japonés o coreano para generar el output en ese mismo idioma; por defecto usa inglés.
- **Estilo visual**: Tipografía oversized, paneles geométricos redondeados, iconos decorativos manuales y silueta de hoja editorial.
- **Restricciones**: No inventar arquitecturas nuevas ni mezclar idiomas sin solicitud explícita del usuario.
