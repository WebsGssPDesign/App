# artistic.md

## Resumen
Esta guía define el "modo artístico" para crear páginas web que sean visualmente impactantes y distinguibles inmediatamente de las páginas por defecto. Su objetivo es transformar los datos en elementos visuales funcionales mediante un único motivo organizador, priorizando la legibilidad rápida y la estética contenida dentro de una sola archivo autocontenido.

## Datos clave
- **Motivo único:** Seleccionar una idea visual derivada directamente de los datos (ej. columnas fijas, contenedores llenos) antes de escribir cualquier marcado.
- **Escala plana:** Incluir al menos un elemento con 5 veces el tamaño del cuerpo para establecer jerarquía inmediata; evitar rangos entre 13px y 40px sin estructura clara.
- **Ornamento como dato:** Cada marca (líneas, puntos, arcos) debe codificar información específica; eliminar cualquier decoración sin significado.
- **Romper la cuadrícula:** Permitir que elementos se desborden al borde, usar asimetría y superposiciones para variar el ritmo visual.
- **Paleta de color:** Máximo 3 o 4 tonos con significado consistente sobre fondo off-white e tinta oscura; evitar monocromatismo por defecto.
- **Tipografía:** Contraponer una fuente de exhibición (local) con fuentes monoespaciadas para datos y etiquetas; no cargar fuentes web desde CDN.
- **Restricciones técnicas:** Archivo único, sin dependencias externas (máximo 2 componentes reescritos), seguro para impresión y bajo 200 palabras de prosa.
