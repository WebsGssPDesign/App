# luxury-layout.md

## Resumen
Este documento define la guía de diseño para layouts de lujo, estableciendo una paleta de colores dorado/negro/blanco y composiciones simétricas. Su propósito es estandarizar la creación de materiales visuales premium para marcas exclusivas y lanzamientos de alto nivel.

## Datos clave
- **Paleta:** Dorado, negro, blanco o tonos profundos tipo joya.
- **Tipografía:** Serif clásica o sans-serif elegante.
- **Estructura:** Composición centrada con espaciado generoso y decoración contenida.
- **Elementos visuales:** Acentos metálicos y texturas doradas.
- **Uso recomendado:** Comunicaciones de marcas de lujo, lanzamientos premium e invitaciones VIP.
- **Emparejamientos sugeridos:** `aged-academia`, `origami` y `knolling`.
