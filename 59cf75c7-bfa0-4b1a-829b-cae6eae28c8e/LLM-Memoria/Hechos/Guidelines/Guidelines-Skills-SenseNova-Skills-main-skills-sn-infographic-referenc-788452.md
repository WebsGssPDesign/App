# luxury-minimal.md

## Resumen
Este archivo define una guía de estilo visual para marcas de lujo que prioriza el minimalismo extremo y la elegancia. Sirve como referencia técnica para diseñadores al establecer reglas estrictas sobre paletas de color, tipografía y elementos gráficos para transmitir exclusividad.

## Datos clave
- **Estilo**: Minimalismo de alto nivel con énfasis en espacios negativos y una sola imagen focal.
- **Paleta de colores**: Negro, blanco, dorado y champán; fondos puros o profundos.
- **Tipografía**: Fuentes serif elegantes con trazos finos, espaciado amplio y texto reducido para máximo impacto.
- **Elementos visuales**: Formas geométricas, texturas sutiles (lino, grano de cuero) y líneas delgadas.
- **Aplicaciones**: Moda de alta gama, joyería, cosméticos y experiencias exclusivas.
