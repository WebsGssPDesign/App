# jigsaw.md

## Resumen
Este documento define una plantilla de diseño para infografías tipo rompecabezas, ideal para visualizar cómo se relacionan y encajan diferentes componentes de un sistema o equipo. Sirve como guía visual para ilustrar la integración estratégica, el ajuste de habilidades y la evaluación de la completitud mediante piezas interconectadas.

## Datos clave
- **Concepto central**: Piezas entrelazadas que representan componentes individuales con conexiones visibles entre ellas.
- **Casos de uso**: Relaciones entre componentes, idoneidad del equipo (skill fit), estrategias corporativas y conceptos de integración.
- **Elementos visuales**: Formas clásicas de rompecabezas, colores distintivos por pieza, bordes entrelazados visibles e iconos o etiquetas en cada fragmento.
- **Ubicación del texto**: Título superior, etiquetas dentro o al lado de las piezas y descripciones de conexiones.
- **Estilos recomendados**: `cartoon-hand-drawn` para conceptos amigables, `paper-cutout` para sensación táctil y `corporate-memphis` para estrategias empresariales.
