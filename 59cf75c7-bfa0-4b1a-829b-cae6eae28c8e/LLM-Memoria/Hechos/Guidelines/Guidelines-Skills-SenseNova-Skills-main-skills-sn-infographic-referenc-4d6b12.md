# comparison-matrix.md

## Resumen
Este documento define la estructura y mejores prácticas para crear matrices de comparación basadas en cuadrículas. Sirve como guía visual para evaluar productos, herramientas o especificaciones mediante criterios múltiples, facilitando la toma de decisiones claras a través del uso de símbolos, colores y resaltados estratégicos.

## Datos clave
- **Estructura**: Tablas con filas (ítems), columnas (criterios) y celdas (puntuaciones o verificaciones).
- **Elementos visuales**: Líneas de cuadrícula claras, marcas de verificación/cruce, codificación por colores e iconos.
- **Colocación de texto**: Título superior, nombres de ítems en la primera columna, criterios en el encabezado y valores breves en las celdas.
- **Parejas recomendadas**: `corporate-memphis` para comparaciones de herramientas empresariales, `ui-wireframe` para matrices técnicas y `technical-schematic` para especificaciones.
