# nonlinear-path.md

## Resumen
Este documento describe una estructura de diseño no lineal para infografías, donde el contenido se organiza en un camino orgánico y energético en lugar de una línea recta. Su propósito es facilitar la presentación creativa o educativa de temas complejos, ideal para audiencias jóvenes o procesos de brainstorming mediante rutas visuales irregulares.

## Datos clave
- **Estructura**: Contenido disperso conectado por una ruta serpenteante; el orden de lectura se infiere por números, flechas o señales visuales.
- **Elementos visuales**: Nodos con tamaños y orientaciones variados, conectores divertidos (líneas punteadas, huellas) y fondos coloristas.
- **Colocación de texto**: Etiquetas dentro o al lado de cada nodo; títulos en una posición ancla prominente.
- **Parejas recomendadas**: Estilos `kawaii`, `crayon-hand-drawn` y `storybook-watercolor`.
