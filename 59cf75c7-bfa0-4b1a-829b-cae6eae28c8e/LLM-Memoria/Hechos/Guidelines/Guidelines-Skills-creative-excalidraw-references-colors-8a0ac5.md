# colors.md

## Resumen
Este documento define una paleta de colores estandarizada para diagramas en Excalidraw, asegurando consistencia visual. Establece códigos hexadecimales específicos para acciones primarias, estados (éxito/error), rellenos suaves y zonas de fondo con opacidad controlada. Su objetivo es mejorar la legibilidad y el significado semántico de los diagramas técnicos.

## Datos clave
- **Colores primarios**: Azul (`#4a9eed`), Ámbar, Verde, Rojo, Púrpura, Rosa, Cian y Lima para acciones y series de datos.
- **Rellenos pastel**: Tonos claros asignados a nodos de entrada, éxito, advertencias, procesamiento, errores, notas, almacenamiento y analítica.
- **Zonas de fondo**: Azul (UI), Púrpura (Lógica/Agentes) y Verde (Datos/Herramientas) con opacidad del 30-35%.
- **Reglas de contraste**: Texto mínimo `#757575` sobre blanco; usar variantes oscuras para texto sobre rellenos claros; evitar gris claro sobre fondo blanco.
