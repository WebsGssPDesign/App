# full-illustration.md

## Resumen
Esta guía define el estilo de infografías donde una ilustración narrativa grande domina la composición, integrando el texto como anotaciones dentro de la escena. Sirve para explicar historias complejas, ecosistemas o procesos mediante imágenes detalladas que actúan como portadores principales del mensaje.

## Datos clave
- **Propósito**: Narrativa visual y explicaciones basadas en escenas (ej. funcionamiento de una ciudad).
- **Elementos visuales**: Ilustración rica y detallada, líneas de llamada (callouts) o burbujas de diálogo, personajes u objetos actuando el contenido.
- **Ubicación del texto**: Etiquetas integradas en la ilustración; título solo arriba o abajo fuera de la escena.
- **Estilos recomendados**: `storybook-watercolor` (escenas narrativas pintorescas), `cartoon-flat` (ilustraciones con personajes) y `crayon-hand-drawn` (mundos dibujados a mano).
