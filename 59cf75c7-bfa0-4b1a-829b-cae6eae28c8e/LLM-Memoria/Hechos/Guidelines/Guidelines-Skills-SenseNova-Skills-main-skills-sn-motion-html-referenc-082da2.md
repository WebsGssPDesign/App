# workflow.md

## Resumen
Este documento define un flujo de trabajo de producción estructurado para crear experiencias multimedia interactivas, asegurando coherencia visual y narrativa antes de generar activos finales costosos. Su objetivo es guiar al equipo desde la conceptualización hasta el ensamblaje del sitio web mediante hitos de aprobación estrictos.

## Datos clave
- **Proyecto**: SenseNova Skills (sn-motion-html).
- **Documentación central**: `docs/production-spec.md` para especificaciones y `content/story.json` como fuente de verdad.
- **Hitos de aprobación**: Se requieren dos aprobaciones creativas explícitas (estilo visual y plan de rodaje) antes de generar imágenes o videos pagados.
- **Generación de medios**: Preferir edición sobre referencias existentes; guardar masters sin pérdida en `assets/images/scenes/`.
- **Flujo de video**: Ejecutar pruebas secas (dry-run), extraer marcos límite para conectores y validar acceso a la API antes del pago.
- **Herramientas**: Uso de `scripts/contact_sheet.py` para validación final y carga diferida (lazy-load) de videos como Blob URLs en el frontend.
