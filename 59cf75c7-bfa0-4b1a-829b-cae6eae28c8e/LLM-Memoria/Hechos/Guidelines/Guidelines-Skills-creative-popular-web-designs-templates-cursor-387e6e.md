# cursor.md

## Resumen
Esta guía define el sistema de diseño visual del sitio web de Cursor, enfocándose en una estética minimalista cálida que imita la elegancia de un editor de código. Sirve como referencia técnica para replicar fielmente la tipografía, paleta de colores y espaciado utilizando fuentes CDN y espacios de color oklab.

## Datos clave
- **Fuentes:** `Inter` (principal), `JetBrains Mono` (monoespaciada) y referencias a `CursorGothic`, `jjannon` y `berkeleyMono`.
- **Colores principales:** Fondo crema (`#f2f1ed`) y texto negro cálido (`#26251e`).
- **Acentos:** Naranja de marca (`#f54e00`) y uso del espacio de color `oklab` para bordes orgánicos.
- **Herramientas:** Uso de `write_file`, `generative-widgets` (cloudflared) y verificación con `browser_vision`.
- **Tipografía:** Espaciado negativo agresivo en títulos (-2.16px a 72px) y alternancia de cursivas en el cuerpo.
