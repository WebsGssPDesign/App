# f-pattern.md

## Resumen
Este documento define la estructura "F-pattern" para el diseño de infografías, explicando cómo los usuarios escanean visualmente el contenido. Sirve como guía técnica para organizar jerarquías de información en diseños centrados en texto y lectura rápida.

## Datos clave
- **Proyecto**: SenseNova-Skills (layout f-pattern).
- **Estructura**: Contenido principal en una banda horizontal superior, seguido de una banda secundaria; el contenido vertical está alineado a la izquierda.
- **Mejor uso**: Infografías con mucho texto, informes estilo artículo y diseños donde la jerarquía es crítica.
- **Elementos visuales**: Banner superior fuerte con titular, columna de contenido izquierda y columna derecha para detalles complementarios.
- **Emparejamientos recomendados**: `aged-academia` (informes editoriales), `ui-wireframe` (wireframes densos) y `corporate-memphis` (reportes empresariales estructurados).
