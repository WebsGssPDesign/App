# minimalism.md

## Resumen
Este documento define una guía de estilo para el minimalismo visual en infografías y contenido gráfico. Su objetivo es eliminar elementos decorativos innecesarios para maximizar el impacto mediante la restricción y el uso estratégico del espacio negativo, asegurando que cada componente justifique su presencia.

## Datos clave
- **Paleta de colores:** Fondo blanco o off-white (#FAFAFA), predominio de negro/blanco con un solo color de acento usado escaramentamente.
- **Elementos visuales:** Un único elemento focal por composición, ausencia de bordes decorativos o texturas, uso exclusivo de formas geométricas simples si se requiere ilustración.
- **Tipografía:** Fuentes sans-serif delgadas o ligeras con grandes diferencias de tamaño entre jerarquías y espaciado amplio en encabezados.
- **Uso recomendado:** Declaraciones de marca, estadísticas clave, presentaciones de productos premium y contenido de liderazgo de pensamiento.
