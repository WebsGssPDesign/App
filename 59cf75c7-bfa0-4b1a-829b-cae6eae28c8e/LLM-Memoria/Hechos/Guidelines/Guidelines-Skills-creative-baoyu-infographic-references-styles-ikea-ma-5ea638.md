# ikea-manual.md

## Resumen
Este documento define un estilo visual de instrucciones de montaje basado en líneas mínimas y arte lineal, similar a los manuales de IKEA. Su propósito es facilitar la comunicación universal mediante dibujos simples, secuencias numeradas y símbolos universales para guías paso a paso sin depender del texto extenso.

## Datos clave
- **Estilo**: Arte lineal minimalista con trazos negros sobre fondo blanco o crema.
- **Paleta de colores**: Líneas negras, rellenos mínimos, rojo para advertencias y azul para resaltados.
- **Elementos visuales**: Dibujos simples, secuencias numeradas, indicadores de flechas, vistas desmontadas (exploded views) y figuras humanas esquemáticas para escala.
- **Tipografía**: Texto mínimo, números de pasos prominentes, símbolos universales y fuentes sans-serif simples cuando sea necesario.
- **Aplicación ideal**: Instrucciones paso a paso, guías de ensamblaje y contenido educativo universal.
