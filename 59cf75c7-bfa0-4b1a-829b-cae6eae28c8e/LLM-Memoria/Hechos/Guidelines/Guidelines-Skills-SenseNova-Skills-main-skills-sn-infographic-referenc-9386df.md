# line-drawing.md

## Resumen
Este documento establece las directrices para crear ilustraciones basadas exclusivamente en líneas de contorno puro, sin rellenos ni gradientes. Su objetivo es guiar el diseño hacia una estética elegante y minimalista que reduce la forma a sus elementos esenciales mediante trazos precisos y deliberados.

## Datos clave
- **Estilo visual**: Líneas continuas con variación de grosor para dar profundidad; uso de hachuras y espacio negativo.
- **Paleta de colores**: Primario en negro o tinta única sobre fondo blanco/crema; acentos opcionales con un segundo color.
- **Tipografía**: Serif o letra manuscrita; caracteres con contorno que integran el estilo de línea.
- **Casos de uso ideales**: Ilustraciones editoriales, diagramas botánicos y científicos, bocetos arquitectónicos, arte de líneas para productos y guías educativas minimalistas.
