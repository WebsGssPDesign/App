# SKILL.md

## Resumen
Este documento define el flujo de trabajo para crear arte generativo y visualizaciones interactivas utilizando p5.js, priorizando la calidad estética inicial sobre la mera funcionalidad. Su objetivo es guiar al desarrollador desde la conceptualización creativa hasta la exportación final en formatos como HTML, video o vectores, asegurando que cada pieza sea visualmente impactante y cohesiva.

## Datos clave
- **Proyecto**: Pipeline de producción para arte creativo en p5.js.
- **Tecnologías**: p5.js 1.11.3 (CDN), p5.sound.js, CCapture.js, Puppeteer + Node.js, ffmpeg.
- **Decisiones**: Se prefiere la versión 1.x por estabilidad; se exige un archivo HTML único sin pasos de compilación.
- **Rutas**: `references/visual-effects.md`, `references/interaction.md`, `references/webgl-and-3d.md`.
- **Pasos del pipeline**: CONCEPT → DESIGN → CODE → PREVIEW → EXPORT → VERIFY.
