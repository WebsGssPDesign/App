# DESCRIPTION.md

## Resumen
Este documento describe las habilidades necesarias para generar y orquestar agentes de IA autónomos dedicados a la codificación. Su propósito es facilitar la ejecución de procesos independientes, la delegación de tareas específicas y la coordinación eficiente de múltiples flujos de trabajo paralelos.

## Datos clave
- **Proyecto**: Gestión de agentes de IA autónomos para desarrollo de código.
- **Tecnologías**: Flujos de trabajo multi-agente (multi-agent workflows).
- **Decisiones**: Implementación de orquestación para coordinar tareas simultáneas.
- **Pasos importantes**: Despliegue de procesos independientes y delegación estratégica de responsabilidades entre agentes.
