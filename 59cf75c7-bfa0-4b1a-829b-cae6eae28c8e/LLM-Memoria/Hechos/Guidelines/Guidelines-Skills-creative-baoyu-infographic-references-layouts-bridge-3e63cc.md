# bridge.md

## Resumen
Este documento define la estructura y el propósito de un diagrama tipo "puente" para visualizar el tránsito desde un estado actual o problema hacia una solución deseada. Sirve como guía visual para representar desafíos, obstáculos y los pasos metodológicos necesarios para lograr una transformación estratégica.

## Datos clave
- **Concepto central**: Estructura que conecta un lado izquierdo (estado actual/problema) con un lado derecho (solución/futuro).
- **Elementos visuales**: Dos plataformas distintas separadas por un vacío visible, soportes de puente y piedras o tablas escalonadas.
- **Ubicación del texto**: Título superior, etiquetas laterales ("From"/"To") y descripción del hueco debajo.
- **Casos de uso ideales**: Análisis de brechas (gap analysis), viajes problema-solución e iniciativas estratégicas.
- **Estilos recomendados**: `cartoon-hand-drawn` para viajes amigables, `corporate-memphis` para transformaciones empresariales y `isometric-3d` para transiciones técnicas.
