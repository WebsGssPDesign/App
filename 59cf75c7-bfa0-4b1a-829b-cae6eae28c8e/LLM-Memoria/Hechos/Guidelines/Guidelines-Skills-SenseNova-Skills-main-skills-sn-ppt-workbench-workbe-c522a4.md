# page_003.query.txt

## Resumen
Este archivo define las especificaciones de diseño para una diapositiva PPT sobre los cuatro escenarios principales de OpenClaw. Su objetivo es guiar la creación visual mediante instrucciones detalladas de estilo, tipografía y disposición del contenido en un formato de cuadrícula 2x2.

## Datos clave
- **Proyecto**: Presentación de OpenClaw (SenseNova).
- **Tecnologías**: CSS puro para decoración e iconos (sin imágenes), fuentes Inter, Noto Sans SC, Roboto.
- **Decisiones de diseño**: Paleta oscura con acentos en azul cielo (#2196F3) y cian; uso de símbolos Unicode (💬, 🔍, 📄, 📊) para representar servicios.
- **Contenido**: Cuatro tarjetas para "Servicio al cliente", "Revisión de código", "Generación de documentos" y "Análisis de datos".
- **Información adicional**: Etiqueta inferior indicando industrias aplicables (Finanzas, Salud, E-commerce).
