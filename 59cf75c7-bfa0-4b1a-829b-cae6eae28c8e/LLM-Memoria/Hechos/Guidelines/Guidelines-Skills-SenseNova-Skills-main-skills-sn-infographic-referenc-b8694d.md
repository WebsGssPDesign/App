# tile-layout.md

## Resumen
Este documento define una estructura de diseño basada en "tiles" (baldosas) estilo Metro, compuesta por bloques rectangulares de colores sólidos con iconos y etiquetas. Su propósito es organizar la navegación de aplicaciones, índices temáticos o paneles de control mediante un sistema visual claro y categorizado.

## Datos clave
- **Estructura**: Cuadrícula de baldosas en tamaños variables (1×1, 2×1 o 2×2).
- **Elementos visuales**: Fondos de color sólido, iconos grandes centrados y bordes con radio consistente.
- **Tipografía**: Etiqueta principal dentro del bloque, subtítulo opcional debajo y título de sección encima de los grupos.
- **Casos de uso ideales**: Navegación general, índices por categoría o sistemas de clasificación por color.
- **Combinaciones recomendadas**: `corporate-memphis`, `high-contrast-ad` y `pixel-art`.
