# overlapping.md

## Resumen
Esta guía define la técnica de superposición en diseño visual, donde elementos se apilan para crear profundidad y complejidad. Sirve como referencia para diseñar composiciones editoriales ricas o collage que muestren interconexiones, asegurando siempre la legibilidad del texto crítico mediante un orden de capas claro.

## Datos clave
- **Técnica**: Superposición intencional con opacidad y sombras para generar profundidad (z-order).
- **Uso ideal**: Diseños editoriales estratificados, composiciones tipo collage y presentaciones artísticas complejas.
- **Elementos visuales**: Máscaras de recorte, modos de fusión y jerarquías de capas definidas.
- **Ubicación del texto**: Colocar títulos en zonas no superpuestas y evitar textos críticos bajo elementos opacos.
- **Estilos recomendados**: `glitch-art`, `storybook-watercolor` y `high-contrast-ad`.
