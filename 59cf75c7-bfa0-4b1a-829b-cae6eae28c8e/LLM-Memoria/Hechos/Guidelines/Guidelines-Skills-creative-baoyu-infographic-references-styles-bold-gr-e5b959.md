# bold-graphic.md

## Resumen
Este documento define una paleta de colores y elementos visuales para un estilo gráfico de cómic de alto contraste. Sirve como guía técnica para crear diseños impactantes con líneas gruesas, sombreados dramáticos y tipografía expresiva, ideales para narrativas intensivas o marketing.

## Datos clave
- **Estilos**: Graphic-novel (narrativa dramática) y Pop-art (alto impacto energético).
- **Colores**: Primarios fuertes (rojo, amarillo, azul, negro), fondos blancos con patrones halftone y sombras dramáticas.
- **Elementos visuales**: Contornos negros gruesos, líneas de acción, viñetas opcionales, globos de diálogo y efectos sonoros (POW/BANG).
- **Tipografía**: Letra estilo cómic, fuentes de impacto para énfasis y cajas de texto narrativo.
- **Uso recomendado**: Contenido que requiere atención inmediata, historias dramáticas, cultura pop y presentaciones de alta energía.
