# iceberg.md

## Resumen
Esta guía define la estructura y aplicación del concepto de "iceberg" para visualizar la diferencia entre factores superficiales y causas ocultas. Sirve como referencia técnica para diseñar infografías que contrasten elementos visibles con aquellos subyacentes, utilizando proporciones y texturas acuáticas para enfatizar la profundidad de los problemas no aparentes.

## Datos clave
- **Concepto central**: Metáfora del iceberg (parte visible vs masa oculta).
- **Aplicaciones ideales**: Comparar síntomas versus causas raíz, trabajo público frente a privado, o lo conocido contra lo desconocido.
- **Elementos visuales**: Línea de agua clara, degradado de profundidad, textura de olas y proporción mayor para la sección sumergida (más grande y oscura).
- **Colaboraciones sugeridas**: Estilo `cartoon-hand-drawn` para un tono amigable, `storybook-watercolor` para arte profundo o `graphic-novel` para revelaciones dramáticas.
