# SKILL.md

## Resumen
Esta guía define una habilidad para crear prototipos de interfaz desechables mediante HTML y CSS, permitiendo explorar 2-3 variantes de diseño distintas antes de comprometerse con una solución final. Su objetivo es facilitar la comparación visual rápida de diferentes direcciones de UI/UX sin generar código de producción.

## Datos clave
- **Proyecto**: Skill `sketch` del sistema GSD (Get-Shit-Done).
- **Tecnologías**: HTML5, CSS inline, Tailwind vía CDN, fuentes del sistema o Google Fonts.
- **Flujo principal**: Intake (sentimiento, referencias, acción clave) → Generación de 2-3 variantes → Verificación visual con herramientas de navegador → Comparativa head-to-head.
- **Estructura de archivos**: Carpetas por variante (ej. `001-calm-editorial/`) conteniendo `index.html` y `README.md`.
- **Reglas de diseño**: Las variantes deben diferir en ejes como densidad, énfasis o estética; nunca solo en color. Deben incluir interactividad básica (hover, toggles).
- **Comandos sugeridos**: `browser_navigate`, `browser_vision` para validar renders visuales y detectar errores de layout.
