# dark-mode.md

## Resumen
Esta guía establece las reglas para crear diagramas con tema oscuro en Excalidraw, asegurando la legibilidad mediante un fondo base específico y paletas de colores contrastantes. Sirve como referencia técnica para diseñadores que necesitan mantener consistencia visual en entornos oscuros sin perder claridad en textos o elementos gráficos.

## Datos clave
- **Fondo obligatorio**: Rectángulo negro (`#1e1e2e`) con coordenadas extremas (-4000, -3000) y dimensiones 10000x7500 como primer elemento del array JSON.
- **Paleta de rellenos**: Azul oscuro (`#1e3a5f`), Verde oscuro (`#1a4d2e`), Púrpura oscuro (`#2d1b69`), Naranja oscuro (`#5c3d1a`), Rojo oscuro (`#5c1a1a`) y Turquesa oscuro (`#1a4d4d`).
- **Texto crítico**: Usar blanco (`#e5e5e5`) para títulos; evitar colores oscuros como `#555`. Para texto independiente, establecer explícitamente `strokeColor: "#e5e5e5"`.
- **Bordes y flechas**: Utilizar colores primarios brillantes (Azul `#4a9eed`, Ámbar `#f59e0b`, Verde `#22c55e`, Rojo `#ef4444`, Púrpura `#8b5cf6`) o gris medio (`#555555`) para contornos.
- **Estructura JSON**: Emplear `boundElements` en lugar de la propiedad `"label"` para vincular texto a formas.
