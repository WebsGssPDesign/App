# README.md

## Resumen
Este archivo define una línea de producción para crear arte visual interactivo y generativo utilizando la librería p5.js a partir de prompts textuales. El sistema genera código completo que produce archivos HTML autocontenidos listos para ejecutar en cualquier navegador sin necesidad de compilación ni servidores complejos.

## Datos clave
- **Proyecto**: Pipeline de arte generativo con p5.js.
- **Modos de operación**: Arte generativo, visualización de datos, experiencias interactivas, motion graphics, escenas 3D y procesamiento de audio/imagen.
- **Formatos de exportación**: HTML (autocontenido), PNG (`saveCanvas`), GIF (`saveGif`) y MP4 (vía `scripts/render.sh`).
- **Requisitos técnicos**: Navegador moderno; para exportación headless se requieren Node.js, Puppeteer y ffmpeg.
- **Estructura de archivos**: Incluye documentación técnica en `references/` (API, geometría, shaders) y scripts de utilidad como `setup.sh`, `serve.sh` y `render.sh`.
