# DESCRIPTION.md

## Resumen
Este documento describe las habilidades necesarias para gestionar correos electrónicos desde la línea de comandos, cubriendo funciones como enviar, recibir, buscar y organizar mensajes sin necesidad de una interfaz gráfica. Sirve como guía técnica para usuarios que buscan automatizar o optimizar su flujo de trabajo de correo mediante herramientas de terminal.

## Datos clave
- **Proyecto**: Gestión de correo desde la terminal (CLI).
- **Habilidades principales**: Enviar, recibir, buscar y gestionar correos electrónicos.
- **Enfoque**: Automatización y eficiencia operativa sin interfaz gráfica.
