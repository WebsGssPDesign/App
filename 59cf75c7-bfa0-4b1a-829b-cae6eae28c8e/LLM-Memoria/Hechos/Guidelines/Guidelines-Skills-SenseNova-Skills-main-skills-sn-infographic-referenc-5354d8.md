# heading-subheading.md

## Resumen
Este documento define una jerarquía visual basada en tipografía para infografías y diseños editoriales, eliminando la necesidad de cuadrículas rígidas. Su función es guiar el uso de contrastes en tamaño y peso entre títulos principales, subtítulos y cuerpo del texto para destacar mensajes clave.

## Datos clave
- **Estructura**: Título principal grande seguido de un subtítulo más pequeño y luego el contenido.
- **Tecnologías/Estilos**: `aged-academia` (editorial), `high-contrast-ad`, `ikea-manual`.
- **Decisiones de diseño**: Uso de contraste dramático en tamaño y variación de peso (negrita vs regular).
- **Elementos visuales**: Reglas decorativas opcionales entre niveles; imágenes mínimas.
- **Jerarquía tipográfica**: H1 (más grande/prominente), H2 (contexto secundario), Cuerpo (detalle más pequeño).
