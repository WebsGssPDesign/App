# s-curve.md

## Resumen
Esta guía define el diseño de una estructura visual en forma de "S" para organizar nodos de contenido, ideal para narrativas o procesos complejos que requieren un ritmo fluido. Su función es guiar la mirada del usuario a través de una trayectoria curva suave, alternando la posición izquierda-derecha para crear dinamismo visual superior a las líneas rectas tradicionales.

## Datos clave
- **Estructura**: Nodos dispuestos en doble curva suave de arriba hacia abajo con alternancia lateral.
- **Elementos visuales**: Uso de curvas Bézier y cintas conectores; opcionalmente decoraciones a lo largo del camino.
- **Ubicación de texto**: Títulos en la parte superior, conclusiones en la inferior y etiquetas junto a cada nodo.
- **Pares recomendados**: `storybook-watercolor`, `crayon-hand-drawn` y `corporate-memphis`.
