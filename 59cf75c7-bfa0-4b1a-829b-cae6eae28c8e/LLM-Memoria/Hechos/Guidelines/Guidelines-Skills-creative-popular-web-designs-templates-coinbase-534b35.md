# coinbase.md

## Resumen
Este documento detalla el sistema de diseño oficial de Coinbase, proporcionando una guía técnica para replicar su interfaz limpia y confiable en entornos web. Sirve como referencia esencial para agentes de desarrollo o diseñadores que necesitan implementar componentes visuales precisos utilizando fuentes alternativas y una paleta de colores específica cuando no se dispone de los activos propietarios originales.

## Datos clave
- **Fuentes:** Sustitución de `CoinbaseDisplay`, `CoinbaseSans` y `CoinbaseText` por `DM Sans` (CDN) y pila monoespaciada del sistema.
- **Paleta de colores:** Azul marca (`#0052ff`), fondo oscuro (`#0a0b0d`) y gris secundario (`#eef0f3`).
- **Botones:** Radio de 56px para CTA, con transición a `#578bfa` en hover.
- **Tipografía:** Línea base ajustada (1.00) para titulares heroicos; jerarquía definida por tamaños y pesos específicos.
- **Herramientas sugeridas:** Uso de `write_file`, `generative-widgets` y verificación con `browser_vision`.
