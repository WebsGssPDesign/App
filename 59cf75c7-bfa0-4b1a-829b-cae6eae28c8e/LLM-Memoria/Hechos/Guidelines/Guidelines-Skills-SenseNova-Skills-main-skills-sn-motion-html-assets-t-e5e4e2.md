# style-motion.txt

## Resumen
Este archivo define las directrices técnicas para el renderizado de movimiento, la conducta de la cámara y la coherencia temporal dentro del proyecto SenseNova. Su función es establecer reglas estrictas para evitar artefactos visuales no deseados y garantizar una consistencia estilística en la generación de contenido animado.

## Datos clave
- **Proyecto**: SenseNova (Skills)
- **Tecnologías/Contexto**: Generación de video o animación con estilo visual específico
- **Reglas definidas**: Comportamiento de cámara, coherencia temporal y prohibición de artefactos visuales
- **Propósito**: Establecer un estándar de calidad para el renderizado de movimiento
