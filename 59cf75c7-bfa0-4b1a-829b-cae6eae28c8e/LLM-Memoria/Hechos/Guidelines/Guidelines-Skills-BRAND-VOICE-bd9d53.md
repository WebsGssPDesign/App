# BRAND-VOICE.md

## Resumen
Este documento establece las directrices para definir la voz y el tono de comunicación de una marca. Su objetivo es asegurar que todos los mensajes transmitan confianza y estilo de vida, evitando tácticas agresivas como la escasez o los descuentos no autorizados. Sirve como manual operativo para redactores y creadores de contenido al proporcionar reglas claras, patrones a evitar y una plantilla estandarizada para publicaciones.

## Datos clave
- **Frase norte**: Define la emoción central que vende la marca en una sola oración.
- **Jerarquía de contenido**: Prioriza emoción → estilo de vida → historia → prueba; las especificaciones técnicas nunca deben ser protagonistas.
- **Restricciones**: Prohibido usar FOMO, escasez o descuentos como palancas principales (salvo campañas autorizadas). Evitar adjetivos vacíos y títulos centrados en specs.
- **Plantilla de publicación**: Estructura fija que incluye una línea de emoción, mención del producto (si aplica), el dominio web y 2–3 hashtags de marca.
- **Registro**: Se debe definir explícitamente si el tono es tú/usted y cercano/formal, así como el idioma (ES/EN).
