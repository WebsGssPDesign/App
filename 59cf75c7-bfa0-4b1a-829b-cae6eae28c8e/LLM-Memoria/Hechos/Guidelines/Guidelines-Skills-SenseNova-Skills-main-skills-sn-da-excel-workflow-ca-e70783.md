# SKILL.md

## Resumen
Este documento describe una habilidad técnica para analizar datos de series temporales y categorías en Excel mediante Python. Su objetivo es limpiar datos, modelar tendencias, predecir valores futuros basándose en niveles de rendimiento y generar informes visuales detallados para la toma de decisiones empresariales.

## Datos clave
- **Proyecto**: Análisis de datos de negocio (KPIs) y predicción de tendencias.
- **Tecnologías**: Python, Pandas, NumPy, Matplotlib, Seaborn.
- **Decisiones**: Implementación de un algoritmo de clasificación multinivel (Top 30% alto, medio 40%, bajo 30%) para asignar tasas de crecimiento diferenciadas.
- **Pasos importantes**:
    1. Configuración de fuentes de caracteres chinos (`SimHei`) para visualización correcta.
    2. Limpieza de columnas con formato de porcentaje y cálculo de diferencias temporales.
    3. Agrupamiento por categoría, ordenamiento y asignación de etiquetas ('Alto', 'Medio', 'Bajo').
    4. Generación de cuatro gráficos: área apilada (tendencia), barras comparativas (actual vs predicción), distribución de crecimiento y análisis de volumen.
    5. Cálculo de métricas globales (crecimiento total) y emisión de conclusiones estratégicas.
