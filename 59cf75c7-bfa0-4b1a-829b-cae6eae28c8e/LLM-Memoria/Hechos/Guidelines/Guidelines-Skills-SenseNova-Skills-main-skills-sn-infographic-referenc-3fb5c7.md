# edge-tension.md

## Resumen
Esta guía define la técnica de composición "edge-tension", donde el sujeto principal se recorta parcialmente en los bordes del lienzo para generar dinamismo y continuidad implícita. Su objetivo es crear layouts editoriales impactantes, ideales para presentaciones de productos o formatos sociales que requieren atención inmediata mediante una asimétrica fuerte.

## Datos clave
- **Concepto**: Sujeto extendido más allá del marco con recortes intencionales (cabeza, extremidad u objeto).
- **Energía visual**: Dirección fuerte hacia el borde cortado; espacio opuesto reservado para texto o elementos de apoyo.
- **Ubicación de texto**: Títulos y cuerpo en el área abierta lejos del sujeto; etiquetas cerca de la porción visible.
- **Evitar**: Colocar texto sobre las áreas recortadas.
- **Emparejamientos recomendados**: `high-contrast-ad`, `claymation` y `corporate-memphis`.
