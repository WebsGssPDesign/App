# superhuman.md

## Resumen
Este documento define el sistema de diseño "Superhuman", estableciendo una estética minimalista y lujosa basada en fondos blancos, tipografía variable personalizada y un único acento morado. Su propósito es guiar la implementación de réplicas del sitio web utilizando fuentes CDN como sustitutos y herramientas específicas para generar y verificar visualmente el código HTML.

## Datos clave
- **Proyecto:** Design System Superhuman (Hermes Agent).
- **Tecnologías:** `write_file`, `generative-widgets` (cloudflared tunnel), `browser_vision`.
- **Decisiones de fuentes:** Sustitución de "Super Sans VF" por `Inter` y `JetBrains Mono` vía CDN para mantener el diseño autocontenido.
- **Paleta de colores crítica:** Morado Mysteria (`#1b1938`), Lavender Glow (`#cbb7fb`) como único acento, Crema Cálido (`#e9e5dd`) para botones y Negro Carbón (`#292827`) para texto.
- **Reglas tipográficas:** Altura de línea ultra-compacta (0.96) en títulos y uso exclusivo de radios de 8px y 16px.
