# README_CN.md

## Resumen
Este documento describe un ejemplo de uso del framework SenseNova-Skills para analizar datos de desempeño laboral extraídos de hojas de cálculo. Su objetivo es transformar diez archivos Excel mensuales en informes visuales detallados que identifiquen tendencias, comparaciones por puesto y necesidades de mejora en el personal.

## Datos clave
- **Proyecto**: Análisis de desempeño del departamento eólico (2024-2025).
- **Tecnologías**: `sn-da-excel-workflow` (análisis de datos), `sn-md-to-html-report` (renderizado visual).
- **Entradas**: Carpeta con 10 archivos `.xlsx` desensibilizados.
- **Salidas**: Informe `.docx` estructurado y reporte `.html` interactivo con 8 gráficos PNG.
- **Pasos críticos**: Descomprimir el archivo ZIP, solicitar análisis por niveles (mes, puesto, empleado) e incluir interpretación de datos; luego convertir el Markdown generado a HTML para visualización web.
