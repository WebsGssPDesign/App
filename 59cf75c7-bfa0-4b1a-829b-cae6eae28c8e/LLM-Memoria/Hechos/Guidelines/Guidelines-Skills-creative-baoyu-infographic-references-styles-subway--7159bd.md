# subway-map.md

## Resumen
Este documento define una guía de estilo para crear diagramas de mapas de metro utilizando líneas coloreadas y estaciones simplificadas. Sirve como referencia visual para diseñar flujos de procesos, mapas de viaje o explicaciones de redes que requieran claridad y jerarquía en la información.

## Datos clave
- **Proyecto:** Estilo visual "subway-map" (mapa de metro).
- **Paleta de colores:** Líneas primarias en rojo, azul, verde, amarillo y naranja; fondo blanco o gris claro.
- **Elementos visuales:** Rutas con ángulos de 45° y 90°, círculos para estaciones, símbolos de intercambio y geografía simplificada.
- **Tipografía:** Sans-serif limpia para nombres de estaciones y etiquetas de líneas (horizontales o inclinadas).
- **Uso recomendado:** Mapas de trayecto, diagramas de flujo de procesos y explicaciones de rutas.
