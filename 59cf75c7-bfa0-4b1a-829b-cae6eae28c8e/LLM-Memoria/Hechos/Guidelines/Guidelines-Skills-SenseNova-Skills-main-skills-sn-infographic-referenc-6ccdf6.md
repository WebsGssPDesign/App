# structured-content-template.md

## Resumen
Este documento define una plantilla de Markdown para transformar material fuente en contenido estructurado listo para el diseño gráfico. Su función es organizar objetivos de aprendizaje y datos verbatim, separando explícitamente la información del contenido de las instrucciones visuales para los diseñadores.

## Datos clave
- **Proyecto**: Generación de infografías educativas (SenseNova).
- **Tecnologías**: Markdown como formato único de salida.
- **Decisiones críticas**: Todo el texto destinado a etiquetas en imágenes debe listarse explícitamente; se prohíbe la parafraseo o adición de información nueva.
- **Pasos del proceso**: 1) Esquema general (título, visión), 2) Desarrollo de secciones (concepto clave, contenido verbatim, elemento visual, etiquetas de texto), 3) Verificación de integridad de datos.
- **Tipos de secciones**: Procesos paso a paso, comparaciones, jerarquías y datos estadísticos.
