# README.md

## Resumen
Este documento describe un ejemplo de uso de la capacidad de generación de presentaciones (PPT) del sistema SenseNova-Skills. Permite crear una presentación lista para abrir directamente desde un único prompt, sin necesidad de archivos de entrada previos, automatizando todo el proceso de diseño y renderizado.

## Datos clave
- **Herramientas**: `sn-ppt-entry` (despacho inicial) y `sn-ppt-standard` (generación estándar).
- **Flujo de trabajo**: El agente genera un esquema, planifica activos, crea HTML por página y compila el PPTX mediante capturas de pantalla.
- **Entrada**: Un prompt único que define tema, número de páginas, paleta de colores, estilo y audiencia.
- **Salidas principales**: Archivo `.pptx` final y archivo `.zip` con fuentes HTML individuales para edición posterior.
- **Artifacts intermedios**: `outline.json`, `asset_plan.json`, `style_spec.json`, entre otros.
