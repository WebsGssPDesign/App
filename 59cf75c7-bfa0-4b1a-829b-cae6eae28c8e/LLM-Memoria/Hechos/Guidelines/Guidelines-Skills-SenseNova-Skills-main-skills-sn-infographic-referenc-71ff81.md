# disrupted-flow.md

## Resumen
Este documento define la técnica de "disrupted-flow" para diseños gráficos, donde el texto y los elementos se orientan verticalmente o invertidamente para romper el orden de lectura convencional. Su objetivo es forzar una participación activa del espectador, ideal para contenidos sobre innovación, cambio o presentaciones artísticas que desafíen el pensamiento tradicional mediante composiciones visuales no lineales.

## Datos clave
- **Concepto principal**: Mezcla de texto horizontal, vertical e invertido para alterar la jerarquía visual.
- **Uso recomendado**: Contenido creativo, experimental y temas relacionados con la disrupción o innovación.
- **Elementos visuales**: Colocación inesperada de elementos, señales visuales que guían un camino de lectura no lineal y alto contraste.
- **Posicionamiento estratégico**: El mensaje clave debe ubicarse en la posición más disruptiva, mientras el texto secundario varía su orientación.
- **Combinaciones sugeridas**: `high-contrast-ad`, `neon-futurism` (estilo glitch) y `pixel-art`.
