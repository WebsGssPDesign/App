# ui-wireframe.md

## Resumen
Este documento define un estilo de interfaz en escala de grises para maquetas de alambre (wireframes), ideal para explicar conceptos de diseño y flujos de usuario sin distracciones visuales. Sirve como guía técnica para mantener la consistencia en elementos gráficos, tipografía y paleta de colores durante el desarrollo de prototipos.

## Datos clave
- **Paleta de colores**: Gris claro (#E5E5E5), gris medio (#9CA3AF), carbón oscuro (#374151), blanco (#FFFFFF) y azul interactivo (#3B82F6).
- **Elementos visuales**: Uso de cajas de alambre, marcadores "X" para imágenes, iconos de línea simple y llamadas a la acción con anotaciones.
- **Tipografía**: Fuentes del sistema con texto relleno tipo "Lorem ipsum" y estilo sans-serif generalizado.
- **Aplicación**: Diseños de productos, explicaciones de interfaces, conceptos de aplicaciones y diagramas de flujo de usuario.
