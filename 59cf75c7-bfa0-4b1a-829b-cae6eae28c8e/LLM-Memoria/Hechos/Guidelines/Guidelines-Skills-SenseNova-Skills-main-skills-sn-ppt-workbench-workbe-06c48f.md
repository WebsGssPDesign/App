# page_001.query.txt

## Resumen
Este documento define las especificaciones de diseño para una diapositiva de portada en PowerPoint sobre la plataforma OpenClaw. Su objetivo es presentar el producto como un agente de IA inteligente con un estilo visual oscuro y tecnológico, utilizando CSS puro para generar gráficos e iconos sin imágenes externas.

## Datos clave
- **Proyecto**: Presentación de productos (OpenClaw).
- **Tecnologías**: PowerPoint, CSS (para iconos y efectos), fuentes Inter y Noto Sans SC.
- **Decisiones de diseño**: Paleta de colores azul cielo (#2196F3) y cian (#00BCD4); enfoque en tipografía y efectos visuales generados por código debido a la falta de assets gráficos.
- **Contenido principal**: Título "OpenClaw 产品介绍", subtítulo "智能AI代理平台" y tres módulos clave: toma de decisiones autónoma, fusión de modelos múltiples y despliegue empresarial.
