# resend.md

## Resumen
Este documento define el sistema de diseño visual para la plataforma Resend, orientado a crear una experiencia cinematográfica y premium mediante un esquema oscuro. Su función es estandarizar tipografías, paletas de colores y elementos de interfaz para garantizar consistencia en el desarrollo web.

## Datos clave
- **Tipografía:** Sustitución de fuentes propietarias por Geist (principal) y Geist Mono; jerarquía con Domaine Display, ABC Favorit e Inter.
- **Estilo visual:** Fondo negro puro (#000000), texto blanco cercano (#f0f0f0) y bordes icónicos azules helados (`rgba(214, 235, 253, 0.19)`).
- **Paleta de acentos:** Escalas definidas para naranja, verde, azul, amarillo y rojo con variables CSS específicas (ej. `--color-orange-10`).
- **Componentes:** Botones en forma de píldora (radio 9999px), sombras sutiles azules y uso de conjuntos estilísticos OpenType (`ss01`, `ss03`).
- **Implementación:** Uso de CDN para fuentes, generación de HTML vía `write_file` y verificación visual con `browser_vision`.
