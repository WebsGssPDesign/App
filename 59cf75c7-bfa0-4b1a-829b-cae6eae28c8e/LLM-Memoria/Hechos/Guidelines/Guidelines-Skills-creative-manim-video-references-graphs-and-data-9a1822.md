# graphs-and-data.md

## Resumen
Este documento es una guía técnica para crear visualizaciones matemáticas y de datos animadas usando la biblioteca Manim. Explica cómo configurar ejes, graficar funciones dinámicas, generar diagramas de barras y representar conceptos abstractos como campos vectoriales o planos complejos mediante código Python.

## Datos clave
- **Tecnologías**: Manim (Python), NumPy para cálculos matemáticos.
- **Conceptos principales**: `Axes`, `BarChart`, `Graph`/`DiGraph`, `ArrowVectorField`, `StreamLines`.
- **Patrones de animación**: Uso de `ValueTracker` y `always_redraw` para parámetros dinámicos; `LaggedStart` para algoritmos paso a paso.
- **Algoritmos de layout**: `"spring"`, `"circular"`, `"kamada_kawai"`, `"planar"`.
- **Funciones matemáticas específicas**: Transformación de planos complejos (`apply_complex_function`) y representación de campos vectoriales.
