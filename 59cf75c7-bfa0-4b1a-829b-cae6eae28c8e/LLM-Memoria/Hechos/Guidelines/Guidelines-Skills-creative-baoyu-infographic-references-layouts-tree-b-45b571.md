# tree-branching.md

## Resumen
Este documento define una estructura jerárquia que se ramifica desde un nodo raíz hasta nodos terminales, diseñada para visualizar categorías y subcategorías. Es útil para representar taxonomías, árboles de decisión, organigramas y estructuras de archivos mediante relaciones padre-hijo claras.

## Datos clave
- **Concepto**: Estructura jerárquica con raíz (tronco) superior o izquierda y hojas como nodos finales.
- **Elementos visuales**: Líneas conectivas, nodos en puntos de ramificación, iconos/etiquetas y codificación por color.
- **Ubicación del texto**: Título arriba, concepto raíz destacado, etiquetas en ramas/hojas y leyenda opcional.
- **Estilos recomendados**: `cartoon-hand-drawn` (taxonomías amigables), `da-vinci-notebook` (clasificaciones científicas) y `origami` (estructuras geométricas).
