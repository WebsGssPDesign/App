# dashboard.md

## Resumen
Este documento define las pautas para diseñar paneles de control (dashboards) que muestran múltiples métricas, gráficos e indicadores clave de rendimiento. Su objetivo es facilitar la visualización clara de datos analíticos y estados operativos mediante una estructura modular y jerárquica.

## Datos clave
- **Propósito**: Resúmenes de KPIs, informes de estado y análisis de rendimiento.
- **Estructura**: Uso de widgets modulares en cuadrícula con indicadores de estado prominentes.
- **Elementos visuales**: Gráficos (barras, líneas, pasteles), números grandes para métricas, flechas de tendencia y codificación por colores (verde/rojo).
- **Tipografía**: Títulos superiores, etiquetas claras de unidades y períodos de tiempo definidos.
- **Estilos recomendados**: `corporate-memphis` (negocios), `ui-wireframe` (técnico) y `cyberpunk-neon` (futurista).
