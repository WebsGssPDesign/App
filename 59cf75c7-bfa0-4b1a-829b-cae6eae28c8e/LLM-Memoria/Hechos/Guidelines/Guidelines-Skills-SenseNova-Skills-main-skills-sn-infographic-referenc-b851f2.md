# venn-diagram.md

## Resumen
Este documento define la estructura y mejores prácticas para crear diagramas de Venn, utilizados para visualizar relaciones entre conceptos o habilidades. Sirve como guía técnica para diseñar gráficos que muestren áreas comunes y exclusivas mediante círculos superpuestos con etiquetas claras e iconos.

## Datos clave
- **Estructura**: 2 a 3 círculos superpuestos donde el centro representa lo común a todos y las zonas externas son exclusivas.
- **Casos de uso**: Análisis de habilidades, segmentos de mercado y comparativas conceptuales.
- **Elementos visuales**: Relleno translúcido, colores distintos por círculo, iconos en regiones y etiquetas en los bordes.
- **Estilos recomendados**: `crayon-hand-drawn` para conceptos amigables, `corporate-memphis` para análisis de negocio y `high-contrast-ad` para comparaciones de alto contraste.
