# crayon-hand-drawn.md

## Resumen
Este archivo define una guía de estilo visual basada en texturas dibujadas a mano con crayón. Su propósito es establecer una estética cálida y juguetona para materiales educativos, infantiles o presentaciones amigables, asegurando que todo el contenido mantenga un aspecto artesanal y no fotográfico.

## Datos clave
- **Paleta de colores**: Pastel cálido, fondo crema (#FFF8F0) y acentos en rojo, azul, amarillo y verde (colores de caja de crayones).
- **Elementos visuales**: Textura cerosa, líneas imperfectas tipo niño, bordes suaves y doodles simples.
- **Restricción estricta**: Exclusivamente elementos dibujados a mano; prohibido el uso de realismo o fotografía.
- **Tipografía**: Fuentes manuscritas o casuales con etiquetas claras y letras divertidas.
