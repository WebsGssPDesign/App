# requirements.txt

## Resumen
Este archivo define las dependencias de Python necesarias para un proyecto que busca y procesa artículos académicos, probablemente integrando fuentes como arXiv y Semantic Scholar mediante scraping y análisis de PDFs. Sirve para garantizar la compatibilidad del entorno de desarrollo al instalar los paquetes requeridos por el sistema de búsqueda.

## Datos clave
- **Proyecto**: sn-search-academic (SenseNova Skills)
- **Tecnologías**: Python, arXiv API, Semantic Scholar, Playwright (automatización web), PDF parsing.
- **Decisiones técnicas**: Se requieren versiones específicas para `httpx` (>=0.27), `arxiv` (>=2.0.0) y `pypdf` (>=4.0.0).
- **Paquetes clave**: `beautifulsoup4` para extracción de datos HTML, `deepxiv-sdk` para acceso a arXiv, `semanticscholar` para consultas bibliográficas.
