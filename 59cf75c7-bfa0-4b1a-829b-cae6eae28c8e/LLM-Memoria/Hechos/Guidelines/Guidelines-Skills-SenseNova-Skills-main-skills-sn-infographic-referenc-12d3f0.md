# newspaper-collage.md

## Resumen
Este archivo define una guía de estilo para crear composiciones tipo collage con recortes de periódicos y revistas vintage. Sirve como referencia visual para diseñar infografías que evoquen estética histórica, periodística o de zine mediante texturas envejecidas y tipografías mixtas.

## Datos clave
- **Estilo visual**: Recortes superpuestos con bordes desgarrados, manchas de tinta y marcas de sello de goma rojo.
- **Paleta de colores**: Amarillos de papel viejo, sepia, crema, fondo kraft o blanco envejecido.
- **Tipografía**: Fuentes de titulares de periódico, ensamblaje estilo "ransom note" y texto de máquina de escribir para anotaciones manuscritas.
- **Uso recomendado**: Contenido histórico, temas de investigación, periodismo, comentario cultural y estética DIY.
