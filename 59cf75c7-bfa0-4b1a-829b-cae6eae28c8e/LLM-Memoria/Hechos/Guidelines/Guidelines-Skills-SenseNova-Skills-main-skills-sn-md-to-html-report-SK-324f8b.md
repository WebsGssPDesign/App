# SKILL.md

## Resumen
Este documento define un flujo de trabajo para transformar informes Markdown complejos en páginas HTML únicas, estéticamente diseñadas y autocontenidas. Su objetivo es mejorar la legibilidad y el impacto visual sin alterar los hechos originales, priorizando siempre una planificación detallada antes de la codificación.

## Datos clave
- **Proceso obligatorio**: Escribir `plan.md` (incluyendo brainstorming de diseño, revisión de unicidad y contrato de diseño) antes de generar cualquier HTML.
- **Principios de diseño**: El primer plano debe reflejar el tema del informe; usar tipografía específica para cada proyecto; evitar decoraciones sin propósito informativo.
- **Restricciones técnicas**: Un solo archivo HTML con CSS incrustado (sin CDN ni archivos externos); gráficos y diagramas deben ser manuscritos dentro del código.
- **Integridad de datos**: No inventar logotipos, testimonios o datos; editar el texto para fluidez pero mantener la intensidad de las conclusiones originales.
- **Referencias clave**: Consultar guías sobre dirección estética (`01-aesthetic-direction.md`), diseño de layout (`02-layout-and-content-design.md`) y revisión (`04-review-angles.md`).
