# pr-body-bugfix.md

## Resumen
Este documento establece una plantilla estandarizada para la descripción del cuerpo de las pull requests (PR) enfocadas en correcciones de errores. Su función es guiar a los desarrolladores para que documenten sistemáticamente el problema, la causa raíz, la solución aplicada y los pasos de verificación, asegurando una revisión clara y completa.

## Datos clave
- **Proyecto**: GitHub PR Workflow Templates.
- **Tecnologías**: Markdown (`.md`), GitHub Actions/PRs.
- **Decisiones**: Estructura obligatoria que incluye secciones para descripción del bug, causa raíz, solución, plan de prueba y evaluación de riesgos.
- **Pasos importantes**: Los revisores deben seguir una lista numerada específica para confirmar la corrección antes de fusionar el código.
