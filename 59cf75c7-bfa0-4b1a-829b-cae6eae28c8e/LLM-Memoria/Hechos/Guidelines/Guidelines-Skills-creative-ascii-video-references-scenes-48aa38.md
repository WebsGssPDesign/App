# scenes.md

## Resumen
Este documento establece una filosofía de diseño para escenas de video ASCII, definiéndolas como unidades narrativas con concepto y arco, no solo demostraciones de efectos. Proporciona patrones compositivos específicos, como jerarquías de capas (fondo, contenido, acento) y curvas direccionales para parámetros, asegurando que las transiciones tengan propósito visual en lugar de oscilar aleatoriamente.

## Datos clave
- **Filosofía**: Las escenas deben tener un concepto narrativo, un arco temporal y un rol claro dentro del video.
- **Jerarquía de capas**: Se define una estructura estricta con Fondo (atmósfera), Contenido (idea principal) y Acento (puntos destacados).
- **Arcos direccionales**: Uso de fórmulas como `progress` para crear transiciones lineales, ease-in/out o reveladas paso a paso, evitando oscilaciones sin sentido.
- **Técnicas compositivas**: Implementación de sistemas duales contrarrotatorios y colisiones de ondas mediante manipulación del tiempo (`-t`) y fases.
- **Metáforas visuales**: Los nombres de las escenas deben reflejar el concepto (ej. "emergencia", "entropía") más que el nombre técnico del efecto.
