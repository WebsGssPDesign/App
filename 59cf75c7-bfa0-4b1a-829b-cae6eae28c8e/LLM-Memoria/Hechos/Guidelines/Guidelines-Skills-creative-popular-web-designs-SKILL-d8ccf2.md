# SKILL.md

## Resumen
Este archivo define un sistema de habilidades para generar 54 plantillas HTML/CSS basadas en sistemas de diseño reales (como Stripe o Linear). Sirve como referencia visual y técnica para replicar estilos web específicos utilizando tokens CSS, tipografías sustituidas y componentes predefinidos.

## Datos clave
- **Proyecto**: popular-web-designs (54 plantillas de sistemas de diseño).
- **Tecnologías**: HTML, CSS, Google Fonts (como substitutos para fuentes propietarias), cloudflared tunnel.
- **Decisiones**: Mapeo de fuentes propietarias a sustitutos gratuitos (ej: Source Sans 3 para Stripe, Inter para Figma).
- **Comandos/Pasos**: `skill_view` para cargar plantillas, `write_file` para crear el código, `browser_vision` para verificar visualmente.
- **Flujo recomendado**: Combinar con la habilidad `claude-design` para el proceso creativo y `generative-widgets` para servir el resultado en la nube.
