# paper-collage.md

## Resumen
Este archivo define una guía de estilo para crear infografías con estética de recortes y collage en papel. Su objetivo es asegurar que todos los elementos visuales mantengan una sensación artesanal, evitando cualquier imagen fotográfica o realista a favor de texturas hechas a mano.

## Datos clave
- **Estilo visual**: Recortes de papel, bordes desgarrados, sombras proyectadas y formas geométricas superpuestas.
- **Paleta de colores**: Tonos de cartón de construcción, fondo crema (#F5F0E6) o kraft marrón con acentos contrastantes.
- **Tipografía**: Estilo de letras recortadas, negritas legibles y cortes de revistas opcionales.
- **Restricciones estrictas**: Prohibido el uso de elementos fotográficos; todo debe parecer artesanía de papel.
- **Uso recomendado**: Contenido educativo, presentaciones creativas e infografías amigables.
