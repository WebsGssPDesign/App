# style-presets.md

## Resumen
Este documento define tres conjuntos de estilos visuales coherentes para generar contenido en HTML, imágenes estáticas y video motion. Su función es garantizar la alineación estética entre las diferentes capas del proyecto mediante parámetros específicos de color, tipografía, iluminación y movimiento, evitando mezclas no intencionadas.

## Datos clave
- **Estilos disponibles**: `--style anime` (fondo papel blanco, cel shading), `--style cinematic` (iluminación práctica, profundidad de campo) y `--style cgi` (materiales PBR, geometría estable).
- **Personalización**: Se permite sobrescribir colores mediante la clave `meta.accent` en el archivo `content/story.json`.
- **Restricciones**: No inferir elementos como "folio" o "caption" del nombre del estilo; evitar imitar artistas vivos por nombre.
- **Errores a evitar**: En video, prevenir line boil, face drift, flicker, extra fingers y mesh melting.
- **Uso recomendado**: Anime para mitología/fantasía; Cinematic para documentales/historia; CGI para ciencia/tecnología.
