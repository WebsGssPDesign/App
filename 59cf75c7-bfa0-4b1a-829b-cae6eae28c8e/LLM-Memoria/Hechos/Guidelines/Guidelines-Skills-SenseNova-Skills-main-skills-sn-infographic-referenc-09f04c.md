# dashboard.md

## Resumen
Este documento define las directrices de diseño para crear paneles de control (dashboards) que muestren múltiples métricas mediante gráficos, números grandes e indicadores KPI. Su propósito es estandarizar la visualización de datos clave para resaltar el rendimiento y el estado del sistema de manera clara y efectiva.

## Datos clave
- **Estructura**: Diseño modular o en cuadrícula con widgets de datos prominentes.
- **Elementos visuales**: Uso de gráficos (barras, líneas, pasteles), flechas de tendencia y codificación de colores (verde/rojo).
- **Tipografía**: Títulos superiores, etiquetas claras y unidades visibles junto a los valores numéricos.
- **Estilos recomendados**: `corporate-memphis` para entornos corporativos, `ui-wireframe` para técnicos y `neon-futurism` para interfaces futuristas.
