# periodic-table.md

## Resumen
Este documento define una estructura de cuadrícula rectangular para organizar elementos categorizados, ideal para matrices de habilidades o catálogos de recursos. Establece normas visuales como celdas uniformes, colores por categoría y símbolos prominentes, además de sugerir combinaciones con estilos como pixel art o Memphis corporativo.

## Datos clave
- **Proyecto**: SenseNova Skills (layouts/periodic-table.md)
- **Tecnologías/Estilos recomendados**: high-contrast-ad, pixel-art, corporate-memphis
- **Decisión de diseño**: Uso de una cuadrícula rectangular con celdas uniformes y agrupaciones opcionales.
- **Elementos visuales**: Símbolos o abreviaturas destacados, icono pequeño por celda y leyenda de categorías.
- **Pasos de implementación**: Colocar título arriba, incluir nombre e información breve en la celda, añadir encabezados opcionales y notas al pie para casos especiales.
