# SKILL.md

## Resumen
Este documento define una habilidad técnica para extraer valores numéricos de cadenas con unidades y generar un panel de visualización multidimensional. Su objetivo es analizar la distribución de datos mediante gráficos como histogramas, diagramas de pastel y curvas acumulativas, destacando tendencias centrales.

## Datos clave
- **Proyecto**: SenseNova-Skills (análisis de datos).
- **Tecnologías**: Python, Pandas, NumPy, Matplotlib.
- **Pasos principales**:
  1. Limpieza de datos: Eliminación de valores nulos y cadenas con marcadores como '...'.
  2. Extracción numérica: Función para convertir strings (ej. "50g") a floats eliminando unidades.
  3. Visualización: Creación de un dashboard de 4 subgráficos (histograma, pastel, barras, acumulativo).
- **Configuración**: Fuentes configuradas en `SimHei` y `DejaVu Sans` para evitar errores de codificación.
- **Salida**: Archivo `distribution_dashboard.png` con resolución de 300 dpi.
