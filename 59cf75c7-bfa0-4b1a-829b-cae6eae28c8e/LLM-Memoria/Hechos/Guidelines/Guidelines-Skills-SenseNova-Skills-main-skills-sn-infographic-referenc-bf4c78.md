# tech-brand.md

## Resumen
Este archivo define una guía de estilo visual para empresas tecnológicas, estableciendo una paleta de colores limpia y profesional junto con elementos gráficos minimalistas. Su propósito es estandarizar la apariencia de presentaciones, sitios web y materiales B2B que transmitan precisión técnica y modernidad.

## Datos clave
- **Proyecto**: SenseNova Skills (tech-brand)
- **Paleta de colores**: Azules corporativos, grises tecnológicos y fondos blancos o gris claro con degradados sutiles.
- **Elementos visuales**: Ilustraciones abstractas de circuitos/nodos, mockups de dispositivos, iconografía limpia y fotografía profesional mezclada con gráficos.
- **Tipografía**: Fuentes sans-serif modernas como SF Pro, Inter o Roboto con jerarquía clara y mucho espacio en blanco.
- **Uso recomendado**: Pitch decks de startups, contenido B2B y presentaciones profesionales.
