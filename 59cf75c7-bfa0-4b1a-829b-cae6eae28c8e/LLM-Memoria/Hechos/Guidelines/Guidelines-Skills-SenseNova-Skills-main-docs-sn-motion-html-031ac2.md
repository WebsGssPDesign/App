# sn-motion-html.md

## Resumen
Este documento describe `sn-motion-html`, una herramienta para crear historias web inmersivas impulsadas por el desplazamiento, ideales para marcas y narrativas visuales continuas. Genera proyectos reutilizables con estructuras JSON organizadas y soporta modos de movimiento reducido para accesibilidad.

## Datos clave
- **Proyecto**: `sn-motion-html` (plantilla en `docs/sn-motion-html/SKILL.md`).
- **Tecnologías**: Python, FFmpeg, generación de imágenes por IA, cuenta Ark-compatible Seedance.
- **Decisiones**: Uso de archivos `.env` locales para credenciales; separación estricta entre aprobación creativa y autorización de pago.
- **Rutas/Comandos**: `python scripts/init_project.py`, `scripts/seedance_pipeline.py . plan`, `scripts/verify_media.py`.
- **Pasos críticos**: Definir audiencia y alcance, crear blueprint de capítulos, generar set de imágenes estáticas (gate), ejecutar dry-run del manifiesto y validar QA en navegador antes de la entrega.
