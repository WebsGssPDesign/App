# mintlify.md

## Resumen
Este documento define el sistema de diseño visual de Mintlify, enfocado en la claridad y la legibilidad mediante un esquema minimalista basado en blanco y acentos verdes. Sirve como guía técnica para replicar la atmósfera "documentation-as-product" utilizando fuentes específicas, una paleta de colores precisa y reglas tipográficas estrictas.

## Datos clave
- **Fuentes:** Inter (texto principal) y Geist Mono (código), con enlaces CDN para Google Fonts.
- **Paleta de colores:** Fondo blanco (#ffffff), texto casi negro (#0d0d0d) y acento verde marca (#18E299).
- **Tipografía:** Tracking negativo (-0.8px a -1.28px) en títulos para compresión visual; altura de línea 150% en cuerpo.
- **Estilo UI:** Bordes sutiles de opacidad 5%, esquinas ultra-redondeadas (16px–9999px) y ausencia de sombras pesadas.
- **Herramientas sugeridas:** `write_file` para generar HTML, `generative-widgets` para servir y `browser_vision` para verificación visual.
