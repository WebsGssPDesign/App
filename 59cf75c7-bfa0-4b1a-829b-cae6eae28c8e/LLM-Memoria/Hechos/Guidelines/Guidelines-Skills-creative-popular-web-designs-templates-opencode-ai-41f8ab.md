# opencode.ai.md

## Resumen
Este documento define el sistema de diseño "OpenCode" para un agente de IA, estableciendo una estética nativa de terminal con tipografía monoespaciada exclusiva y una paleta de colores cálidos. Su objetivo es guiar la implementación visual coherente del sitio web, asegurando que todos los elementos reflejen una filosofía de "todo es código".

## Datos clave
- **Tipografía:** Berkeley Mono como única fuente (sin fuentes sans-serif), con `JetBrains Mono` como sustituto en CDNs.
- **Paleta principal:** Fondo oscuro cálido (`#201d1d`) y texto off-white (`#fdfcfc`).
- **Colores semánticos:** Uso de la paleta Apple HIG (azul, rojo, verde, naranja) para estados interactivos.
- **Detalles visuales:** Bordes con radio de 4px, espaciado base de 8px y enlaces subrayados por defecto.
- **Implementación:** Generar HTML vía `write_file`, servir mediante `generative-widgets` y verificar con `browser_vision`.
