# page_002.query.txt

## Resumen
Este archivo define las especificaciones de diseño para una página de transición de sección centrada en las funciones principales de SenseNova. Su objetivo es guiar al desarrollador en la creación de un layout tecnológico con fondo oscuro, utilizando texto y elementos CSS decorativos para equilibrar la composición visual sin imágenes externas.

## Datos clave
- **Proyecto**: SenseNova Skills (sn-ppt-workbench).
- **Tecnologías**: HTML/CSS, fuentes Inter y Noto Sans SC.
- **Colores**: Fondo oscuro, primario #2196F3, acento #00BCD4.
- **Contenido clave**: Tareas de orquestación visual, integración de conocimiento con RAG, monitoreo en tiempo real.
- **Decisión de diseño**: Sustitución del espacio para imagen (1:1) por gráficos abstractos generados con CSS debido a la falta de assets visuales.
