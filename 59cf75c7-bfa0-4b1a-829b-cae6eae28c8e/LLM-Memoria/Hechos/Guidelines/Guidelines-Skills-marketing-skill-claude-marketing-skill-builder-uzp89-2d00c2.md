# SKILL.md

## Resumen
Esta guía define un flujo de trabajo para generar múltiples variantes de texto publicitario optimizadas para Meta, Google y LinkedIn. Su objetivo es facilitar pruebas A/B al crear ángulos de gancho distintos (como puntos de dolor o prueba social) que respeten los límites de caracteres específicos de cada plataforma, basándose en el tono de marca configurado previamente.

## Datos clave
- **Proyecto**: Generador de copys publicitarios (`ad-copy-generator`).
- **Tecnologías/Flujo**: Uso de `CLAUDE_PLUGIN_ROOT`, lectura de `brand-voice.md` para configuración y restricciones de palabras prohibidas.
- **Pasos críticos**: Verificar estado de onboarding, confirmar plataformas objetivo (Meta, Google Search, LinkedIn) y número de variantes por ángulo único.
- **Restricciones técnicas**: Límites de caracteres específicos (ej. Google Headline ≤30, Meta Primary Text ~125, LinkedIn Intro ~150).
- **Reglas de salida**: Tablas Markdown con conteo real de caracteres, CTA idéntico en todas las variantes y prohibición estricta de inventar estadísticas no presentes en la fuente.
