# prompt-writing-rules.md

## Resumen
Este documento establece un conjunto de reglas estrictas para redactar prompts de alta calidad en modelos de generación de imágenes. Su objetivo es garantizar la precisión visual, la consistencia estética y la correcta interpretación del texto dentro de las imágenes generadas.

## Datos clave
- **Reglas principales**: Definir siempre textura de fondo y estilo tipográfico; evitar códigos hexadecimales usando nombres de color específicos (ej. "sage green"); encerrar todo el texto literal en comillas dobles.
- **Diseño visual**: Minimizar flechas, preferiendo la proximidad espacial; asegurar que cada ícono corresponda semánticamente al contenido adyacente.
- **Estructura de pasos**: Detallar individualmente cada etapa del proceso sin fusionarlas; presentar datos duros (números, fechas) en formatos visuales distintivos como cajas o notas adhesivas.
- **Puntuación**: Usar comillas únicamente para citas de texto, no para describir estilos, layouts o colores.
