# ikea-manual.md

## Resumen
Este documento define un estilo de diseño minimalista basado en líneas para manuales de ensamblaje, inspirado en las instrucciones de IKEA. Su propósito es facilitar la comunicación universal mediante dibujos simples y secuencias numéricas sin depender excesivamente del texto.

## Datos clave
- **Estilo visual**: Arte lineal minimalista con trazos negros sobre fondo blanco o crema.
- **Paleta de colores**: Negro (líneas), Rojo (advertencias) y Azul (destacados).
- **Elementos gráficos**: Dibujos simples, flechas, vistas explosivas y figuras humanas para escala.
- **Tipografía**: Texto reducido, números de pasos prominentes y símbolos universales.
- **Uso ideal**: Guías paso a paso, instrucciones de montaje y contenido "cómo hacer".
