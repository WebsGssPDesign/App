# panorama.md

## Resumen
Este documento define las directrices para crear un lienzo panorámico ultra-ancho diseñado para mostrar escenas expansivas y continuas. Su función principal es facilitar la exploración visual de izquierda a derecha, ideal para representaciones de grandes conjuntos como líneas de tiempo o comparativas ambientales.

## Datos clave
- **Proporción**: Relación de aspecto extremadamente ancha (3:1 o superior).
- **Estructura**: Escena única continua que abarca todo el ancho con distribución natural del contenido.
- **Elementos visuales**: Uso de capas de profundidad y una cuadrícula opcional para la navegación.
- **Ubicación del texto**: Títulos en el borde izquierdo o superior, etiquetas en ubicaciones relevantes y leyendas en la parte inferior.
- **Estilos recomendados**: `storybook-watercolor`, `origami` e `crayon-hand-drawn`.
