# axial-expansion.md

## Resumen
Este documento define la estructura y mejores prácticas para crear diagramas de expansión axial, donde el contenido se distribuye simétricamente o asimétricamente desde un eje central. Sirve como guía visual para organizar comparaciones, líneas de tiempo y análisis de causa-efecto con un diseño equilibrado.

## Datos clave
- **Estructura**: Eje vertical u horizontal que actúa como columna vertebral; ramas hacia ambos lados.
- **Uso ideal**: Comparaciones con línea base compartida, líneas de tiempo, diagramas de causa-efecto y pros/contras.
- **Elementos visuales**: Línea central prominente, bloques de contenido extendidos, flechas o conectores desde el eje.
- **Colocación de texto**: Etiquetas del eje en la línea central, etiquetas de contenido junto a cada rama, título superior.
- **Estilos recomendados**: `corporate-memphis`, `technical-schematic` y `paper-collage`.
