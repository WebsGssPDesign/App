# comic-strip.md

## Resumen
Este documento define la estructura y elementos visuales de un cómic secuencial para explicar conceptos o narrar historias. Sirve como guía técnica para diseñar infografías que utilicen viñetas, burbujas de diálogo y efectos sonoros organizados en una lectura lineal.

## Datos clave
- **Propósito**: Narración secuencial, explicaciones de viaje del usuario e ilustración de escenarios paso a paso.
- **Elementos visuales**: Marcos de panel, burbujas de pensamiento/habla, efectos de sonido y fondos de escena.
- **Ubicación de texto**: Títulos en la parte superior, diálogos dentro de las burbujas y narraciones en cajas de pie.
- **Pares recomendados**: `graphic-novel` (narrativas dramáticas), `kawaii` (historias tiernas) y `cartoon-hand-drawn` (explicaciones amigables).
