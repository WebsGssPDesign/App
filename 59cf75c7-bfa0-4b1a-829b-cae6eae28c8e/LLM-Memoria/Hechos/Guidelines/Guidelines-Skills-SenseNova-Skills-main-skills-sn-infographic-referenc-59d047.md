# swiss-grid.md

## Resumen
Este documento define un sistema de cuadrícula estricto basado en el estilo internacional suizo, diseñado para garantizar una comunicación visual racional y objetiva. Sirve como guía fundamental para la creación de diseños corporativos, informes anuales y materiales técnicos que priorizan la claridad extrema y el orden estructural sobre la decoración.

## Datos clave
- **Estilo**: Internacional Suizo (Swiss Style) con enfoque matemático y objetivo.
- **Estructura**: Cuadrícula precisa con 3 a 6 columnas y alineación estricta sin excepciones.
- **Tipografía**: Jerarquía impulsada por el tipo, uso de línea base consistente y márgenes generosos pero uniformes.
- **Paleta**: Blanco, negro y un solo color de acento; la estructura es el elemento estético principal.
- **Uso recomendado**: Comunicaciones institucionales, documentos formales y referencias técnicas.
- **Emparejamientos sugeridos**: `technical-schematic`, `ui-wireframe` y `corporate-memphis`.
