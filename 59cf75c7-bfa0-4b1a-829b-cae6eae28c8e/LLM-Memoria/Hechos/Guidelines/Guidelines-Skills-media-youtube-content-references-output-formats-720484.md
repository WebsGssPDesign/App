# output-formats.md

## Resumen
Este documento establece los estándares de formato para documentar el contenido de videos, como conferencias o tutoriales. Sirve para estructurar la información en capítulos cronológicos, resúmenes ejecutivos y publicaciones derivadas como hilos de Twitter o artículos de blog. Facilita la reutilización del material audiovisual en diferentes plataformas digitales manteniendo la coherencia temática.

## Datos clave
- **Proyecto**: Estandarización de documentación para contenido multimedia (YouTube).
- **Tecnologías/Formatos**: Markdown, timestamps (ej. 00:00), hilos de Twitter/X, artículos de blog.
- **Decisiones**: Los resúmenes deben escribirse en tercera persona y tiempo presente; los capítulos requieren tiempos específicos.
- **Pasos importantes**: Extraer citas clave con sus marcas temporales exactas para respaldar argumentos principales.
