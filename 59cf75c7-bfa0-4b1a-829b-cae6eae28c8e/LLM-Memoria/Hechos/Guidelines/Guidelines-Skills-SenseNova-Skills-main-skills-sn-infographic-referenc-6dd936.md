# evaluation-standard.md

## Resumen
Este documento define un protocolo de evaluación para prompts de generación de imágenes, diseñado para verificar la calidad y completitud de las instrucciones visuales. Su función es asegurar que los prompts generen infografías o gráficos estructurados con suficiente detalle técnico y semántico para modelos de lenguaje.

## Datos clave
- **Proyecto**: SenseNova-Skills (evaluación de prompts).
- **Criterios obligatorios (R01-R08)**: Verificación de contenido accionable, sujeto principal, información estructurada, descripciones visuales, elementos concretos, detalles tipográficos, relaciones organizacionales y densidad de detalle.
- **Criterios opcionales (O01-O12)**: Evaluación de causalidad, codificación de datos, jerarquía de importancia, contexto escénico, efectos dinámicos, texturas, simbolismo cultural, atmósfera emocional, terminología técnica, uso de texto bilingüe y público objetivo.
- **Formato de salida**: Estrictamente JSON con listas `required_results` e `optional_results`.
