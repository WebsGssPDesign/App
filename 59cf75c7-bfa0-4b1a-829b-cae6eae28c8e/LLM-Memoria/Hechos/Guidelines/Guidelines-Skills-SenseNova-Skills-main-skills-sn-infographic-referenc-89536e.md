# swimlane.md

## Resumen
Este documento define la estructura y mejores prácticas para crear diagramas de carriles (swimlane), una herramienta visual diseñada para mapear flujos de trabajo multifuncionales. Sirve para asignar responsabilidades, visualizar intercambios entre departamentos y representar procesos complejos con múltiples actores en un mismo cronograma.

## Datos clave
- **Concepto central**: Carriles paralelos horizontales o verticales que representan roles, departamentos o actores específicos.
- **Elementos visuales**: Flechas cruzadas para indicar transferencias de tareas (handoffs) entre carriles y etiquetas claras para cada paso del proceso.
- **Casos de uso ideales**: Diagramas de planos de servicio (service blueprints), asignación de responsabilidades y flujos de trabajo con múltiples partes interesadas.
- **Estilos recomendados**: `corporate-memphis` para procesos empresariales, `technical-schematic` para diagramas de ingeniería y `ui-wireframe` para bocetos de planos de servicio.
