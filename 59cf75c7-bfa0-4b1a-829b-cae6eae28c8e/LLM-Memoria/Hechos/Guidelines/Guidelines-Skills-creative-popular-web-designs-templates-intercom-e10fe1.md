# intercom.md

## Resumen
Este documento define el sistema de diseño visual de Intercom, enfocado en una estética editorial cálida y precisa. Sirve como guía técnica para replicar la interfaz utilizando fuentes específicas, una paleta de colores distintiva con acentos naranjas y componentes geométricos con bordes casi rectangulares.

## Datos clave
- **Fuentes:** `Inter` (substituto CDN), `Saans`, `Serrif`, `SaansMono`.
- **Colores principales:** Fondo crema (`#faf9f6`), texto negro suave (`#111111`) y acento naranja Fin (`#ff5600`).
- **Tipografía:** Tracking negativo agresivo en títulos (ej. -2.4px a 80px) y altura de línea estricta de 1.00.
- **Componentes:** Botones con radio de 4px, efectos hover `scale(1.1)` y activo `scale(0.85)`.
- **Herramientas sugeridas:** Uso de `write_file`, `generative-widgets` y verificación con `browser_vision`.
