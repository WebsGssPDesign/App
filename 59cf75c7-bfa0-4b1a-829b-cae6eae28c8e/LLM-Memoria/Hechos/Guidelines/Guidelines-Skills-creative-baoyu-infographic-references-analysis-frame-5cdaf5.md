# analysis-framework.md

## Resumen
Este documento establece un marco de análisis profundo para la creación de infografías, aplicando principios de diseño instruccional. Su objetivo es guiar al creador a entender el contenido fuente, definir objetivos de aprendizaje claros y seleccionar las mejores combinaciones de estructura y estilo visual sin alterar los datos originales.

## Datos clave
- **Principios**: Comprensión profunda, enfoque centrado en el aprendiz, narrativa visual y carga cognitiva reducida.
- **Clasificación de contenido**: Mapeo específico para tipos como línea de tiempo, procesos, comparaciones, jerarquías y datos métricos con sus layouts óptimos (ej. `linear-progression`, `dashboard`).
- **Objetivos de aprendizaje**: Deben ser específicos, medibles y redactados desde la perspectiva del espectador ("After viewing...").
- **Análisis de complejidad**: Evaluación basada en el número de puntos principales para determinar si el layout debe ser escaso, equilibrado o denso.
- **Integridad de datos**: Regla estricta de extracción verbatim; nunca redondear números ni parafrasear citas.
- **Formato de salida**: Generación de un archivo `analysis.md` en formato YAML que incluye título, tipo de dato, complejidad y objetivos definidos.
