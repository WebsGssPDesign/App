# tree-branching.md

## Resumen
Este documento define una estructura jerárquica tipo árbol para visualizar categorías y subcategorías, ideal para taxonomías, árboles de decisión o organigramas. Sirve como guía visual para organizar información desde un nodo raíz hasta nodos terminales mediante líneas conectivas y etiquetas claras.

## Datos clave
- **Concepto central**: Estructura jerárquica (árbol) con raíz, ramas y hojas.
- **Casos de uso**: Taxonomías, árboles de decisión, organigramas, estructuras de archivos y genealogías.
- **Elementos visuales**: Líneas conectivas, nodos en puntos de ramificación, iconos/etiquetas por nodo y codificación por color.
- **Diseño textual**: Título superior, concepto raíz destacado, etiquetas en ramas/hojas y leyenda opcional.
- **Estilos recomendados**: `crayon-hand-drawn` (taxonomías amigables), `aged-academia` (clasificaciones científicas) y `origami` (estructuras geométricas).
