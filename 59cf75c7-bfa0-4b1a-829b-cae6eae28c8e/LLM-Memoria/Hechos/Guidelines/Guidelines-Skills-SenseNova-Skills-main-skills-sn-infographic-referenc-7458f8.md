# circular-flow.md

## Resumen
Este documento define la estructura y mejores prácticas para crear diagramas de flujo cíclico, ideales para representar procesos recurrentes o bucles de retroalimentación. Sirve como guía visual para organizar pasos en un círculo continuo sin inicio ni fin definidos, facilitando la comprensión de ciclos naturales o etapas de mejora continua.

## Datos clave
- **Concepto central**: Proceso cíclico sin punto de partida fijo.
- **Elementos visuales**: Forma circular, flechas direccionales y nodos espaciados uniformemente con iconos.
- **Ubicación del texto**: Título superior, etiquetas en cada nodo y descripciones breves; el concepto principal puede ir en el centro.
- **Estilos recomendados**: `crayon-hand-drawn` (ciclos amigables), `corporate-memphis` (procesos empresariales) y `subway-map` (estilo de mapas de tránsito).
