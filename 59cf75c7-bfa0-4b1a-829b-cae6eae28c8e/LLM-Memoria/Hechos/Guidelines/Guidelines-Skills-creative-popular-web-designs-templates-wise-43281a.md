# wise.md

## Resumen
Este documento define el sistema de diseño visual para la plataforma fintech Wise, enfocándose en una estética audaz que utiliza tipografía masiva y un verde lima distintivo. Su objetivo es guiar el desarrollo de interfaces web autocontenidas que transmitan confianza y optimismo, reemplazando fuentes propietarias con alternativas accesibles vía CDN.

## Datos clave
- **Tipografía:** Sustitución de "Wise Sans" por `Inter` (Google Fonts) para asegurar compatibilidad; uso exclusivo del peso 900 para titulares y 600 para cuerpo.
- **Paleta de colores:** Verde Wise (`#9fe870`) como acento principal sobre fondo off-white (`#e8ebe6`) y texto casi negro (`#0e0f0c`).
- **Componentes:** Botones tipo píldora (radio 9999px) con animación de escala al pasar el cursor; tarjetas con bordes redondeados entre 30px y 40px.
- **Detalles técnicos:** Activación obligatoria de alternativos contextuales (`calt`) en todas las fuentes para mejorar legibilidad; uso de sombras mínimas tipo anillo.
