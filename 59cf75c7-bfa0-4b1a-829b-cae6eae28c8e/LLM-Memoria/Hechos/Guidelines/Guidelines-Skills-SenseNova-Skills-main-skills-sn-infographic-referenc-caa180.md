# corporate-memphis.md

## Resumen
Este archivo define las directrices de estilo visual para la marca "Corporate Memphis", especificando el uso de ilustraciones vectoriales planas con figuras humanas desproporcionadas y colores vibrantes. Su propósito es estandarizar la apariencia gráfica para materiales corporativos, presentaciones tecnológicas y recursos de marketing que requieran un tono profesional pero amigable.

## Datos clave
- Estilo visual: Figuras humanas abstractas sin contornos, rellenos sólidos y elementos geométricos flotantes.
- Paleta de colores: Tonos primarios saturados (púrpura, naranja, turquesa, amarillo) sobre fondos blancos o pasteles claros.
- Tipografía: Fuentes sans-serif limpias con encabezados en negrita para mantener la legibilidad y el equilibrio entre formalidad y cercanía.
- Aplicaciones ideales: Presentaciones de negocios, productos tecnológicos, material publicitario y capacitación corporativa.
