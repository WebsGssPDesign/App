# SKILL.md

## Resumen
Esta guía define una habilidad para generar páginas HTML únicas que resumen conversaciones, ramas de código o instrucciones de usuario mediante visualizaciones claras en lugar de texto extenso. Su objetivo es crear entregables digeribles y estéticamente consistentes que faciliten la comprensión rápida del estado actual del trabajo.

## Datos clave
- **Proyecto**: Skill `summary` para generación de reportes visuales.
- **Tecnologías**: HTML único, SVG incrustado (sin frameworks ni CDNs).
- **Decisiones**: Priorizar diagramas sobre tablas; limitar el cuerpo del texto a menos de 200 palabras.
- **Rutas/Comandos**: `git status`, `git log --oneline -20`, `git diff --stat`.
- **Pasos importantes**: Recopilar datos reales antes de escribir (Step 1); estructurar la página en flujo lógico con patrones Z y F; ofrecer sugerencias de modo solo si hay una petición adjunta.
