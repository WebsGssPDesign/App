# lego-brick.md

## Resumen
Este documento define una guía de estilo visual basada en la estética de construcción con bloques tipo LEGO. Su propósito es estandarizar el diseño para proyectos que requieran un aspecto juguetón, modular y educativo mediante paletas de colores específicas y tipografías robustas.

## Datos clave
- **Estilo visual**: Construcción modular visible con protuberancias (studs) y acabado brillante de plástico.
- **Paleta de colores**: Primarios clásicos (rojo, azul, amarillo, verde, blanco), fondo gris claro o blanco.
- **Tipografía**: Fuentes gruesas y cuadradas imitando instrucciones oficiales de LEGO con numeración de pasos.
- **Elementos gráficos**: Personajes tipo minifigura y elementos apilables.
- **Casos de uso ideales**: Conceptos de construcción, sistemas modulares, educación infantil y contenido para niños.
