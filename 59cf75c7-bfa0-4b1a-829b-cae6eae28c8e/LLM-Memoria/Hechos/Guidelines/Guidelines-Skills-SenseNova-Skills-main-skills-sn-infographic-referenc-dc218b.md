# surrealism.md

## Resumen
Este documento define las directrices visuales para aplicar el estilo surrealista en proyectos creativos. Sirve como referencia técnica para integrar elementos oníricos, perspectivas imposibles y tipografía distorsionada que fusionen la realidad con la fantasía de manera inesperada.

## Datos clave
- **Estilo visual**: Combinaciones de colores inusuales, gradientes etéreos y objetos flotantes en contextos extraños.
- **Elementos gráficos**: Perspectivas imposibles, metamorfosis de formas, relaciones de escala alteradas y elementos fundidos o derretidos.
- **Tipografía**: Letras distorsionadas, integradas dentro de escenas o flotando libremente con un aspecto etéreo.
- **Aplicaciones ideales**: Conceptos creativos abstractos, narrativas oníricas, presentaciones artísticas e historias imaginativas que buscan provocar pensamiento.
