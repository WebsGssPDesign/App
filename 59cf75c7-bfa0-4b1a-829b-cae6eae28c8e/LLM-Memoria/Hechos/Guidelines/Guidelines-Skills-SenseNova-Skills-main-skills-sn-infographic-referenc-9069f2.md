# left-image-right-text.md

## Resumen
Esta guía define el diseño de una disposición visual con imagen a la izquierda y texto a la derecha, optimizada para contenido narrativo como perfiles o estudios de caso. Su función es estandarizar la jerarquía visual mediante columnas equilibradas verticalmente, donde la ilustración establece el contexto y el texto proporciona detalles clave.

## Datos clave
- **Estructura**: Columna izquierda (50-60%) para imagen; columna derecha (40-50%) para contenido textual.
- **Alineación**: Ambas columnas deben estar centradas verticalmente.
- **Elementos visuales**: Línea de acento vertical opcional entre las secciones.
- **Ubicación del texto**: Título en la parte superior derecha, seguido del cuerpo y puntos clave.
- **Estilos recomendados**: `storybook-watercolor` para introducciones, `corporate-memphis` para casos de negocio y `high-contrast-ad` para llamadas a la acción.
