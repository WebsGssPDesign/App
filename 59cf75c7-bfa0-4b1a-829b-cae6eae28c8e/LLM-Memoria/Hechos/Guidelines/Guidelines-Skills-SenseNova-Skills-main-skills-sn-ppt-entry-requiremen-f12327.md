# requirements.txt

## Resumen
Este archivo define las dependencias de Python necesarias para un módulo de procesamiento de documentos dentro del proyecto SenseNova. Su función es garantizar que el entorno tenga instaladas las librerías correctas para manipular archivos PDF y Word antes de ejecutar la lógica de entrada de datos.

- **Proyecto**: SenseNova (módulo `sn-ppt-entry`)
- **Tecnologías**: Python, PyPDF, python-docx, PyMuPDF
- **Decisiones de versión**: Se establecen versiones mínimas específicas para asegurar compatibilidad (`>=4.0`, `>=1.1`, `>=1.24`).
- **Pasos importantes**: Ejecutar `pip install -r requirements.txt` en el directorio correspondiente para instalar las librerías.
