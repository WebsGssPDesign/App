# brand-voice.md

## Resumen
Este archivo actúa como la fuente única de verdad para configurar la voz de marca y preferencias de marketing dentro de un plugin. Sirve para estandarizar el tono, formato y restricciones lingüísticas antes de generar cualquier contenido automatizado.

## Datos clave
- **Estado actual**: No configurado; requiere ejecutar `/marketing-skill:marketing-setup` o editar manualmente.
- **Marcador de máquina**: La primera línea debe permanecer como `<!-- MARKETING-SKILL:UNCONFIGURED -->` hasta la configuración final.
- **Restricciones lingüísticas**: Prohibido usar palabras como "game-changer", "revolutionary" o "synergy".
- **Estilo preferido**: Confidente, directo y sin jerga corporativa; uso de comas de Oxford sí.
- **Formato de salida**: Preferencia por oraciones cortas a medias y evitar frases largas (run-ons).
- **Identidad sonora**: Pendiente de definir género, tempo y clave para videos cortos.
