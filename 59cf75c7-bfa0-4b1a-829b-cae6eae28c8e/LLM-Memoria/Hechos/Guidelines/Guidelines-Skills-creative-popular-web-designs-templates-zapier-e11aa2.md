# zapier.md

## Resumen
Este documento define el sistema de diseño visual de Zapier, enfocándose en una estética cálida y profesional que evita la frialdad del minimalismo técnico. Establece reglas estrictas para tipografía, paleta de colores y atmósfera general, utilizando fuentes como Inter y Degular Display junto con un naranja distintivo (#ff4f00) sobre fondos crema. Sirve como guía técnica para replicar fielmente la identidad visual de la marca en implementaciones web propias.

## Datos clave
- **Proyecto:** Sistema de diseño (Design System) para Zapier.
- **Tipografía:** Degular Display (títulos hero), Inter (UI general), GT Alpina (acentos editoriales).
- **Paleta de colores:** Fondo crema (#fffefb), texto casi negro cálido (#201515), acento naranja (#ff4f00).
- **Decisiones técnicas:** Sustitución de fuentes propietarias por CDN (Inter) para HTML autocontenido.
- **Implementación:** Uso de `write_file` y verificación visual con `browser_vision`.
- **Estilo:** Líneas de borde prominentes en lugar de sombras, espaciado base de 8px.
