# editorial-vogue.md

## Resumen
Este archivo define la plantilla "editorial-vogue", diseñada para crear composiciones visuales de lujo con tipografía serif y superposiciones refinadas. Sirve como guía estética para contenidos de alta gama en moda, estilo de vida o cultura editorial.

## Datos clave
- **Proyecto**: SenseNova Skills (layout `editorial-vogue`)
- **Estilo visual**: Títulos grandes en serif, fotografía de alta calidad y espacios en blanco elegantes.
- **Paleta de colores**: Neutros, negro y blanco para mantener sofisticación.
- **Colocación de texto**: El titular es un elemento visual primario; el cuerpo de texto debe estar en una zona limpia y legible.
- **Emparejamientos recomendados**: `aged-academia`, `storybook-watercolor` y `high-contrast-ad`.
