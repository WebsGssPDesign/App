# base-prompt.md

## Resumen
Este documento es una plantilla de prompt para generar infografías profesionales. Establece reglas estrictas sobre la estructura, el estilo visual y los requisitos tipográficos, asegurando que el contenido final sea claro, jerárquico y libre de problemas de derechos de autor.

## Datos clave
- **Propósito**: Generar infografías visuales coherentes y profesionales.
- **Variables dinámicas**: Utiliza placeholders como `{{LAYOUT}}`, `{{STYLE}}` y `{{CONTENT}}` para personalizar cada solicitud.
- **Principios de diseño**: Prioriza la arquitectura de información, el uso generoso del espacio en blanco y una jerarquía visual clara.
- **Gestión de derechos**: Instruye a crear alternativas estilizadas si se incluyen figuras sensibles o con copyright.
- **Requisitos textuales**: Exige que todos los textos coincidan con el tratamiento estilizado especificado, con títulos prominentes y etiquetas legibles.
