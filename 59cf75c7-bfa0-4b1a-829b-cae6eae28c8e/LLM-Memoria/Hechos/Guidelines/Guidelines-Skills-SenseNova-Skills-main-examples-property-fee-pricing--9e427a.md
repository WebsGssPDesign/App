# README_CN.md

## Resumen
Este documento describe un ejemplo de uso del sistema SenseNova-Skills para generar presentaciones PPTX desde cero, sin archivos de entrada. El proceso automatiza la creación de contenido y diseño basándose en una instrucción textual específica sobre el tema, estilo y audiencia objetivo.

## Datos clave
- **Proyecto**: SenseNova-Skills (Ejemplo:物业费定价体系).
- **Tecnologías**: `sn-ppt-entry` (enrutamiento), `sn-ppt-standard` (generación estándar), HTML renderizado, captura de pantalla para síntesis.
- **Decisiones**: Generación automática del esquema y materiales; síntesis final mediante screenshots de páginas HTML individuales en lugar de exportar directamente a PPTX.
- **Rutas/Archivos clave**: `result/*.pptx` (producto final), `result/*.zip` (colección de fuentes HTML), `pages/page_XXX.html` (páginas intermedias).
- **Comandos/Prompt**: "制作一个关于物业费定价体系的PPT，共26页..." (Crear un PPT sobre tarifas de administración de propiedades...).
