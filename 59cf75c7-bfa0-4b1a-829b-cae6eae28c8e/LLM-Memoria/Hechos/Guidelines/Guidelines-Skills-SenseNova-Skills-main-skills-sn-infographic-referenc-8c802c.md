# winding-roadmap.md

## Resumen
Este documento define las especificaciones para crear diagramas de "mapa de ruta" con un diseño curvo, ideal para visualizar trayectorias de proyectos o carreras. Sirve como guía técnica para estructurar elementos visuales como hitos, obstáculos y marcadores de progreso en una narrativa lineal.

## Datos clave
- **Concepto central**: Ruta serpenteante (S-curve) que conecta un punto de inicio con uno final.
- **Elementos obligatorios**: Hitos a lo largo del camino, indicadores de progreso y elementos laterales (obstáculos o ayudantes).
- **Casos de uso**: Mapas de proyectos, trayectorias laborales, viajes del cliente y cronogramas estratégicos.
- **Estilos recomendados**: `storybook-watercolor` para tonos fantásticos, `crayon-hand-drawn` para un estilo amigable y `origami` para rutas técnicas.
