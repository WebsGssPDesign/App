# DESCRIPTION.md

## Resumen
Este documento describe las habilidades necesarias para gestionar repositorios de GitHub mediante la línea de comandos. Su objetivo es enseñar el uso de `gh` y `git` para controlar flujos de trabajo como solicitudes de extracción, revisiones de código e integración continua.

## Datos clave
- **Herramientas principales**: CLI de GitHub (`gh`) y Git vía terminal.
- **Áreas de gestión**: Repositorios, Pull Requests (PR), Code Reviews, Issues y CI/CD pipelines.
- **Enfoque**: Automatización y control manual del flujo de trabajo desde la consola.
