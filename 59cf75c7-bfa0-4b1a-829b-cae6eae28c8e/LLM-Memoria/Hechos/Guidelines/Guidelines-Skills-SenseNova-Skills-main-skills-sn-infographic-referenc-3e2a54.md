# ukiyo-e.md

## Resumen
Este archivo define las directrices de estilo visual para imitar la estética japonesa de los grabados en madera ukiyo-e. Sirve como referencia técnica para diseñadores que buscan aplicar esta tradición artística a infografías y contenido cultural, especificando paletas de colores, elementos gráficos y tipografía adecuada.

## Datos clave
- **Estilo visual**: Contornos negros gruesos, rellenos planos sin degradados, texturas de "grano de madera" visibles.
- **Paleta de colores**: Azul prusiano (azul Hiroshige), rojo bermellón, negro; fondo crema/hueso (#F5EDD6); acentos en verdes suaves, ocre y rosa apagado.
- **Motivos decorativos**: Ondas, nubes y elementos naturales estilizados con perspectiva no occidental.
- **Tipografía**: Orientación vertical opcional, fuentes estilo pincel o caligráficas, uso de sellos o estampillas para etiquetas.
- **Uso recomendado**: Contenido cultural japonés, temas de naturaleza, viajes, artesanía tradicional e infografías sobre patrimonio asiático.
