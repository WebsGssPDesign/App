# interaction.md

## Resumen
Este documento detalla las funciones y patrones de interacción del usuario en p5.js, cubriendo eventos de ratón, teclado y táctil. Sirve como referencia técnica para implementar controles físicos, interfaces gráficas (DOM) e integración de audio en aplicaciones creativas.

## Datos clave
- **Proyecto**: p5.js (librería JavaScript creativa).
- **Tecnologías**: Eventos de navegador, DOM manipulation, Web Audio API.
- **Decisiones**: Uso de `return false` para prevenir comportamientos predeterminados del navegador; requisito de gesto de usuario (`userStartAudio`) para activar micrófono.
- **Rutas/Comandos**: Patrones de código para spawn al hacer clic, seguimiento con resorte, arrastrar objetos y efecto de repulsión en partículas.
- **Elementos DOM**: `createSlider`, `createButton`, `createCheckbox`, `createSelect`, `createColorPicker`, `createInput`.
