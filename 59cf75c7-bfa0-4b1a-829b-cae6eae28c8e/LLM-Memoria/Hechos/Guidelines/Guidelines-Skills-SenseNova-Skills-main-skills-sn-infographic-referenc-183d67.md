# flashback.md

## Resumen
Este documento define la estructura y elementos visuales para crear infografías con escenas principales incrustadas de momentos pasados o futuros. Sirve como guía técnica para diseñar narrativas que expliquen contextos históricos, causas-efectos temporales o proyecciones futuras mediante paneles destacados conectados visualmente.

## Datos clave
- **Concepto central**: Escena principal con ventanas pequeñas (flashbacks/flashforwards).
- **Elementos visuales**: Paneles incrustados con bordes distintos (ej. borde punteado, color sepia), flechas o líneas que conectan la escena principal con los paneles secundarios y etiquetas de tiempo.
- **Uso recomendado**: Explicar "cómo llegamos aquí", mostrar contexto histórico dentro de una narrativa actual o previsualizar escenarios futuros.
- **Estilos sugeridos**: `aged-academia` (paneles históricos), `cartoon-flat` (estilo cómic) y `storybook-watercolor` (ventanas ilustradas).
