# hashicorp.md

## Resumen
Este documento define el sistema de diseño visual de HashiCorp, detallando su estrategia dual de modos claro y oscuro para comunicar infraestructura compleja de manera accesible. Sirve como guía técnica para replicar la tipografía autoritaria, la paleta de colores específica por producto y los componentes basados en tokens CSS del ecosistema MDS.

## Datos clave
- **Tipografía**: Uso primario de HashiCorp Sans (pesos 600–700) con aperturas ajustadas; sustitutos web `Inter` y `JetBrains Mono`.
- **Modos visuales**: Fondo claro (`#f1f2f3`) para contenido informativo vs. modo oscuro dramático (`#15181e`, `#0d0e12`) para héroes.
- **Colores de producto**: Tokens CSS específicos como `--mds-color-terraform-button-background` (#7b42bc) y `--mds-color-vault-button-background` (#ffcf25).
- **Sombras sutiles**: Uso de sombras duales con opacidad 0.05 para profundidad mínima sin perder elegancia.
- **Herramientas sugeridas**: Generación de HTML vía `write_file`, visualización con `browser_vision` y túnel mediante `generative-widgets`.
