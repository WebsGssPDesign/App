# hierarchical-layers.md

## Resumen
Este documento define una guía de diseño para diagramas jerárquicos basados en capas anidadas, organizadas desde un núcleo central hasta una periferia. Sirve como referencia visual para representar conceptos de importancia decreciente, influencia o proximidad mediante estructuras como pirámides o círculos concéntricos.

## Datos clave
- **Estructura**: Múltiples niveles (3 a 7) con límites claros; el nivel superior es más importante.
- **Variantes principales**: Pirámide (triángulo vertical, enfoque top-down/cantidad) y Concéntrica (anillos radiales, enfoque centro-proximidad).
- **Casos de uso ideales**: Jerarquías tipo Maslow, análisis de partes interesadas (stakeholders), estructuras organizacionales y esferas de influencia.
- **Elementos visuales**: Colores distintos por nivel, íconos por capa, tamaño proporcional a la importancia y etiquetas internas o externas.
- **Colaboraciones sugeridas**: Estilos `paper-collage` (conceptos juguetones), `corporate-memphis` (jerarquías empresariales) y `technical-schematic` (pirámides 3D técnicas).
