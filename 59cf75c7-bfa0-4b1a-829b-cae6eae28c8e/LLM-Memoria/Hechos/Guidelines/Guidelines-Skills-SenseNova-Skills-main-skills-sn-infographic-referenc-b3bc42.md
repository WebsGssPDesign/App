# bento-grid.md

## Resumen
Este documento define la estructura y mejores prácticas para implementar un diseño de cuadrícula modular tipo "bento box", ideal para resaltar múltiples temas o características clave. Su función principal es organizar contenido visualmente jerárquico mediante celdas de tamaños variables, priorizando el impacto del elemento principal sobre los secundarios.

## Datos clave
- **Estructura**: Celdas rectangulares con tamaños mixtos (1x1, 2x1, 1x2, 2x2) sin simetría estricta; incluye una celda "Hero" central.
- **Casos de uso**: Resúmenes de dashboards, portafolios y resaltes de funciones.
- **Elementos visuales**: Límites claros, fondos variados por celda, iconos/ilustraciones y jerarquía mediante tamaño.
- **Tipografía**: Título principal arriba, subtítulos internos en cada celda, texto mínimo y máximo impacto visual.
- **Pares recomendados**: `paper-collage` (por defecto), `corporate-memphis`, `pixel-art`.
