# sci-fi-ui.md

## Resumen
Este documento define una guía de estilo para interfaces de ciencia ficción con estética holográfica. Sirve como referencia visual para diseñar elementos futuristas, paneles flotantes y tipografías tecnológicas en proyectos de videojuegos o conceptos espaciales.

## Datos clave
- **Paleta de colores**: Cian, azul y tintes naranjas sobre fondo oscuro (#0D1117) con superposiciones transparentes.
- **Elementos visuales**: Paneles holográficos, líneas de escaneo, rejillas, widgets de visualización de datos y marcos hexagonales/circulares.
- **Tipografía**: Fuentes monoespaciadas y tecnológicas con efectos de brillo y texto estilo lectura de datos.
- **Uso recomendado**: Diseño de UI para videojuegos, temas espaciales y conceptos de tecnología avanzada.
