# modular-repetition.md

## Resumen
Este documento define una estructura de diseño basada en la repetición modular, donde el mismo contenedor se reutiliza para presentar contenido variable. Su objetivo es organizar listas de características, perfiles o instrucciones manteniendo una jerarquía visual y espacial consistente.

## Datos clave
- **Concepto central**: Repetición de módulos idénticos (icono, título, texto) con espaciado fijo.
- **Casos de uso ideales**: Listas de funciones equiponderadas, perfiles de equipo, instrucciones paso a paso y filas de comparación de productos.
- **Elementos visuales**: Contenedores uniformes (tarjetas o celdas), ubicación constante de iconos y ritmo visual mediante colores alternados.
- **Jerarquía textual**: Título general superior al array de módulos; posición fija para subtítulos y cuerpo del texto.
- **Combinaciones recomendadas**: `ikea-manual` (instrucciones limpias), `corporate-memphis` (listas empresariales) y `ui-wireframe` (cuadrículas de componentes).
