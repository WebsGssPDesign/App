# surreal-collage.md

## Resumen
Este documento define las directrices de estilo para crear collages fotográficos surrealistas que mezclan elementos reales en contextos imposibles. Sirve como referencia visual y técnica para diseñadores que buscan evocar sueños, subconsciente o conceptos abstractos mediante composiciones oníricas yuxtapuestas.

## Datos clave
- **Estilo**: Fotomontaje surrealista con yuxtaposiciones imposibles y detalles hiper-reales en contextos ilógicos.
- **Paleta de colores**: Tonos fotográficos realistas ligeramente desplazados, fondos con gradientes oníricos o espacios imposibles, y acentos de color inesperados.
- **Elementos visuales**: Violaciones de escala (objetos gigantes), fusión sin costuras de realidades incompatibles, composiciones flotantes que defían la gravedad y sustituciones de objetos inusuales.
- **Tipografía**: Fuentes sans-serif limpias y neutras para contraste o texto pintado a mano con estilo onírico; se prioriza el minimalismo.
- **Uso ideal**: Contenido de la industria creativa, temas de innovación e imaginación, publicidad conceptual, arte cultural y ideas filosóficas abstractas.
