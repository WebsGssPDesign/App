# page_004.query.txt

## Resumen
Este documento define las especificaciones de diseño para una diapositiva final de presentación sobre "OpenClaw". Su propósito es servir como cierre visual y llamado a la acción, utilizando un esquema de colores oscuros con acentos en azul cielo y elementos puramente textuales para evitar espacios vacíos.

## Datos clave
- **Tema**: Inmediatamente experimentar OpenClaw (Subtítulo: "开启智能自动化之旅").
- **Estilo visual**: Fondo oscuro degradado, tipografía Inter y Noto Sans SC, color principal #2196F3.
- **Elementos de diseño**: Botón central grande con texto (CTA), tres puntos clave horizontales (API abierto, prueba gratuita de 30 días, soporte profesional) y una frase final narrativa.
- **Restricciones**: No hay imágenes; el diseño debe depender exclusivamente del texto y CSS para la estética.
