# story-mountain.md

## Resumen
Este documento define la estructura visual de un diagrama tipo "montaña" para representar arcos narrativos o ciclos de proyectos. Su función es guiar el diseño de infografías que muestren claramente la progresión desde una base inicial, pasando por un punto álgido hasta una resolución final.

## Datos clave
- **Estructura**: Forma de montaña o arco con pendiente ascendente (tensión), pico (clímax) y pendiente descendente (resolución).
- **Elementos visuales**: Curvas suaves, puntos a lo largo del camino y campamentos base como hitos.
- **Ubicación de texto**: Título en la parte superior, etiquetas de etapas a lo largo del sendero y descripciones breves en los puntos clave.
- **Emparejamientos recomendados**: Estilos `storybook-watercolor` para viajes narrativos, `crayon-hand-drawn` para diagramas educativos y `cartoon-flat` para arcos dramáticos.
