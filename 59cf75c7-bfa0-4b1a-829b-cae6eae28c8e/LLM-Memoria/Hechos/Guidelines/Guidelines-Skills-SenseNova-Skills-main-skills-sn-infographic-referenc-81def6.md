# storyboard.md

## Resumen
Este documento define la estructura y variantes para crear layouts de storyboards que imitan planos cinematográficos secuenciales. Sirve como guía visual para explicar narrativas, recorridos de usuario o procesos paso a paso mediante paneles rectangulares con ilustraciones de escenas.

## Datos clave
- **Estructura**: Múltiples paneles rectangulares dispuestos en filas con relación de aspecto cinematográfica (más ancha que alta).
- **Variantes principales**: "Film Storyboard" para narrativas escena por escena y "Process Storyboard" enfocado en acciones paso a paso.
- **Elementos visuales**: Ilustraciones dentro de cada panel, números o timestamps, bordes consistentes y notas opcionales del director debajo.
- **Ubicación de texto**: Descripción de la escena debajo del panel, número del panel en la esquina superior y título general encima de la cuadrícula.
- **Estilos recomendados**: `cartoon-flat`, `crayon-hand-drawn` y `high-contrast-ad`.
