# Biweekly Report.md

## Resumen
Este informe detalla las iteraciones recientes de SenseNova Skills, una biblioteca open-source para automatización de oficina. Destaca mejoras en investigación profunda con CLI independiente, generación de presentaciones PPT unificada y nuevos agentes colaborativos que gestionan contextos a largo plazo.

## Datos clave
- **Proyecto**: SenseNova Skills (automatización de oficina).
- **Herramientas nuevas**: `sn-deepreseach-cli` (investigación profunda), `TeamHarness` (colaboración humano-AI), `sn-proactive-agent` (memoria a largo plazo).
- **Actualizaciones PPT**: Reestructuración completa del pipeline v2 con rutas estáticas y dinámicas (`sn-ppt-entry`, `sn-ppt-dazzle`).
- **Tecnologías**: Soporte para agentes como Codex, Hermes y Claude Code; exportación a Markdown, PDF, Word y HTML.
- **Rutas de flujo**: Comprensión de materiales → investigación opcional → estructura narrativa (outline.md) → generación final.
