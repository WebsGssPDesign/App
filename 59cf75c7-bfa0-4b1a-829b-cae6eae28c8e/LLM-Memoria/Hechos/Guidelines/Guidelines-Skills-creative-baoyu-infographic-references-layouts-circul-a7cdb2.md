# circular-flow.md

## Resumen
Este documento define la estructura y mejores prácticas para crear diagramas de flujo circular que representan procesos cíclicos, bucles de retroalimentación o ciclos naturales sin un inicio ni fin definidos. Sirve como guía visual para organizar conceptos recurrentes en una disposición continua donde el centro puede contener el concepto principal.

## Datos clave
- **Estructura**: Disposición circular con nodos espaciados equitativamente y flechas direccionales que indican flujo continuo.
- **Elementos visuales**: Uso de círculos o anillos, íconos por paso y un elemento opcional en el centro.
- **Ubicación del texto**: Título superior, etiquetas en cada nodo y descripciones breves cerca de los nodos.
- **Estilos recomendados**: `cartoon-hand-drawn` para ciclos amigables, `corporate-memphis` para procesos empresariales y `subway-map` para estilos tipo mapa de tránsito.
