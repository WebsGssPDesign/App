# bento-grid.md

## Resumen
Este documento define la estructura y mejores prácticas para implementar un diseño de rejilla modular tipo "bento box", ideal para resaltar múltiples temas o características clave. Sirve como guía visual para organizar contenido heterogéneo mediante celdas de tamaños variables que priorizan la jerarquía sobre la simetría estricta.

## Datos clave
- **Estructura**: Celdas rectangulares con tamaños mixtos (1x1, 2x1, 1x2, 2x2) y una celda principal destacada ("hero").
- **Uso recomendado**: Resúmenes de dashboards, portafolios, resúmenes corporativos y presentaciones de características.
- **Elementos visuales**: Límites claros entre celdas, fondos variados, iconos/ilustraciones por celda y jerarquía mediante el tamaño.
- **Tipografía**: Título principal en la parte superior, subtítulos dentro de cada celda y texto mínimo para maximizar lo visual.
- **Pares sugeridos**: `craft-handmade` (para resúmenes amigables), `corporate-memphis` (resúmenes empresariales) y `pixel-art` (cuadrículas retro).
