# synthwave.md

## Resumen
Este documento define una guía de estilo visual inspirada en la estética synthwave de los años 80. Su propósito es estandarizar el uso de colores neón, elementos retro-futuristas y tipografías metálicas para campañas de entretenimiento, gaming y promociones nocturnas.

## Datos clave
- **Paleta de colores**: Rosa intenso (#FF006E), púrpura eléctrico (#7B2FBE), cian (#00F5FF) sobre fondo negro profundo (#0A0015).
- **Elementos visuales**: Rejilla de perspectiva, sol retro con cortes horizontales, efectos cromados, destellos de lente y líneas de escaneo VHS.
- **Tipografía**: Fuentes retro cursivas o inclinadas con relleno metálico, bordes neón y estilos condensados o anchos.
- **Casos de uso ideales**: Contenido musical, campañas temáticas retro, visuales para videojuegos y promoción de eventos nocturnos.
