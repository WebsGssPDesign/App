# SKILL.md

## Resumen
Este documento describe la guía de uso de Weights & Biases (W&B), una plataforma para el seguimiento de experimentos de aprendizaje automático y MLOps. Sirve para visualizar entrenamientos en tiempo real, optimizar hiperparámetros mediante barridos automáticos y gestionar registros de modelos con control de versiones.

## Datos clave
- **Proyecto**: Weights & Biases (W&B) para gestión del ciclo de vida de ML.
- **Tecnologías**: Python, PyTorch, TensorFlow, HuggingFace.
- **Comandos e instalación**: `pip install wandb`, `wandb login`.
- **Conceptos principales**: Inicialización de ejecuciones (`wandb.init`), registro de métricas escalares y media (imágenes/tablas), guardado de artefactos y modelos, y configuración de barridos de hiperparámetros (`wandb.sweep`).
- **Flujo de trabajo**: Definir proyecto -> Iniciar run -> Loggear métricas en bucle de entrenamiento -> Guardar checkpoints o artefactos.
