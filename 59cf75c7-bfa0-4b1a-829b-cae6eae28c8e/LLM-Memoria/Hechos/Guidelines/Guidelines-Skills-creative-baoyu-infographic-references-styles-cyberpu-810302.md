# cyberpunk-neon.md

## Resumen
Este documento define una paleta de colores y elementos visuales para un estilo estético "cyberpunk-neon". Sirve como guía técnica para diseñar interfaces o gráficos con atmósferas futuristas, utilizando contrastes altos entre neones brillantes sobre fondos oscuros.

## Datos clave
- **Proyecto**: Estilo visual Cyberpunk Neon.
- **Paleta de colores**: Rosa neón (#FF00FF), cian (#00FFFF) y azul eléctrico como primarios; fondo negro profundo (#0A0A0A) con degradados púrpuras.
- **Elementos visuales**: Contornos brillantes, efectos de glitch digital, patrones de circuitos, elementos holográficos y reflejos de lluvia.
- **Tipografía**: Fuentes digitales/tecnológicas con efectos parpadeantes y letras con brillo en contorno.
- **Uso recomendado**: Contenido de videojuegos, cultura digital, conceptos futuristas y estética nocturna.
