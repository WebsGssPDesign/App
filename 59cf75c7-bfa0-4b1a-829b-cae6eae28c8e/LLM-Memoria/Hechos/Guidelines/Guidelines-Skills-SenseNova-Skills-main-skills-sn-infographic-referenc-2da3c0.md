# hidden-details.md

## Resumen
Este documento define una estructura para infografías interactivas donde elementos pequeños se ocultan dentro de ilustraciones complejas para ser descubiertos por el espectador. Su propósito es aumentar la participación del usuario mediante formatos tipo "encuentra la diferencia" o resúmenes visuales de sistemas detallados que requieren exploración activa.

## Datos clave
- **Proyecto**: SenseNova-Skills (sección de infografías).
- **Estructura recomendada**: Ilustración rica como lienzo principal con objetos ocultos integrados; leyenda opcional al final.
- **Ubicación del texto**: Título e instrucciones arriba, leyenda abajo; minimizar texto dentro de la escena para no interferir con el descubrimiento.
- **Estilos visuales sugeridos**: `storybook-watercolor` (acuarela), `crayon-hand-drawn` (dibujo a mano alzada) y `pixel-art`.
