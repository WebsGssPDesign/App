# multi-focal.md

## Resumen
Este documento define la estructura y mejores prácticas para crear diagramas visuales con múltiples puntos focales interconectados. Sirve como guía técnica para diseñar infografías que presenten temas complejos, redes o sistemas donde ninguna parte domina sobre las demás, utilizando conectores visuales para guiar el flujo de lectura.

## Datos clave
- **Concepto central**: Distribución equitativa de varios puntos focales prominentes en un lienzo único.
- **Mecanismo de navegación**: Uso de líneas, flechas o codificación por color para establecer el orden secuencial sin jerarquía dominante.
- **Casos de uso ideales**: Diagramas de redes, resúmenes de múltiples temas con peso igual y narrativas de eventos simultáneos.
- **Elementos visuales requeridos**: Elementos de alto contraste, líneas conectivas, insignias numeradas o claves de color, y etiquetas cercanas a cada foco.
- **Posicionamiento del texto**: Etiquetas adyacentes a los focales, títulos en zonas neutras (arriba o abajo) y subtítulos subordinados.
- **Combinaciones recomendadas**: `subway-map` para mapas de red, `corporate-memphis` para resúmenes empresariales y `technical-schematic` para diagramas de arquitectura de sistemas.
