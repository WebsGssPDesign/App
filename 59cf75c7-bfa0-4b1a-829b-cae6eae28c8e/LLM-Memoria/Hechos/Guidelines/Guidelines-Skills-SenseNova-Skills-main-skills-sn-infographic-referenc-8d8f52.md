# skewed-grid.md

## Resumen
Este documento describe la estructura y aplicación de una cuadrícula inclinada ("skewed-grid") para diseños visuales. Su función principal es generar dinamismo y energía en composiciones modernas, alineando los bloques de contenido con un ángulo rotado entre 5 y 30 grados mientras mantiene el orden interno.

## Datos clave
- **Proyecto**: Layouts para infografías (SenseNova).
- **Tecnologías/Estilos**: `neon-futurism`, `high-contrast-ad`, `corporate-memphis`.
- **Decisiones de diseño**: Rotación de la cuadrícula entre 5° y 30°.
- **Elementos visuales**: Líneas de cuadratura rotadas como estructura base, bloques alineados al ángulo y fondo horizontal para contraste.
- **Colocación de texto**: El título puede permanecer horizontal para legibilidad, mientras que las etiquetas siguen la rotación de la cuadrícula.
