# speech-bubbles.md

## Resumen
Este documento define las directrices para crear diseños de infografías que utilicen burbujas de diálogo dirigidas a personajes o sujetos específicos. Sirve como referencia visual y estructural para organizar contenido conversacional, monólogos internos o anotaciones mediante formas gráficas distintivas.

## Datos clave
- **Estructura**: Personajes posicionados alrededor del lienzo con burbujas que apuntan a ellos; permite mostrar múltiples perspectivas simultáneamente.
- **Variantes principales**: Diálogo (conversación alterna), Pensamiento (monólogo interno en forma de nube) y Anotación (etiquetas con punteros).
- **Elementos visuales**: Uso de avatares como anclas, colas de las burbujas para indicar el hablante y codificación por colores.
- **Colocación del texto**: El contenido va dentro de la burbuja, los nombres debajo de los avatares y el título fuera del grupo.
- **Emparejamientos recomendados**: Estilos `cartoon-flat`, `kawaii` y `crayon-hand-drawn`.
