# single-object-art.md

## Resumen
Este documento define la guía de estilo para crear imágenes de "arte de objeto único", donde un producto se presenta como una pieza escultórica o artística. Su propósito es elevar objetos cotidianos mediante iluminación profesional y fondos limpios, ideal para destacar productos heroicos o mostrar materiales con un enfoque minimalista.

## Datos clave
- **Estructura**: Un solo objeto como sujeto principal con reverencia artística; fondo mínimo o nulo.
- **Iluminación**: Uso de luz dramática, sombras definidas y reflejos opcionales.
- **Texto**: Nombre del título debajo del sujeto y descripciones breves sin superponerse al objeto.
- **Fondos**: Limpios o degradados para evitar elementos distractores.
- **Emparejamientos recomendados**: `knolling` (disposición plana), `technical-schematic` (esquemas técnicos) y `aged-academia` (presentación de especímenes).
