# SKILL.md

## Resumen
Este documento describe un flujo de trabajo en Python para analizar datos en archivos Excel con múltiples hojas. El proceso incluye limpieza, agrupación estadística y generación de informes visuales y tabulares estéticos. Sirve como guía técnica para automatizar el análisis de datos y producir resultados presentables sin intervención manual extensa.

## Datos clave
- **Proyecto**: sn-da-excel-workflow (análisis de datos en Excel).
- **Tecnologías**: Python, pandas, matplotlib, openpyxl, re.
- **Pasos principales**:
  1. Limpieza: manejo de celdas fusionadas (`ffill`), filtrado con expresiones regulares y mapeo de categorías.
  2. Estadística: agrupamiento (`groupby`) para contar y sumar, cálculo de porcentajes y agregación de fila total.
  3. Visualización: creación de gráficos de barras con soporte para caracteres chinos y etiquetas numéricas.
  4. Reporte: generación de Excel final con encabezados coloreados, bordes y resaltado condicional (celdas verdes).
