# multi-directional.md

## Resumen
Este documento define las directrices para crear composiciones visuales con elementos orientados en tres o más direcciones simultáneamente. Su propósito es facilitar la visualización de conceptos complejos, mapas mentales y presentaciones que requieren mostrar múltiples perspectivas desde un punto central cohesivo.

## Datos clave
- **Estructura**: Mínimo 3 direcciones distintas para lograr efectos radiales, explosivos o caóticos con estilo consistente.
- **Casos de uso ideales**: Visualizaciones de conceptos "explosivos", contenido multi-perspectiva, mapas de lluvia de ideas y presentaciones abstractas.
- **Elementos visuales**: Uso de etiquetas alineadas a su dirección específica, un elemento central ancla y codificación por colores según la dirección.
- **Estilos recomendados**: `cartoon-flat` para composiciones explosivas, `crayon-hand-drawn` para diseños radiales hechos a mano y `kawaii` para estallidos tiernos.
