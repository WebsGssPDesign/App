# lego-brick.md

## Resumen
Este archivo define una guía de estilo visual basada en la estética de construcción con bloques tipo LEGO. Sirve para establecer una identidad gráfica juguetona y modular, ideal para conceptos creativos, sistemas educativos infantiles o contenido lúdico que requiera un aspecto tridimensional y colorido.

## Datos clave
- **Estilo visual**: Construcción modular con elementos apilables y brillo plástico simulado.
- **Paleta de colores**: Colores primarios clásicos (rojo, azul, amarillo, verde) sobre fondo gris claro o blanco.
- **Tipografía**: Fuentes gruesas y cuadradas que imitan las instrucciones oficiales de LEGO.
- **Elementos gráficos**: Incluir protuberancias visibles en los bloques y personajes tipo minifigura.
- **Aplicaciones recomendadas**: Educación infantil, sistemas modulares y contenido para niños.
