# high-contrast-ad.md

## Resumen
Este archivo define una guía de estilo para publicidad de alto contraste diseñada para maximizar el impacto visual. Sirve como referencia técnica para crear composiciones gráficas llamativas en campañas de marketing y materiales promocionales que requieren atención inmediata del espectador.

## Datos clave
- **Estilo**: Alto contraste con formas geométricas, diagonales dinámicos y patrones de puntos halftone.
- **Paleta de colores**: Primarios intensos (rojo, amarillo, azul), negro/blanco para fondos y acentos neón.
- **Tipografía**: Fuentes de impacto para titulares, textos grandes en negrita y énfasis en llamadas a la acción.
- **Uso recomendado**: Campañas publicitarias, contenido que busca captar la atención y visuales promocionales audaces.
