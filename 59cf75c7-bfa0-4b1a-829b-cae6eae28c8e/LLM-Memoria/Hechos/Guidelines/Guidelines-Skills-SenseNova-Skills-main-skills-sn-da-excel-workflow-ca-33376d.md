# SKILL.md

## Resumen
Este documento describe un flujo de trabajo en Python para analizar tendencias en datos de Excel mediante evaluación por niveles y predicción basada en crecimiento diferenciado. Su objetivo es generar métricas agregadas y visualizaciones comparativas útiles para evaluaciones de rendimiento y establecimiento de objetivos estratégicos.

## Datos clave
- **Tecnologías**: Pandas, NumPy, Matplotlib.
- **Lógica de negocio**: Clasificación de datos en tres niveles (alto, medio, bajo) basándose en el percentil 30/70.
- **Reglas de crecimiento**: Se aplican tasas diferenciadas: +10% para alto rendimiento, +8% para medio y +15% para bajo rendimiento.
- **Visualización**: Generación de gráficos de barras horizontales que contrastan valores actuales frente a predicciones por categoría.
- **Configuración**: Uso obligatorio de fuentes chinas (WenQuanYi Zen Hei) para garantizar la legibilidad en etiquetas y ejes.
