# hub-spoke.md

## Resumen
Este documento define la estructura y mejores prácticas para crear diagramas de tipo "hub-spoke" (centro-hub), ideales para visualizar conceptos centrales conectados a elementos relacionados. Sirve como guía técnica para diseñar infografías que muestren ecosistemas, roles de equipo o características de productos con una distribución equilibrada y clara.

## Datos clave
- **Concepto central**: Un nodo principal rodeado por nodos secundarios conectados mediante líneas radiantes.
- **Casos de uso**: Mapeo de ecosistemas, diagramas de roles del equipo, mapas mentales y características de productos.
- **Elementos visuales requeridos**: Hub prominente en el centro, líneas de conexión claras, iconos para cada nodo y estilos consistentes.
- **Colocación de texto**: Título arriba, concepto central en el hub, etiquetas breves en los nodos y descripciones cercanas a ellos.
- **Estilos recomendados**: `crayon-hand-drawn` (mapas conceptuales amigables), `corporate-memphis` (ecosistemas empresariales) y `subway-map` (conexiones tipo red).
