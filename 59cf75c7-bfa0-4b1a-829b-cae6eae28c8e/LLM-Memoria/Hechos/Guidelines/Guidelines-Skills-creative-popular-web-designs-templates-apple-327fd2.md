# apple.md

## Resumen
Este documento define el sistema de diseño visual de Apple, centrado en una estética minimalista y cinematográfica que prioriza la fotografía del producto sobre elementos decorativos. Establece reglas estrictas para tipografía, paleta de colores binaria (negro/blanco) y el uso exclusivo del azul corporativo para interactividad. Sirve como guía técnica para replicar fielmente la atmósfera premium y la jerarquía visual de las páginas web oficiales de Apple en entornos autocontenidos.

## Datos clave
- **Tipografía:** Sustitución de fuentes propietarias (SF Pro) mediante pilas de sistema (`system-ui`, `SF Mono`) para HTML independiente.
- **Paleta de colores:** Fondo negro puro (`#000000`) alternado con gris claro (`#f5f57`), texto blanco y azul interactivo único (`#0071e3`).
- **Reglas tipográficas:** Altura de línea ajustada (1.07 para títulos) y espaciado de letras negativo en encabezados grandes.
- **Herramientas sugeridas:** Uso de `write_file` para generar HTML, `generative-widgets` para servir y `browser_vision` para verificación visual.
