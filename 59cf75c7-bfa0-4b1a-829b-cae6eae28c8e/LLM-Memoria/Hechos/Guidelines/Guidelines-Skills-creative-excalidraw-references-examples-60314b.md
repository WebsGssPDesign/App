# examples.md

## Resumen
Este archivo proporciona ejemplos de código JSON listos para copiar y pegar que generan diagramas funcionales en Excalidraw. Su utilidad principal es servir como referencia técnica para estructurar elementos gráficos, asegurando el uso correcto del enlace de contenedores (`containerId`) para evitar etiquetas vacías.

## Datos clave
- **Formato**: JSON con la estructura `excalidraw` (versión 2).
- **Regla crítica**: Usar `boundElements` en lugar de la propiedad `"label"` para vincular texto a formas.
- **Ejemplos incluidos**: Un flujo simple de inicio-fin y un diagrama detallado del proceso de fotosíntesis con zonas, nodos y flechas direccionales.
- **Propiedades clave**: `containerId`, `boundElements`, `startBinding`/`endBinding` para anclar elementos.
