# gmail-search-syntax.md

## Resumen
Este documento detalla la sintaxis de búsqueda avanzada para Gmail, proporcionando una referencia rápida sobre operadores estándar y combinaciones lógicas. Sirve como guía técnica para filtrar correos electrónicos por estado, fecha, remitente, tamaño o contenido específico mediante consultas estructuradas en el argumento `query`.

## Datos clave
- **Operadores comunes**: `is:unread`, `in:inbox`, `from:`, `has:attachment`, `filename:`.
- **Filtrado temporal**: Uso de `newer_than:` (días, meses, años) y `older_than:` para rangos de fecha.
- **Lógica booleana**: Combinación implícita con espacios, uso explícito de `OR`, exclusión con `-` y agrupación con `()`.
- **Patrones prácticos**: Ejemplos incluyen búsqueda de correos no leídos recientes, archivos PDF adjuntos de un remitente específico y eliminación de archivos grandes antiguos.
