# header-body.md

## Resumen
Este documento define la estructura y mejores prácticas para diseñar encabezados en infografías de larga duración, informes y diapositivas. Su objetivo es guiar el uso de zonas visuales contrastadas con tipografía grande para destacar títulos y subtítulos, dejando el contenido principal en un área limpia inferior.

## Datos clave
- **Estructura**: Zona de encabezado (15-25%) con título, subtítulo y visual; zona de cuerpo (75-85%) para contenido principal.
- **Contraste**: Se requiere un fuerte contraste visual entre el encabezado y el cuerpo, usando colores o imágenes distintivas.
- **Elementos visuales**: Tipografía negrita grande, fondos decorativos/ilustrativos e iconos opcionales.
- **Ubicación de texto**: El título principal va en la zona superior; subtítulos y fechas debajo; todo el contenido del cuerpo en la zona inferior.
- **Emparejamientos recomendados**: `corporate-memphis` (informes profesionales), `high-contrast-ad` (anuncios de alto impacto) y `chalkboard` (encabezados educativos).
