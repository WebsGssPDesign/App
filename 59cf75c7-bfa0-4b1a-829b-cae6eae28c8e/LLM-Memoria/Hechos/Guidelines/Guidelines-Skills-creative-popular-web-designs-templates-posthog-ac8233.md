# posthog.md

## Resumen
Este documento define el sistema de diseño visual de PostHog, caracterizado por una estética cálida y anti-corporativa que utiliza tonos oliva y crema en lugar del típico azul SaaS. Su objetivo es guiar la implementación técnica para replicar fielmente este estilo único mediante componentes modernos como Tailwind CSS y Radix UI.

## Datos clave
- **Tecnologías**: Tailwind CSS, Radix UI, shadcn/ui, generative-widgets skill.
- **Tipografía**: IBM Plex Sans Variable (display/cuerpo) y JetBrains Mono/Source Code Pro (código).
- **Paleta de colores**: Fondo "Warm Parchment" (#fdfdf8), texto "Olive Ink" (#4d4f46), acento oculto "PostHog Orange" (#F54E00) en hover.
- **Decisiones de diseño**: Uso de ilustraciones manuales, ausencia de gradientes y bordes con tinte salvia (#bfc1b7).
- **Flujo de trabajo**: Generar HTML con `write_file`, servir vía túnel cloudflared y validar visualmente con `browser_vision`.
