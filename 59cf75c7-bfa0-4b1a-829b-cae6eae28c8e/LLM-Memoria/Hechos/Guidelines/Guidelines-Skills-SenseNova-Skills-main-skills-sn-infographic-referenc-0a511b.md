# data-landscape.md

## Resumen
Este documento define las pautas para visualizar datos de alta dimensión como terrenos o nubes de puntos en 3D. Sirve como guía técnica para representar variables complejas mediante superficies, gradientes de color y etiquetas de ejes, optimizando la interpretación científica y espacial.

## Datos clave
- **Concepto central**: Mapeo de valores a superficies 3D donde picos indican altos valores y valles bajos.
- **Codificación visual**: Uso de gradientes de color para dimensiones adicionales y líneas de contorno opcionales.
- **Ubicación del texto**: Etiquetas en los bordes, títulos superiores y leyendas explicativas.
- **Casos de uso ideales**: Análisis geográfico, estudios de densidad/distribución y presentaciones de investigación científica.
- **Combinaciones recomendadas**: `technical-schematic`, `neon-futurism` y `ui-wireframe`.
