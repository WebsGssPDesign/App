# structured-content-template.md

## Resumen
Este documento es una plantilla de referencia para crear contenido estructurado destinado a diseñadores visuales. Su función principal es transformar material fuente en un formato listo para el diseño, separando estrictamente los datos verbatim de las instrucciones estéticas y de layout.

## Datos clave
- **Proyecto**: Generación de infografías educativas basadas en análisis de contenido.
- **Tecnologías**: Formato Markdown para la estructura del texto.
- **Decisiones**: Se prohíbe cualquier paráfrasis; todos los datos, estadísticas y citas deben copiarse textualmente (verbatim).
- **Pasos importantes**:
  1. Definir título, visión general y objetivos de aprendizaje.
  2. Desarrollar secciones con concepto clave, contenido verbatim, elemento visual y etiquetas de texto exactas.
  3. Recopilar puntos de datos, citas y términos clave en una sección dedicada.
  4. Extraer instrucciones de estilo, layout y requisitos del usuario.
- **Reglas críticas**: Mantener tono de entrenador experto, usar solo información fuente y evitar añadir ejemplos no presentes originalmente.
