# minimax.md

## Resumen
Este documento define el sistema de diseño para la web de MiniMax, una empresa de IA china, enfocándose en un estilo limpio y amigable que combina claridad técnica con elementos visuales coloridos. Sirve como guía para replicar fielmente la atmósfera visual, tipografía multifuente y paleta de colores del sitio original utilizando tecnologías web estándar.

## Datos clave
- **Proyecto:** Diseño del sistema MiniMax (Hermes Agent).
- **Tipografías:** DM Sans (UI), Outfit (display), Poppins (encabezados medios) y Roboto (datos técnicos).
- **Substitución de fuentes:** Uso de `Inter` y `JetBrains Mono` vía CDN para evitar dependencias propietarias.
- **Geometría distintiva:** Botones tipo píldora (radio 9999px) y tarjetas con bordes redondeados suaves (8px–24px).
- **Paleta de colores:** Azul marca (`#1456f0`), rosa secundario (`#ea5ec1`) y fondos blancos dominantes.
- **Sombras:** Uso de sombras con tinte púrpura para crear profundidad de marca.
- **Flujo de trabajo:** Generar HTML con `write_file`, servir mediante `generative-widgets` y verificar visualmente con `browser_vision`.
