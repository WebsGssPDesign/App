# visual-design.md

## Resumen
Este documento establece principios de diseño visual y plantillas de layout para crear videos educativos con Manim, priorizando la claridad geométrica sobre lo algebraico. Su objetivo es guiar a los creadores en la construcción de escenas coherentes que mantengan la atención del espectador mediante un uso intencional del color, el espacio y la jerarquía visual.

## Datos clave
- **Principios**: Geometría antes de álgebra, opacidad por capas (PRIMARY=1.0), una idea nueva por escena y fondo oscuro (#1C1C1C).
- **Layouts**: FULL_CENTER para ecuaciones simples, LEFT_RIGHT para comparaciones, PROGRESSIVE para algoritmos paso a paso.
- **Tipografía**: Uso obligatorio de fuentes monoespaciadas (Menlo, JetBrains Mono) para evitar problemas de kerning en Pango; texto mínimo 18px.
- **Colores**: Paletas definidas como Classic 3B1B y Warm Academic asignando colores a conceptos específicos.
- **Comandos**: `self.wait(1.5)` para pausas, `MathTex` para fórmulas matemáticas en lugar de texto plano.
