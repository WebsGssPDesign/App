# sn-infographic-examples_CN.md

## Resumen
Este documento presenta una galería de casos de uso para la herramienta `sn-infographic`, que genera infografías visuales basadas en prompts detallados. Su función es servir como inspiración y referencia técnica para crear diagramas complejos, desde estructuras mecánicas hasta conceptos de inteligencia artificial, utilizando estilos gráficos específicos.

## Datos clave
- **Proyecto**: `sn-infographic` (capacidades base provistas por `sn-image-base`).
- **Tecnologías**: Generación de imágenes con IA, diseño técnico, estética "glassmorphism" y diagramas de arquitectura neuronal.
- **Decisiones de diseño**: Uso de composiciones horizontales 16:9, paletas de colores industriales (azul ingeniero, gris metálico) y estilos futuristas oscuros para productos tecnológicos.
- **Ejemplos destacados**: Diagrama de explosión de cámara interna con etiquetas precisas; Infografía del modelo "SenseNova-U1" destacando su arquitectura NEO-Unify y capacidades multimodales.
