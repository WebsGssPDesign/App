# ui-wireframe.md

## Resumen
Este documento define un estilo de diseño para maquetas de interfaz en escala de grises, ideal para explicar flujos de usuario y conceptos de aplicaciones sin distracciones visuales. Sirve como guía técnica para mantener la consistencia en wireframes mediante una paleta específica, elementos gráficos simples y tipografía estándar.

## Datos clave
- **Paleta de colores**: Gris claro (#E5E5E5), gris medio (#9CA3AF), gris oscuro (#374151), fondo blanco (#FFFFFF) y acentos en azul (#3B82F6) y rojo.
- **Elementos visuales**: Uso de cajas, marcadores 'X' para imágenes, iconos de línea simple, layouts basados en rejilla y anotaciones.
- **Tipografía**: Fuentes del sistema con texto relleno "Lorem ipsum" y estilo sans-serif generalizado.
- **Casos de uso**: Diseños de productos, explicaciones de UI, conceptos de apps y diagramas de flujo.
