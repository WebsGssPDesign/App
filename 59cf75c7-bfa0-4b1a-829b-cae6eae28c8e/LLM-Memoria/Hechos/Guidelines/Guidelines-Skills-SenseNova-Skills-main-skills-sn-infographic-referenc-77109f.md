# single-focal-point.md

## Resumen
Este documento define la estructura y mejores prácticas para diseños con un único punto focal visual, ideal para destacar productos o mensajes clave mediante el uso de contraste y espacio negativo. Sirve como guía técnica para crear composiciones minimalistas donde un elemento dominante captura toda la atención del espectador sin distracciones.

## Datos clave
- **Concepto central**: Un solo elemento dominante en posición primaria con fuerte contraste respecto al fondo.
- **Elementos visuales**: Uso de viñetas sutiles o gradientes radiales para dirigir la mirada; fondos limpios o desenfocados.
- **Tipografía**: Títulos ubicados arriba o abajo del sujeto principal, evitando texto que compita visualmente.
- **Combinaciones recomendadas**: `knolling` (disposición plana de productos), `high-contrast-ad` y `ui-wireframe`.
