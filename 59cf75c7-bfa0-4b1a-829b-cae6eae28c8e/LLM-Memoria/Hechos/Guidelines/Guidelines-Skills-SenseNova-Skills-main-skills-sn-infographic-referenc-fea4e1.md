# macro-closeup.md

## Resumen
Este documento define la estructura y elementos visuales para un formato de "macro-closeup", donde un detalle mínimo ocupa todo el lienzo. Sirve como guía técnica para crear imágenes que revelen complejidad oculta, ideal para mostrar texturas, explicar detalles científicos o resaltar la calidad de productos.

## Datos clave
- **Estructura**: El sujeto debe llenar la mayor parte del canvas con un fondo mínimo y profundidad de campo reducida (bordes borrosos).
- **Elementos visuales**: Indicadores de escala opcionales (regla, moneda) y líneas de llamada (callout lines) para señalar detalles específicos.
- **Ubicación de texto**: Títulos en la parte superior o inferior con huella mínima; etiquetas conectadas a los detalles mediante líneas.
- **Parejas recomendadas**: Se sugiere combinar este estilo con `technical-schematic` (vistas de ingeniería), `aged-academia` (ilustraciones de especímenes) y `knolling` (fotos planas).
