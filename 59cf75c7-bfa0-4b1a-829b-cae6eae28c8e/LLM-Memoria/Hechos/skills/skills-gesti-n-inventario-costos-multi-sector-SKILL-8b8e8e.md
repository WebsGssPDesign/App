# SKILL.md

## Resumen
Esta guía estandariza el cálculo de precios para inventarios en sectores como gaming, iluminación y cuidado personal, automatizando la conversión entre USD y UYU. Su función principal es eliminar cálculos manuales al actualizar tipos de cambio o costos de importación, integrando control de ventas con sistemas ERP.

## Datos clave
- **Proyecto**: Gestión de inventario multi-sector (gaming, iluminación, cuidado personal).
- **Tecnologías**: Hojas de cálculo y scripts básicos para procesamiento de datos.
- **Decisiones**: Mantener separación estricta entre costos en USD y precios locales hasta la actualización del tipo de cambio.
- **Rutas de archivos fuente**: `Context/emprendimientos/proyectosInconclusos/erp/readme.md`, carpetas de respaldo con `costos.txt` para sectores específicos (ej. `cuidadoPersonal/costos.txt`).
- **Pasos críticos**: Recopilar costos declarados, estandarizar descripciones y códigos únicos, aplicar tipos de cambio actuales sumando IVA, y validar coincidencia de códigos en el ERP para evitar duplicidades.
