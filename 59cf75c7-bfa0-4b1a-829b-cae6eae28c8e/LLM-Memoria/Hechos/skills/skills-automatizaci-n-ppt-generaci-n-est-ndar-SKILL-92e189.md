# SKILL.md

## Resumen
Este documento define el flujo de trabajo del generador de presentaciones estándar SenseNova, diseñado para crear archivos PPTX o HTML automáticamente a partir de datos estructurados preexistentes. Su función principal es orquestar la renderización visual respetando estrictamente el contenido y el orden lógico provistos por el usuario sin inventar información.

## Datos clave
- **Proyecto**: Generador de Presentaciones Estándar SenseNova.
- **Entradas requeridas**: Archivos `outline.md` (esquema) o `task_pack.json` (datos estructurados).
- **Módulos disponibles**: `standard` (corporativo), `dazzle` y `creative` (estilos avanzados según parámetros).
- **Reglas críticas**: Nunca generar contenido nuevo ni alterar la secuencia lógica definida en las entradas originales.
- **Orquestación**: El sistema enruta automáticamente la tarea al módulo adecuado basándose en los datos de entrada y aplica plantillas corporativas estrictas.
