# SKILL.md

## Resumen
Este documento define una habilidad técnica para automatizar la creación de reportes Excel avanzados, como tablas dinámicas y gráficos embebidos, utilizando scripts de Python. Su objetivo es optimizar el flujo de trabajo al permitir la lectura, limpieza, filtrado condicional y exportación de datos sin intervención manual.

## Datos clave
- **Proyecto**: Automatización de reportes Excel avanzados con Python.
- **Tecnologías**: `pandas` para manipulación de datos y limpieza; `matplotlib` para visualizaciones (histogramas, diagramas de pastel).
- **Pasos críticos**: Normalizar formatos numéricos antes de filtrar; validar integridad comparando totales calculados contra valores esperados.
- **Filtros avanzados**: Aplicación de condiciones basadas en rangos numéricos, colores RGB y expresiones regulares.
- **Restricciones**: No incluir contraseñas ni tokens; marcar pasos no detallados como "pendiente de confirmar".
