# SKILL.md

## Resumen
Esta guía detalla cómo crear diagramas de arquitectura técnica profesionales, oscuros y escalables utilizando únicamente HTML, CSS y SVG incrustados. Su objetivo es permitir la visualización autónoma de sistemas complejos sin depender de herramientas externas ni claves API, garantizando que el archivo funcione en cualquier navegador.

## Datos clave
- **Tecnologías**: HTML5, CSS3, SVG (Scalable Vector Graphics).
- **Estilo visual**: Tema oscuro, perspectiva isométrica 2.5D con capas horizontales conectadas verticalmente.
- **Requisito de autonomía**: El archivo debe ser un documento único que renderice sin conexión a internet ni librerías externas.
- **Pasos críticos**: Estructurar el contenido en apilamiento isométrico, definir elementos geométricos (cajas, flechas) dentro del código SVG y asegurar la incrustación directa.
- **Errores a evitar**: Dependencia de cuentas de usuario o servicios externos, mala estructuración de jerarquías y falta de autenticidad del documento.
