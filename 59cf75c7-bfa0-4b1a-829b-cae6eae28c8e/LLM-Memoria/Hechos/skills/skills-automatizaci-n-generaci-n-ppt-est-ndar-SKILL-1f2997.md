# SKILL.md

## Resumen
Este documento define un flujo automatizado para transformar datos crudos en presentaciones PowerPoint profesionales mediante scripts y agentes de IA. Su objetivo es estandarizar la creación de diapositivas, evitando diseños genéricos y asegurando una calidad visual robusta a través de módulos específicos como SenseNova.

## Datos clave
- **Proyecto**: Automatización de generación de PPT estándar dentro del ecosistema SenseNova.
- **Tecnologías**: Manipulación de archivos `.pptx`, orquestación con agentes Hermes y OpenClaw, exportación a HTML/PPTX.
- **Decisiones**: Selección dinámica de módulos (standard, dazzle o creative) basada en la investigación inicial si no se especifica un estilo.
- **Pasos importantes**: Ingesta y enrutamiento de datos -> Selección del módulo de diseño -> Ejecución con agentes -> Validación de calidad final antes de la entrega.
