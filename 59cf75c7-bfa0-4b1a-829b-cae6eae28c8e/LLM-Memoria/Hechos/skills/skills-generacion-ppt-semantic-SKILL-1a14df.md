# SKILL.md

## Resumen
Esta habilidad permite generar presentaciones PowerPoint (.pptx) coherentes y visualmente consistentes directamente desde un prompt único, sin necesidad de archivos de entrada previos. Su función es sintetizar información semántica para estructurar diapositivas, gráficos y textos basándose en parámetros explícitos como tema, diseño y audiencia.

## Datos clave
- **Parámetros obligatorios**: Tema central, número de diapositivas, paleta de colores, estilo visual y perfil de audiencia deben definirse claramente en la solicitud inicial.
- **Flujo de trabajo**: 1) Definir parámetros completos; 2) Ejecutar generación mediante el agente para crear estructura lógica; 3) Validar que el archivo resultante cumpla con las instrucciones de diseño y conteo.
- **Restricciones críticas**: La generación no admite archivos de entrada previos ni debe incluir contraseñas, claves o tokens en los parámetros.
- **Errores a evitar**: Omitir especificaciones de estilo (resultando en presentaciones genéricas) o solicitar muchas páginas sin suficiente contenido semántico para llenarlas coherentemente.
