# SKILL.md

## Resumen
Este documento es una guía técnica para desarrollar la landing page de "Sose Transporte", enfocada en servicios logísticos y mudanzas. Su objetivo principal es estructurar una interfaz moderna que combine estilos neumórficos y glassmorphism, priorizando el uso exclusivo de fotografías reales del cliente sobre ilustraciones para generar confianza.

## Datos clave
- **Proyecto**: Landing page corporativa para Sose Transporte (servicios de transporte y logística).
- **Estilos visuales**: Neumorfismo y Glassmorphism bajo la estética "Neumorphic Glass Corporate".
- **Secciones críticas**: Rastreo de envíos, visualización de flota y formulario de contacto.
- **Requisito principal**: Uso obligatorio de fotografías reales; prohibido el uso de renders o gráficos generados por IA.
- **Contenido comercial**: Debe incluir tarifas base, zonas de cobertura (ej. Montevideo) y métodos de pago.
- **Flujo de trabajo**: Configurar layout -> Aplicar diseño visual -> Integrar imágenes reales -> Definir contenido comercial.
