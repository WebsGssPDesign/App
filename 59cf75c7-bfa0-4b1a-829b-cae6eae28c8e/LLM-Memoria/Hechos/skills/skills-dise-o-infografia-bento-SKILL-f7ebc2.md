# SKILL.md

## Resumen
Este documento describe una técnica de diseño para crear layouts tipo "Bento Grid" utilizando CSS Grid, ideales para dashboards e infografías técnicas. Su objetivo es organizar contenido heterogéneo mediante celdas de tamaños variables que priorizan la jerarquía visual sobre la simetría estricta.

## Datos clave
- **Tecnología**: CSS Grid (`display: grid`, `grid-template-columns`, `gap`).
- **Pasos principales**: Definir estructura base con filas/columnas dinámicas, asignar tamaños variables a las celdas según importancia (ej. `span 2` para elementos clave) y validar consistencia modular.
- **Reglas de diseño**: Priorizar la jerarquía visual del contenido sobre la simetría perfecta; mantener espaciado (`gap`) uniforme entre todas las celdas.
- **Errores a evitar**: Forzar simetrías perfectas, ignorar la jerarquía o no adaptar el layout para mezclar tipos de contenido (texto vs gráficos).
