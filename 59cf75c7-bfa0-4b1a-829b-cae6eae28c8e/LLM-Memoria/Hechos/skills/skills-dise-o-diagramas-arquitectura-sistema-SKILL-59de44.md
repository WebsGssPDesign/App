# SKILL.md

## Resumen
Esta guía define una metodología para crear diagramas de arquitectura de software autónomos, claros y escalables utilizando HTML con SVG incrustado. Su objetivo es visualizar topologías de microservicios, infraestructura en la nube y componentes de monitoreo sin depender de herramientas externas ni claves API.

## Datos clave
- **Herramientas**: Excalidraw o Mermaid para el bosquejo inicial.
- **Formato final**: Archivos HTML autónomos con SVG incrustado que se abren localmente en cualquier navegador.
- **Componentes típicos**: Microservicios, colas de tareas, bases de datos vectoriales, Prometheus Metrics, Grafana Dashboards y Loki System Logs.
- **Reglas de diseño**: Estilo oscuro profesional, evitar dependencias externas (imágenes/scripts remotos) y no inventar detalles técnicos faltantes (marcar como "pendiente").
- **Errores a evitar**: Sobrecarga visual con datos operativos específicos o diseñar arquitecturas in-memory cuando se busca robustez.
