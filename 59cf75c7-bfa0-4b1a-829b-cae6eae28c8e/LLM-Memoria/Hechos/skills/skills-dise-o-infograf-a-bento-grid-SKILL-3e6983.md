# SKILL.md

## Resumen
Este documento sirve como plantilla maestra para diseñar infografías modernas utilizando el patrón de diseño "Bento Grid" con CSS. Su objetivo es organizar datos complejos en celdas modulares y uniformes, facilitando la visualización clara mediante una estructura rectangular similar a las tablas periódicas.

## Datos clave
- **Tecnologías**: CSS Grid para layouts flexibles y modularidad.
- **Pasos críticos**: Definir contenedor padre con `display: grid`, crear celdas individuales usando propiedades como `grid-column: span 2` o `grid-row: span 3`, y aplicar estilos visuales coherentes (colores/símbolos) a cada bloque.
- **Reglas de diseño**: Mantener una estructura rectangular estricta, asegurar bordes definidos entre celdas y priorizar la claridad visual sobre tamaños fijos que rompan la modularidad.
- **Errores a evitar**: Forzar tamaños fijos sin usar la flexibilidad del Grid, mezclar paletas de colores dentro de las celdas o desalinear los ejes de la cuadrícula.
