# SKILL.md

## Resumen
Esta guía describe cómo configurar pipelines automatizados para publicar contenido en redes sociales de forma segura, gestionando credenciales mediante OAuth o tokens. Su objetivo es empaquetar activos aprobados en JSON y enviarlos a herramientas como n8n o APIs directas, garantizando siempre una validación explícita del usuario antes de cualquier envío crítico.

## Datos clave
- **Proyecto**: Automatización segura de flujo de publicación con gestión de tokens.
- **Tecnologías**: OAuth, Tokens, JSON, n8n, Make, Meta Business Suite (Planificador).
- **Pasos importantes**: Preparación de credenciales fuera del repositorio, validación explícita de contenido en cola, empaquetado estricto en formato JSON y ejecución del pipeline.
- **Reglas críticas**: Nunca imprimir tokens ni claves en código/logs; obtener aprobación previa para cada envío programado.
